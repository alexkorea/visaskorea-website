# 韓国外国人向け医療利用完全ガイド（2026年）：病院・健康保険・救急

## 1. 外国人の国民健康保険加入

韓国に6か月以上合法的に在留する外国人は、国民健康保険（NHIS）への加入が義務付けられています。

| 項目 | 内容 |
|---|---|
| 加入条件 | 外国人登録後6か月以上の合法在留 |
| 加入方法 | 自動加入（就労者）または申請加入（地域加入者として国民健康保険公団で手続き） |
| 保険料 | 所得または資産に基づいて算定（地域加入者には最低保険料あり） |
| 給付 | 韓国国民と同等の健康保険給付 |
| 問い合わせ | 国民健康保険公団：1577-1000（多言語対応あり） |

> 健康保険未加入の場合、医療費は全額自己負担となります。就労者は就職と同時に加入；それ以外の方は入国後6か月で自動加入となります。

## 2. 韓国の三段階医療制度

| 機関タイプ | 規模 | 特徴 |
|---|---|---|
| 1次（医院・クリニック） | 小規模 | 風邪・発熱などの一般疾患。費用が安い |
| 2次（病院・総合病院） | 中規模 | 入院・手術など専門治療。紹介状なしでも受診可 |
| 3次（高次総合病院・大学病院） | 大規模 | 重症・難治疾患。2次機関からの紹介状が推奨（紹介状なしは自己負担が高くなる） |

> 風邪や軽症の場合は近くの医院（クリニック）が速くて安くてお勧めです。峨山病院・サムスンソウル病院などの大型病院は予約が必須です。

## 3. 受診手順

| ステップ | 内容 |
|---|---|
| 1 | 症状に合った科を選ぶ（내과＝内科、정형외과＝整形外科、피부과＝皮膚科など） |
| 2 | 電話またはアプリで予約（大型病院）または当日来院（医院） |
| 3 | 受付で外国人登録証またはパスポートを提示 |
| 4 | 健康保険加入状況を確認 |
| 5 | 診察後に処方箋を受け取る |
| 6 | 院内または近くの薬局で処方薬を受け取る |

## 4. 外国人がよく利用する医療機関

| 病院タイプ | 特徴 |
|---|---|
| 外国人専門クリニック | 英語・中国語・日本語の通訳対応、多言語案内あり |
| 大型病院の国際診療センター | ソウル峨山・サムスンソウル・延世医院などに専任の国際医療チームあり |
| 近くの家庭クリニック（가정의학과） | 一般診療。通訳なしの場合が多い（翻訳アプリが活用できる） |
| 歯科・眼科・皮膚科 | 外国人の利用が多い。ほとんどが医院レベル |

> Naver MapsやKakaoMapで「International Clinic」や「외국인 진료」と検索すると、外国人対応病院が見つかります。

## 5. 救急医療の利用方法

| 状況 | 対応 |
|---|---|
| 緊急事態 | 119に電話（救急車は無料。韓国語・英語通訳あり） |
| 救急室への来院 | 最寄りの救急医療センターへ（24時間365日対応） |
| 夜間の非緊急受診 | Naver/Kakaoで「야간진료」（夜間診療）を検索 |
| 電話相談 | 1339緊急医療情報センター（24時間、英語・多言語対応） |

> 救急室は緊急度に応じて順番が決まります。軽症の場合は待ち時間が長いため、非緊急時は夜間診療クリニックの利用をお勧めします。

## 7. 処方箋と薬局の利用

| 項目 | 内容 |
|---|---|
| 処方箋の有効期間 | 通常、処方日から3日以内 |
| 薬局の探し方 | 病院近くの薬局、またはNaver Mapsで「약국」と検索 |
| 夜間・休日の薬局 | 各地域で当番薬局が運営（韓国薬剤師協会ウェブサイトで確認） |
| 市販薬（OTC） | 処方箋なしで購入可能：鎮痛剤・整腸剤・一般的な風邪薬など |
| 多言語での服薬説明 | 日本語・英語・中国語での説明書を依頼で提供可能 |

## 8. 自己負担額と節約のコツ

| コツ | 内容 |
|---|---|
| 1次クリニックを優先利用 | 地域クリニックは3次大型病院より自己負担がはるかに低い |
| 紹介状を持参 | 2次→3次への紹介状があると自己負担を抑えられる |
| 無料健康診断 | NHIS加入者は2年ごとに無料健康診断を受けられる（The Healthアプリで確認） |
| 民間保険 | 補充的な民間医療保険で残りの自己負担をさらに抑えられる |
| ジェネリック薬品の選択 | 先発薬の代わりにジェネリック（제네릭）を選ぶと費用が下がる |

## 9. 長期処方と慢性疾患の管理

| 項目 | 内容 |
|---|---|
| 慢性疾患登録制度 | 高血圧・糖尿病などの登録患者は追加の自己負担軽減がある |

## 10. よくある質問（FAQ）

**Q. 健康保険なしで受診するとどのくらいかかりますか？**
A. 保険未加入の場合は全額自己負担です。地域クリニックの受診費用は5〜15万ウォン程度、救急室は20〜50万ウォン以上かかる場合があります。

**Q. 外国人も無料健康診断を受けられますか？**
A. はい。NHIS加入者は2年ごとに無料健康診断を受けることができます。対象かどうかはNHISアプリ（The Health）で確認できます。

**Q. 緊急時に韓国語が話せない場合はどうすればいいですか？**
A. 119に電話すれば英語の通訳サービスが利用できます。1339緊急医療情報センターも24時間英語・多言語対応しています。大型病院の救急室には英語が話せるスタッフがいることが多いです。

**Q. 韓国で海外の処方薬を続けて服用できますか？**
A. 韓国の医師が再診断することで同等の薬を処方してもらえます。元の処方箋と服薬記録を持参して、該当する専門科を受診してください。

**Q. 韓国でメンタルヘルスの相談はどこでできますか？**
A. 精神健康医学科のクリニックや国立精神健康センター（02-2204-0200）で相談できます。外国人向けに英語でカウンセリングを提供するコミュニティ組織もあります。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
