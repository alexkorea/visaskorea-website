# 韩国投资签证 D-8 申请条件、所需材料和办理流程 2026 完整指南

韩国 D-8 投资签证（外国人企业投资签证）是依据《[外国人投资促进法](https://www.law.go.kr/법령/외국인투자촉진법)》，向在韩国设立外资法人并投资1亿韩元以上的外国投资者发放的长期居留签证。这是中国企业家进入韩国市场最常用的签证类型。

D-8 签证的核心要求是**从海外汇入1亿韩元以上的外资**，并通过外汇银行完成正式的外国人投资申报手续。仅凭携带现金入境是不被认可的。

## 1. D-8 投资签证概述 <a id="section-1"></a>

D-8 签证是韩国对外开放经济政策的核心签证类型。设立外资法人后，外国投资者作为该法人的董事或高管获得 D-8 签证，可以长期在韩国居住、运营业务。

| 项目 | 内容 |
|---|---|
| 法律依据 | 外国人投资促进法 + 出入境管理法 |
| 最低投资额 | 1亿韩元（约75,000美元 / 530,000人民币） |
| 汇款方式 | 海外外币 → 韩国法人账户（外汇银行申报） |
| 居留期限 | 1-2年（可延长） |
| 永驻权路径 | 5年以上 D-8 居留 + 经营条件达标 → F-5 |

## 2. D-8 签证申请条件 <a id="section-2"></a>

申请人需满足以下所有条件：

- **海外汇款**：1亿韩元以上以外币汇入韩国法人账户
- **外资法人注册**：在韩国产业通商资源部完成外国人投资企业登记
- **董事或高管职位**：作为韩国法人的代表理事、理事或核心专家
- **业务计划**：在韩国实际开展业务的计划（办公室、人员、销售计划）
- **无不良记录**：无出入境违规、无犯罪记录

## 3. D-8 签证类型 (D-8-1 / D-8-2 / D-8-3 / D-8-4) <a id="section-3"></a>

| 代码 | 类型 | 适用对象 |
|---|---|---|
| D-8-1 | 外资法人董事 | 投资1亿韩元+ 的外资法人外国董事 |
| D-8-2 | 风险企业 / 高新技术 | 风险企业认证或高新技术拥有外国人 |
| D-8-3 | 贸易/服务业员工 | 外资企业的外国员工 |
| D-8-4 | 技术创业 | 技术能力被认可的外国人技术创业 |

最常见的是 **D-8-1（外资法人董事）**。

## 4. D-8 签证申请流程 7步 <a id="section-4"></a>

### 第1步：业务规划和公司设计
- 行业、注册资本、董事构成、办公室位置确定
- 韩国业务计划书（中韩双语）

### 第2步：外国人投资申报
- 通过外汇银行完成外国人投资申报
- 准备外币汇款

### 第3步：资金汇款
- 1亿韩元以上外币汇至韩国法人虚拟账户
- 外汇银行发放外国人投资汇款证明

### 第4步：法人设立登记
- 营业执照 + 法人登记（首尔登记所）
- 章程、董事会决议、股票发行事项

### 第5步：外资企业登记
- 在产业通商资源部或 KOTRA Invest KOREA 完成外资企业登记
- 获得外资企业登记证

### 第6步：出入境签证申请
- 申请签证发放许可书或在海外韩国领事馆申请签证
- 在出入境管理事务所提交 D-8 签证申请

### 第7步：签证发放和入境
- 签证发放后入境韩国
- 入境后90天内完成外国人登录

## 5. 所需材料清单 <a id="section-5"></a>

标准材料：

- 签证申请书（出入境表格）
- 照片（3.5×4.5cm，白底）
- 护照（有效期6个月以上）
- 外资企业登记证
- 法人登记簿副本
- 营业执照
- 外汇银行汇款证明（1亿韩元+ 汇款凭证）
- 办公室租赁合同
- 业务计划书（中韩双语）
- 董事任命证明（董事会决议）
- 学历、经历证明（大学毕业证、工作经历证明）
- 海外居住地无犯罪证明（海牙认证）

## 6. 1亿韩元资金汇款方法 <a id="section-6"></a>

D-8 签证的核心要点是证明 1 亿韩元资金已**从海外汇至韩国法人账户**：

1. **韩国法人虚拟账户开设**：在韩国市中银行开设外资企业虚拟账户
2. **外汇银行外国人投资申报**：汇款前申报（必须）
3. **外币汇款**：1亿韩元以上（USD/EUR/JPY/CNY等）
4. **资金入金证明**：汇款后外汇银行发放
5. **资金登记**：在登记所完成资金入金登记

1亿韩元按汇款时点汇率约：
- **USD 75,000 / JPY 11,000,000 / EUR 70,000 / CNY 530,000**

## 7. D-8 vs D-7 签证差异 <a id="section-7"></a>

| 区分 | D-8 (企业投资) | D-7 (派遣) |
|---|---|---|
| 韩国法人形态 | 新设外资法人 | 海外总部的韩国分公司/联络处 |
| 投资金 | 1亿韩元+ 海外汇款 | 不需要投资 |
| 总部工作经历 | 不需要 | 1年+ 必须 |
| F-5 路径 | 5年后直接申请 | F-2-7 (3年) → F-5 (5年) |
| 签证发放对象 | 外国投资者本人 | 总部派遣员工 |

新在韩国**开始业务**选 D-8，在现有海外总部**韩国分公司工作**选 D-7。

## 8. F-5 永驻权路径 <a id="section-8"></a>

D-8 签证持有者转 F-5 永驻权：

- **F-5-3**：5年以上 D-8 居留 + 1亿韩元+ 投资 + 雇佣5名以上韩国人 + 年销售额5亿+
- **F-5-5**：通过积分制（F-2-7）获得 80分以上后申请 F-5
- **F-5-6**：拥有高新技术博士学位等特殊情况

5年以上 D-8 + 销售额 + 雇佣条件达标后可申请永驻权。

## 9. 常见问题 FAQ <a id="section-9"></a>

**Q. 1亿韩元以下能申请 D-8 签证吗？**
原则上必须是1亿韩元以上。1亿以下需考虑 D-9-2（设备投资签证）等其他类别。

**Q. D-8 签证发放需要多长时间？**
从法人设立到签证发放通常需要6-12周。通过行政书士代理可缩短至4-8周。

**Q. 我自己带1亿韩元入境算投资吗？**
不算。必须通过外汇银行的**官方外币汇款**才被认可。现金携带入境不算投资。

**Q. 韩国法人的外国员工也能申请 D-8 签证吗？**
完成外资企业登记的法人的外国核心董事可申请 D-8-1 或 D-8-3 签证。普通员工更适合 E-7 签证。

**Q. 业务不顺利会被取消签证吗？**
延长时需提交正常运营证明（销售额、办公室运营、员工雇佣）。业务不振可能成为延长拒绝或强制出境的原因。
