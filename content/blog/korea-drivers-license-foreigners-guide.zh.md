# 在韩外国人驾驶证完整指南（2026年）：取得·换证·国际驾照

## 1. 韩国驾驶证种类

韩国驾驶证分为1种和2种。

| 种类 | 类型 | 可驾驶车辆 |
|---|---|---|
| 1种 | 大型（1종 대형） | 公共汽车、大型货车、特种车辆 |
| 1种 | 普通（1종 보통） | 15座以下客车、12吨以下货车 |
| 1种 | 特殊（1종 특수） | 吊车、低板车、牵引车 |
| 2种 | 普通（2종 보통） | 10座以下客车、4吨以下货车 |
| 2种 | 自动挡（2종 자동） | 仅限自动挡车辆 |
| 2种 | 小型（2종 소형） | 摩托车（125cc以上） |

> 大多数外国人申请的是**2种普通（2종 보통）**或**1种普通（1종 보통）**。

## 2. 外国驾照换领韩国驾照

持有有效外国驾照者，可在减免考试的条件下申请换领韩国驾照。

### 协定国家——全程免试

与韩国签订驾照互认协议国家的公民，**笔试、场地考试、道路考试全部免除**，只需携带所需材料前往驾照考试所办理即可。

| 国家 | 免试范围 |
|---|---|
| 美国 | 笔试+场地+道路考试全免 |
| 日本 | 笔试+场地+道路考试全免 |
| 英国 | 笔试+场地+道路考试全免 |
| 德国 | 笔试+场地+道路考试全免 |
| 加拿大 | 笔试+场地+道路考试全免 |
| 法国 | 笔试+场地+道路考试全免 |
| 澳大利亚 | 笔试+场地+道路考试全免 |

> 协定国家名单可能会有变化，申请前请向道路交通公团确认最新信息。

### 非协定国家（如中国）

非协定国家公民只需通过**笔试**，场地考试和道路考试免除。

### 换领驾照所需材料

1. 有效的外国驾驶证（原件）
2. 官方翻译件（如需，须经大使馆或公证处认证）
3. 外国人登记证
4. 护照
5. 证件照一张
6. 体检结果（2年内有效）
7. 申请费用

## 3. 新考驾照：考试流程

无外国驾照者须完成全部考试流程。

| 步骤 | 内容 | 合格标准 |
|---|---|---|
| 1. 体检 | 视力、听力、色觉检查 | 合格/不合格 |
| 2. 笔试 | 40道交通法规题 | 60分（2种）/70分（1种） |
| 3. 场地考试 | 封闭场地驾驶技能 | 80分 |
| 4. 道路驾驶练习 | 在驾校练习至少10小时 | 须完成 |
| 5. 道路驾驶考试 | 公开道路实际驾驶 | 70分 |

## 4. 笔试指南

### 考试概要

| 项目 | 详情 |
|---|---|
| 题目数量 | 40道 |
| 考试时间 | 40分钟 |
| 合格分数 | 60分（2种）/70分（1种） |
| 可选语言 | 韩语、英语、中文、日语、越南语 |
| 考试地点 | 全国各驾照考试所 |

### 考试内容

- 交通标志、道路标线和信号灯
- 安全驾驶原则和交通法规
- 事故预防与急救
- 车辆基本构造

> 道路交通公团官网（safedriving.or.kr）提供练习题，强烈建议考前练习。

## 5. 场地考试指南

场地考试在考试所封闭场地内进行。

| 项目 | 详情 |
|---|---|
| 合格分数 | 80分 |
| 考试内容 | 停车、转弯、绕障、起步/停车 |
| 扣分项目 | 压线、急刹车等均会扣分 |
| 补考 | 不合格后次日可重新预约 |

---

## 6. 道路驾驶考试指南

道路驾驶考试在考试所附近的公开道路上进行。

| 项目 | 详情 |
|---|---|
| 前提条件 | 须完成10小时道路驾驶练习 |
| 合格分数 | 70分 |
| 考试时长 | 约15—20分钟 |
| 扣分项目 | 超速、闯信号、不安全变道等均会扣分 |

## 8. 国际驾照

持有有效韩国驾照者，可申请国际驾驶执照（국제운전면허증）用于在海外驾车。

| 项目 | 详情 |
|---|---|
| 发放机关 | 各驾照考试所、网上申请（safedriving.or.kr） |
| 有效期 | 1年 |
| 承认国家 | 约100个国家（1968年《维也纳公约》缔约国） |
| 所需材料 | 韩国驾照、证件照、申请表 |
| 费用 | 约8,500韩元 |

> 国际驾驶执照须与韩国驾照一同使用，不得单独作为驾驶证使用。

| 项目 | 详情 |

## 10. 常见问题解答

**Q. 持外国驾照在韩国可以开车吗？**
A. 自入境之日起1年内可凭外国驾照驾车。1年后须取得韩国驾照。依据《维也纳公约》发放的国际驾驶执照同样有效1年。

**Q. 韩国笔试支持中文吗？**
A. 支持。笔试提供韩语、英语、中文、日语、越南语五种语言，预约时选择所需语言即可。

**Q. 全程考试大约需要多长时间？**
A. 从体检到取证，在驾校学习通常需要2—4周，自学并自行预约考试一般需要1—2周。

**Q. 笔试不合格怎么办？**
A. 次日可重新预约笔试，不限补考次数，但每次均需缴纳费用。

**Q. 必须去驾校吗？**
A. 没有强制要求，但道路驾驶考试前必须完成10小时道路练习，驾校是完成这一要求最便捷的方式。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
