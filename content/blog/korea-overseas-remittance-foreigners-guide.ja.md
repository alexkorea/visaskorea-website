# 韓国から海外送金完全ガイド（2026年）：外国人のための送金方法まとめ

韓国に在住する外国人は、家族への仕送りや貯蓄の本国への移転など、さまざまな理由で海外送金が必要になります。このガイドでは、主な送金手段・手数料比較・手続き・注意点を詳しく解説します。

## 1. 海外送金の基本条件

| 項目 | 内容 |
|---|---|
| 必要書類 | 外国人登録証（ARC）またはパスポート＋韓国銀行口座 |
| 受取人情報 | 氏名・住所・銀行名・口座番号・SWIFT/BICコード |
| 送金通貨 | 韓国ウォン（KRW）→ 換算後に目的外貨で送金 |
| ARCの優位性 | ARC保有者は送金限度が高く手続きも簡便 |
| 税申告 | 個人の生活費送金は年5万ドル以下なら申告不要 |

> 給与・生活費性質の個人海外送金は、韓国での別途税申告なしで可能です。多額の資産移転は事前に外国為替の専門家に確認してください。

## 2. 銀行送金

| 銀行 | サービス名 | 特徴 |
|---|---|---|
| ハナ銀行 | グローバルウォン/ハナワン | 中国・東南アジア特化、アプリ送金可 |
| 新韓銀行 | SOL海外送金 | アプリで24時間送金、為替優遇イベントあり |
| 国民銀行 | KB海外送金 | KBスターバンキングアプリで操作、135か国対応 |
| 우리銀行 | ウィービー海外送金 | アプリ・ATMで利用可能 |
| 企業銀行（IBK） | IBK海外送金 | 外国人労働者専用サービスあり |

| 項目 | 内容 |
|---|---|
| 手数料 | 1件3,000〜20,000ウォン＋コレスポンデント銀行手数料 |
| 為替レート | 基準レートに1〜2%のスプレッド |
| 処理時間 | 1〜3営業日 |
| 送金限度 | ARC保有者：年5万ドル以下は特別申告不要 |
| 最低金額 | 銀行により異なる（原則なし） |

> 外国人労働者は企業銀行（IBK）やハナ銀行グローバルウォンの利用が多いです。モバイルアプリ利用で手数料割引が適用される場合があります。

## 3. フィンテック送金サービス（Wiseなど）

| サービス | 特徴 | 手数料 |
|---|---|---|
| Wise（旧TransferWise） | 中間為替レートを使用、透明な手数料 | 送金額の約0.4〜1%＋少額固定手数料 |
| ウェスタンユニオン | 全世界200か国以上で現金受取可能、迅速処理 | 約5〜15ドル＋為替マージン |
| マネーグラム | 現金受取可能、韓国国内に代理店あり | 約5〜10ドル |
| センドビー（센트비） | 韓国フィンテック、東南アジア特化 | 1件1,000〜3,000ウォン |
| Payoneer | フリーランサー・オンラインビジネス専用 | サービスにより異なる |

> Wiseは透明な為替レートと低手数料で、韓国在住の外国人に最も人気のあるフィンテック送金サービスです。韓国の銀行口座から直接ウォンで送金できます。

## 4. コンビニ送金

| サービス | 場所 | 対象国 |
|---|---|---|
| GS25マネーグラム | GS25コンビニ | 全世界（現金受取可能） |
| CU海外送金 | CUコンビニ | 一部アジア諸国 |
| 韓国郵便局国際送金 | 全国郵便局 | 主要国 |

> 銀行口座がない方や緊急の送金が必要な場合、コンビニのマネーグラムが利用できます。ただし手数料は割高になります。

## 5. 主要送金サービスの手数料比較

*例：100万ウォン（約700ドル）をアメリカへ送金する場合*

| サービス | 送金手数料 | 為替スプレッド | 予想総コスト |
|---|---|---|---|
| Wise | 約3,000〜5,000ウォン | なし（中間レート） | 低 |
| ハナ銀行（アプリ） | 約3,000〜5,000ウォン | 約1% | 中 |
| 国民銀行（窓口） | 約10,000〜15,000ウォン | 約1.5% | 高 |
| ウェスタンユニオン | 約5,000〜15,000ウォン | 約2〜3% | 高 |
| GS25マネーグラム | 約7,000〜20,000ウォン | 約2〜3% | 高 |

> 少額送金では1件あたりの固定手数料が重要で、大額送金では為替スプレッドの影響がより大きくなります。

## 6. 送金限度額と申告義務

| 区分 | 内容 |
|---|---|
| 年5万ドル以下 | 個人の生活費・給与送金は申告不要 |
| 年5万ドル超 | 韓国銀行または外国為替取扱金融機関への申告が必要 |
| 非居住者（短期滞在） | 資金取得経緯を証明した上で送金可能 |
| 不動産・株式の収益 | 譲渡所得税の納付証明が必要 |
| 1回1万ドル超の送金 | 金融機関がFIU（金融情報機関）に自動報告 |

> 多くの外国人労働者は年5万ドル以内で生活費を送金するため、特別な申告は不要です。資産移転や投資収益の送金は税理士または行政書士に事前確認してください。

## 7. 為替節約のコツ

| コツ | 内容 |
|---|---|
| 為替アラートを設定 | 銀行アプリやWiseで目標レート時に通知を受け有利なタイミングで送金 |
| モバイルアプリを利用 | 窓口に比べて手数料を50〜70%削減できる場合が多い |
| 為替優遇クーポンを活用 | ハナ・新韓・国民銀行アプリで為替優遇イベントを確認 |
| まとめて1回送金 | 少額を複数回送るより、まとめて送ると固定手数料を節約できる |
| Wiseと銀行を比較 | 中小額はWiseが有利なことが多い。大額は銀行の優遇レートも検討 |

## 9. よくある質問（FAQ）

**Q. 韓国の銀行口座なしで海外送金できますか？**
A. できます。ウェスタンユニオンやコンビニのマネーグラムを使えば現金でも送金できます。ただし手数料が割高で限度額も低い場合があります。

**Q. 海外送金で税金はかかりますか？**
A. 個人の生活費・給与性質の送金であれば、韓国側での課税はありません。ただし受取国の税法によっては受取側に課税される場合もあるので確認してください。

**Q. 送金が届くまでどのくらいかかりますか？**
A. Wiseやウェスタンユニオンは数時間〜当日に処理されることが多く、銀行のSWIFT送金は通常1〜3営業日です。受取銀行の処理によりさらに1〜2日かかる場合があります。

**Q. 手数料が最も安い送金方法はどれですか？**
A. Wiseは中間為替レートを使用し、手数料が透明なため、少額〜中額送金では最も経済的なことが多いです。大額送金では銀行の為替優遇イベントを活用する方法もあります。

**Q. 中国への送金で注意点はありますか？**
A. 中国は個人の外貨受取が年5万ドルの上限があります。受取人は実名認証された銀行口座を保有していることが必要です。人民元への換算には中国の外貨管理規則が適用されますのでご確認ください。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
