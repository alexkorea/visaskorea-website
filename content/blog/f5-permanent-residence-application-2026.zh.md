# 韩国F-5永久居留权申请完全指南2026

F-5永久居留资格允许在韩国无限期居住，无需定期续签。

## 主要申请途径

| 途径 | 主要条件 |
|------|---------|
| F-5-1（长期居住） | 合法居住5年以上 |
| F-5-7（海外韩国人） | F-4 + 2年以上 + 资产3亿韩元 |
| F-5-16（积分制） | F-2-7 + 3年 + 收入GNI 2倍 |
| F-5-18（高额投资） | 直接投资5亿韩元以上 |

## 申请流程
1. 确认资格条件
2. 准备材料（4~6周）
3. 前往出入境管理局申请
4. 等待审查（4~12周）
5. 领取F-5居留证
