## 1. 韓国ビザ不許可とは？

ビザ不許可とは、韓国の在外公館（大使館・領事館）または法務部出入国当局がビザ申請を認めない決定です。

| 区分 | 機関 | 処理タイミング |
|---|---|---|
| 在外公館審査 | 大使館・領事館 | 入国前のビザ審査 |
| 出入国審査 | 仁川・金浦空港等 | 入国時の審査 |
| 在留資格変更・更新 | 出入国・外国人庁 | 韓国滞在中の申請 |

---

## 2. ビザ拒否の主な理由

| 分類 | 具体的な理由 |
|---|---|
| 書類不備 | 必要書類の未提出、書類の期限切れ、翻訳未添付 |
| 財力不足 | 残高証明の金額不足、収入の不安定 |
| 訪問目的の不明確さ | ビザ目的と実際の訪問理由の不一致 |
| 帰国意思への疑念 | 不法就労または長期滞在の懸念 |
| 過去の違反履歴 | 以前の在留期間超過や不法就労歴 |
| 身元・安全上の理由 | 犯罪歴・入国禁止登録 |
| 招聘者の問題 | 国内招聘者の法的問題、財力不足 |

## 3. 不許可通知の確認方法

| 申請チャネル | 確認方法 |
|---|---|
| 在外公館申請 | パスポート返却時の拒否スタンプまたは書面通知 |
| e-Visa（オンライン）申請 | evisa.go.krのマイページで不許可理由を確認 |
| Hi Koreaポータル申請 | hikorea.go.krのマイページで処理結果を確認 |
| 出入国庁窓口申請 | 直接通知または郵便通知 |

> 不許可理由が記載されない場合も多くあります。大使館や出入国庁に理由の説明を求めることはできますが、公開義務はない場合があります。

## 4. 異議申請 vs. 再申請：選択基準

| 方法 | 内容 | 適している場合 |
|---|---|---|
| 異議申請 | 同一機関に不許可決定の再審査を要請 | 明らかな書類漏れ・誤り・事情変更 |
| 行政審判 | 法務部または行政審判委員会に不服申立 | 処分が違法・不当と判断できる場合 |
| 行政訴訟 | 裁判所に取消訴訟を提起 | 法的権利侵害が明確な場合 |
| 再申請 | 書類を補完して新規申請 | 書類補完で問題を解決できる場合 |

## 5. 異議申請の手順

### 在外公館ビザ拒否に対する異議申請

| 項目 | 内容 |
|---|---|
| 申請先 | ビザを申請した大使館・領事館 |
| 申請期限 | 通知日から通常30日以内（機関によって異なる） |
| 提出方法 | 書面またはメール提出 |
| 添付書類 | 異議申請書・補完書類・不許可通知書のコピー |

### 国内出入国庁への異議申請

| 項目 | 内容 |
|---|---|
| 申請先 | 管轄出入国・外国人庁 |
| 申請期限 | 不許可通知日から30日以内 |
| 提出方法 | 窓口訪問または郵送 |
| 処理期間 | 通常30日以内 |

---

## 6. 行政審判の申請手順

行政審判は、ビザ不許可処分が違法または不当と判断される場合に、公式に不服を申し立てる手続きです。

| 項目 | 内容 |
|---|---|
| 申請先 | 法務部行政審判委員会または中央行政審判委員会 |
| 申請期限 | 不許可通知日から90日以内 |
| 提出方法 | 書面またはオンライン（simpan.go.kr） |
| 処理期間 | 60日以内（延長可） |
| 費用 | 無料 |

---

## 7. 行政訴訟の手順

行政審判で解決しない場合や法的権利侵害が明確な場合は、行政訴訟を提起できます。

| 項目 | 内容 |
|---|---|
| 管轄裁判所 | ソウル行政裁判所または処分機関所在地の行政裁判所 |
| 提訴期限 | 不許可通知日または行政審判結果通知日から90日以内 |
| 訴訟の種類 | 取消訴訟（処分の取消・無効確認） |
| 費用 | 訴訟費用＋弁護士費用 |
| 処理期間 | 数か月〜1年以上 |

> 行政訴訟は複雑な法的手続きを伴うため、弁護士・行政書士等の専門家への依頼が不可欠です。

## 8. 再申請戦略

### 拒否理由別の補完方法

| 拒否理由 | 補完方法 |
|---|---|
| 財力不足 | 残高証明の増額、雇用契約書・在職証明書の追加 |
| 訪問目的の不明確さ | 招待状の強化、日程表・予約確認書の追加 |
| 帰国意思への疑念 | 帰国航空券の事前購入、国内資産・不動産・家族関係の証明 |
| 書類不備 | 必要書類を完備し、公証・アポスティーユ処理 |
| 過去の違反履歴 | 違反理由の説明書を作成、専門家への相談必須 |

### 再申請前チェックリスト

- [ ] 拒否理由を正確に把握する
- [ ] 書類全体を見直し補完する
- [ ] 申請内容の一貫性を確認する
- [ ] 適切な待機期間を確認する
- [ ] 専門行政書士のチェックを受けてから提出する

| ビザ種別 | 主な拒否理由 | 重要対策 |
|---|---|---|
| C-3（短期訪問） | 帰国意思への疑念・財力不足 | 帰国意思・資産証明を強化 |

## 10. よくある質問（FAQ）

**Q. 拒否後、再申請まで何か月待てばよいですか？**
A. 法的な待機期間はありませんが、同じ書類ですぐに再申請すると再拒否の可能性が高くなります。最低1〜3か月後に書類を大幅に改善して再申請することをお勧めします。

**Q. 拒否理由を教えてもらえない場合はどうすればいいですか？**
A. 韓国のビザ当局には拒否理由の開示義務はありません。専門の行政書士とともに申請書類全体を見直し、考えられる拒否原因を特定することが重要です。

**Q. 過去の拒否歴は今後の申請に影響しますか？**
A. はい。拒否歴は記録に残り、将来のビザ審査に不利に働く可能性があります。再申請前の十分な準備が欠かせません。

**Q. 行政審判と行政訴訟、どちらが現実的ですか？**
A. 一般的に、費用・時間の面で行政審判が効率的です。行政訴訟は法的権利侵害が明確な場合や行政審判で敗れた場合に検討してください。

**Q. 現在韓国に滞在中で、在留延長が不許可になりました。どうすればよいですか？**
A. 在留可能期間内に出国しなければなりません。すぐに専門家に相談し、異議申請または行政審判で在留を維持できるか検討するか、出国日程を調整してください。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
