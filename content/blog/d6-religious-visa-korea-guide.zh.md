# 韩国D-6宗教签证完整指南（2026年）：资格条件、所需材料与许可活动

D-6（宗教）签证面向受外国宗教团体或社会福利团体派遣、赴韩从事宗教或社会福利活动的外国人发放。这是传教士、神职人员、修道士等宗教工作者在韩国合法开展宗教事业的主要签证途径。

## 1. D-6签证是什么？

D-6是韩国《出入境管理法》规定的"宗教"在留资格，向受外国宗教团体或社会福利团体派遣、在韩国从事宗教或社会福利活动的外国人发放。

主要特征：
- 面向宗教团体派遣的神职人员·传教士
- 允许从事纯宗教活动及相关社会福利活动
- 原则上须以"宗教团体派遣"的形式入境，不接受以个人身份申请
- 仅限非营利宗教事业，不包括商业活动

---

## 2. 允许活动及适用领域

| 领域 | 主要活动 |
|---|---|
| 宗教事业 | 主持礼拜·弥撒·法会，讲道，带领圣经学习等 |
| 传教活动 | 宗教教育、社区传教·宣教事业 |
| 社会福利活动 | 在宗教团体运营的福利设施志愿服务、救援活动等 |
| 宗教教育 | 在神学院·宗教教育机构授课（非营利） |
| 其他宗教相关活动 | 在所属宗教团体韩国分支机构的正式事业 |

> **注意**：D-6仅限于以特定宗教团体所属·派遣的形式开展活动。无所属的个人活动或以营利为目的的宗教活动不被允许。

---

## 3. 申请资格要求

| 要求 | 详情 |
|---|---|
| 派遣宗教团体 | 韩国境内宗教团体或社会福利团体的正式派遣 |
| 活动目的 | 宗教·社会福利活动（非营利） |
| 宗教资格 | 相关宗教神职人员·传教士·宗教工作者的资格证明 |
| 韩国所属机构 | 韩国境内官方宗教团体或所属机构 |

---

## 4. 所需材料

### 共同提交材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 驻外使馆或法务部格式 |
| 护照原件 | 有效期6个月以上 |
| 照片 | 3.5×4.5cm |
| 派遣确认书 | 海外宗教团体出具的正式派遣确认书 |
| 韩国宗教团体所属确认书 | 韩国境内官方所属机构出具的确认书 |
| 宗教资格证明 | 受戒证书·任职证书·传教士证书等 |
| 韩国宗教团体登记证或营业执照 | 所属机构的官方注册证明 |
| 活动计划书 | 在韩宗教·社会福利活动计划 |

---

## 5. 申请流程

1. **确定韩国宗教团体·所属机构并完成派遣决定**
2. **在驻外使馆申请D-6签证**或**在韩国申请在留资格变更**
3. **材料审查** — 确认宗教活动的真实性及所属团体（2~4周）
4. **签证发放及入境韩国**
5. **外国人登记** — 入境后90天内

| 区分 | 详情 |
|---|---|
| 最初在留期限 | 根据活动期限，最长2年 |
| 续签 | 活动持续期间可续签 |
| 最长在留期限 | 宗教活动持续的期间内 |

---

## 7. 允许活动及限制

| 允许活动 | 限制事项 |
|---|---|
| 在所属宗教团体的宗教仪式·事业 | 不得在团体外另行从事营利就业 |
| 宗教团体相关社会福利·志愿活动 | 不得从事领取报酬的商业性宗教活动 |
| 宗教教育（非营利宗教教育机构） | 不得在一般营利教育机构领取薪酬授课 |

---

## 8. 从D-6转换为其他在留资格

| 情况 | 转换路径 |
|---|---|
| 转向韩国学校·教育机构授课 | E-1或E-2就业签证 |
| 与韩国人结婚 | F-6结婚移民 |
| 满足长期在留条件 | F-2-7积分制居住资格或F-5永久居留权 |

---

## 9. D-6持有人重要注意事项

| 事项 | 注意内容 |
|---|---|
| 所属机构变更 | 变更所属宗教团体时须向出入境管理事务所申报 |
| 社会福利活动 | 须在正式登记的宗教团体从事志愿活动，而非营利机构 |
| 传教活动范围 | 仅限韩国法律允许的范围内，须确认特定宗教法人要求 |
| 就业禁止 | D-6持有人未获就业许可不得从事营利目的就业 |

## 10. 常见问题解答

**Q. 传教士也可以申请D-6签证吗？**
A. 可以。受海外宗教团体或传教会派遣赴韩从事传教活动的外国人可申请D-6签证，需提交派遣确认书和韩国所属教会·传教会的确认书。

**Q. 持D-6可以从韩国教会领取薪酬吗？**
A. D-6是非营利宗教事业签证。从所属宗教团体领取生活费性质的薪酬可能被允许，但以就业形式领取报酬不被允许。具体情况建议咨询专业人士。

**Q. 持D-6可以携带家属来韩国吗？**
A. 可以。D-6持有人的配偶及未成年子女可持F-3（随行人员）签证在韩国共同居留。

**Q. 没有派遣团体可以以个人身份申请D-6吗？**
A. 较为困难。D-6原则上须以"宗教团体派遣"的形式申请。如需以个人身份从事宗教活动，可能需要考虑其他在留资格。

**Q. D-6在留期间可以计入F-2-7积分吗？**
A. 可以。D-6在留期间纳入F-2-7积分计算。通过韩语能力、收入、纳税记录等达到80分以上，即可申请F-2-7居住资格。
