# H-2访问就业签证许可就业行业与限制职种 — 2026年完整整理

H-2访问就业签证持有者不得在所有行业就业，只能在法律许可的行业从事工作。
在许可行业以外就业将被视为非法就业，成为签证取消及强制出境的事由。

## H-2访问就业签证是什么？

H-2访问就业签证是允许中国及原苏联地区的同胞（海外朝鲜族）在韩国从事就业活动的签证。
由[出入境·外国人厅](https://www.immigration.go.kr)签发，最长体留期间为3年（续签一次最长可达4年10个月）。
该制度面向希望就业而非单纯访问的同胞，与E-9就业许可制属于独立的体系。

H-2签证的核心特征是"行业限制方式"。
与E-9签证绑定特定工作单位不同，H-2持有者可以在许可行业内自由跳槽。
但在许可行业以外工作将立即构成非法就业。

## 许可就业行业列表（2026年基准）

根据[雇佣劳动部](https://www.moel.go.kr)告示，H-2签证持有者可就业的行业如下。

### 制造业

- 食品制造业
- 纺织·服装·鞋类制造业
- 纸张·木材制造业
- 化工·橡胶·塑料制造业
- 金属·机械·电气·电子制造业
- 其他制造业（仅限30人以下事业场）

### 农畜牧业

- 农作物种植业（水田·旱田农业、设施园艺、特用作物）
- 畜牧业（家畜饲养、屠宰）
- 农业支援服务业

### 渔业

- 近海·远洋渔业
- 养殖渔业
- 水产品加工·处理

### 建筑业

- 建筑工地单纯劳务（仅限许可事业场）
- 建筑装修施工业
- 部分土木工程业

### 服务业（限定范围）

- 餐饮业（厨房助手、服务等单纯业务）
- 住宿业（清洁·洗涤等单纯支援业务）
- 废品回收业
- 建筑清洁业
- 家政服务业（含护理服务）
- 停车场运营业
- 保安业（部分）

**重要：** 上述列表为大类基准，具体行业代码的许可情况可能有所不同。
若不确定是否属于许可行业，建议就业前与专业人士共同确认。

## 禁止从事的职种

以下职种持H-2签证不得就业。

**专业职（需要执照·资格的职种）**

- 医疗职：医生、护士、药剂师
- 法律职：律师、法务士、行政士
- 教育职：教师、讲师（外语会话须另行持有相应签证）
- 注册会计师、税务士

**管理职·事务职**

- 企业高管
- 公司事务职（一般行政、财务等）
- 人事·劳务管理职

**其他限制职种**

- 娱乐场所相关业种（适用E-6签证）
- 成人娱乐·赌博相关业种
- 保险设计师·证券相关营销职
- 50人以上制造业事业场（部分例外）

## 就业教育完成义务

H-2签证持有者在韩国首次就业前，必须完成就业教育。

**就业教育基本信息**

| 项目 | 内容 |
| --- | --- |
| 教育机构 | 韩国产业人力公团指定教育机构 |
| 教育时间 | 16小时（2天课程） |
| 教育内容 | 韩国劳动法、产业安全、就业程序等 |
| 完成时间 | 首次就业前必须完成 |
| 费用 | 小额自费（因情况而异） |

未完成教育就业将被视为非法就业。
课程日程可在[韩国产业人力公团](https://www.hrdkorea.or.kr)网站查询。
完成后将发放就业教育确认书，需提交给雇主。

## 雇主雇用·解雇申报义务

雇用H-2签证外国人的事业主须履行以下申报义务。

**雇用申报**

- 录用后14天内
- 通过[雇佣劳动部就业许可制门户](https://www.eps.go.kr)或前往就业中心
- 提交材料：劳动合同、外国人登记证复印件、营业执照复印件

**解雇·离职申报**

- 劳动关系终止后14天内
- 向同一机关申报解雇（离职）
- 未申报：处以100万韩元以下过怠金

**注意事项：** 未经申报雇用H-2外国人可能面临非法雇用处罚。
[雇佣劳动部](https://www.moel.go.kr)近期已加强对外国人非法雇用的查处力度。

## 工作单位变更规定

与E-9签证持有者不同，H-2签证持有者在许可行业内跳槽相对自由。

**自由跳槽条件**

- 新工作单位须属于许可行业
- 保持就业教育完成状态
- 新雇主须在14天内完成雇用申报

**变更工作单位后的必要程序**

跳槽后，新雇主在就业中心完成新的雇用申报即可。
无需像E-9签证那样单独申请就业许可证或受次数限制。
但跳槽至许可行业以外属于违法行为，将成为签证取消事由。

## 违规处罚标准

**外国劳工违规**

| 违规类型 | 处罚 |
| --- | --- |
| 在许可行业外就业 | 签证取消、强制出境、禁止入境 |
| 未完成就业教育就业 | 罚款、签证取消 |
| 非法就业 | 强制出境、5年禁止入境 |

**雇主（事业主）违规**

| 违规类型 | 处罚 |
| --- | --- |
| 非法雇用（违反许可行业规定） | 3年以下有期徒刑或2000万韩元以下罚款 |
| 雇用·解雇申报义务违反 | 100万韩元以下过怠金 |
| 雇用未完成就业教育者 | 罚款、就业许可限制 |

实际查处案例中，因误解许可行业范围而遭强制出境的情况频繁发生。
就业前务必确认所在行业的许可情况。

## 常见问题解答（FAQ）

**Q1. 持H-2签证可以在餐厅工作吗？**

餐饮业属于H-2许可行业，但仅限于厨房助手、服务等单纯业务。
高级餐厅的正式厨师职位或管理职可能不适用。
就业前请向就业中心或专业人士确认具体行业代码。

**Q2. 就业教育只需参加一次吗？**

持H-2签证首次就业时完成16小时教育后，每次跳槽无需重新参加。
但重新签发签证或长期回国后再就业的情况可能需要重新完成。
最新规定请向[韩国产业人力公团](https://www.hrdkorea.or.kr)确认。

**Q3. 持H-2签证可以从事事务职吗？**

一般事务职、财务、人事等事务相关职种不属于H-2许可行业。
若希望从事事务职，应考虑E-7特定活动签证等其他签证种类。
适合个人情况的签证种类建议通过专业咨询确认。

**Q4. 雇主未履行申报义务时，外国劳工是否也会受到不利影响？**

申报义务原则上由雇主承担。
但若非法雇用状态持续，外国劳工也可能被视为非法就业者。
若雇主未履行申报义务，请直接向就业中心举报或寻求行政士协助。

**Q5. H-2签证体留期间可以变更为F-4或F-5签证吗？**

满足条件的情况下可以变更体留资格。
F-4（海外朝鲜族）需满足国籍条件和居所申报条件，F-5（永久居留）需满足体留期间、收入、犯罪记录等多项要求。
是否符合资格因个人情况而异，强烈建议咨询专业人士。
