# F-2居住ビザ点数制 項目別スコア計算法 完全解説

F-2-7居住ビザは、基本項目の合計スコアが80点以上に達した時点で初めて申請資格が得られます。

学歴、年齢、韓国語能力、所得、国内居住期間など7つの基本項目に加点・減点項目を合算して算出する仕組みで、申請者自身が自分の点数を正確に把握していないと、書類準備の段階からつまずいてしまいます。

本記事では、項目ごとの配点構造、実際の審査でつまずきやすいポイント、そして加点を確実に積み上げるための実務的なコツまで詳しく解説します。

<h2 id="section-1">F-2居住ビザ点数制とは</h2>

F-2-7は、専門人材でなくとも点数の合算によって居住資格を取得できる制度です。

[出入国・外国人政策本部](https://www.immigration.go.kr)の告示に基づいて運用されており、7つの基本項目と加点・減点項目で構成されています。

### 申請資格の全体像

基本要件は満18歳以上で、国内における合法的な滞在期間が一定水準以上であることです。

E-1からE-7、D-5からD-10までのビザ保持者が対象に含まれますが、単純労務ビザ(E-9、H-2)は原則として除外されます。

基本項目で80点以上を獲得すれば一次通過となり、加点があれば不足分を補うことができます。

### 点数計算の基本構造

点数は**基本項目7つ+加点+減点**で算出されます。

基本項目だけで80点を満たせる申請者は稀で、通常は加点をかき集めて合算スコアを作り上げます。

ここで差がつくのは、加点をどう設計するかという点です。

<h2 id="section-2">学歴スコアの計算方法</h2>

学歴は最終学位を基準に配点され、国内学位と海外学位では評価が異なります。

### 学位別の基本配点

| 学歴 | 基本点数 | 備考 |
|------|----------|------|
| 博士号 | 35点 | 国内外共通 |
| 修士号 | 32点 | 国内外共通 |
| 学士号 | 25点 | 国内外共通 |
| 短期大学(専門学士) | 18点 | 国内認定校基準 |
| 高卒 | 5点 | 基本点数のみ適用 |

海外学位は[韓国学力振興院](https://www.kacis.or.kr)による認証、またはアポスティーユ・領事認証を経て初めて認められます。

### 国内学位への加点

国内の短期大学以上の学位保持者には追加の加点が与えられます。

特に国内大学の学士以上であれば加点が付与されるため、基本点数よりもはるかに有利な状況になります。

実務上は、国内修士+加点の組み合わせが80点ラインに最短で到達する経路です。

> **実務のヒント:** 海外学歴の認証が漏れていると、学歴スコアは0点扱いとなります。認証書の発行には時間がかかるため、申請の2〜3ヶ月前から準備を始めましょう。

<h2 id="section-3">年齢スコアと韓国語能力スコア</h2>

年齢は若いほど高得点となり、韓国語能力はTOPIKまたは社会統合プログラム(KIIP)の等級で評価されます。

### 年齢別の配点

| 年齢区分 | 点数 |
|----------|------|
| 18〜24歳 | 25点 |
| 25〜29歳 | 23点 |
| 30〜34歳 | 20点 |
| 35〜39歳 | 18点 |
| 40〜50歳 | 15点 |
| 51歳以上 | 5点 |

年齢は本人がコントロールできない項目であるため、申請時期が遅れるほど点数は下がっていきます。

40代以降の申請者は、他の項目で点数を補う必要があります。

### 韓国語能力の配点

| 韓国語等級 | 点数 |
|------------|------|
| TOPIK 5級以上 / KIIP 5段階修了 | 20点 |
| TOPIK 4級 / KIIP 4段階修了 | 15点 |
| TOPIK 3級 / KIIP 3段階修了 | 10点 |
| TOPIK 2級 / KIIP 2段階修了 | 5点 |

KIIP 5段階修了者は韓国語スコアに加えて社会統合の加点も同時に獲得できるため、最も効率の良いルートとなります。

[社会統合プログラム](https://www.socinet.go.kr)は無料で運営されており、評価日程や段階認定範囲は毎年一部変更されます。

ご自身の状況に最も適したルートは、相談を通じて確認することをおすすめします。

<h2 id="section-4">所得・資産、そして国内居住期間</h2>

所得項目は前年度の年間所得を基準に算定されます。

所得基準は毎年一部調整されるため、当年の正確な基準は管轄出入国への確認が必要です。

### 所得項目の計算方法

所得スコアは、本人名義の給与所得・事業所得・その他所得の合算額で決まります。

基準ライン以上で10点、一定割合を超えた場合に追加加点が付与される構造です。

> **注意点:** 所得は必ず税務署への申告資料([国税庁ホームタックス](https://www.hometax.go.kr))で証明する必要があり、預金通帳の取引明細だけでは認められません。

### 国内居住期間のスコア

| 居住期間 | 点数 |
|----------|------|
| 5年以上 | 15点 |
| 4年 | 10点 |
| 3年 | 7点 |
| 2年 | 5点 |
| 1年 | 3点 |

居住期間は合法的な滞在期間のみが認められ、出国期間が長かった場合は差し引かれます。

実務では、短期出国が積み重なって居住期間スコアが削られるケースが頻繁に発生します。

<h2 id="section-5">加点項目 — スコアを引き上げる鍵</h2>

基本項目だけで80点を満たせない申請者がほとんどであるため、結局のところ合格ラインは加点で決まります。

### 主な加点項目

以下の項目は加点として追加で認定されます。

- 国内学位保持(学士・修士・博士で配点が異なる)
- 社会奉仕活動の実績(年間累計時間が基準)
- 社会統合プログラム(KIIP)5段階修了
- 国内公認資格の保有
- 先端産業分野での就業
- 地方居住(首都圏以外の地域)

ボランティア活動は[1365ボランティアポータル](https://www.1365.go.kr)に登録された実績のみが認められ、任意に作成した確認書では点数は認定されません。

### 加点設計の事例

基本点数が65点程度の申請者であれば、KIIP 5段階+ボランティア活動+国内資格の組み合わせで80点ラインを作ることができます。

最近の類似事例では、加点項目のみで不足していた12点を埋めて通過したケースもありますが、ご自身にどの組み合わせが合うのかは、まずスコアシミュレーションから始める必要があります。

<h2 id="section-6">減点項目 — 見落とすと通過できない</h2>

減点は加点と異なり、本人が気づかないうちに蓄積しているケースが多くあります。

### 減点事由

| 減点事由 | 減点点数 |
|----------|----------|
| 出入国管理法違反(罰金刑) | 事案別 -10〜-50点 |
| 滞在資格外活動の摘発 | -50点以上 |
| 租税滞納 | -5〜-10点 |
| 刑事処罰歴(罰金刑) | -10〜-50点 |

飲酒運転、暴行、窃盗などの軽犯罪も減点事由に該当します。

税金の滞納は本人が認識しないまま、審査段階で発覚するケースが多く見られます。

> **注意点:** 過去の罰金刑歴は本人が忘れていても、[犯罪経歴照会書](https://www.police.go.kr)の発行時にそのまま記載されます。スコア計算を行う前に、まずご自身の経歴を確認してください。

### 減点回復のタイミング

減点は一定期間が経過すれば回復し、その時期の見極めが申請タイミングを左右します。

罰金刑歴は通常、刑の執行終了後に一定期間が経過すると減点が解除されますが、ご自身のケースの回復時期は事案によって異なります。

<h2 id="section-7">F-2-7の申請手続きと提出書類</h2>

スコア計算が完了したら、書類準備と申請手続きへと進みます。

### 申請手続き

申請は[ハイコリア](https://www.hikorea.go.kr)でのオンライン予約後、管轄の出入国・外国人庁を訪問して受付するのが原則です。

処理期間は出入国事務所ごとに差があり、最も処理が早い窓口を選んで進めることで時間を節約できます。

### 主な提出書類リスト

| 区分 | 書類 |
|------|------|
| 身分 | パスポート、外国人登録証、写真 |
| 学歴 | 学位証、成績証明書、学歴認証書 |
| 所得 | 給与・事業所得証明、税金納付証明 |
| 韓国語 | TOPIK成績表またはKIIP修了証 |
| 加点 | ボランティア活動確認書、資格証、居住証明 |
| 身元 | 本国・国内の犯罪経歴照会書 |

書類が多くても、項目別のスコア根拠と整合が取れていなければ補完要請が繰り返されることになります。

費用は事案ごとに異なるため、無料相談の際に正確にご案内いたします。

<h2 id="section-8">よくある質問(FAQ)</h2>

**Q1. 基本スコアが80点に届かなければ、必ず却下されますか?**

基本スコアが不足していても、加点を合算して総合点が80点以上であれば申請が可能です。

ただし、加点の認定範囲や証明方法が定められているため、独自に算定したスコアは認められません。

**Q2. KIIP 5段階修了とTOPIK 5級では、どちらが有利ですか?**

KIIP 5段階の方がスコア効率に優れています。

韓国語スコアに加えて社会統合の加点まで同時に獲得できるためです。

**Q3. 海外学位は必ず認証を受ける必要がありますか?**

学歴スコアを獲得するには、学歴認証またはアポスティーユ・領事認証が必須となります。

未認証の状態では学歴スコアが0点扱いとなり、スコア不足で却下される可能性があります。

**Q4. 過去に飲酒運転の罰金刑がある場合、申請は難しいですか?**

減点事由に該当し、刑の執行終了後に一定期間が経過しなければ減点は解除されません。

ご自身のケースの回復時期は事案によって異なるため、事前の検討が必要です。

**Q5. F-2-7通過後、すぐに永住権(F-5)申請が可能ですか?**

F-2-7で一定期間滞在し、別途要件を満たした上でF-5への切替申請が可能となります。

F-5は点数制とは別の審査基準が適用されます。

**Q6. スコア計算を自分自身で行ってもよいですか?**

おおよそのスコアは自身で計算可能ですが、加点・減点の認定範囲は毎年一部変動します。

特にボランティア活動の認定範囲、居住期間の計算方法、所得の証明基準については、実際の審査基準とご自身の解釈にズレが生じるケースが頻繁にあります。

<h2 id="section-9">専門家の相談が必要ですか?</h2>

F-2-7点数制は、自分のスコアを合算することよりも、**不足する点数をどのように埋めるかを設計すること**が核心です。

学歴、年齢、韓国語、所得、居住期間、加点項目までご自身の状況を正確に分析すれば、通過の可能性が高い申請タイミングが見えてきます。

ビジョン行政士事務所は、F-2-7申請の豊富な実績をもとに、スコアシミュレーションから加点設計、書類準備、申請代行まで全プロセスをサポートいたします。
