# 韩国E-2英语会话指导签证完整指南（2026年）：资格·材料·续签

## 1. 什么是E-2签证？

E-2（会话指导）签证适用于在韩国认可教育机构（公私立学校、语言培训机构、大学、企业等）从事外语会话教学活动的外国人。

| 项目 | 内容 |
|---|---|
| 签证类型 | E-2（会话指导） |
| 允许活动 | 外语会话教学（以英语为主） |
| 允许雇主 | 经认可的教育机构、公私立学校、语言学院、大学、企业 |
| 有效期 | 初次1年（可续签） |
| 签证范围外活动 | 原则上禁止（需事先获得许可） |

## 2. 申请资格要求

| 要求 | 具体内容 |
|---|---|
| 国籍 | 持有符合资格的英语母语国家公民身份（见下方名单） |
| 学历 | 本科学士学位以上（专业不限） |
| 劳动合同 | 与韩国雇主签订有效劳动合同 |
| 犯罪记录 | 无重大犯罪前科（含性犯罪） |
| 健康状况 | 毒品检测阴性及HIV检测阴性 |

> **专业不限**：E-2签证对学士学位专业不作限制，无需英语或教育学背景。但须为四年制正规大学授予的学士学位。

## 5. 体检及犯罪背景调查

### 体检

| 项目 | 内容 |
|---|---|
| 检查项目 | 毒品检测（尿检）、HIV检测、肺结核检测、一般健康检查 |
| 有效期 | 出具后1年以内 |
| 指定医院 | 法务部指定医院（出入境外国人厅官网查询） |

### 犯罪背景调查

| 项目 | 内容 |
|---|---|
| 出具机构 | 本国警察局或政府机关 |
| 附加证书 | 必须附加（非海牙公约成员国可以领事公证代替） |
| 有效期 | 出具后3个月以内 |
| 性犯罪调查 | 还须单独提交性犯罪经历调查证明 |

## 6. 签证申请流程

### 在海外申请（新入境）

| 步骤 | 内容 |
|---|---|
| 1 | 与韩国雇主签订劳动合同 |
| 2 | 为学位证书及成绩单办理附加证书 |
| 3 | 从本国获取犯罪背景调查证明+附加证书 |
| 4 | 在本国或入境后在指定医院完成体检 |
| 5 | 向驻华（或当地）韩国大使馆/领事馆提交签证申请 |
| 6 | 签证发放后入境韩国 |
| 7 | 入境后90天内办理外国人登记 |

### 在韩国境内变更签证类型

| 步骤 | 内容 |
|---|---|
| 1 | 签订劳动合同 |
| 2 | 准备材料（学位证书、犯罪背景调查、体检证明） |
| 3 | 前往户籍所在地出入境外国人厅提交申请 |
| 4 | 审查通过后获得许可 |

## 8. 携家属同住（F-3签证）

E-2签证持有者可申请配偶及未成年子女以F-3随行签证赴韩同住。

| 项目 | 内容 |
|---|---|
| F-3适用家属 | 配偶、18岁以下子女 |
| F-3活动限制 | 不可就业（就业需另行申请工作签证） |
| 所需材料 | 婚姻关系证明（或家庭关系证明）、护照、申请人外国人登记证复印件 |
| 申请方式 | 出入境外国人厅或驻外使馆/领事馆 |

## 9. E-2签证转换为其他签证

| 目标签证 | 条件 |
|---|---|
| F-2-7（积分制居住签证） | 积分达到申请标准（韩国语、收入、居留年限均可加分） |
| F-6（婚姻签证） | 与韩国国民结婚 |
| E-1（教授签证） | 在大学担任讲师或教授 |
| F-5（永久居留） | 居留满10年或取得F-2-7后满3年 |

> E-2签证仅限英语会话教学工作。备考教学、数学、科学等科目的教学须另行申请相应签证。

## 10. 常见问题解答

**Q. 学士专业不是英语或教育学，可以申请E-2签证吗？**
A. 可以。E-2签证对学位专业不作任何限制，四年制正规大学授予的学士学位均符合要求，无论专业。

**Q. 入境前必须完成体检吗？**
A. 不是必须的。体检可以在入境后在法务部指定医院完成。但若在海外使馆申请签证，有时需随申请材料一并提交体检证明。

**Q. 持E-2签证可以兼职做家教吗？**
A. 原则上不可以。E-2签证仅允许在劳动合同所指定的机构从事教学工作。在指定机构以外的兼职或私教属于超出签证范围的活动，一经发现可能导致签证被撤销或被强制遣返。

**Q. 换工作单位时应如何处理？**
A. 换工作单位不属于简单续签，须单独向出入境外国人厅申请**工作单位变更许可**。离开原单位后凭新单位合同提出申请。

**Q. 能否同时在两家机构持E-2签证工作？**
A. 同时在两家以上机构工作须事先取得**多工作单位授权**，标准E-2签证不自动允许此类情形。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
