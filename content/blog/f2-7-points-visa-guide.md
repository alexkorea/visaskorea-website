# F-2-7 점수제 장기체류비자 신청 완벽 가이드 2026

F-2-7(거주·점수제) 비자는 고학력·고소득·한국어 능력 등 여러 요소를 점수화하여 일정 기준 이상인 외국인에게 장기 체류를 허용하는 비자입니다.

---

## 1. F-2-7 비자란?

F-2-7은 전문 인력을 대상으로 하는 점수제 거주비자입니다. 취업 활동에 제한이 없으며, 최대 3년간 체류할 수 있고 갱신도 가능합니다.

- **대상:** 합법적으로 국내에 체류 중인 외국인 전문인력
- **체류기간:** 최초 1~3년 (갱신 가능)
- **취업 제한:** 없음 (모든 분야 취업 허용)
- **가족 동반:** 배우자·미성년 자녀 F-3 동반 가능

---

## 2. 점수 배점 기준 (총 120점 기준, 80점 이상 신청 가능)

| 항목 | 최고 배점 |
|------|---------|
| 나이 (만 25~29세 최고) | 20점 |
| 학력 (이공계 석사 이상 우대) | 35점 |
| 소득 (GNI 대비) | 20점 |
| 한국어 능력 (TOPIK) | 10점 |
| 국내 체류 경력 | 15점 |
| 가점 (자격증, 투자, 사회봉사 등) | +10점 |
| 감점 (출입국법 위반 등) | -최대 20점 |

**80점 이상이면 신청 자격이 됩니다.** 점수 계산 전 자가 체크가 중요합니다.

---

## 3. 신청 자격 요건

- **합법적 체류 중:** 유효한 체류자격 보유
- **소득:** 최근 1년간 연소득 GNI 이상 (약 4,200만 원 수준)
- **체류 이력:** 국내 1년 이상 체류
- **범죄 이력:** 없음

---

## 4. 구비서류

| 서류 | 비고 |
|------|------|
| 체류자격 변경 신청서 | 출입국청 양식 |
| 여권 원본 + 외국인등록증 | |
| 학위증명서 + 번역본 | 아포스티유 또는 공증 필요 |
| 졸업증명서 | |
| 소득 관련 서류 (원천징수영수증·납세사실증명) | 최근 1년 |
| 재직증명서 또는 사업자등록증 | |
| TOPIK 성적표 | 해당자 |
| 국내외 자격증 사본 | 해당자 |
| 점수 계산표 (자가 작성) | |

---

## 5. 신청 절차

1. **점수 자가 계산** — 출입국·외국인청 홈페이지 또는 행정사 상담
2. **서류 준비** — 학력·소득·언어 증빙 서류 수집
3. **신청서 제출** — 관할 출입국·외국인청 방문 또는 하이코리아 온라인
4. **심사 및 결과** — 통상 2~4주 소요
5. **F-2-7 발급 후** — 취업 제한 없이 장기 체류 시작

---

## 6. F-2-7에서 F-5(영주) 전환

F-2-7으로 3년 이상 체류하면 F-5(영주비자) 신청 자격이 생깁니다.

- **체류 기간:** F-2-7 체류 3년 이상
- **소득 기준:** GNI 이상 유지
- **납세 성실:** 세금 체납 없음
- **법규 위반 없음**

F-5로 전환하면 체류기간 갱신 없이 영구 체류가 가능합니다.

---

## 7. 자주 묻는 질문

**Q. 현재 E-7 비자인데 F-2-7으로 변경 신청할 수 있나요?**
A. 네. E-7 등 합법적 체류자격을 유지하면서 점수 요건을 충족하면 신청 가능합니다.

**Q. 점수 계산을 어떻게 하나요?**
A. 출입국·외국인청에서 제공하는 점수표를 사용하거나, 행정사에게 의뢰하면 정확하게 산출할 수 있습니다.

**Q. 한국어를 못해도 신청할 수 있나요?**
A. 가능합니다. TOPIK 점수가 없으면 해당 항목 배점을 받지 못할 뿐, 다른 항목으로 80점을 채우면 신청할 수 있습니다.
