# 韓国D-2留学ビザ完全ガイド（2026年）：申請・更新・アルバイト

## 1. D-2留学ビザとは？ {#section-1}

D-2（留学）ビザは、韓国の教育部認可高等教育機関の正規学位課程に入学した外国人留学生に発給されます。

| 項目 | 内容 |
|---|---|
| ビザ種類 | D-2（留学） |
| 許可活動 | 正規学位課程での就学（短期大学・学士・修士・博士） |
| 対象機関 | 教育部認可の4年制大学・専門大学・大学院 |
| 有効期間 | 最大2年（学期または学年単位で発給） |
| アルバイト | 事前許可取得後、週20時間以内が可能 |

| D-2-6 | 交換留学 |
| D-2-7 | 単位交流 |
| D-2-8 | 通信制大学 |

## 3. 申請資格要件 {#section-3}

| 要件 | 詳細 |
|---|---|
| 入学許可 | 韓国認可高等教育機関からの入学許可書（入学許可書）を取得 |
| 学歴 | 高校卒業以上（大学院課程は学士号以上） |
| 財政能力 | 学費と生活費を賄える十分な資金の証明 |
| 学業維持 | 更新時に出席率・成績基準を充足する必要あり |

## 5. ビザ申請手続き {#section-5}

| ステップ | 内容 |
|---|---|
| 1 | 韓国の大学に出願・合格通知を受け取る |
| 2 | 入学許可書（Letter of Acceptance）を取得 |
| 3 | 在外公館（韓国大使館・領事館）でD-2ビザを申請 |
| 4 | ビザ発給後に韓国入国 |
| 5 | 入国後90日以内に外国人登録（出入国・外国人庁） |
| 6 | 学生証・外国人登録証を受け取り、学校生活を開始 |

---

## 6. 入国後の外国人登録 {#section-6}

入国後90日以内に住所地管轄の出入国・外国人庁で**外国人登録**を行う必要があります。

| 必要書類 | 備考 |
|---|---|
| パスポート | |
| 証明写真1枚 | |
| 在学証明書または入学許可書 | 学校が発行 |
| 住居証明（寮確認書または賃貸借契約書） | |
| 登録手数料 | 約30,000ウォン |

## 7. D-2ビザの更新 {#section-7}

| 項目 | 内容 |
|---|---|
| 更新周期 | 学期または学年単位（通常1〜2年） |
| 申請時期 | 期限切れの2〜3か月前 |
| 更新条件 | 出席率要件の充足が必要。成績不振の場合は更新が制限される場合あり |
| 必要書類 | 在学証明書・成績証明書・出席確認書・パスポート・外国人登録証 |

> 出席率が低い場合や学業警告を受けた場合は更新が制限されることがあります。学校の国際部で事前に確認しましょう。

---

## 8. アルバイト許可（時間制就業） {#section-8}

D-2ビザ保有者は、出入国・外国人庁に**時間制就業許可**を申請することでアルバイトが可能になります。

| 項目 | 内容 |
|---|---|
| 許可時間 | 学期中は週20時間以内 |
| 長期休暇中 | 時間制限なし |
| 申請方法 | 出入国・外国人庁への来所またはHi Koreaオンライン申請 |
| 必要書類 | 在学証明書・外国人登録証 |
| 許可業種 | 単純労務を除く幅広い業種 |

> 時間制就業許可なしでアルバイトを行うと、ビザ取消・出国処分の対象になります。

---

## 9. 卒業後のビザ変更 {#section-9}

| 変更先ビザ | 条件 |
|---|---|
| D-10（求職） | 卒業後の就職活動期間（最大1〜2年） |
| E-1〜E-7（就労） | 就職先が確定後、対応する就労ビザに変更 |
| F-2-7（点数制居住） | 十分な点数を満たした場合（韓国語・成績・就労などが加点対象） |
| F-6（結婚） | 韓国国民と婚姻した場合 |

> D-2在学中の韓国在留期間は、F-2-7点数制居住ビザの在留期間加点としても算定されます。

## 10. よくある質問（FAQ） {#section-10}

**Q. D-2ビザで学期中にアルバイトはできますか？**
A. はい、可能です。ただし、必ず事前に時間制就業許可を取得する必要があります。学期中は週20時間以内、長期休暇中は時間制限がありません。

**Q. 専攻や学校を変えた場合、ビザも変更が必要ですか？**
A. 同じ学校内での専攻変更には別途ビザ変更は不要です。転校する場合は出入国・外国人庁に変更を届け出る必要があります。

**Q. 休学中もD-2ビザは有効ですか？**
A. 休学期間中もD-2在留資格を維持できますが、更新時に復学予定の証明が必要です。長期休学の場合は出入国・外国人庁に届け出ることをお勧めします。

**Q. 卒業後すぐに就労ビザに変更できますか？**
A. 卒業後はD-10（求職）ビザに変更して就職活動ができます（最大1〜2年）。就職先が確定してから対応する就労ビザ（E系統）に変更します。

**Q. D-4語学研修ビザからD-2留学ビザに変更するにはどうすればよいですか？**
A. 韓国の大学から入学許可を受けた後、管轄の出入国・外国人庁で在留資格変更を申請します。語学研修中（D-4）に大学に合格した場合も、国内で手続き可能です。
