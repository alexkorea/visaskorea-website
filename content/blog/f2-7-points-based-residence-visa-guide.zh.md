# F-2-7积分制居留签证完整指南（2026年）：评分标准·申请方法

F-2-7签证（积分制居留签证）是韩国通过积分制评估向优秀外国人才发放的长期居留签证，合格标准为80分（满分200分），取得后可最终过渡至F-5永居签证。

## 1. 什么是F-2-7签证？ {#section-1}

F-2-7是F-2（居留）签证的第7类子类别，由法务部通过积分制评估向优秀外国人才发放。

| 项目 | 内容 |
|---|---|
| 签证类别 | F-2（居留）第7类 |
| 合格标准 | 80分及以上（满分200分） |
| 居留期限 | 初次1年，可续签3年 |
| 就业权利 | 允许自由就业 |
| 家庭团聚 | 配偶及未成年子女可持F-3签证同行 |

---

## 2. 申请资格 {#section-2}

| 条件 | 内容 |
|---|---|
| 在留资格 | 持有有效的韩国在留资格 |
| 居留状态 | 申请时须合法居留韩国 |
| 积分要求 | 最终合计80分及以上 |
| 不合格情形 | 无强制出境记录；无被判处监禁以上刑罚的犯罪记录 |

## 3. 评分标准（基础项目） {#section-3}

基础项目最多可获130分。

### 年龄（最多25分）

| 年龄 | 分数 |
|---|---|
| 25~29岁 | 25分 |
| 30~34岁 | 20分 |
| 35~39岁 | 15分 |
| 40~44岁 | 10分 |
| 45~49岁 | 5分 |
| 50岁及以上 | 0分 |

### 学历（最多25分）

| 学历 | 分数 |
|---|---|
| 国内大学博士毕业 | 25分 |
| 国内大学硕士毕业 | 20分 |
| 海外大学博士毕业 | 20分 |
| 国内大学本科毕业 | 15分 |
| 海外大学硕士毕业 | 15分 |
| 海外大学本科毕业 | 10分 |
| 专科（国内外） | 5分 |

### 韩语能力（最多20分）

| 资质 | 分数 |
|---|---|
| TOPIK 5~6级 或 KIIP第5阶段修读完成 | 20分 |
| TOPIK 3~4级 或 KIIP第4阶段修读完成 | 15分 |
| TOPIK 1~2级 或 KIIP第2~3阶段修读完成 | 10分 |

### 收入或资产（最多60分）

| 年收入水平（上年度） | 分数 |
|---|---|
| 国民人均GNI的3倍及以上 | 60分 |
| 国民人均GNI的2.5~3倍 | 50分 |
| 国民人均GNI的2~2.5倍 | 40分 |
| 国民人均GNI的1.5~2倍 | 30分 |
| 国民人均GNI的1~1.5倍 | 20分 |
| 低于国民人均GNI 或 资产3亿韩元以上 | 10分 |

> 2026年韩国人均GNI约为4200万韩元，请以申请当年的最新数据为准。

## 4. 加分项目（最多+40分） {#section-4}

| 加分项目 | 分数 |
|---|---|
| 在韩国内院校本科及以上毕业 | +5分 |
| 完成KIIP社会融合项目 | +5分 |
| 国内就业经历（每年） | +1分（最多+5分） |
| 国内纳税记录优良 | +5分 |
| 志愿服务活动（每年50小时以上） | +5分 |
| 与韩国国民或F-5永居签证持有人结婚 | +5分 |
| 在韩持有不动产 | +3分 |
| 持有公认资格证书或专业执照 | +3分 |
| 居留期限（每年合法居留） | +1分（最多+5分） |

---

## 5. 减分项目（最多-70分） {#section-5}

| 减分原因 | 分数 |
|---|---|
| 超出在留资格范围的活动违规 | -5至-20分 |
| 非法务工 | -20至-40分 |
| 税款拖欠 | -10至-30分 |
| 出境禁止记录 | -10分 |
| 罚款·行政处罚未缴清 | -3至-10分 |

---

## 6. 如何计算得分 {#section-6}

**最终得分 = 基础项目分 + 加分 − 减分 ≥ 80分**

### 示例计算（30岁，韩国硕士，TOPIK 4级，年收入6000万韩元）

| 项目 | 分数 |
|---|---|
| 年龄（30~34岁） | 20分 |
| 学历（韩国硕士） | 20分 |
| 韩语（TOPIK 4级） | 15分 |
| 收入（约GNI 1.4倍） | 20分 |
| 加分：国内就业3年 | +3分 |
| **合计** | **78分** |

> 上例距80分合格线差2分。若将TOPIK从4级提升至5级（20分替代15分），总分即可达83分。

## 7. 申请方法与流程 {#section-7}

### STEP 1：提前估算积分

根据官方评分标准预估得分，建议咨询专业行政士以确保无误。

### STEP 2：准备材料

准备各评分项目的证明材料。

### STEP 3：前往出入境·外国人厅提交申请

前往居住地管辖的出入境·外国人厅，提交申请表及相关材料。

### STEP 4：等待审查结果

法务部审查材料，通常在2~4周内通知审查结果。

### STEP 5：领取签证

审查通过后，在留资格变更为F-2-7。

## 9. 从F-2-7到F-5永居签证 {#section-9}

取得F-2-7签证后，可进一步申请F-5永居签证。

| 条件 | 内容 |
|---|---|
| F-2-7居留期限 | 连续居留至少3年以上 |
| 合法居留 | 持续保持合法在留状态 |
| 收入·纳税要求 | 稳定收入及完税记录 |
| 韩语要求 | TOPIK 3级及以上或完成KIIP |

> 取得F-5永居签证后无需续签，可永久居留韩国，同时也是申请归化的重要基础。

## 10. 常见问题解答 {#section-10}

**Q. 距80分差距较大，提升哪个项目最有效？**
A. 收入（最多60分）和韩语能力（最多20分）占比最大。收入稳定的情况下，取得TOPIK 5级或完成KIIP可额外获得15~20分。

**Q. 持F-2-7签证可以为家人办理来韩手续吗？**
A. 可以。配偶及未成年子女可持F-3（同行）签证同行居住。

**Q. 我目前持E-7签证，可以转换为F-2-7吗？**
A. 可以。满足80分要求即可申请变更。收入、学历和韩语成绩是关键得分项。

**Q. 申请后未达80分怎么办？**
A. 申请不予许可，但原有在留资格不受影响，可提升积分后重新申请。

**Q. 有减分记录是否一定无法通过？**
A. 不一定。只要最终合计达80分即可。但重大违规行为（非法务工、被强制出境等）可能构成绝对不合格条件，请务必事先咨询专业人士。
