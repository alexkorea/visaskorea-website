# 韩国社会融合项目（KIIP）完整指南（2026年）：申请方法与修读福利

韩国社会融合项目（KIIP，Korea Immigration & Integration Program）是由法务部运营的外国人韩语及韩国社会理解教育项目。完成KIIP可在申请F-5永居签证时免除预评审，在归化申请时免除笔试，享有多种实质性福利。

## 1. 什么是KIIP？

韩国社会融合项目（KIIP）是韩国法务部出入境·外国人政策本部主办的移民社会融合教育制度。

| 项目 | 内容 |
|---|---|
| 运营机构 | 法务部出入境·外国人政策本部 |
| 教学内容 | 韩语（0~4阶段）+ 韩国社会理解（5阶段） |
| 总学时 | 最多415小时（按入学阶段不同） |
| 官方网站 | socinet.go.kr |
| 目的 | 支持外国人早日融入并自立于韩国社会 |

### KIIP核心特点

- 免费或极低费用参与
- 全国300余家运营机构授课
- 提供线上与线下两种授课方式
- 与永居签证及归化申请挂钩

## 2. 申请对象与资格

| 对象 | 条件 |
|---|---|
| 合法在韩外国人 | 持有有效在留资格 |
| 婚姻移民 | F-6签证持有人（优先支持） |
| 海外韩裔 | F-4签证持有人 |
| 就业外国人 | E-9、H-2等就业签证持有人 |
| 其他长期居留外国人 | D、E、F签证类别人员 |

> 短期停留者（C-3等）及非法居留者不得申请。

## 3. 课程阶段与教学内容

| 阶段 | 级别 | 学时 | 内容 |
|---|---|---|---|
| 0阶段 | 基础韩语 | 15小时 | 韩字字母·基本问候·日常表达 |
| 1阶段 | 初级韩语1 | 100小时 | 日常生活基本沟通 |
| 2阶段 | 初级韩语2 | 100小时 | 社会生活基础沟通 |
| 3阶段 | 中级韩语1 | 100小时 | 职场与社会活动沟通 |
| 4阶段 | 中级韩语2 | 100小时 | 多元话题沟通能力 |
| 5阶段 | 韩国社会理解 | 50小时（基础）/ 70小时（深化） | 历史·政治·经济·文化·法律 |

> 归化申请者须完成5阶段深化课程（70小时）。

## 4. 预测评与阶段分配

申请者须通过KIIP预测评，根据本人韩语水平从相应阶段开始学习。

| 项目 | 内容 |
|---|---|
| 测评方式 | 在线预测评（socinet.go.kr） |
| 测评内容 | 韩语阅读·听力·写作 |
| 结果反映 | 依据得分自动分配1~4阶段 |
| 0阶段分配 | 完全不懂韩语者 |

### 凭TOPIK成绩免测评直接入阶

| TOPIK级别 | 入学阶段 |
|---|---|
| TOPIK 1级及以上 | 从1阶段起 |
| TOPIK 2级及以上 | 从2阶段起 |
| TOPIK 3级及以上 | 从3阶段起 |
| TOPIK 4级及以上 | 从4阶段起 |
| TOPIK 5~6级 | 仅需完成5阶段（韩国社会理解） |

## 5. 申请方法与步骤

### STEP 1：在socinet.go.kr注册账号

访问官方网站，使用外国人登记号完成注册。

### STEP 2：申请并参加预测评

注册后申请在线预测评，测评全年常态化开展。

### STEP 3：确认分配阶段

系统根据测评结果自动分配入学阶段。

### STEP 4：选择教育机构与课程

在全国机构列表中选择就近机构及合适的课程时间表进行报名。

### STEP 5：出勤修读并参加评估

按时出勤，完成各阶段评估后晋级下一阶段。

### STEP 6：领取结业证书

完成全部阶段后，可在socinet.go.kr下载结业证书。

## 10. 常见问题解答

**Q. KIIP是强制参加的吗？**
A. 不是，参与完全自愿。但如果您计划申请F-5永居签证或归化，完成KIIP可获得考试豁免等实质福利，强烈建议参加。

**Q. 完全不懂韩语也能报名吗？**
A. 可以。完全不懂韩语的学员从0阶段开始，学习韩字字母和基础表达。

**Q. 上班族也能参加吗？**
A. 可以。很多机构提供晚间和周末课程，部分阶段也可在线学习。

**Q. 持有TOPIK证书可以跳过阶段吗？**
A. 可以。根据TOPIK级别可直接进入相应阶段。例如TOPIK 5级持有者只需完成5阶段（韩国社会理解）即可。

**Q. 签证变更后，已完成的KIIP进度还有效吗？**
A. 有效。KIIP进度与外国人登记号绑定，与签证类别无关。变更签证后，建议向出入境管理局确认适用福利的最新要求。

**A**：是的，可以通过驻华韩国大使馆或总领事馆申请。北京、上海、广州、成都、青岛、沈阳、武汉、西安等地均设有领事馆。建议提前预约并确认所需材料。

### Q4. 签证续签需要提前多久申请？

**A**：大多数长期居住签证允许配偶和未成年子女以F-1（家庭陪同）签证一同来韩居住。具体要求请咨询专业人士。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
