# F-2-7点数制居住ビザ完全ガイド（2026年）：配点基準・申請方法

F-2-7ビザ（点数制居住ビザ）は、法務部の点数制評価を通じて優秀な外国人人材に付与される長期居住ビザです。合格基準は200点満点中80点以上で、取得後は最終的にF-5永住権へのステップとなります。

## 1. F-2-7ビザとは？

F-2-7はF-2（居住）ビザの7番目の下位類型で、法務部の点数制評価を通じて優秀な外国人人材に付与されます。

| 項目 | 内容 |
|---|---|
| ビザ種別 | F-2（居住）第7類型 |
| 合格基準 | 80点以上（200点満点） |
| 在留期間 | 初回1年、更新時3年 |
| 就労権利 | 自由な就労活動が可能 |
| 家族 | 配偶者・未成年の子はF-3ビザで同伴可能 |

## 2. 申請資格

| 要件 | 内容 |
|---|---|
| 体留資格 | 有効な韓国の体留資格を保有していること |
| 滞在状況 | 申請時に合法的に韓国に滞在していること |
| 点数要件 | 最終合計80点以上 |
| 欠格事由 | 強制退去命令の履歴なし・禁固以上の刑事処罰歴なし |

## 3. 点数算定基準（共通項目）

共通項目では最大130点を獲得できます。

### 年齢（最大25点）

| 年齢 | 点数 |
|---|---|
| 25〜29歳 | 25点 |
| 30〜34歳 | 20点 |
| 35〜39歳 | 15点 |
| 40〜44歳 | 10点 |
| 45〜49歳 | 5点 |
| 50歳以上 | 0点 |

### 学歴（最大25点）

| 学歴 | 点数 |
|---|---|
| 国内大学の博士修了 | 25点 |
| 国内大学の修士修了 | 20点 |
| 海外大学の博士修了 | 20点 |
| 国内大学の学士修了 | 15点 |
| 海外大学の修士修了 | 15点 |
| 海外大学の学士修了 | 10点 |
| 短期大学（国内外） | 5点 |

### 韓国語能力（最大20点）

| 資格 | 点数 |
|---|---|
| TOPIK 5〜6級 またはKIIP5段階修了 | 20点 |
| TOPIK 3〜4級 またはKIIP4段階修了 | 15点 |
| TOPIK 1〜2級 またはKIIP2〜3段階修了 | 10点 |

### 所得または資産（最大60点）

| 年間所得（前年度） | 点数 |
|---|---|
| 国民1人当たりGNIの3倍以上 | 60点 |
| 同2.5〜3倍 | 50点 |
| 同2〜2.5倍 | 40点 |
| 同1.5〜2倍 | 30点 |
| 同1〜1.5倍 | 20点 |
| 同未満 または 資産3億ウォン以上 | 10点 |

> 2026年の韓国国民1人当たりGNIは約4,200万ウォンです。申請年の最新数値で確認してください。

## 6. 点数の計算方法

**最終点数 = 共通項目点数 + 加点 − 減点 ≥ 80点**

### 計算例（30歳・国内修士・TOPIK 4級・年収6,000万ウォン）

| 項目 | 点数 |
|---|---|
| 年齢（30〜34歳） | 20点 |
| 学歴（国内修士） | 20点 |
| 韓国語（TOPIK 4級） | 15点 |
| 所得（GNI約1.4倍） | 20点 |
| 加点：国内就労3年 | +3点 |
| **合計** | **78点** |

> この例では合格基準の80点に2点届きません。TOPIK 5級（20点）を取得すれば合計83点になります。

## 7. 申請方法と手順

### STEP 1：事前点数の計算

公式点数表をもとに予想点数を計算します。行政書士に確認してもらうと正確です。

### STEP 2：書類準備

各点数項目の証拠書類を揃えます。

### STEP 3：出入国・外国人庁での申請

居住地を管轄する出入国・外国人庁に申請書と書類を提出します。

### STEP 4：審査と結果通知

法務部が書類を審査し、通常2〜4週間以内に結果を通知します。

### STEP 5：F-2-7資格の付与

合格した場合、F-2-7の在留資格が付与されます。

## 9. F-2-7からF-5永住権へ

F-2-7ビザ取得後、F-5（永住権）申請への道が開かれます。

| 条件 | 内容 |
|---|---|
| F-2-7在留期間 | 継続して最低3年以上 |
| 合法的在留 | 継続して合法的在留を維持 |
| 所得・納税要件 | 安定した収入と納税実績 |
| 韓国語要件 | TOPIK 3級以上またはKIIP修了 |

> F-5永住権取得後はビザの更新が不要で、韓国に永続的に居住できます。帰化への第一歩でもあります。

## 10. よくある質問（FAQ）

**Q. 80点まで点数が足りない場合、どの項目を上げるのが最も効果的ですか？**
A. 所得（最大60点）と韓国語能力（最大20点）が最大の比重を占めます。所得が安定していれば、TOPIK 5級取得またはKIIP修了で15〜20点の上乗せが可能です。

**Q. F-2-7ビザで家族を韓国に呼ぶことはできますか？**
A. はい。配偶者と未成年の子はF-3（同伴）ビザで同伴体留が可能です。

**Q. 現在E-7ビザですが、F-2-7に変更できますか？**
A. はい。80点の要件を満たせば体留資格変更が可能です。所得・学歴・韓国語の点数が主要なカギになります。

**Q. 申請して80点に達していなかった場合はどうなりますか？**
A. 不許可決定が通知されます。既存の体留資格は維持されますので、点数を高めてから再申請できます。

**Q. 減点があると合格は無理ですか？**
A. 最終合計が80点以上であれば合格可能です。ただし重大な違反（不法就労・強制退去歴など）は絶対的欠格事由となる場合があるため、専門家への相談が必要です。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
