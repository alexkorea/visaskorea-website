# F-2-7ポイント制永住権申請ガイド2026

## F-2-7ビザとは？

F-2-7は、韓国法務部が運営する**ポイント制居住ビザ**です。年齢・学歴・所得・職業・韓国語能力などの項目を総合評価し、一定点数以上を取得した外国人に居住（F-2）資格を付与します。

満点120点中**80点以上**で申請資格が与えられます。F-2-7資格を**2年間**維持すると、F-5永住権の申請へ進むことができます。雇用に縛られない広い就労の自由が魅力で、Eビザからの転換を目指す専門人材に特に人気があります。

## 2026年配点表

### 1. 年齢（最大25点）

| 年齢 | 点数 |
|------|------|
| 18～24歳 | 20点 |
| 25～29歳 | 25点 |
| 30～34歳 | 20点 |
| 35～39歳 | 15点 |
| 40～44歳 | 10点 |
| 45～49歳 | 5点 |
| 50歳以上 | 0点 |

25～29歳が最高点となるため、若年申請者に有利な設計となっています。

### 2. 学歴（最大35点）

| 学歴 | 一般分野 | 理工系分野 |
|------|----------|------------|
| 博士 | 35点 | 35点 |
| 修士 | 30点 | 33点 |
| 学士 | 20点 | 23点 |
| 短期大学・専門学校 | 15点 | 18点 |

理工系（理学・工学・医薬学）は**3点加算**されます。海外の学位は韓国学術振興財団（NRCS）による学力認定を受けた後に加算が適用されます。

### 3. 所得（最大20点）

| 年間所得（1人当たりGNI比） | 点数 |
|--------------------------|------|
| GNIの3倍以上 | 20点 |
| GNIの2倍以上 | 15点 |
| GNIの1倍以上 | 10点 |
| GNI未満 | 0点 |

2026年の1人当たりGNI基準は約**4,200万ウォン**（法務部告示）です。給与所得以外に、賃貸収入や配当収入も合算可能です。

### 4. 職業（最大20点）

| 職業タイプ | 点数 |
|-----------|------|
| OECD高度熟練職（管理・専門職） | 20点 |
| 準専門職 | 15点 |
| 一般事務職 | 10点 |
| その他 | 5点 |

### 5. 韓国語能力（最大20点）

| TOPIK等級 | 点数 |
|-----------|------|
| 6級 | 20点 |
| 5級 | 18点 |
| 4級 | 14点 |
| 3級 | 10点 |
| 2級以下・未取得 | 0点 |

TOPIK成績は試験日から**2年間**有効です。期限切れには注意が必要です。

### 6. 加点・減点項目

**加点：**
- 韓国の4年制大学卒業：+2点
- 韓国国内での創業・継続経営：+5点
- 国家表彰受賞：+5点

**減点：**
- 出入国違反歴：−5〜−15点
- 税金滞納：−5点

## 合格ラインと戦略

公式の合格基準は**80点以上**ですが、競争が激しい時期は**85〜90点以上**を目標にするとより安全です。

### 効果的な得点向上戦略

**①TOPIK 6級の取得**  
最大20点が得られる最も効果的な方法です。6ヶ月程度の集中学習で6級取得を目指しましょう。

**②理工系学歴の加算確認**  
海外の理工系学位をお持ちの方は、学力認定手続きを先に完了させることで3点加算を確保できます。

**③所得証明の最大化**  
給与所得だけでなく、税務署発行の所得確認書を用意し、賃貸収入・配当収入も合算申告を検討しましょう。

**④違反歴・滞納の事前解消**  
HiKoreaで出入国記録を確認し、税金滞納がある場合は申請前に解消しておくことが重要です。

## よくある間違い

### 間違い1：理工系学歴加算の見落とし
多くの海外理工系卒業生が学力認定手続きを怠り、3点を逃しています。申請書類を提出する前に認定手続きが完了しているか確認してください。

### 間違い2：所得計算期間の誤認
所得は**申請日から直近12ヶ月**が対象であり、前年の確定申告ベースではありません。この期間をカバーする所得証明書を準備しましょう。

### 間違い3：期限切れTOPIK成績の提出
TOPIK成績は試験から2年で失効します。申請時点で有効期間内かを必ず確認してください。

### 間違い4：在留資格の適格確認不足
F-2-7はD-2（留学）やE-1〜E-7（就労）など特定の在留資格から申請可能ですが、資格によっては制限があります。現在の在留資格が変更可能かを事前に確認してください。

### 間違い5：減点項目の見落とし
出入国違反や税金滞納があると得点が大きく下がります。HiKoreaでの事前確認を怠らないようにしましょう。

## 申請手続き

### ステップ1：点数の事前確認
法務部の**HiKorea（www.hikorea.go.kr）**またはKIIPポータルで点数シミュレーションを実施。現在の在留資格がF-2-7申請の対象かも確認します。

### ステップ2：書類の準備
- パスポートおよび外国人登録証のコピー
- 学位証明書 + 学力認定書（海外学位の場合は必須）
- 所得証明書類：所得確認書、源泉徴収票、在職証明書
- TOPIK成績証明書（有効期限内のもの）
- 加点に関する証明書類（該当する場合）
- 税金滞納なし証明書

### ステップ3：申請の受付
- **申請先**：居住地管轄の出入国・外国人庁
- **オンライン申請**：HiKoreaより可能
- **手数料**：60,000ウォン

### ステップ4：審査・発給
- 標準審査期間：**2〜4週間**
- 補充書類が必要な場合は30日以内に提出
- 承認後、F-2-7ビザステッカーまたは在留資格変更許可書を受領

## 資格確認チェックリスト

申請前に以下をすべて確認してください。

- [ ] 現在の在留資格がF-2-7申請対象である
- [ ] 合計点数が80点以上に達している
- [ ] 海外学位の学力認定手続きが完了している（該当者のみ）
- [ ] TOPIKの成績が有効期間（2年）内である
- [ ] 直近12ヶ月の所得証明書類が準備できる
- [ ] 出入国違反歴がない
- [ ] 税金滞納がない
- [ ] 国民健康保険の納付履歴がある

## よくある質問（FAQ）

**Q1. F-2-7を取得すると、どの職業でも就労できますか？**
はい。F-2-7（居住）ビザは就労制限がありません。単純労務職から専門職まで自由に就業できます。これはE系就労ビザと比べた際の大きな強みです。

**Q2. 配偶者や子どもも一緒に在留できますか？**
主申請者がF-2-7を取得すると、配偶者と未成年の子どもは**F-3（同伴）ビザ**で一緒に在留することができます。

**Q3. 点数が80点に届かない場合はどうすればよいですか？**
最も現実的な方法はTOPIK等級の向上（最大20点）または所得増加です。職種によってはE-7-1（特定活動）など別の在留資格も検討してみてください。

**Q4. 海外の大学で取得した学位も認められますか？**
認められます。ただし、**韓国学術振興財団（NRCS）による外国学力認定手続き**を先に完了する必要があります。処理には通常2〜4週間かかります。

**Q5. F-2-7からF-5永住権にはいつ転換できますか？**
F-2-7資格を**継続して2年間**保有した後（期間中の重大な違反や長期出国がないこと）、F-5永住権の申請が可能となります。在留中の法令遵守が不可欠です。

## まとめ

F-2-7ポイント制ビザは、韓国での長期在留を目指す外国人にとって戦略的に取り組むべき重要な制度です。**TOPIK成績の向上**と**所得証明の最大化**が合格への鍵です。申請前の自己点検と書類準備を丁寧に行うことで、スムーズな審査が期待できます。
