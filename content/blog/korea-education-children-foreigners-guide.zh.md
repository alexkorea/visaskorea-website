# 韩国外国人子女教育完整指南（2026年）：入学·国际学校·语言支持

在韩国，外国人子女享有就读公立学校的法定权利。与此同时，外国人专属学校和国际学校也在全国各地运营，为家庭提供多元化的教育选择。本指南详细介绍入学手续、语言支援项目、各类学校对比、学费及升学信息。

## 1. 外国人子女的受教育权利

| 项目 | 内容 |
|---|---|
| 法律依据 | 《初中等教育法》第19条第3款、《教育基本法》第3条 |
| 入学资格 | 持外国人登记证（ARC）或已完成国内居住登记的外国人子女 |
| 适用学段 | 小学·初中·高中均可入学 |
| 学费 | 公立小学·初中免收学费（义务教育） |
| 语言障碍 | 韩语不熟练时可申请韩语特别班支援 |

> 外国人子女依法享有就读韩国公立学校的权利，不得以韩语能力不足为由拒绝入学。

## 2. 公立学校入学手续

| 步骤 | 内容 |
|---|---|
| 1 | 联系居住地所属教育厅或就近公立学校 |
| 2 | 完成转入登记（持外国人登记证在社区服务中心办理） |
| 3 | 向学校行政室提交入学申请 |
| 4 | 所需材料：外国人登记证、护照、原就读学校在读/毕业证明 |
| 5 | 学校根据出生年月及既往学历确定年级 |
| 6 | 完成入学或转学手续 |

| 注意事项 | 内容 |
|---|---|
| 无原学校证明 | 由学校或教育厅酌情分配年级 |
| 境外学历认定 | 原则上认可，可能需要提供经公证的韩语译本 |
| 咨询联系方式 | 各地教育支援厅或教育厅多元文化教育部门 |

## 3. 韩语特别班及支援项目

| 项目 | 内容 |
|---|---|
| 韩语特别班（KSL） | 面向韩语不熟练的外国人·多元文化学生开设专项韩语课程 |
| 预备学校 | 部分地区教育厅在入学前提供集中韩语培训 |
| 多元文化教育支援中心 | 全国各地设立，提供翻译、口译及咨询服务 |
| 双语教育 | 部分学校开设英语·中文·越南语等双语教学 |
| 导师制度 | 配对大学生志愿者导师，提供学业辅导 |

> 韩语特别班的开设情况因学校而异。外国人居住较集中的地区（安山、水原、首尔九老/永登浦等）学校的配套更为完善。

## 4. 外国人学校vs国际学校对比

| 项目 | 外国人学校 | 国际学校 |
|---|---|---|
| 招生对象 | 外国人（含长期居留或归国子女） | 韩国人与外国人均可（韩国人有名额限制） |
| 课程 | 本国或国际课程（IB·AP等） | IB·AP·A-Level等国际认证课程 |
| 授课语言 | 英语或本国语言 | 主要为英语 |
| 年学费 | 1,500—4,000万韩元 | 2,000—6,000万韩元以上 |
| 韩语课程 | 选修或不提供 | 部分提供 |
| 韩国人入学 | 不可（或受严格限制） | 部分名额开放 |

## 9. 常见问题解答

**Q. 外国人子女可以就读韩国公立学校吗？**
A. 可以。持外国人登记证的外国人子女依法享有就读公立小学、初中和高中的权利。小学和初中属义务教育，免收学费。

**Q. 孩子不会说韩语怎么办？**
A. 不得以韩语不熟练为由拒绝入学。建议联系地区教育厅，申请分配到开设韩语特别班（KSL）的学校。

**Q. 外国人学校和国际学校有什么区别？**
A. 外国人学校仅限外国人就读，通常沿用本国教育体系；国际学校韩国人和外国人均可就读，采用IB·AP等国际认证课程。

**Q. 如何申请济州岛国际学校？**
A. 直接向学校（NLCS·BHA等）提交申请，须参加英语面试及入学考试。等候名单较长，建议尽早申请。

**Q. 持境外学历的孩子如何在韩国参加大学升学？**
A. 凭境外高中毕业证、成绩单及TOPIK或英语成绩，可通过外国人特别招生通道申请大多数韩国大学。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
