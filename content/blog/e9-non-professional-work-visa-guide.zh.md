# 韩国E-9非专业就业签证完整指南（2026年）：雇佣许可制、配额与E-7-4转换

E-9（非专业就业）签证是韩国政府为解决特定行业劳动力短缺而引进外国非专业劳动者的制度。该签证依据《外国人雇佣等相关法律》通过**雇佣许可制（EPS，Employment Permit System）**运营，与H-2等签证不同，个人无法直接申请E-9——所有录用程序均须通过EPS进行。

参与国（16个国家）的国民通过韩国语考试（EPS-TOPIK）后，将被登录到求职数据库，并由申请了雇佣许可的韩国雇主进行匹配录用。

## 1. E-9签证是什么？

E-9是韩国《出入境管理法》规定的"非专业就业"在留资格，发放给通过雇佣许可制（EPS）在韩国中小企业就业的外国非专业劳动者。

主要特征：
- 不可个人直接申请——须通过韩国产业人力公团EPS进行配置
- 必须通过韩国语考试（EPS-TOPIK）
- 仅限在许可行业内就业
- 实行年度配额制
- 满足一定条件后可转换为E-7-4熟练技能人才

## 2. 申请资格——参与国与语言考试

### 雇佣许可制参与国（16个国家）

| 地区 | 国家 |
|---|---|
| 东南亚 | 菲律宾、泰国、印度尼西亚、越南、柬埔寨、缅甸、老挝、东帝汶 |
| 南亚 | 巴基斯坦、孟加拉国、斯里兰卡、尼泊尔 |
| 中亚 | 乌兹别克斯坦、吉尔吉斯斯坦、蒙古 |
| 东北亚 | 中国（与H-2分开，E-9也适用） |

**非参与国国民不可申请E-9。**

### EPS-TOPIK（韩国语考试）

| 项目 | 内容 |
|---|---|
| 考试名称 | EPS-TOPIK（雇佣许可制韩国语能力考试） |
| 主管机构 | 韩国产业人力公团 |
| 合格标准 | 达到规定分数（因国家和年度不同而有差异） |
| 有效期 | 2年 |
| 考试地点 | 参与国本国指定考场 |

## 3. 允许就业行业

E-9仅限在以下行业就业：

| 行业 | 内容 |
|---|---|
| 制造业 | 中小型制造工厂（原则上为300人以下企业） |
| 建筑业 | 建筑工地单纯劳务（专业工种除外） |
| 农业・畜牧业 | 农场・牧场季节性劳动 |
| 渔业 | 近海渔船及水产养殖场 |
| 部分服务业 | 餐厅辅助、清洁、住宿设施辅助（有限制） |
| 冷冻冷藏仓储业 | |

企业规模要求：制造业原则上须为常时雇佣300人以下或注册资本80亿韩元以下的中小企业。

## 4. 雇佣许可制（EPS）流程

E-9就业按以下顺序进行：

### 外国劳动者（申请人）角度

1. **参加EPS-TOPIK并合格** — 在本国指定考场参加考试
2. **登录求职者名册** — 登录韩国产业人力公团管理的数据库
3. **等待韩国企业选择** — 招聘企业从名册中进行选择
4. **签证发放及入境** — 发放E-9签证后入境韩国
5. **外国人登录** — 入境后90日内完成登录

### 雇主角度

1. 证明在国内寻找劳动者的努力后，向雇佣劳动部申请雇佣许可
2. 获得雇佣许可证
3. 通过产业人力公团从求职者名册中选择外国劳动者
4. 签订劳动合同并协助办理签证

## 5. 在留期间与延期

| 区分 | 期间 |
|---|---|
| 初期在留期间 | 最长3年 |
| 第一次延期 | 再追加1年10个月（维持同一工作场所时） |
| 再入境就业 | 利用再入境特例制度最多可再追加4年10个月 |
| 最长在留总期 | 最长约9年8个月（含再入境） |

雇佣期间届满后须返回本国，仅满足再入境特例要件者方可再次入境。

---

## 6. 工作场所变更限制

E-9原则上只能在入境时指定的工作场所工作。工作场所变更仅在有限情况下获准。

### 允许变更工作场所的事由

| 事由 | 是否可变更 |
|---|---|
| 工作场所倒闭 | 可以 |
| 雇主违反劳动合同 | 可以（须经劳动厅确认） |
| 劳动者权益侵害（欠薪、暴行等） | 可以（须经核实） |
| 非雇主过失的劳动者主动申请变更 | 仅限3次以内 |

---

## 7. 年度配额制度

E-9签证发放须在年度配额（总量）范围内进行。

| 项目 | 内容 |
|---|---|
| 配额决定主体 | 雇佣劳动部与法务部协商决定 |
| 国家别分配 | 向参与16个国家按国别分配配额 |
| 超出配额时 | 当年度无法进行新的配置 |

配额每年变动，按行业和国家进行调整。

---

## 8. 从E-9转换为E-7-4熟练技能人才

持E-9签证就业满一定期间并满足条件后，可转换为E-7-4（熟练技能人才）资格。E-7-4放宽了就业限制，并开辟了通过F-2-7取得长期在留资格的途径。

### E-7-4转换主要要件

| 要件 | 标准 |
|---|---|
| E-9或H-2在留期间 | 合法就业4年以上 |
| 同一行业就业 | 转换时的行业连续性 |
| 熟练技能证明 | 职业培训修了证书、资格证书、业务能力评估 |
| 韩国语能力 | 社会融合项目（KIIP）修了或韩国语能力证明 |
| 雇主继续雇佣意愿 | 现有或新雇主的录用意向确认 |

取得E-7-4后，可转换为F-2-7积分制居住，之后还可申请F-5-16永久居留权。

## 9. E-9与H-2对比

| | E-9 非专业就业 | H-2 访问就业 |
|--|--|--|
| 对象 | EPS 16个参与国国民 | 中国・CIS旅居韩裔同胞 |
| 申请方式 | 只能通过EPS（雇佣许可制）申请 | 可个人直接申请 |
| 韩国语考试 | 须通过EPS-TOPIK | 不需要 |
| 工作场所变更 | 严格限制 | 相对自由 |
| 配额 | 国家别・行业别配额 | 年度总量配额 |
| 转换路径 | E-7-4 → F-2-7 → F-5-16 | H-2 → F-4 → F-5-7 |
| 对象行业 | 制造・建筑・农业・渔业等 | 类似但略有不同 |

若为可申请H-2的同胞，在工作场所变更灵活性和自由寻找工作地方面，H-2更具优势。

## 10. 常见问题解答

**Q. 通过EPS-TOPIK后可以立即来韩国吗？**
A. 不能直接来。通过EPS-TOPIK后登录求职者名册，须等韩国企业从名册中选择您后方可实现就业。通过考试本身不保证入境资格。

**Q. 持E-9入境就业，但雇主拖欠工资。可以换工作场所吗？**
A. 可以。欠薪属于雇主违反劳动合同，符合工作场所变更许可事由。请向雇佣劳动部地方机关举报，并按工作场所变更程序办理。

**Q. 持E-9来韩国已4年，可以申请永久居留权吗？**
A. 不可直接申请永久居留权。E-9就业满4年以上后，可转换为E-7-4（熟练技能人才），之后经F-2-7（积分制居住）→ F-5-16（永久居留权）路径申请。但须满足各阶段的所有要件。

**Q. 我是越南国籍，E-9和H-2哪个适合我？**
A. 越南不属于H-2对象国，因此只能申请E-9。H-2仅适用于中国朝鲜族或CIS旅居韩裔同胞。

**Q. 持E-9在韩国就业期间结婚了，签证会变吗？**
A. 若与韩国人结婚，可变更为F-6（结婚移民）签证。F-6没有就业限制，在留资格更为稳定。请咨询移民专家以处理资格变更手续。
