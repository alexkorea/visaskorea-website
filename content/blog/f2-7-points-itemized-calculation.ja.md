# F-2 居住ビザ ポイント制 項目別スコア計算法 完全分析

F-2-7居住ビザは120点満点中80点以上で申請資格が与えられますが、実務では80点を超えた申請者の中でも合否が分かれるポイントが明確に存在します。

対象は国内に合法的に滞在中の外国人のうち、学歴・韓国語・所得・年齢の項目でスコアを満たせる方であり、単純な合算ではなく項目別の認定範囲が狭いという点を最初に理解しておく必要があります。

本記事では、項目別スコア計算基準、実務で見落とされやすい減点ポイント、そしてスコアが不足した際に挽回できる実際の方法を扱います。

<h2 id="section-1">F-2-7 ポイント制の基本構造</h2>

F-2-7のポイント制は、基本項目と加点・減点項目に分かれます。

基本項目は学歴、韓国語能力、年間所得、年齢の4つで構成され、合計80点が第一次通過ラインとなります。

加点項目にはボランティア活動、社会統合プログラムの修了、国内留学経歴などが含まれ、減点項目は出入国法違反・税金滞納・犯罪歴から発生します。

### 総合スコア算定のポイント

ポイントはここです。

80点を満たせば終わりではなく、項目別に1つでも0点になってはいけない項目があります。

実際の審査では、韓国語スコアが0点であれば他の項目のスコアがどれほど高くても資格が認められません。

### 義務項目と選択項目の区分

学歴・韓国語・所得・年齢はすべて義務スコア項目です。

このうち1項目でも0点であれば申請自体が困難なケースが多く、この部分は[ハイコリア公知事項](https://www.hikorea.go.kr)で毎年細部の変動があります。

本年度の適用基準は、出入国・外国人庁ごとに運営指針が異なる形で案内される場合があり、ご本人のケースに合った基準確認のためには相談が必要です。

<h2 id="section-2">学歴スコア計算法</h2>

学歴は最大35点まで認定されます。

| 学歴区分 | 認定スコア | 備考 |
|---|---|---|
| 博士学位 | 35点 | 国内・海外いずれも認定 |
| 修士学位 | 32点 | 国内学位の場合は加点別途 |
| 学士学位 | 25点 | 4年制正規課程 |
| 専門学士 | 20点 | 2〜3年制 |
| 高卒 | 15点 | 基本認定 |

### 国内学位の加点

国内で取得した学位には追加加点が付与されます。

国内学士学位は+5点、修士・博士は項目別に異なる加算が行われます。

むしろ海外学位のみの方は、学歴スコアが十分に見えても、国内学位保有者と比較すると総合スコアで劣るケースが多く見られます。

### 学位認定手続きで詰まる部分

海外学位は、アポスティーユまたは領事確認を経た卒業証明書・成績証明書がなければ学歴認定が下りません。

書類は揃っていても、学位名の翻訳が韓国の学制と合致せず、認定等級が1ランク下がるというケースが、通常もっとも頻繁に発生します。

この部分が弱いと博士学位が修士として算定される事態が実際に起こり得るため、学位認定の段階で事前検討が必要です。

<h2 id="section-3">韓国語能力スコア計算法</h2>

韓国語スコアはTOPIK、または社会統合プログラム(KIIP)修了で立証します。

| 立証方法 | スコア | 備考 |
|---|---|---|
| TOPIK 5〜6級 / KIIP 5段階修了 | 20点 | 最高スコア |
| TOPIK 4級 / KIIP 4段階修了 | 15点 | |
| TOPIK 3級 / KIIP 3段階修了 | 10点 | |
| TOPIK 2級 / KIIP 2段階修了 | 5点 | 最低認定 |
| TOPIK 1級または無資格 | 0点 | 申請資格不可 |

### TOPIKとKIIPの違い

TOPIKは試験結果で直ちにスコアが確定し、KIIPは段階別授業の修了によりスコアが累積されます。

実務上はKIIP修了の方が、学業・勤務で多忙な申請者には負担が少ない傾向にありますが、段階別の出席要件は厳しめです。

KIIP段階の認定は[社会統合情報網](https://www.socinet.go.kr)の記録がそのまま反映されるため、途中で欠席が累積すると段階が1ランク下がります。

### 韓国語スコアでよく詰まるポイント

最初に確認すべきは、ご本人のTOPIK成績が有効期間内にあるかどうかです。

TOPIK成績は発行日から2年が有効期間であり、期限切れの成績はスコアとして認定されません。

最近の類似ケースでは、TOPIK 5級を保有していたものの有効期限が過ぎており、0点扱いとなって申請自体が止まった事例がありました。

<h2 id="section-4">所得スコア計算法</h2>

所得は直前年度の年間所得を基準に計算します。

GNI(国民1人当たり総所得)に対するご本人の年間所得比率によりスコアが区分され、1人当たりGNIは[韓国銀行経済統計システム](https://ecos.bok.or.kr)の発表数値が基準となります。

### 所得立証書類

所得の立証には2つの方向があります。

給与所得者: [ホームタックス](https://www.hometax.go.kr)で発行された勤労所得源泉徴収領収証

事業所得者: 総合所得税申告確認書 + 納税証明書

実務上、所得はあるのに申告が漏れていてスコアが0点と判定されるケースが、最も多く詰まる部分です。

### 所得スコアの落とし穴

所得スコアの基準金額は毎年GNIの変動に応じて変わるため、本年度の正確な基準金額は相談を通じてご確認ください。

特にフリーランス・一人事業者は、売上が多くても経費処理後の総合所得金額が低く算定され、スコアが不足する事例が頻発します。

税務申告の時点からF-2-7を念頭に置いておけば、経費処理の幅を見直すことが実際のスコアに直結します。

> **実務のヒント:** 総合所得申告の直前にF-2-7申請計画が決まった場合、申告方式がスコアに直接影響を及ぼします。

<h2 id="section-5">年齢およびその他の加点項目</h2>

年齢は最大25点まで認定され、18〜24歳および50歳以上はスコアが低く算定されます。

| 年齢層 | スコア |
|---|---|
| 25〜29歳 | 20点 |
| 30〜34歳 | 25点 |
| 35〜39歳 | 23点 |
| 40〜44歳 | 20点 |
| 45〜49歳 | 18点 |
| 50歳以上 | 15点 |

### 加点項目の整理

加点は次の項目から発生します。

ボランティア活動実績(年50時間以上)

KIIP 5段階の修了完了

国内4年制学士以上の卒業

海外優秀人材として分類される職種での勤務

加点項目は重複合算が可能なため、スコアが微妙なときは加点から取りに行く方が、学歴・所得を引き上げるより手早く済みます。

### ボランティア実績がよく漏れる理由

ボランティア実績は[1365ボランティアポータル](https://www.1365.go.kr)または[VMS社会福祉ボランティア](https://www.vms.or.kr)に登録された時間のみ認定されます。

非公式のボランティア活動は、時間が長くてもスコアには加算されません。

ボランティア時間の登録機関および認定範囲は変更される場合があるため、申請前の確認が必要です。

<h2 id="section-6">減点項目とよく見落とされる部分</h2>

減点は、出入国法違反、税金滞納、刑事処罰歴から発生します。

| 減点事由 | 減点幅 | 備考 |
|---|---|---|
| 出入国法違反(罰金) | -5〜-30点 | 違反回数の累積 |
| 租税滞納 | -10点 | 納税後一定期間で回復 |
| 刑事処罰(罰金刑以上) | -10〜-50点 | 刑確定日基準 |
| 単純な過料 | 減点適用の可能性あり | 事案別判断 |

### 出入国法違反の減点で詰まる部分

出入国法違反は、本人が認識していない過去の警告処分も記録として残り、減点対象となります。

滞在期間延長の遅延で受けた過料、居所変更の未申告のような軽微な違反も減点の対象に含まれます。

実際の審査では、この部分が明るみに出て80点の通過ラインを越えられない事例が、通常もっとも多く発生します。

> **注意:** ご本人の違反履歴の確認は出入国情報公開請求で行えますが、減点への換算は[出入国・外国人政策本部](https://www.immigration.go.kr)の運営指針によって異なります。

### 税金滞納の減点が回復する時点

税金を納付したとしても、一定期間は減点が維持されます。

納付と同時に減点が消えるわけではなく、納付後に一定期間が経過してからスコアが回復します。

回復期間は事案によって分かれるため、ご本人のケース確認が必要です。

<h2 id="section-7">スコアが不足したときの挽回戦略</h2>

スコアが不足したとき、最も早い挽回経路は次の2つです。

### 韓国語スコアを上げる

TOPIKは定期試験の日程があり結果が出るまでに時間がかかりますが、KIIP 5段階の修了はご本人の進度次第で短期間に終えることができます。

特にKIIPは学歴加点とは別に、韓国語スコア + 加点が同時に確保できる項目であり、スコア挽回の効率がもっとも高くなります。

### 加点項目の補強

ボランティア時間は短期間で満たせる項目です。

海外優秀人材職種の加点は、ご本人の職業が[韓国産業人力公団 KQ認定職種](https://www.hrdkorea.or.kr)に該当するかの確認が必要です。

職種分類は毎年更新されるため、ご本人のケースが加点職種に該当するかは相談を通じてご確認ください。

<h2 id="section-8">よくある質問 FAQ</h2>

**Q1. F-2-7のスコアがちょうど80点であれば必ず通過しますか?**

A. 80点は申請資格ラインであり、通過を保証するものではありません。

審査過程で項目別の認定範囲が再調整され、スコアが下がる可能性があり、事案によっては追加書類の提出が要求されます。

**Q2. TOPIKとKIIPの両方を持っていればスコアは合算されますか?**

A. 合算はされません。

両者のうちスコアの高い方のみが認定されるため、ご自身に有利な方を選んで提出する必要があります。

**Q3. 学歴は韓国の学位でなくとも、博士であれば35点ですか?**

A. 博士学位自体は35点で同一です。

ただし国内学位の加点は別項目であるため、海外学位のみの場合は加点が抜けることになります。

**Q4. ボランティア時間はどれくらい満たせばスコアになりますか?**

A. 年間で一定時間以上の累積が必要であり、認定機関への登録が前提条件となります。

非公式のボランティアは時間が長くてもスコアには反映されません。

**Q5. 所得は本人名義の通帳残高でも認められますか?**

A. 認められません。

税務申告された勤労所得または総合所得金額を基準にのみスコアが算定されます。

**Q6. 減点があっても加点で挽回することは可能ですか?**

A. 可能なケースもあります。

ただし刑事処罰のような大きな減点は、単純な加点では相殺されないため、事案別の検討が必要です。
