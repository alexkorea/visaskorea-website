## 1. 再入境许可免除制度概述

再入境许可免除制度，是指在韩国合法居住的外国人临时出境时，无需事先申请再入境许可证，即可在签证有效期内自由出境和再入境的制度。

### 制度背景

2016年以前，长期居住韩国的外国人每次出境都必须提前申请"재입국허가"，既耗时又费钱。2016年修法后，符合条件的外国人自动适用免除，大大减轻了外国人居留者的行政负担。

### 制度目的
- 提升长期居住外国人的生活便利性
- 简化出入境行政手续
- 改善外国人生活环境

## 2. 免除对象签证类型

以下签证类型通常适用再入境许可免除制度：

| 签证类型 | 说明 |
|---------|------|
| F-1（家庭陪同） | 长期居住外国人的家属 |
| F-2（居住） | 积分制居住签证 |
| F-3（陪同） | 就业签证持有人家属 |
| F-4（在外同胞） | 海外居住韩裔外国人 |
| F-5（永久居留） | 韩国永居权持有人 |
| F-6（结婚移民） | 韩国籍配偶的外国人 |
| E-7（特定活动） | 专业就业签证 |
| D-8（企业投资） | 外国人投资者签证 |
| D-7（企业内部调动） | 驻在员签证 |

### 适用免除的基本条件

1. 持有**有效的外国人登录证**
2. 出境时签证在有效期内
3. 未受强制退出令或出入境违法处分
4. 不属于出入境管理法禁止事项

## 3. 不适用免除的情况

以下情形不适用再入境许可免除，需在出境前申请并取得再入境许可证：

### 需要办理再入境许可的情形

**签证相关**
- 外国人登录证已过期或即将过期
- 签证有效期在出境后不足1年到期
- 正处于签证变更申请审查期间

**行政处理**
- 因出入境管理法违规正在接受调查
- 曾被强制退出或受驱逐令
- 持短期签证（C-1、C-3等）在韩滞留

**其他**
- 未完成외국인등록（外国人登录）的滞留者

## 4. 出境前后的注意事项

### 出境前检查事项

1. **确认外国人登录证有效期**  
   出境前请务必核查外国人登录证的有效期。如已过期，需先完成续签方可享受免除。

2. **确认签证有效期**  
   请确保在签证有效期内能够回国。如有效期不足，建议出境前先办理续签。

3. **确认护照有效期**  
   护照有效期须涵盖在韩国境外的滞留期间及回国后的使用时间。

### 入境时的注意事项

1. **在签证有效期内入境**  
   必须在签证有效期内再次入境韩国，超期入境将被认定为非法入境。

2. **随身携带外国人登录证**  
   入境审查时需出示外国人登录证，请务必随身携带。

3. **长期出境（1年以上）的注意事项**  
   若出境时间超过1年，回国前可能需要在当地的韩国大使馆/领事馆办理相关手续。

## 6. 免除期限的计算方法

适用再入境许可免除时，免除期限通常为签证有效期届满日，但需注意以下情形：

### 基本规则

- **原则**：至签证有效期届满日止
- **注意**：若签证有效期在出境后1年内届满，请提前办理续签

### 计算示例

**案例1（无需担心）**  
签证有效期：2028年6月30日  
出境日期：2026年5月10日  
→ 有效期尚余2年以上，可放心出境。

**案例2（需注意）**  
签证有效期：2026年11月30日  
出境日期：2026年8月1日  
→ 有效期仅剩约4个月，回国后需尽快办理续签。

**案例3（建议出境前续签）**  
签证有效期：2026年6月30日  
出境日期：2026年5月15日  
→ 强烈建议在出境前完成签证续签手续。

## 7. 外国人登录证有效期与再入境

외국인등록증（外国人登录证，ARC）的有效期直接影响再入境许可免除的适用。

### 外国人登录证的更新时机

**外国人登录证有效期临近时，请在出境前务必完成更新。**

- 申请地点：管辖出入境·外国人厅（或分局）
- 申请时间：有效期届满前3个月起可申请
- 所需材料：护照、外国人登录证、证件照、申请表

### 外国人登录证过期后出境的后果

持过期外国人登录证出境，再入境时可能遭遇问题。请务必确保在外国人登录证有效期内出境。

## 8. 常见问题解答（FAQ）

### Q1. 适用免除时，出境时需要办理什么手续吗？
**A**：不需要任何特别手续。按正常流程通过机场出入境审查即可。但建议出境前事先确认外国人登录证和签证的有效期。

### Q2. 回中国探亲2个月，需要再入境许可吗？
**A**：若您持有适用免除的签证，且能在签证有效期内回国，则不需要。但若回国后即将面临签证续签，请注意时间安排。

### Q3. 在外期间签证过期怎么办？
**A**：签证过期后无法再入境韩国。需前往当地韩国大使馆/总领事馆重新申请签证，或在出境前提前完成续签。

### Q4. 出境超过6个月会有什么影响？
**A**：长期出境（特别是超过6个月）可能对韩国居留资格（尤其是住民登录相关事项）产生影响。建议提前咨询出入境·外国人厅或专业行政士。

### Q5. 再入境许可免除和普通再入境许可有什么区别？
**A**：免除制度无需任何申请，自动适用。普通再入境许可需在出境前申请并取得许可证，且需缴纳手续费。

### Q6. F-5永居权持有者也适用免除吗？
**A**：是的，F-5永居权持有者同样适用。但需注意永居权的有效期管理，长期出境（通常超过2年）可能导致永居权被撤销，建议提前咨询专业人士。

### Q7. 未完成外国人登录的外国人适用免除吗？
**A**：未完成外国人登录则不适用免除制度。在韩滞留超过90天的外国人须依法办理外国人登录。
