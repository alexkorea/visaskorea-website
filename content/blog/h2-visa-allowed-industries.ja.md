# H-2訪問就労ビザの就労許可業種と制限職種 — 2026年完全整理

H-2訪問就労ビザ所持者はすべての業種で就労することはできず、法律で許可された業種でのみ就労が認められます。
許可業種以外での就労は不法就労とみなされ、ビザ取消・強制退去の事由となります。
本記事では、2026年基準のH-2就労許可業種、禁止職種、就労教育受講義務、雇用主申告義務、違反時の処罰について実務の観点から整理します。

## H-2訪問就労ビザとは？

H-2訪問就労ビザは、中国・旧ソ連地域の同胞（在外韓国人）が韓国で就労活動を行えるよう許可するビザです。
[出入国・外国人庁](https://www.immigration.go.kr)が発行し、在留期間は最大3年（1回更新で最長4年10か月）です。
単なる訪問ではなく就労を希望する同胞のための制度で、E-9雇用許可制とは別の体系で運営されます。

H-2ビザの核心的な特徴は「業種制限方式」です。
E-9のように特定の事業場に縛られることなく、許可業種内であれば自由に転職できます。
ただし、許可業種リスト外の職種で働いた場合、即座に不法就労となります。

## 就労許可業種一覧（2026年基準）

[雇用労働部](https://www.moel.go.kr)告示基準において、H-2ビザ所持者が就労できる業種は以下のとおりです。

### 製造業

- 食料品製造業
- 繊維・衣類・靴製造業
- 紙・木材製造業
- 化学・ゴム・プラスチック製造業
- 金属・機械・電気・電子製造業
- その他製造業（従業員30名未満の事業場に限る）

### 農畜産業

- 作物栽培業（水田・畑作農業、施設園芸、特用作物）
- 畜産業（家畜飼育、と畜）
- 農業支援サービス業

### 漁業

- 沿岸・沖合漁業
- 養殖漁業
- 水産物加工・処理

### 建設業

- 建設現場の単純労務（許可事業場に限る）
- 建築仕上工事業
- 一部の土木工事業

### サービス業（許可範囲限定）

- 飲食業（調理補助・接客等の単純業務）
- 宿泊業（清掃・洗濯等の単純支援業務）
- 再生資源回収業
- 建物清掃業
- 家事サービス業（介護サービスを含む）
- 駐車場運営業
- 警備業（一部）

**重要：** 上記リストは大分類基準であり、詳細業種コード別に許可の可否が異なります。
許可業種に該当するかどうか不安な場合は、就労前に専門家とともに確認することが安全です。

## 就労禁止職種

以下の職種はH-2ビザで就労できません。

**専門職（免許・資格が必要な職種）**

- 医療職：医師・看護師・薬剤師
- 法律職：弁護士・法務士・行政士
- 教育職：教師・講師（外国語会話は別途ビザが必要）
- 公認会計士・税理士

**管理職・事務職**

- 企業役員
- 会社事務職（一般事務、経理等）
- 人事・労務管理職

**その他制限職種**

- 風俗業関連業種（E-6ビザ対象）
- アダルト娯楽・ギャンブル関連業種
- 保険設計士・証券関連営業職
- 従業員50名以上の製造業事業場（一部例外あり）

## 就労教育受講義務

H-2ビザ所持者が韓国で初めて就労する際は、就労前に必ず就労教育を受講しなければなりません。

**就労教育基本情報**

| 項目 | 内容 |
| --- | --- |
| 教育機関 | 韓国産業人力公団指定教育機関 |
| 教育時間 | 16時間（2日間のコース） |
| 教育内容 | 韓国労働法、産業安全、就労手続き等 |
| 受講時期 | 初回就労前に必須受講 |
| 費用 | 少額の自己負担（事例により異なる） |

教育を受講せずに就労した場合、不法就労とみなされます。
教育日程は[韓国産業人力公団](https://www.hrdkorea.or.kr)のウェブサイトで確認できます。
受講後に就労教育確認書が発行されますので、雇用主に提出してください。

## 雇用主の雇用・解雇申告義務

H-2ビザ外国人を雇用する事業主は、以下の申告義務を履行しなければなりません。

**雇用申告**

- 採用後14日以内
- [雇用労働部雇用許可制ポータル](https://www.eps.go.kr)またはハローワーク窓口
- 提出書類：労働契約書、外国人登録証の写し、事業者登録証の写し

**解雇・退職申告**

- 労働関係終了後14日以内
- 同機関に解雇（退職）申告
- 申告漏れ：100万ウォン以下の過料

**注意事項：** 申告なしにH-2外国人を雇用すると、不法雇用として処罰を受ける場合があります。
[雇用労働部](https://www.moel.go.kr)は近年、外国人の不法雇用に対する取り締まりを強化しています。

## 事業場変更規定

H-2ビザ所持者はE-9と異なり、許可業種内であれば比較的自由に転職できます。

**自由転職の条件**

- 新しい職場が許可業種に該当すること
- 就労教育受講済み状態の維持
- 新たな雇用主が14日以内に雇用申告を完了すること

**事業場変更後の必要手続き**

転職後、新たな雇用主が雇用センターに新規雇用申告を行えば完了です。
E-9のように別途雇用許可証の取得や変更回数の制限はありません。
ただし、許可業種以外への転職は違法であり、ビザ取消の事由となります。

## 違反時の処罰基準

**外国人労働者の違反**

| 違反類型 | 処罰 |
| --- | --- |
| 許可業種以外での就労 | ビザ取消、強制退去、入国禁止 |
| 就労教育未受講での就労 | 過料、ビザ取消 |
| 不法就労 | 強制退去、5年入国禁止 |

**雇用主（事業主）の違反**

| 違反類型 | 処罰 |
| --- | --- |
| 不法雇用（許可業種違反） | 3年以下懲役または2000万ウォン以下の罰金 |
| 雇用・解雇申告義務違反 | 100万ウォン以下の過料 |
| 就労教育未受講者の雇用 | 過料、雇用許可制限 |

実際の取り締まり事例では、許可業種を誤解して就労し、強制退去となったケースが頻発しています。
就労前に必ずご自身の業種の許可可否を確認してください。

## よくある質問（FAQ）

**Q1. H-2ビザで飲食店で働くことはできますか？**

飲食業はH-2の許可業種に含まれますが、調理補助・接客等の単純業務に限定されます。
高級レストランの正式な調理師職や管理職は該当しない場合があります。
就労前に雇用センターまたは専門家に具体的な業種コードを確認してください。

**Q2. 就労教育は一度だけ受講すればよいですか？**

H-2ビザで初めて就労する際に16時間の教育を受ければ、以降の転職のたびに再受講する必要はありません。
ただし、ビザを再発行する場合や長期帰国後に再就労する場合は、再受講が求められることがあります。
最新の規定は[韓国産業人力公団](https://www.hrdkorea.or.kr)にご確認ください。

**Q3. H-2ビザで事務職に就くことはできますか？**

一般事務職・経理・人事等の事務関連職種はH-2の許可業種に含まれません。
事務職への就労を希望される場合は、E-7特定活動ビザ等の別のビザをご検討ください。
個別の状況に合ったビザの種類は専門家との相談を通じてご確認ください。

**Q4. 雇用主が申告義務を果たさない場合、外国人労働者も不利益を受けますか？**

申告義務は原則として雇用主が負います。
ただし、不法雇用状態が継続すると、外国人労働者も不法就労者とみなされる可能性があります。
雇用主が申告を行わない場合は、雇用センターに直接申告するか、行政士の助けを求めてください。

**Q5. H-2ビザの在留期間中にF-4やF-5ビザに変更できますか？**

要件を満たしている場合、在留資格の変更が可能です。
F-4（在外韓国人）は国籍要件と居所登録要件を、F-5（永住）は在留期間・所得・犯罪歴等の複数要件を満たす必要があります。
資格があるかどうかは個別の状況によって異なりますので、専門家への相談を強くお勧めします。
