# 韩国外国人就医完整指南（2026年）：医院·医保·急诊

韩国拥有全球领先的医疗体系，外国人加入国民健康保险后可享有与韩国国民同等的医疗福利。本指南为初次在韩就医的外国人提供实用信息，帮助您顺畅使用韩国医疗服务。

## 1. 外国人国民健康保险加入

在韩国合法居留满6个月以上的外国人须强制加入国民健康保险（NHIS）。

| 项目 | 内容 |
|---|---|
| 加入条件 | 完成外国人登记且合法居留满6个月以上 |
| 加入方式 | 自动加入（在职人员）或自愿申请（地区加入者，在国民健康保险公团办理） |
| 保险费 | 根据收入或财产计算（地区加入者有最低保险费标准） |
| 福利 | 与韩国国民享有同等医疗保险福利 |
| 咨询 | 国民健康保险公团：1577-1000（提供外语服务） |

> 未加入健康保险时，须自行承担全额医疗费用。就业人员入职即自动加入；其他人员在入境6个月后自动加入。

## 2. 韩国医疗机构三级体系

| 机构类型 | 规模 | 特点 |
|---|---|---|
| 一级（诊所/医院） | 小规模 | 普通疾病（感冒、发烧等）治疗，费用低廉 |
| 二级（医院/综合医院） | 中等 | 住院、手术等专科治疗，无需转诊即可就诊 |
| 三级（高级综合医院/大学医院） | 大规模 | 重症、疑难疾病，建议持二级医院转诊信（无转诊信自付比例更高） |

> 感冒等轻症建议优先就诊一级诊所，速度快、费用低。三星首尔医院、首尔峨山医院等大型医院须提前预约。

## 3. 就诊流程

| 步骤 | 内容 |
|---|---|
| 1 | 根据症状选择科室（内科·骨科·皮肤科等） |
| 2 | 电话或APP预约（大型医院）或直接前往（诊所） |
| 3 | 挂号时出示外国人登记证或护照 |
| 4 | 确认健康保险加入情况 |
| 5 | 就诊后领取处方 |
| 6 | 在院内药房或附近药房购药 |

## 4. 外国人常用的医院类型

| 医院类型 | 特点 |
|---|---|
| 外国人专属诊所 | 提供英语/中文/日语翻译，配备多语言说明材料 |
| 大型医院国际诊疗中心 | 峨山医院、三星首尔、延世医院等设有专属国际医疗团队 |
| 社区全科诊所（家庭医学科） | 提供普通诊疗，通常无翻译（可使用翻译软件） |
| 牙科·眼科·皮肤科 | 外国人就诊较多，多为诊所级别 |

> 在Naver地图或KakaoMap上搜索"International Clinic"或"외국인 진료"，可找到外国人友好型医院。

## 5. 急诊就医方法

| 情况 | 应对方式 |
|---|---|
| 紧急情况 | 拨打119（救护车免费，提供韩语/英语口译） |
| 前往急诊 | 就近前往急诊医疗中心（24小时全天候开放） |
| 非紧急夜间就诊 | 在Naver/Kakao搜索"야간진료"（夜间诊疗）的诊所 |
| 电话咨询 | 1339急诊医疗信息中心（24小时，提供英语及外语服务） |

> 急诊室按紧急程度排队就诊。轻症患者可能等待时间较长，非紧急情况建议就诊夜间诊所。

## 7. 处方与药房使用

| 项目 | 内容 |
|---|---|
| 处方有效期 | 一般为处方日起3天内 |
| 查找药房 | 在医院附近或Naver地图搜索"약국" |
| 夜间·节假日药房 | 各地区设有轮值药房（可在韩国药剂师协会官网查询） |
| 非处方药（OTC） | 无需处方可购买：止痛药、消化药、普通感冒药等 |
| 多语言用药说明 | 可向药房要求提供中文/英文/日文用药说明书 |

## 8. 医疗费自付及省钱技巧

| 技巧 | 内容 |
|---|---|
| 优先就诊一级诊所 | 社区诊所自付比例远低于三级大医院 |
| 携带转诊信 | 持二级转三级医院转诊信可降低自付比例 |
| 免费体检 | 医保加入者每2年可享受免费健康检查（健康保险公团APP查询） |
| 购买补充医疗保险 | 民间实损医疗保险可进一步降低自付费用 |
| 选择仿制药 | 可要求以仿制药代替原研药，降低费用 |

## 9. 长期处方与慢性病管理

| 项目 | 内容 |
|---|---|
| 慢性病登记制度 | 高血压、糖尿病等慢性病登记患者可享受自付减免 |
| 长期处方 | 病情稳定者最长可一次开具90天处方 |
| 远程诊疗 | 部分情况下可进行线上诊疗（依法规调整而有所变动） |
| 病历转移 | 携带以往病历和影像CD可减少重复检查 |

## 10. 常见问题解答

**Q. 没有健康保险就医要花多少钱？**
A. 未加入医保须自付全额费用。社区诊所就诊费用约5—15万韩元，急诊就诊可达20—50万韩元以上。

**Q. 外国人可以享受免费健康检查吗？**
A. 可以。国民健康保险加入者每2年可享受一次免费健康检查。可通过健康保险APP（The Health）确认是否符合条件。

**Q. 紧急情况下不会说韩语怎么办？**
A. 拨打119后可获得英语翻译服务。1339急诊医疗信息中心全天24小时提供英语及多语言支持。大型医院急诊室通常也有英语服务人员。

**Q. 在韩国可以继续服用在国外开具的药物吗？**
A. 须经韩国医生重新评估后才能开具对应处方药。请携带原处方及用药记录，前往相应专科就诊。

**Q. 在韩国哪里可以获得心理健康咨询？**
A. 可前往精神健康医学科诊所或联系国立精神健康中心（02-2204-0200）。部分外国人社群组织也提供英语心理咨询服务。
