# 韓国E-1教授ビザ完全ガイド（2026年版）：資格・書類・在留・永住権転換

E-1（教授）ビザは、韓国の教育機関で専門的な教育や研究活動を行う外国人に発給されるビザです。4年制大学以上またはそれに準ずる教育機関で、教授・准教授・講師・研究員として活動する外国人が主な対象です。

韓国の大学に教員として採用された場合や、国公立研究機関での教育・研究活動を予定している場合は、E-1ビザが適切な選択となります。

## 1. E-1ビザとは？ {#section-1}

E-1は韓国出入国管理法上の「教授」在留資格で、韓国の高等教育機関（大学、大学院、専門大学等）で専門的な教育または研究活動を行う外国人に発給されます。

主な特徴：
- 高等教育機関またはそれに準ずる機関での教育・研究活動
- 博士号または同等水準の学歴・経歴要件
- 該当機関（大学等）がビザ招請手続きを行う
- 長期在留および永住権への転換経路あり

---

## 2. 申請資格 {#section-2}

E-1ビザを取得するには以下の要件を満たす必要があります。

### 学歴・経歴要件

| 要件 | 基準 |
|---|---|
| 最低学歴 | 該当分野の博士号 |
| 博士号に代わる経歴 | 修士号 + 該当分野5年以上の専門経歴 |
| さらなる代替 | 学士号 + 10年以上の専門経歴（一部の場合に認定） |
| 職位 | 正教授、准教授、助教授、専任講師、客員教授等 |

### 招請機関の要件

| 要件 | 基準 |
|---|---|
| 機関の種類 | 「高等教育法」に基づく大学、大学院、専門大学等 |
| 雇用契約 | 該当機関との雇用契約または招聘契約の締結 |
| 活動内容 | 講義、研究、学生指導等の教育関連活動 |

---

## 3. 招請可能な機関 {#section-3}

E-1ビザ招請が可能な機関の種類は以下のとおりです。

| 機関の種類 | 例 |
|---|---|
| 4年制大学 | ソウル大学、延世大学、高麗大学等 |
| 大学院 | 各大学附属の大学院 |
| 専門大学 | 2〜3年制の専門大学 |
| サイバー・遠隔大学 | 韓国放送通信大学、遠隔大学等 |
| 国公立教育機関 | 韓国教育開発院等の教育部所管機関 |

> **注意**：語学院、私設塾、小・中・高等学校等はE-1の招請機関に該当しません。その場合はE-2（英語原語民教師）またはE-7（特定活動）ビザを検討してください。

---

## 4. 必要書類 {#section-4}

### 申請者提出書類

| 書類 | 備考 |
|---|---|
| 査証発給申請書 | 韓国在外公館または法務部様式 |
| パスポート原本 | 有効期間6か月以上 |
| 写真 | 3.5×4.5cm |
| 履歴書 | 学歴・職歴を含む |
| 最終学位証明書 | 公証またはアポスティーユ添付 |
| 経歴証明書 | 関連機関発行 |
| 論文・研究実績一覧 | 該当する場合 |

### 招請機関提出書類

| 書類 | 備考 |
|---|---|
| 招請状 | 機関代表者または担当者の署名 |
| 雇用（任用）契約書 | 給与、職位、期間を明記 |
| 事業者登録証または機関固有番号証 | |
| 機関認可書類 | 教育部の認可または登録確認書 |

---

## 5. 申請手続き {#section-5}

1. **機関との雇用契約の締結** — 大学または研究機関との任用契約を完了
2. **招請書類の準備** — 機関が招請状および関連書類を発行
3. **在外公館または出入国・外国人庁での申請** — 海外在住の場合は韓国大使館、韓国在留中の場合は在留資格変更を申請
4. **書類審査** — 通常5〜15営業日
5. **ビザ発給または在留資格変更許可**
6. **入国及び外国人登録** — 入国後90日以内

---

## 6. 在留期間と更新 {#section-6}

| 区分 | 期間 |
|---|---|
| 初回在留期間 | 1〜2年（任用契約期間による） |
| 更新 | 契約更新時に更新可能 |
| 更新回数の制限 | 雇用契約が継続する限り特に制限なし |

雇用契約が終了した場合、他機関への異動には新たな招請書類とともに在留資格変更または更新申請が必要です。

---

## 7. 配偶者・家族の帯同 {#section-7}

E-1ビザ所持者の配偶者および未成年の子はF-3（帯同）ビザで共に韓国に在留できます。

| 区分 | 内容 |
|---|---|
| 配偶者の在留資格 | F-3（帯同） |
| 子どもの在留資格 | F-3（未成年）またはD-4/D-2（留学） |
| F-3の就労許可 | F-3は原則として就労不可——別途就労許可が必要 |

---

## 8. E-1から長期在留・永住権への転換 {#section-8}

E-1の在留期間はF-2-7ポイント制居住資格の算定に含まれ、永住権への明確な経路があります。

| 状況 | 転換経路 |
|---|---|
| F-2-7ポイント要件の充足 | F-2-7ポイント制居住資格への申請 |
| 韓国人と結婚 | F-6結婚移民 |
| F-5要件の充足 | F-5永住権の申請 |

F-2-7ポイント制居住資格は韓国語能力、年収、専門資格、在留期間等を総合点数化し、80点以上で申請資格が得られます。教授・研究職は学歴と所得の点数で有利になりやすいです。

---

## 9. E-1・E-7・D-2の比較 {#section-9}

| | E-1教授 | E-7特定活動 | D-2留学 |
|--|--|--|--|
| 対象 | 高等教育機関の教授・講師 | 指定職種の専門人材 | 大学在籍の学生 |
| 学歴要件 | 博士号または同等経歴 | 職種により異なる | 入学許可書 |
| 雇用主 | 大学・研究機関 | 韓国企業 | なし（学生身分） |
| 就労許可 | 招請機関のみ | 雇用事業主のみ | 時間制就労許可が必要 |
| 長期在留への転換 | F-2-7, F-5 | F-2-7, F-5 | 卒業後：D-10, E-7等 |

## 10. よくある質問（FAQ） {#section-10}

**Q. 博士号がなくてもE-1を取得できますか？**
A. 修士号 + 関連分野5年以上の専門経歴があれば認定される可能性があります。ただし機関によって要件が異なり、審査官の裁量も関係します。可能であれば博士号を取得してから申請する方が有利です。

**Q. 韓国語ができなくてもE-1ビザを取得できますか？**
A. 英語または他言語での授業を行う機関であれば韓国語能力は不要です。ただし、将来的にF-2-7ポイント制居住資格を目指す場合は、韓国語（TOPIK）スコアが重要になります。

**Q. E-1で他大学でも講義できますか？**
A. 原則として招請機関以外での就労活動は不可です。他大学での講義は別途就労許可の申請または在留資格変更が必要になる場合があります。

**Q. 非常勤（時間講師）契約でE-1を取得できますか？**
A. フルタイムの雇用契約でない場合、発給が難しい場合があります。非常勤・非正規契約はE-7または類似する資格審査対象となる可能性があるため、専門家への相談をお勧めします。

**Q. E-1在留中にF-5永住権を申請できますか？**
A. E-1で5年以上在留し、F-2-7ポイント制で80点以上を満たせば、F-2-7居住資格を経てF-5永住権を申請することが可能です。教職は所得・学歴の点数で有利になりやすいです。

---

## 11. 相談案内 {#section-11}

E-1教授ビザは、学歴の証明方法、招請機関の適格性、雇用契約の構造によって審査結果が大きく変わります。F-2-7ポイント制居住資格やF-5永住権への長期在留計画がある場合は、専門家への早めの相談をお勧めします。

ビジョン行政書士事務所では、E-1ビザの申請・更新、E-7特定活動ビザへの転換、F-2-7居住資格およびF-5永住権の計画まで幅広くサポートしています。
