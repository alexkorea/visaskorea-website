# 韩国F-6结婚移民签证申请手续与所需文件【2026年版】

🌐 可用流利中文沟通及处理所有行政业务的专业行政士事务所 — 飞展行政士事务所。

F-6签证（结婚移民签证）是与韩国国籍人士结婚的外国人在韩国生活所需的签证。可通过在驻外公馆（驻华韩国大使馆/总领事馆）申请，或在韩国国内办理签证类型变更两种途径获得。本文将从申请要件到所需文件、审查要点及常见问题，为您全面解析。

## 1. F-6签证概述（类型与特点）

F-6签证根据婚姻状况分为以下几种：

| 类型 | 适用对象 |
|------|---------|
| F-6-1 | 韩国国民的配偶（婚姻关系存续中） |
| F-6-2 | 与韩国国民的婚姻关系已解除，但正在抚养子女 |
| F-6-3 | 婚姻破裂非外国人本人过错（如家暴受害者等） |

### F-6签证的主要特点

- **就业自由**：几乎所有职种均可从事
- **居留期限**：首次通常为1年，续签后可延至2〜3年
- **走向F-5永居权**：婚姻持续并在韩居住，可申请永居权
- **子女入籍**：与韩国人所生子女可取得韩国国籍

## 2. F-6签证申请要件

### 基本要件

1. **有效婚姻关系**：须已在韩国家族关系登录（가족관계등록부）中登记婚姻
2. **合法婚姻**：须符合双方国家法律规定的有效婚姻
3. **经济能力（초청인 수입）**：韩国籍配偶须具有稳定收入
4. **无资格缺失事由**：无犯罪记录、出入境违规、强制退出记录

### 韩国籍配偶方的要件

- 持有韩国国籍
- 符合一定收入标准（非기초수급자）
- 近5年内无配偶暴力等犯罪记录

### 초청 횟수 제한（邀请次数限制）

韩国国籍人士通过结婚移民签证邀请外国人配偶的次数有限制。如有过往邀请记录，请提前确认。

## 3. 申请途径

F-6签证可通过以下两种途径申请：

### 途径一：驻外公馆申请（在中国申请）

在中国的韩国大使馆/总领事馆申请F类签证，取得签证后赴韩入境。

**适合情形**
- 目前在中国居住的人士
- 在韩国无其他签证的人士
- 新近完成结婚登记的人士

### 途径二：韩国境内签证类型变更

已在韩国境内以其他签证合法居留的人士，可在出入境·外国人厅办理变更为F-6手续。

**适合情形**
- 目前持其他签证（如E-7、D-2等）在韩居留中的人士
- 已在韩国境内完成婚姻登记的人士

## 4. 所需文件详细清单

### 共同必备材料

- ✅ 사증발급신청서（签证申请表）
- ✅ 申请人护照（原件）
- ✅ 证件照（3.5cm×4.5cm）
- ✅ 신원보증서（身份担保书）：韩国籍配偶签署
- ✅ 가족관계증명서（家庭关系证明书）：韩国籍配偶的（3个月内）
- ✅ 혼인관계증명서（婚姻关系证明书）：韩国籍配偶的
- ✅ 결혼사실증명서（婚姻事实证明书）：外国人申请人本国出具

### 申请人（外国人）一方的材料

- ✅ 婚姻证明文件（中国：结婚证 + 公证书）
- ✅ 结婚纪念照片（多张）
- ✅ 범죄경력조회 답변서（无犯罪记录证明）：本国出具，需海牙认证（Apostille）
- ✅ 건강진단서（健康诊断书）：指定医疗机构出具

### 韩国籍配偶一方的材料

- ✅ 주민등록등본（住民登录謄本）
- ✅ 소득금액증명원（收入证明书）
- ✅ 근로소득 원천징수영수증（扣缴证明）或사업자등록증（营业执照）
- ✅ 韩国籍配偶护照复印件

### 追加材料（视情况需要）

- 韩语教育修了证明书或면접조서（面试记录）
- 韩语能力证明（TOPIK等）
- 两人交往证明材料：聊天记录截图、照片等

## 5. 在中国办理申请（驻外公馆申请）

### 申请地点

在中国境内的韩国大使馆/总领事馆办理申请。

| 公馆名称 | 管辖地区 |
|---------|---------|
| 驻华韩国大使馆（北京） | 华北、华中 |
| 驻上海韩国总领事馆 | 华东 |
| 驻广州韩国总领事馆 | 华南 |
| 驻成都韩国总领事馆 | 西南 |
| 驻青岛韩国总领事馆 | 山东、华北部分 |
| 驻沈阳韩国总领事馆 | 东北地区 |
| 驻武汉韩国总领事馆 | 中南地区 |
| 驻西安韩国总领事馆 | 西北地区 |

### 申请流程

1. **材料准备**（2〜4周）  
   结婚证公证书、无犯罪记录证明等获取耗时，建议提前准备。

2. **预约·提交申请材料**  
   前往大使馆/总领事馆窗口提交（部分公馆需预约）。

3. **审查·面试**（2〜12周）  
   材料审核后可能安排面试。

4. **签证发放·赴韩入境**  
   取得签证后，从中国赴韩国入境。

### 处理时间参考

- 正常情况：4〜8周
- 材料不齐：可能需要更长时间

## 6. 在韩国境内申请手续

### 申请地点

管辖的출입국·외국인청（出入境·外国人厅）或分局

### 申请流程

1. 在现有签证有效期内提交申请
2. 将全部材料提交至窗口
3. 审核期间以现有签证资格继续居留
4. 获得许可通知后，更新外国人登录证

## 7. 面试审查须知

F-6签证审查过程中，可能会进行**면접（面试）**，以核实婚姻关系的真实性。

### 面试常见问题

- 与配偶相识的经过及交往时间
- 婚礼日期、地点和出席人员
- 配偶的家庭成员构成、职业、兴趣爱好
- 两人日常生活（居住地、日常习惯等）
- 未来生活规划

### 面试准备建议

- 整理好交往期间的聊天记录和照片
- 提前了解配偶家庭成员信息（出生日期、家庭关系等）
- 准确记住中韩两国婚姻登记的时间地点
- 保持表达自然、一致，与书面材料相符

## 8. 取得F-6签证后的手续

### 외국인등록（外国人登录）

入境韩国后须在90日内，前往管辖의 출입국·외국인청（出入境·外国人厅）完成外国人登录。

### 정착안내프로그램（定居指导计划）

首次申请F-6-1签证的结婚移民人士，可能被要求参加사회통합프로그램（社会融合计划）。

### 재류기간 연장（居留期限续签）

- 首次许可：通常为1年
- 续签：可延长至2〜3年
- 婚姻关系的存续和在韩居住是续签的前提条件

## 9. F-6走向F-5（永居权）

持F-6签证在韩居住一定期限后，可申请F-5永居权。

### F-5申请的主要条件（结婚移民路径）

| 条件 | 内容 |
|------|------|
| 居住期限 | 与韩国国民婚姻并在韩居住满2年 |
| 婚姻存续 | 与韩国国籍配偶婚姻关系持续 |
| 生计维持能力 | 具有独立生活能力 |
| 基本韩语能力 | 具备基本韩语沟通能力 |
| 无犯罪 | 无犯罪记录及出入境违规 |

## 10. 常见问题解答（FAQ）

### Q1. 在中国办理结婚登记后，还需要在韩国登记吗？
**A**：是的。在中国完成结婚登记后，还需要向驻华韩国大使馆或韩国国内的市区镇（동사무소）申报혼인신고（婚姻申报），将婚姻登记至韩国家族关系档案。

### Q2. F-6签证申请中，可以来韩国探视配偶吗？
**A**：申请期间可凭有效签证入境韩国。如有顾虑，欢迎向飞展行政士事务所咨询，我们可协助确认申请进度。

### Q3. 可以免面试取得F-6签证吗？
**A**：材料完备的情况下，有时仅凭书面审查即可获批。但审查官认为必要时仍会安排面试，充分的材料准备是免面试的关键。

### Q4. F-6签证申请被拒怎么办？
**A**：收到不许可通知后，需确认原因并采取相应对策。飞展行政士事务所也承接签证被拒后的再申请支持服务。

### Q5. 生了孩子，孩子的签证怎么办？
**A**：若父或母为韩国人，孩子有资格取得韩国国籍。若为外国国籍，则需办理F-1（家属陪同）签证。

### Q6. 离婚后还能继续持F-6签证居留吗？
**A**：F-6-1（配偶签证）在离婚后失效。但若正在抚养子女，可变更为F-6-2；若属于家暴受害情形，可变更为F-6-3。请向专业人士咨询。

## 中韩两国婚姻登记手续详解

与韩国人结婚，需同时在中国和韩国完成婚姻登记手续。

### 在中国的手续

1. **向民政局（婚姻登记处）申请结婚登记**
   - 中韩双方当事人到场
   - 携带韩国籍配偶的有效护照及혼인관계증명서（婚姻关系证明书）等材料

2. **向驻华韩国大使馆/总领事馆申报혼인신고（婚姻申报）**
   - 在中国完成结婚登记后，向韩国家族关系登录档案进行申报
   - 所需材料：中国结婚证公证书等

### 在韩国的手续（配偶在韩时）

1. 向管辖市区郡政府提交婚姻申报
2. 取得F-6签证后办理외국인등록（外国人登录）

### 注意事项

中韩双方同步推进手续，可尽早备齐F-6签证申请所需文件，缩短整体办理周期。

## 生活实用信息

### 国民健康保险

取得F-6签证并完成外国人登录后，须加入国民健康保险（부분 자동가입）。

### 银行开户

持有效外国人登录证，可在韩国各大银行开立账户，方便日常金融业务。

### 子女教育

韩国为外国人子女提供义务教育保障，结婚移民者子女同样可享受平等的教育权利。
