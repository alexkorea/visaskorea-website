# 韩国D-10求职签证完整指南（2026年）：申请·资格·就业签证转换

## 1. 什么是D-10求职签证？

D-10（求职）签证是允许外国人在韩国合法从事求职活动的居留资格。在未确定就业单位的情况下，提供在韩国进行求职准备的时间。

| 项目 | 内容 |
|---|---|
| 签证类型 | D-10（求职） |
| 允许活动 | 求职准备、求职活动、实习（以就业为目的） |
| 有效期 | 最长6个月（可延期，最长1—2年） |
| 就业情况 | 未获得就业签证前不得从事有薪工作 |

## 2. D-10签证细分类型

| 类型 | 对象 |
|---|---|
| D-10-1 | 韩国境内大学（院）毕业或即将毕业者 |
| D-10-2 | 海外优秀人才·专业人士（含KOTRA、产业部推荐等） |

## 3. 申请资格要求

### D-10-1（韩国大学毕业生）

| 要求 | 具体内容 |
|---|---|
| 学历 | 韩国认可大学（院）毕业或即将毕业（学士及以上） |
| 专业 | 建议所学专业与求职方向相关 |
| 韩语能力 | TOPIK等官方语言成绩可加分 |

### D-10-2（海外优秀人才）

| 要求 | 具体内容 |
|---|---|
| 学历 | 海外大学（院）毕业（学士及以上） |
| 经历 | 相关领域专业经历或推荐机构推荐 |
| 收入预期 | 预期薪资须高于目标职位最低工资标准 |

---

## 4. 允许活动范围

| 活动 | 是否允许 |
|---|---|
| 参加求职面试 | 允许 |
| 投递简历、在猎头公司登记 | 允许 |
| 以就业为目的的实习（含部分有薪） | 有条件允许 |
| 有薪就业（正式雇用） | 不允许（须转换为就业签证） |
| 自由职业·经营业务 | 不允许 |

> 持D-10签证从事有薪工作，可能导致签证被取消并被追究非法就业责任。务必转换为就业签证（E系列）后再开始工作。

## 6. 签证申请流程

| 步骤 | 内容 |
|---|---|
| 1 | 在韩境内：向出入境外国人厅申请居留资格变更（如D-2→D-10） |
| 2 | 在海外申请：向韩国大使馆/领事馆申请签证发放认定书 |
| 3 | 入境后90天内办理外国人登记（海外申请者） |
| 4 | 持D-10签证开始求职活动 |
| 5 | 确认就业单位后，申请转换为就业签证（E系列） |

---

## 7. 求职期限及延期

| 项目 | 内容 |
|---|---|
| 首次许可期限 | 6个月 |
| 可延期时间 | 每次最多延长6个月（合计最长1年） |
| D-10-1特例 | 韩国大学毕业生最长可允许2年（学业优秀及韩语能力优先） |
| 延期条件 | 须提供积极求职活动的证明（申请记录、面试确认书等） |

> 若无法证明求职活动记录，或求职行为被认定为不认真，延期申请可能被拒。

## 8. 转换为就业签证（E系列）

确认就业单位后，申请转换为以下相应就业签证类型。

| 就业签证 | 对应职种 |
|---|---|
| E-1 | 大学专任讲师及以上教职 |
| E-2 | 外语会话讲师（英语等7国） |
| E-3 | 研究领域（企业·研究所） |
| E-4 | 技术指导（特殊技术持有者） |
| E-5 | 专业职业（持韩国国家资格的医生、律师、会计师等） |
| E-6 | 艺术演艺（体育·演出·广播等） |
| E-7 | 特定活动（IT·金融·经营等特殊技术人才） |

> 转换时，雇主（公司）须提供邀请函及标准劳动合同。

## 9. 转换为F-2-7积分制居住签证

持D-10签证且积分足够的申请人，即使尚未确认就业单位，也可申请F-2-7积分制居住签证。

| 加分项目 | 主要基准 |
|---|---|
| 年龄 | 25—29岁得分最高 |
| 学历 | 韩国大学院博士学位加分最高 |
| 韩语能力 | TOPIK 6级=最高加分 |
| 在韩收入·就业 | 额外加分 |
| 居留期限 | D-2在校期间也可计入 |

> F-2-7申请须达到80分以上。详情请参阅[F-2-7积分制居住签证指南](/zh/blog/f2-7-points-based-residence-visa-guide)。

## 10. 常见问题解答

**Q. 持D-10签证可以做兼职工作吗？**
A. 原则上D-10签证不允许有薪就业。但以就业为目的的实习在某些情况下可有条件允许，建议提前向出入境外国人厅确认。

**Q. 持D-2留学签证毕业后可以直接转换为D-10吗？**
A. 可以。D-2持有者毕业后可在出入境外国人厅办理居留资格变更为D-10。在毕业前持预计毕业证明也可提前申请转换。

**Q. 如何从海外申请D-10签证？**
A. 海外居住者可向当地韩国大使馆/领事馆申请D-10签证。非韩国大学毕业者（D-10-2）通常须先获取签证发放认定书。

**Q. D-10签证到期前还未找到工作怎么办？**
A. 须出境或转换为其他居留资格。可转换为旅游签证（B-2）或语言进修签证（D-4）等，但无法无限期延期。

**Q. D-10居留期间是否计入F-5永久居留申请期间？**
A. D-10属于合法居留期间，因此计入总居留期限。但在F-2-7或F-5的"就业期间"要求中可能不被计入，请务必核实各签证类型的具体标准。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
