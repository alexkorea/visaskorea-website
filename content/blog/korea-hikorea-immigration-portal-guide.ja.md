# ハイコリア（Hi Korea）完全ガイド（2026年）：外国人出入国ポータルサービス総まとめ

ハイコリア（Hi Korea、hikorea.go.kr）は、韓国法務部出入国・外国人政策本部が運営する外国人専用のオンライン行政ポータルです。外国人登録・在留期間延長・在留資格変更など、出入国関連の手続きをオンラインで申請でき、入国管理局への直接訪問なしに処理できる場合が多くあります。

## 1. 会員登録とログイン {#section-1}

| 項目 | 内容 |
|---|---|
| サイトURL | hikorea.go.kr |
| 対応言語 | 韓国語・英語・中国語・日本語・ベトナム語など多言語対応 |
| 会員登録条件 | 外国人登録番号保有者またはパスポート・ARC認証 |
| ログイン方法 | ID/パスワードまたは公動認証書（공동인증서） |
| モバイル利用 | モバイルウェブ対応（専用アプリなし） |

**会員登録の手順：**
1. hikorea.go.kr にアクセス → 【会員登録】をクリック
2. 外国人登録番号またはパスポート情報を入力
3. 本人認証（SMS認証または公動認証書）
4. IDとパスワードを設定して登録完了

## 2. 主なオンラインサービス一覧 {#section-2}

| サービス | オンライン可否 |
|---|---|
| 外国人登録（初回） | ✅ 可能（入国後90日以内） |
| 在留期間延長 | ✅ 可能 |
| 在留資格変更 | ✅ 可能（一部資格） |
| 再入国許可申請 | ✅ 可能 |
| 勤務先変更・追加申告 | ✅ 可能 |
| 外国人登録証再発行（紛失・毀損） | ✅ 可能 |
| 出入国記録照会 | ✅ 可能 |
| 在留資格確認 | ✅ 可能 |
| 査証発給認定書申請（招待者向け） | ✅ 可能 |
| 帰化・永住権申請 | ❌ 入国管理局への訪問が必要 |
| 外国人登録証の初回受取 | ⚠️ オンライン申請後、直接受取が必要 |

## 3. 外国人登録の申請方法 {#section-3}

| ステップ | 内容 |
|---|---|
| 1 | ログイン → [民願申請] → [外国人登録] |
| 2 | 個人情報・パスポート情報・在留資格を入力 |
| 3 | 申請書および書類をオンラインで提出 |
| 4 | 手数料の支払い（クレジットカードまたは口座振替） |
| 5 | 処理状況の確認 |
| 6 | 完了後、入国管理局で外国人登録証を受取（訪問必要） |

**必要書類：**
- パスポート原本
- 証明写真1枚（3.5×4.5cm）
- 在留目的の証明書類（在職証明書・学生証・事業者登録証など）
- 手数料：30,000ウォン

> 外国人登録は入国後90日以内に申請する必要があります。遅れると過料が科される場合があります。

---

## 4. 在留期間延長の申請方法 {#section-4}

| ステップ | 内容 |
|---|---|
| 1 | ログイン → [民願申請] → [在留期間延長] |
| 2 | 在留資格と現在の満了日を確認 |
| 3 | 延長理由と書類をアップロード |
| 4 | 手数料を支払う |
| 5 | SMS・メールで処理結果を受取る |

**申請可能期間：** 在留期間満了日の4か月前から当日まで

**手数料：** 在留資格により60,000〜120,000ウォン

> 満了日を過ぎての国内在留は不法在留となります。必ず期間内に申請してください。

---

## 5. 在留資格変更の申請方法 {#section-5}

| ステップ | 内容 |
|---|---|
| 1 | ログイン → [民願申請] → [在留資格変更] |
| 2 | 現在の資格と変更希望の資格を選択 |
| 3 | 必要書類を添付 |
| 4 | 手数料を支払う |
| 5 | 審査結果を待つ（平均2〜4週間） |

**注意事項：**
- すべての在留資格変更がオンライン対応ではない（一部は訪問が必要）
- 審査中は現在の資格で引き続き在留可能
- 不許可の場合は異議申し立てまたは再申請が可能

---

## 6. 再入国許可の申請方法 {#section-6}

| 項目 | 内容 |
|---|---|
| 対象 | 国内在留中に一時出国・再入国を希望する外国人 |
| 単数再入国許可 | 1回の出国・入国を許可 |
| 複数再入国許可 | 許可期間内の複数回の出入国を許可 |
| 申請方法 | ハイコリアのオンライン申請または入国管理局への訪問 |
| 手数料 | 単数：30,000ウォン / 複数：50,000ウォン |

> F-5（永住権）保有者や一部のF-4保有者は、再入国許可なしに出国・再入国できる場合があります。在留資格ごとに確認してください。

## 8. ハイコリア活用のコツ {#section-8}

| コツ | 内容 |
|---|---|

## 9. よくある質問（FAQ） {#section-9}

**Q. 外国人登録はハイコリアで完全にオンライン完結できますか？**
A. 申請書の提出はオンラインで可能ですが、外国人登録証の受取には入国管理局への訪問が必要です。

**Q. 在留期間延長はいつから申請できますか？**
A. 在留期間満了日の4か月前から申請できます。少なくとも1か月前には申請することをお勧めします。

**Q. 外国人登録証なしでハイコリアのアカウントを作れますか？**
A. パスポートによる本人認証が可能な場合もありますが、利用できるサービスが制限される場合があります。

**Q. ハイコリアを日本語で使えますか？**
A. はい。ウェブサイト右上の言語切替メニューから日本語を選択できます。

**Q. オンライン申請が却下された場合はどうすればいいですか？**
A. [マイ申請内訳] で却下理由を確認し、書類を補完して再申請してください。複雑なケースは行政書士などの専門家への相談をお勧めします。
