## 1. 韓国就労ビザの概要

韓国で就労するためには、その職種・雇用形態・国籍に応じた適切なビザが必要です。主要な就労ビザの概要は以下の通りです。

| ビザ | 名称 | 対象者 |
|------|------|--------|
| E-7 | 特定活動 | 専門職・高度人材 |
| E-9 | 非専門就業 | 非熟練外国人労働者 |
| H-2 | 訪問就業 | 海外在住韓国系外国人 |

その他の就労関連ビザには、E-1（教授）、E-2（英語指導）、E-3（研究）、E-4（技術指導）、E-5（専門職業）、E-6（芸術興行）なども存在します。

## 2. E-7ビザ（特定活動）の詳細

### E-7ビザとは

E-7ビザは、韓国の法務部が指定する「特定活動」に従事するための専門職ビザです。高度な技術・知識を持つ専門人材を対象としており、韓国政府が必要と認める職種に限定されています。

### 対象となる主な職種

E-7ビザで就労できる職種は、法務部が定める**別表**（약 186種類）に基づいており、主に以下のような分野が対象です。

| 分野 | 職種例 |
|------|--------|
| IT・テクノロジー | ソフトウェア開発者、データサイエンティスト、AI研究者 |
| 製造・エンジニアリング | 機械エンジニア、電気・電子技術者、品質管理 |
| 医療・ヘルスケア | 医師、歯科医師、間護師（一部） |
| 教育・研究 | 語学講師（英語以外）、研究員 |
| ビジネス・金融 | 国際業務担当者、外国人投資家支援 |
| 文化・クリエイティブ | デザイナー、映像制作、通訳・翻訳 |

### E-7ビザの申請要件

| 要件 | 内容 |
|------|------|
| 学歴 | 関連分野の학사（学士）以上、または동등한 경력（同等の経歴） |
| 経験 | 関連職歴1〜2年以上（職種により異なる） |
| 雇用主 | 韓国国内の適法な事業者との雇用契約 |
| 급여（給与） | 最低賃金基準以上（職種により設定額あり） |

### E-7-4（熟練技能人材）

E-7には特別な区分として**E-7-4**（숙련기능인력点数制）があります。E-9・H-2での就労経験者が、一定の点数を達成することでE-7-4に移行できる制度です。

### E-7ビザの特徴

- **在留期間**：最初1年、更新で2〜3年に延長可能
- **가족 동반**：家族をF-1（家族同伴）ビザで呼び寄せ可能
- **직종 변경**：職種変更時は在留資格の変更申請が必要
- **F-2・F-5への道**：長期勤続でF-2居住ビザやF-5永住権の申請対象に

## 3. E-9ビザ（非専門就業）の詳細

### E-9ビザとは

E-9ビザは、韓国の雇用許可制（고용허가제, EPS）に基づいて発給される非熟練外国人労働者向けビザです。日本人は通常E-9の対象外ですが、制度の理解として解説します。

### 対象国

E-9の対象は、韓国政府と二国間協定を締結した16カ国（フィリピン・ベトナム・インドネシア・スリランカ・モンゴル・タイ・ウズベキスタン・パキスタン・カンボジア・中国・バングラデシュ・ネパール・キルギス・ミャンマー・東ティモール・ラオス）です。

### 就労可能業種

- 製造業（중소기업 제조업）
- 建設業
- 農業・漁業
- サービス業（一部）

### E-9ビザの特徴

| 項目 | 内容 |
|------|------|
| 在留期間 | 最初3年、1年10ヶ月の延長可能 |
| 事業場変更 | 原則3回まで変更可能 |
| 가족 동반 | 不可（家族帯同不可） |
| 최저임금 | 最低賃金適用 |

## 4. H-2ビザ（訪問就業）の詳細

### H-2ビザとは

H-2ビザは、中国・旧ソ連地域に居住する韓国系外国人（在外同胞）を対象とした訪問就業ビザです。日本の재일韓国人（在日韓国人）でF-4（在外同胞）ビザを持てない方の中には、H-2の対象となるケースもあります。

### 申請対象者

- 조선족（朝鮮族）：中国の朝鮮族
- 고려인（高麗人）：中央アジアや旧ソ連圏の韓国系
- 대상 국가는 한정됨（対象国は限定）

### 就労可能業種

H-2は就労可能業種が限定されており、主に単純・非熟練職種となります。

| 就労可能 | 就労不可 |
|--------|---------|
| 製造業 | 専門職（医療・法律等） |
| 建設業 | 管理職 |
| 農業・漁業 | 教育関連 |
| 飲食・宿泊業 | 金融・保険 |

### H-2ビザの特徴

| 項目 | 内容 |
|------|------|
| 在留期間 | 最初1年、最長3年 |
| 취업 신고 | 雇用センター（고용센터）への就業申告が必要 |
| 자유로운 직업 변경 | 同一業種内での転職は比較的自由 |
| F-4への移行 | 条件充足でF-4（在外同胞）への変更も可能 |

## 6. どのビザを選ぶべきか

### 日本人の場合

日本人が韓国で働く場合、E-9は対象外のためE-7が主な選択肢となります。

**E-7を選ぶべき状況**
- 専門職（IT・エンジニアリング・通訳・デザイン等）に就く場合
- 韓国企業からのスポンサードを受けている場合
- 長期安定的に韓国でキャリアを築きたい場合
- 将来的に永住権を目指している場合

### E-7取得が難しい場合の代替ルート

- **D-10**（求職ビザ）：求職活動をしながら雇用先を探す
- **D-8**（企業投資ビザ）：独自に法人設立して韓国に滞在する
- **F-2-7**（点数制居住ビザ）：一定の点数を満たせば就労自由なビザを取得

## 7. 各ビザから長期ビザへの移行

### E-7 → F-2-7（居住ビザ）

E-7ビザで一定期間就労後、F-2-7点数制居住ビザに移行することができます。F-2-7取得後は職種・雇用主の制限なく自由に就労できます。

### E-7 → F-5（永住権）

E-7ビザで5年以上滞在（うち3年以上E-7）かつ소득（一定所得）がある場合、F-5永住権の申請が可能です。

### E-9・H-2 → E-7-4（숙련기능인력）

E-9またはH-2での就労経験者が、점수제（点数制）を通じてE-7-4に移行できます。E-7-4取得後は専門就業ビザとして扱われ、F-2やF-5への道が開けます。

## 8. 申請手続きと必要書類

### E-7ビザ申請の主な書類

| 書類 | 説明 |
|------|------|
| 사증발급인정서（ビザ発給認定書） | 韓国の雇用主が法務部に申請 |
| 고용계약서（雇用契約書） | 雇用主との契約書 |
| 학위증 및 경력증명서（学位・経歴証明書） | アポスティーユ等の認証が必要な場合あり |
| 파스포트（パスポート） | 有効なパスポート |
| 범죄경력조회 답변서（犯罪経歴証明書） | 본국 발행（本国発行） |

### E-7ビザ申請の流れ（日本から申請の場合）

1. **雇用主が법무부에 사증발급인정신청（法務部に사증발급認定申請）**
2. **사증발급인정서 발급（ビザ発給認定書発行）**：2〜4週間
3. **在外公館（駐日韓国大使館等）に申請書・インテグレーション書類提出**
4. **審査・ビザ発行**
5. **韓国入国・外国人登録**

## 9. よくある質問（FAQ）

### Q1. 日本人はH-2ビザを申請できますか？
**A**: 通常、日本人はH-2ビザの対象外です。ただし、在日韓国人・在日朝鮮人の方は条件によりH-2またはF-4の対象となる場合があります。専門家にご確認ください。

### Q2. E-7ビザを自分で申請できますか？
**A**: E-7ビザは韓国の雇用主側が主体となって申請します。雇用主が法務部に対して사증발급인정申請（ビザ発給認定申請）を行う必要があります。

### Q3. E-7ビザでフリーランスとして働けますか？
**A**: E-7は原則として雇用契約に基づくビザです。フリーランス・個人事業主として活動したい場合は、D-9（貿易経営）やD-8（企業投資）などが適している場合があります。

### Q4. E-7ビザで韓国に来てから転職したい場合はどうすればよいですか？
**A**: E-7での転職は職種変更を伴う場合に在留資格変更が必要です。同一職種への転職の場合も、雇用主変更の申告が必要です。手続きについてはVISION行政書士事務所にご相談ください。

### Q5. E-7-4（숙련기능인력）とE-7の違いは何ですか？
**A**: E-7は専門職ビザで学歴・経歴要件が主な条件です。E-7-4はE-9・H-2での就労経験者が점수제（点数制）を通じて取得できる숙련기능인력（熟練技能人材）向けのビザで、現場職の経験者にも門戸が開かれています。

### Q6. ビザ申請が不許可になった場合はどうすればよいですか？
**A**: 不許可通知を受け取ったら、理由を確認し対策を講じます。VISION行政書士事務所では不許可後の再申請サポートも承っております。
