# 韓国F-2-7ポイント制長期在留ビザ申請完全ガイド 2026

F-2-7（居住・ポイント制）ビザは、学歴・収入・年齢・韓国語能力などを点数化し、合計80点以上の外国人専門人材に長期在留を認める資格です。就労制限がなく、最大3年の在留が可能です。

---

## 1. F-2-7ビザとは？

F-2-7は専門人材向けのポイント制居住ビザです。就労制限がなく、すべての職種での就労が可能です。

- **対象者：** 韓国に合法的に在留する外国人専門人材
- **在留期間：** 初回1〜3年（更新可能）
- **就労制限：** なし（全職種就労可）
- **家族同伴：** 配偶者・未成年の子はF-3同伴ビザで申請可能

---

## 2. ポイント評価基準（合計120点中80点以上で申請可能）

| 評価項目 | 最高点 |
|---------|-------|
| 年齢（25〜29歳が最高得点） | 20点 |
| 学歴（理工系修士以上優遇） | 35点 |
| 収入（GNI比） | 20点 |
| 韓国語能力（TOPIK） | 10点 |
| 国内在留歴 | 15点 |
| 加点（資格証・投資・社会奉仕等） | +10点 |
| 減点（出入国法違反等） | 最大−20点 |

**80点以上で申請資格が得られます。** 書類準備前に自己採点することが重要です。

---

## 3. 申請要件

- **合法的在留：** 有効な在留資格・外国人登録証保有
- **収入：** 直近1年の年収がGNI以上（約4,200万ウォン水準）
- **在留実績：** 国内1年以上の在留
- **犯罪歴なし**

---

## 4. 必要書類

| 書類 | 備考 |
|------|------|
| 在留資格変更申請書 | 出入国・外国人庁の様式 |
| パスポート原本＋外国人登録証 | |
| 学位証明書＋翻訳文 | アポスティーユまたは公証が必要 |
| 卒業証明書 | |
| 収入関連書類（源泉徴収票・納税証明書） | 直近1年分 |
| 在職証明書または事業者登録証 | |
| TOPIK成績証明書 | 該当者のみ |
| 資格証の写し | 該当者のみ |
| ポイント自己計算表 | |

---

## 5. 申請手順

1. **ポイント自己計算** — 出入国・外国人庁の採点表を使用するか、行政士に相談
2. **書類準備** — 学歴・収入・語学証明書類を収集
3. **申請書提出** — 管轄の出入国・外国人庁へ持参、またはHiKoreaからオンライン申請
4. **審査・結果待ち** — 通常2〜4週間
5. **F-2-7発給後** — 就労制限なしで長期在留スタート

---

## 6. F-2-7からF-5（永住権）への転換

F-2-7で3年以上在留した後、F-5（永住権）の申請資格が得られます。

- **在留期間：** F-2-7での3年以上の在留
- **収入：** GNI以上を維持
- **納税義務：** 未納なし
- **法律違反なし**

F-5取得後は在留期間の更新が不要となり、永続的な在留が可能です。

---

## 7. よくある質問

**Q. 現在E-7ビザです。F-2-7に変更できますか？**
A. はい。有効な在留資格を持ち、ポイント要件を満たしていれば在留資格変更申請が可能です。

**Q. ポイントはどうやって計算しますか？**
A. 出入国・外国人庁のウェブサイトで提供している採点表を使用するか、行政士に相談して正確に算出できます。

**Q. 韓国語が話せなくても申請できますか？**
A. 申請自体は可能です。TOPIK項目の得点は0点になりますが、他の項目で80点以上に達すれば申請できます。
