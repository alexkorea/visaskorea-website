# 韓国F-5永住権申請完全ガイド2026

F-5永住権は、定期更新なしに韓国に無期限滞在できる資格です。

## 主な取得経路

| 経路 | 主な要件 |
|------|---------|
| F-5-1（長期滞在） | 合法滞在5年以上 |
| F-5-7（在外同胞） | F-4 + 2年以上 + 資産3億ウォン |
| F-5-16（ポイント制） | F-2-7 + 3年 + 所得GNIの2倍 |
| F-5-18（高額投資） | 5億ウォン以上の直接投資 |

## 申請手順
1. 資格要件の確認
2. 書類準備（4〜6週間）
3. 管轄出入国管理局への申請
4. 審査（4〜12週間）
5. F-5在留カード受領
