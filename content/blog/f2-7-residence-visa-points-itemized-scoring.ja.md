# F-2居住ビザポイント制 項目別スコア計算法 完全ガイド

F-2居住ビザのポイント制は、120点満点中80点以上で申請可能となり、どの項目で点数を確保するかによって合格ラインが大きく分かれます。
対象は韓国国内に5年以上滞在中の専門職、留学生出身者、E-7などの長期就労者で、韓国語能力と所得が基本軸となります。
以下では年齢・学歴・韓国語・所得・滞在期間など、すべての配点項目を実際の審査基準に沿って整理します。

<h2 id="section-1">F-2居住ビザポイント制の基本構造と通過ライン</h2>

### ポイント制の総点と合格基準

F-2-7は[出入国・外国人政策本部](https://www.immigration.go.kr)告示基準で運用されているポイント制です。
120点中80点以上で申請が可能であり、50点未満の場合は自動的に不合格処理となります。
実務上は、80点をやっと超えた申請者よりも、90点台の申請者の方が審査官の裁量で有利になります。

まず確認すべきは、自分がどの項目で強く、どの項目が不足しているかという点です。
通常は学歴と韓国語で基礎点を固め、所得と滞在期間で加点を埋めていく構造になります。

### 基本項目と加点項目の区分

スコアは大きく**基本項目**と**加点・減点項目**に分かれます。

| 区分 | 詳細項目 | 最大配点 |
| --- | --- | --- |
| 基本項目 | 年齢、学歴、韓国語能力、所得、滞在期間 | 100点 |
| 加点項目 | 社会奉仕、ボランティア、KIIP修了、優秀人材 | 20点 |
| 減点項目 | 出入国法違反、税金滞納、刑事処罰 | 最大 –20点 |

加点項目は一気にスコアを引き上げられるため、80点未満の申請者にとって決定的なカードとなります。
特に[社会統合プログラム(KIIP)](https://www.socinet.go.kr)の修了段階はスコアに直結します。

<h2 id="section-2">年齢・学歴のスコア計算法</h2>

### 年齢項目の配点

年齢は申請時点の満年齢が基準で、30代前半が最も高い配点を獲得します。

| 年齢層 | 配点 |
| --- | --- |
| 満18~24歳 | 比較的低い点数 |
| 満25~29歳 | 中位の点数 |
| 満30~34歳 | 最高配点帯 |
| 満35~39歳 | 中上位の点数 |
| 満40~50歳 | 段階的に減少 |
| 満51歳以上 | 最低点数 |

実際の審査では、満30代前半が学歴・所得と組み合わさり、スコアが最も積み上がりやすい層となります。
年度ごとに細部の配点が調整されますので、ご自身の年齢層に対応する今年の正確な点数は、個別相談でご確認ください。

### 学歴項目の配点

学歴は最終学位を基準とし、韓国国内の学位と海外の学位で扱いに差があります。

- 博士号保持者:最高点
- 修士号保持者:上位点
- 学士号保持者:中位点
- 専門学士:基礎点
- 高卒以下:点数なし

韓国国内の学位に対する加算は別途行われます。
**韓国国内の大学で学位を取得した場合は加点が追加**され、これは留学生出身者にとって大きな武器となります。
むしろ海外の博士よりも、韓国国内の修士の方が合計点で上回るケースも珍しくありません。

<h2 id="section-3">韓国語能力のスコア計算法</h2>

### TOPIKとKIIPの認定基準

韓国語のスコアは[TOPIK](https://www.topik.go.kr)の級、またはKIIPの段階で認定されます。
両者のうち高い方の点数が適用され、両者の同時認定はされません。

| 認定基準 | 該当等級 | 配点レベル |
| --- | --- | --- |
| TOPIK 6級 / KIIP 5段階修了 | 最上位 | 最高配点 |
| TOPIK 5級 / KIIP 5段階未修了 | 上位 | 上位配点 |
| TOPIK 4級 / KIIP 4段階 | 中上位 | 中上位配点 |
| TOPIK 3級 / KIIP 3段階 | 中位 | 基本配点 |
| TOPIK 2級以下 | 下位 | 最低配点 |

実務上よく詰まる箇所が、KIIP 5段階を修了しているかどうかという点です。
4段階までしか受講していないと、韓国語スコアが1段階低く扱われ、合計点で5~10点もの差が生じます。

### KIIP修了の実戦的価値

KIIP 5段階の修了は、韓国語スコアだけでなく加点項目にも同時に反映されます。
一度の修了で2か所のスコアが上がる構造のため、80点に届かない申請者がまず狙うべきカードです。
ただしKIIPは申請から割り当てまでの待機期間が長く、タイミング管理が鍵となります。

> **実務のコツ:** KIIP 5段階の修了証が発行される前に、仮の修了確認書で申請可能なケースがあります。ご自身の状況に応じた可否は、ケースごとに判断が分かれます。

<h2 id="section-4">所得・資産のスコア計算法</h2>

### 年間所得の基準

所得は申請直前1年間の勤労所得・事業所得を合算して計算します。

| 所得区間 | 配点 |
| --- | --- |
| 前年度GNIの4倍以上 | 最高点 |
| 前年度GNIの3倍以上 | 上位点 |
| 前年度GNIの2倍以上 | 中上位点 |
| 前年度GNIの1倍以上 | 基本点 |
| 前年度GNI未満 | 点数なし |

GNI基準は毎年[韓国銀行](https://www.bok.or.kr)の発表値が適用されますので、今年適用されるGNIとご自身の所得とのマッピングは、相談時に正確にご案内いたします。
実際の審査では、源泉徴収票と所得金額証明書の2つで突合確認が行われます。

### 資産には別途のスコアがありません

見落とされがちな点ですが、**資産はスコアに直接換算されません**。
不動産や金融資産がいくら多くても、所得として計上されない限りスコアには反映されません。
むしろ資産よりも申告された勤労所得の方が、スコアにおいては強力です。

<h2 id="section-5">滞在期間・加点・減点の計算法</h2>

### 滞在期間のスコア

韓国国内での合法的な滞在期間が長いほど、スコアが上がります。

| 滞在期間 | 配点 |
| --- | --- |
| 5年以上 | 基本充足 |
| 7年以上 | 加算 |
| 10年以上 | 追加加算 |

滞在期間は出入国記録上の実際の韓国国内滞在日数で計算されます。
短期の出国が多かった場合は累積日数が削られますので、まず[ハイコリア](https://www.hikorea.go.kr)の出入国事実証明書を確認する必要があります。

### 加点項目と減点項目

加点項目は80点未満の申請者にとって決定打になります。

- 一定時間以上の社会奉仕活動
- 優秀人材推薦(大学、機関)
- 韓国政府の表彰
- 国家公認の資格保持

減点項目は一度に点数を崩壊させます。

- 出入国管理法違反歴
- 税金滞納
- 罰金以上の刑事処罰
- 資格外活動違反

**減点項目1つで80点が70点台に落ち込むケースが、実務上もっとも多い不合格パターン**です。

> **注意:** 過去に出入国法違反歴がある場合は、ポイント制申請の前に恩赦・記録の確認が先決です。減点幅は違反の種類によって変動します。

<h2 id="section-6">スコア不足時の補強戦略</h2>

### 短期間で引き上げ可能な項目

スコアが80点に届かない場合、もっとも早く引き上げられる項目には決まった順序があります。

1. KIIP 5段階修了(韓国語スコア + 加点)
2. TOPIK受験(1等級上げればスコアが上昇)
3. ボランティア時間の積み上げ
4. 所得証明の補強(漏れていた所得の合算)

学歴は時間がかかるため短期補強は難しく、年齢は手の付けられない項目です。
むしろボランティアとKIIPがもっとも現実的なカードになります。

### 減点要素の整理

減点要素は時間が経たないと回復しません。
税金滞納は即時の納付で回復可能ですが、刑事処罰は一定期間が経過しなければスコアが正常化しません。
この部分が弱いと、スコアが十分でも審査の段階で阻まれます。

今年はポイント制の詳細配点基準が一部調整されています。
ご自身の状況に応じた今年適用のスコアは、[出入国外国人総合案内センター(局番なしで1345)](https://www.hikorea.go.kr)での確認、または専門家相談が必要です。

<h2 id="section-7">F-2居住ビザポイント制 よくある質問(FAQ)</h2>

**Q1. 80点さえ超えれば必ず通過しますか?**
80点は申請資格ラインであり、合格ラインではありません。
実際の審査では、80点台前半の申請者と90点以上の申請者との間で結果に差が出ます。

**Q2. KIIP 5段階未修了でも申請できますか?**
TOPIKのスコアによる代替認定が可能です。
ただしKIIP 5段階修了者に与えられる別途の加点は受け取れません。

**Q3. 配偶者や子どもの同伴も可能ですか?**
F-2-7本人が居住資格を取得すれば、配偶者と未成年の子どもはF-3同伴ビザで一緒に滞在できます。
要件は本人の所得と居住の安定性も併せて審査されます。

**Q4. 過去の単純な交通反則金も減点になりますか?**
反則金は刑事処罰には該当しないため、スコア減点の対象にはなりません。
ただし罰金刑以上の刑事処罰は減点対象です。

**Q5. 滞在期間が5年未満でも申請可能なケースはありますか?**
先端産業・専門職などの優遇職種では、滞在期間の要件が緩和されるケースがあります。
ご本人の職業や資格保持状況によって異なりますので、事前検討が必要です。

**Q6. ポイント制の審査期間はどのくらいかかりますか?**
管轄の出入国事務所ごとに差があり、補強要請が入ればさらに長くなります。
もっとも早い処理が可能な手続きをご案内いたします。

<h2 id="section-8">費用のご案内</h2>

費用はケースごとに異なりますので、無料相談の際に正確にご案内いたします。
政府への納付料は、政府告示の手数料 + 行政処理費で構成されます。
