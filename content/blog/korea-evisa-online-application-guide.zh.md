# 韩国电子签证（e-Visa）申请完整指南（2026年）：网上签证申请方法

韩国电子签证（e-Visa）是无需亲赴使领馆，通过互联网在线申请韩国签证的系统。申请人可通过法务部电子签证官方门户网站（https://evisa.go.kr）提交申请，适用于大多数签证类别和国籍。

## 1. 什么是电子签证（e-Visa）？ {#section-1}

韩国电子签证（e-Visa）是由法务部出入境·外国人政策本部运营的在线签证申请及签发系统，申请人无需亲赴大使馆或领事馆，即可在线申请并获取韩国签证。

| 项目 | 内容 |
|---|---|
| 运营机构 | 法务部出入境·外国人政策本部 |
| 申请门户 | https://evisa.go.kr |
| 使用时间 | 全年全天24小时在线申请 |
| 语言支持 | 韩语·英语·中文·日语·法语等多语种 |
| 签证费用 | 因签证类型而异 |

## 2. 可申请电子签证的签证类别 {#section-2}

并非所有韩国签证均可通过电子签证方式申请。主要可申请的签证类别如下：

| 签证代码 | 签证名称 | 是否可申请电子签证 |
|---|---|---|
| C-3 | 短期访问（旅游·探亲等） | ✅ 可以 |
| D-2 | 留学 | ✅ 可以 |
| D-4 | 语言研修 | ✅ 可以 |
| D-7 | 驻在 | ✅ 可以 |
| D-8 | 企业投资 | ✅ 可以 |
| D-9 | 贸易经营 | ✅ 可以 |
| E-1~E-7 | 就业类别 | ✅ 可以（部分） |
| F-1 | 访问同居 | ✅ 可以 |
| F-3 | 随行 | ✅ 可以 |
| F-4 | 海外同胞 | ✅ 可以 |
| F-6 | 结婚移民 | ✅ 可以 |

> 部分签证可能因特定国籍或条件受到限制，请在evisa.go.kr门户上确认。

## 3. 可申请电子签证的国家 {#section-3}

电子签证系统对全球大多数国家开放（超过150个国家）。但部分国籍受限，必须通过大使馆申请。

| 类别 | 内容 |
|---|---|
| 可申请电子签证 | 大多数国家（150个以上） |
| 电子签证受限国家 | 特定国籍（需在门户上确认） |
| 免签国家 | 与韩国签订免签协议的国家（无需办理签证） |

> 是否可申请电子签证取决于国籍、签证类型及申请目的，请务必在evisa.go.kr确认。

## 4. 电子签证申请步骤详解 {#section-4}

### 第1步：进入电子签证门户

- 地址：https://evisa.go.kr
- 选择语言后注册账号或以访客身份申请

### 第2步：填写申请表

- 输入护照信息
- 选择访问目的及预计停留时间
- 填写个人及家庭信息

### 第3步：上传材料

- 护照个人信息页扫描件（清晰彩色图像）
- 上传近期证件照（白色背景、正面照）
- 根据签证类型上传相应附加材料

### 第4步：缴纳签证费

- 可使用信用卡、借记卡、境外卡付款
- 费用因签证类型而异

### 第5步：提交申请并跟踪审核进度

- 提交完成后，受理编号将以电子邮件通知
- 可在门户上实时查看申请状态

### 第6步：收到签证发放通知

- 审核通过后以电子邮件通知
- 下载电子签证（PDF）并打印，入境时出示

## 5. 所需材料 {#section-5}

### 共同所需材料

| 材料 | 备注 |
|---|---|
| 护照复印件 | 有效期6个月以上，清晰彩色扫描件 |
| 证件照 | 最近6个月内，白色背景，正面照 |
| 申请表 | 在门户上在线填写 |

### 各签证类型额外所需材料（示例）

| 签证类型 | 额外材料 |
|---|---|
| C-3（短期访问） | 机票预订确认书、住宿预订证明 |
| D-2（留学） | 录取通知书、学费缴纳证明 |
| D-4（语言研修） | 语言学校入学证明 |
| E-7（特定活动） | 劳动合同、营业执照、资格证书 |
| F-4（海外同胞） | 韩国国籍放弃证明或血统证明材料 |
| F-6（结婚移民） | 结婚关系证明书、配偶邀请函 |

## 6. 签证审核时间 {#section-6}

| 签证类型 | 通常审核时间 |
|---|---|
| C-3短期访问 | 3~5个工作日 |
| D-2留学 | 5~10个工作日 |
| E-7特定活动 | 2~4周 |
| F-6结婚移民 | 3~6周 |

> 旺季（暑假·寒假·节假日前后）审核时间可能延长，请提前留足时间申请。

## 7. 电子签证的获取方式 {#section-7}

电子签证以**PDF电子文件**形式签发，而非护照上的贴纸签证。

| 项目 | 内容 |
|---|---|
| 签发形式 | PDF文件（电子邮件或门户下载） |
| 是否需要打印 | 建议打印后在入境审查时出示（也可以电子设备出示） |
| 有效期 | 自签发之日起3个月~1年（视签证类型而定） |
| 入境次数 | 单次或多次（签证上注明） |

## 8. 签证被拒后的应对措施 {#section-8}

| 应对措施 | 内容 |
|---|---|
| 确认被拒原因 | 通过电子邮件或门户查看被拒原因 |
| 补充材料后重新申请 | 若因材料不足被拒，补充后重新申请 |
| 通过使领馆直接申请 | 电子签证被拒后，仍可前往大使馆直接申请 |
| 咨询专业人士 | 分析被拒原因并制定再申请策略 |

> 签证被拒记录可能影响日后的签证申请，重新申请前务必咨询专业人士。

## 9. 电子签证 vs. 使馆直接申请对比 {#section-9}

| 项目 | 电子签证 | 使馆直接申请 |
|---|---|---|
| 申请方式 | 在线（evisa.go.kr） | 亲赴大使馆·领事馆 |
| 便利性 | 高（24小时可申请） | 需亲赴窗口 |
| 材料提交 | 上传电子文件 | 提交原件或公证文件 |
| 审核时间 | 3天~6周 | 5天~8周 |
| 签证获取方式 | 下载PDF | 护照上粘贴贴纸 |
| 复杂情况 | 灵活性有限 | 处理方式更灵活 |

## 10. 常见问题解答 {#section-10}

**Q. 电子签证与普通贴纸签证具有同等法律效力吗？**
A. 是的。电子签证与普通签证贴纸具有相同的法律效力。入境审查时出示打印件或电子设备显示均可。

**Q. 提交申请后可以取消或修改吗？**
A. 审核中的申请可通过门户取消。已签发的签证只能取消，无法修改内容。

**Q. 签证被拒后可以退还申请费用吗？**
A. 原则上，无论审核结果如何，签证申请费用均不予退还。

**Q. 申请电子签证必须有电子邮件地址吗？**
A. 是的。受理确认、签发通知及PDF发送等均需要有效的电子邮件地址。

**Q. 更换新护照后，原有的电子签证还能继续使用吗？**
A. 不能。电子签证与护照号码绑定，换发新护照后须重新申请签证或办理护照变更申报手续。

## 11. 咨询指南 {#section-11}

电子签证虽然便捷，但因材料不足或填写错误导致被拒，可能对日后的签证申请产生不利影响。对于就业、结婚、留学等重要签证，专业人士的协助可大幅降低被拒风险。
