## 1. 什么是签证被拒？

签证被拒（不予签发）是指韩国驻外使领馆或法务部出入境当局拒绝签证申请的决定。

| 阶段 | 机构 | 处理时机 |
|---|---|---|
| 驻外使领馆审查 | 大使馆·领事馆 | 入境前签证审查 |
| 口岸检查 | 仁川·金浦机场等 | 入境时审查 |
| 在留资格变更·延签 | 出入境·外国人厅 | 在韩期间申请 |

---

## 2. 签证被拒的主要原因

| 类别 | 具体原因 |
|---|---|
| 材料不全 | 未提交必要文件、文件过期、未附翻译件 |
| 财力不足 | 存款余额不足、收入不稳定 |
| 访问目的不明 | 签证目的与实际访问原因不符 |
| 返国意图可疑 | 涉嫌非法务工或长期滞留 |
| 既往违规记录 | 超期居留或非法务工记录 |
| 身份·安全原因 | 犯罪记录、被列入禁止入境名单 |
| 邀请人问题 | 国内邀请人存在法律问题或财力不足 |

## 3. 如何查看拒绝通知

| 申请渠道 | 查看方式 |
|---|---|
| 使领馆申请 | 护照退还时附拒绝戳或书面拒绝通知 |
| e-Visa在线申请 | 登录evisa.go.kr查看不予受理原因 |
| Hi Korea门户申请 | 登录hikorea.go.kr查看处理结果 |
| 出入境厅窗口申请 | 当场告知或邮寄通知 |

> 拒绝原因通常不予公开。您可向使领馆或出入境厅申请说明，但对方无义务详细告知。

## 4. 异议申请 vs. 重新申请：如何选择

| 方式 | 内容 | 适用情形 |
|---|---|---|
| 异议申请 | 向同一机构申请复查拒绝决定 | 明显材料遗漏、错误或情况变化 |
| 行政审判 | 向法务部或行政审判委员会提起正式申诉 | 认为处分违法或不当 |
| 行政诉讼 | 向法院提起撤销诉讼 | 法律权益明显受损 |
| 重新申请 | 补充材料后重新提交新申请 | 可通过补充材料解决问题 |

## 5. 异议申请程序

### 驻外使领馆签证被拒异议

| 项目 | 内容 |
|---|---|
| 申请机构 | 受理签证申请的大使馆·领事馆 |
| 申请期限 | 通常为收到通知之日起30天内（各馆不同） |
| 提交方式 | 书面或电子邮件提交 |
| 附件材料 | 异议申请书、补充材料、拒绝通知复印件 |

### 国内出入境厅异议申请

| 项目 | 内容 |
|---|---|
| 申请机构 | 管辖出入境·外国人厅 |
| 申请期限 | 收到不许可通知之日起30天内 |
| 提交方式 | 窗口或邮寄 |
| 处理期限 | 通常30天以内 |

## 6. 行政审判申请程序

行政审判是对签证被拒处分提出正式申诉的程序，适用于认为处分违法或不当的情形。

| 项目 | 内容 |
|---|---|
| 申请机构 | 法务部行政审判委员会或中央行政审判委员会 |
| 申请期限 | 收到拒绝通知之日起90天内 |
| 提交方式 | 书面或在线（행정심판 simpan.go.kr） |
| 处理期限 | 60天以内（可延长） |
| 费用 | 免费 |

---

## 7. 行政诉讼提起程序

行政审判未能解决，或法律权益明显受损时，可向法院提起行政诉讼。

| 项目 | 内容 |
|---|---|
| 管辖法院 | 首尔行政法院或处分机构所在地行政法院 |
| 起诉期限 | 收到拒绝通知或行政审判结果之日起90天内 |
| 诉讼类型 | 撤销诉讼（申请撤销或确认无效处分） |
| 费用 | 诉讼费 + 律师费 |
| 处理期限 | 数月至一年以上 |

> 行政诉讼程序复杂，强烈建议委托专业律师或行政士代理。

## 8. 重新申请攻略

### 针对不同拒绝原因的补充对策

| 拒绝原因 | 补充方法 |
|---|---|
| 财力不足 | 增加存款余额，补充雇佣合同/在职证明 |
| 访问目的不明 | 强化邀请函，附加行程表·预订确认书 |
| 返国意图可疑 | 提前购买回程机票，证明国内资产·不动产·家庭关系 |
| 材料不全 | 补齐全部材料，办理公证·认证附加 |
| 既往违规记录 | 撰写情况说明书，必须寻求专业建议 |

### 重新申请前检查清单

- [ ] 准确掌握拒绝原因
- [ ] 全面检查并补充材料
- [ ] 确认申请书内容前后一致
- [ ] 确认是否经过合理等待期
- [ ] 经专业行政士审核后提交

## 9. 各签证类型应对要点

| 签证类型 | 主要拒绝原因 | 核心对策 |
|---|---|---|
| C-3（短期访问） | 返国意图可疑、财力不足 | 强化返国意图及资产证明 |
| D-2（留学） | 入学许可书问题、财力不足 | 正式入学许可书 + 财力证明 |
| E-7（特定活动） | 雇佣合同不全、学历不符 | 完善合同及学历认证 |
| F-4（在外同胞） | 韩裔证明材料不足 | 强化族籍及韩国国籍历史证明 |
| F-6（婚姻移民） | 婚姻真实性存疑、见面记录不足 | 充分记录交往经历及家庭会面 |
| F-5（永居） | 居留条件不满足 | 证明居留期间、KIIP完成情况及税款缴纳 |

## 10. 常见问题解答

**Q. 签证被拒后需要等多久才能重新申请？**
A. 法律上没有规定等待期，但立即以相同材料重新申请极可能再次被拒。建议至少等待1至3个月，充分补充材料后再重新申请。

**Q. 拒绝原因未告知怎么办？**
A. 韩国签证当局无义务公开拒绝原因。建议与专业行政士合作，全面审查申请材料，推断可能的拒绝原因。

**Q. 曾被拒会影响以后的签证申请吗？**
A. 是的。签证被拒记录将被保留，可能对日后的签证审查产生不利影响。因此，重新申请前必须做好充分准备。

**Q. 行政审判和行政诉讼哪个更实际？**
A. 一般而言，行政审判在费用和时间方面更为高效。仅当法律权益明显受损或行政审判结果不利时，才考虑提起行政诉讼。

**Q. 我目前在韩国，延签申请被拒，该怎么办？**
A. 必须在授权居留期届满前出境。请立即咨询专业人士，探讨通过异议申请或行政审判维持居留的可能性，或协调离境时间。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。
