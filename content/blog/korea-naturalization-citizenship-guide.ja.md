# 韓国国籍取得（帰化）完全ガイド（2026年版）：種類・条件・申請方法

韓国で長期間生活した外国人にとって、大韓民国の国籍取得（帰化）は現実的な選択肢です。帰化は単なる在留延長ではなく、大韓民国国民として全ての法的権利を持つ重要な決断です。このガイドでは帰化の種類から申請条件・必要書類・審査プロセスまで詳しく説明します。

## 1. 帰化とは？

帰化とは、外国人が大韓民国の国籍を取得する手続きです。帰化が完了すると、大韓民国国民として選挙権・公務員任用資格など全ての法的権利を持つことができます。

韓国の国籍法によると、帰化は次の3種類に分類されます：
- **一般帰化**：定められた期間、合法的に韓国に居住した外国人
- **簡易帰化**：韓国人と結婚した方や韓国国民の子どもなど、特別な関係を持つ外国人
- **特別帰化**：国家に特別な貢献をした外国人

---

## 2. 帰化の種類と要件

| 種類 | 主な条件 | 居住期間要件 |
|---|---|---|
| 一般帰化 | 5年以上の継続合法居住 | 5年以上 |
| 簡易帰化（結婚） | 韓国国民との婚姻継続2年以上+国内居住1年以上 | 婚姻2年+居住1年 |
| 簡易帰化（韓国国民の子ども） | 韓国国民の直系の子ども | 1年以上 |
| 簡易帰化（養子縁組） | 韓国国民に養子縁組された場合 | 1年以上 |
| 特別帰化 | 国家・社会への特別な貢献 | 居住要件が免除される場合あり |

---

## 3. 一般帰化の要件詳細

一般帰化は以下の全要件を満たす必要があります：

| 要件 | 内容 |
|---|---|
| 居住期間 | 5年以上の継続合法居住 |
| 年齢 | 満18歳以上 |
| 品行 | 素行が良好であること |
| 生計能力 | 本人と家族を養う経済的能力があること |
| 韓国語能力 | 大韓民国国籍付与に相応しい韓国語能力 |
| 国家観 | 大韓民国の国家体制を受け入れること |

> 「素行良好」の要件は、一般的に重大な犯罪歴がないことを意味します。

---

## 4. 簡易帰化の対象者

簡易帰化は一般帰化より居住期間要件が緩和されています。

### 結婚による帰化（F-6配偶者）

| 要件 | 内容 |
|---|---|
| 標準要件 | 韓国国民との婚姻後2年経過+国内居住1年以上 |
| 代替要件 | 婚姻後3年経過+国内継続居住1年以上 |
| 特殊状況 | 配偶者の死亡・行方不明または離婚後、韓国国民の子どもを育てている場合 |

### その他の簡易帰化

| 種類 | 条件 |
|---|---|
| 韓国国民の子ども | 直系血統、国内居住1年以上 |
| 韓国国民の孫 | 祖父母または親が韓国国民 |
| 韓国生まれの外国人 | 親の一方が韓国国籍保有 |
| 韓国国民に養子縁組された方 | 国内居住1年以上 |

---

## 5. 特別帰化の対象者

特別帰化は国家・社会に顕著な貢献をした外国人に対し、居住要件を免除または緩和して付与されます。

| 対象 | 内容 |
|---|---|
| 科学・経済・文化への貢献者 | 韓国の発展に著しく貢献した外国人 |
| スポーツ貢献者 | 大韓民国代表として国際大会に出場予定、または出場した外国人 |
| 国家安全保障への貢献者 | 国防分野に特別な貢献がある外国人 |

---

## 6. 帰化申請の手続き

1. **要件確認** — 帰化の種類・居住期間・申請資格要件を確認
2. **書類準備** — 帰化種類に応じた書類を一式揃える
3. **法務部出入国・外国人政策本部への申請** — 管轄の出入国・外国人庁を訪問またはオンライン申請
4. **基本素養試験** — 韓国語試験（社会統合プログラム修了または別途受験）
5. **審査** — 素行・経済力・韓国語能力等を総合審査
6. **帰化面接** — 韓国語能力および国家観の面接審査
7. **帰化許可** — 法務部の許可決定後、帰化証書を受け取る
8. **外国国籍の選択・放棄** — 二重国籍が認められない場合、元の国籍を放棄する申告を行う

---

## 7. 必要書類

### 共通書類

| 書類 | 備考 |
|---|---|
| 帰化許可申請書 | 法務部指定の様式 |
| パスポート原本 | 現在有効なもの |
| 外国人登録証 | 外国人登録済みの場合 |
| 本国の身分証明書・出生証明書 | アポスティーユまたは領事認証 |
| 家族関係証明書 | 本国発行・翻訳・認証付き |
| 居住期間証明書類 | 納税証明・健康保険証明等 |
| 在職・事業証明書 | 在職証明書・事業者登録証等 |
| 納税事実証明書 | 所得税・健康保険料の納付履歴 |
| 犯罪歴証明書 | 本国および韓国 |
| 証明写真 | 規格写真 |

---

## 8. 帰化審査の評価項目

| 評価項目 | 内容 |
|---|---|
| 居住期間 | 継続合法居住要件の充足状況 |
| 素行 | 犯罪歴・法令違反の有無 |
| 経済力 | 自活能力の証明 |
| 韓国語能力 | 韓国語の口頭能力（面接またはTOPIKスコア） |
| 国家観 | 韓国憲法および民主主義への理解 |
| 社会統合プログラム | 修了有無（修了すれば帰化試験が免除） |

---

## 9. 帰化後の二重国籍の取り扱い

大韓民国は原則として二重国籍を認めていません。

| 区分 | 対応方法 |
|---|---|
| 原則 | 帰化後1年以内に外国国籍を放棄 |
| 例外認定 | 一部の特別帰化者・結婚帰化者は二重国籍が許可 |
| 外国人登録証の返納 | 帰化完了後に返納 |
| 住民登録の新規登録 | 帰化完了後、初めて住民登録を行う |

> 2011年の国籍法改正により、一部の外国人（結婚帰化者・特別帰化者等）は外国国籍を放棄せずに韓国国籍を維持できる二重国籍が認められています。

## 10. よくある質問（FAQ）

**Q. 韓国国籍を取得したら必ず本国の国籍を放棄しなければなりませんか？**
A. 一般帰化者は帰化後1年以内に外国国籍を放棄する必要があります。ただし、結婚帰化者および一部の特別帰化者は二重国籍が認められています。法律の改正により条件によっては二重国籍が認められるため、専門家への相談をお勧めします。

**Q. 帰化の審査にはどのくらい時間がかかりますか？**
A. 申請から審査完了まで通常1〜2年以上かかります。書類不備や審査の順番によってはさらに長くなることがあります。

**Q. 韓国語があまり得意ではなくても帰化申請はできますか？**
A. 帰化審査には韓国語能力評価（面接または試験）が含まれます。社会統合プログラム（KIIP）5段階を修了すると帰化試験が免除されるため、事前にKIIPを受講することをお勧めします。

**Q. 帰化申請前に住所を変えても問題ありませんか？**
A. 合法居住期間は出入国記録で確認されるため、住所変更よりも合法滞在の継続が重要です。ただし、頻繁な海外渡航により継続居住が途切れると審査に不利になる場合があります。

**Q. 帰化申請が不許可になった場合、再申請はできますか？**
A. はい。不許可の理由を把握して要件を補完した後、再申請できます。不許可決定に対する異議申請も可能です。

---

## 11. 相談案内

帰化は国籍法上の要件が複雑で、書類準備や審査期間が長期にわたるため、専門家のサポートが非常に重要です。特に簡易帰化・特別帰化の対象可否や二重国籍の取り扱いについては、事前の専門家相談が不可欠です。

ビジョン行政書士事務所では、帰化要件の確認・書類準備サポート・審査対応まで専門的にサポートしています。
