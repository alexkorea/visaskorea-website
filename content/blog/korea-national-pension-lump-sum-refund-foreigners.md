# 한국 국민연금 반환일시금 외국인 신청 완벽 가이드 (2026년)

한국에서 취업하며 국민연금 보험료를 납부한 외국인은 한국을 떠날 때 납부한 보험료를 돌려받을 수 있습니다. 이를 **반환일시금**이라고 합니다. 가입 기간이 10년 미만인 외국인이 출국 시 신청할 수 있으며, 원금과 이자를 합산하여 일시에 수령합니다.

## 1. 반환일시금이란?

반환일시금(返還一時金)은 국민연금 가입자가 연금 수급 요건(10년 이상 납부 + 만 60세)을 충족하지 못한 채 한국을 영구적으로 떠나는 경우, 납부한 보험료 원금과 이자를 일시에 돌려받는 제도입니다.

| 항목 | 내용 |
|---|---|
| 제도명 | 국민연금 반환일시금 |
| 관련 법령 | 국민연금법 제77조 |
| 관장 기관 | 국민연금공단 (NPS) |
| 수령 방식 | 일시금 (한 번에 전액 지급) |
| 원금 + 이자 | 납부 원금 + 법정 이자율 적용 이자 |

## 2. 신청 대상 및 조건

### 신청 자격

| 조건 | 내용 |
|---|---|
| 국적 | 한국 국적 미보유자 (외국인) |
| 가입 기간 | 10년 미만 (120개월 미만) |
| 출국 예정 또는 출국 완료 | 한국을 떠나는 외국인 (귀국 또는 타국 이주) |
| 연금 미수령 | 노령연금·장애연금 등을 수령하지 않은 경우 |

### 신청 불가 대상

| 해당 경우 | 이유 |
|---|---|
| 가입 기간 10년 이상 | 노령연금 수급 자격 있음 → 반환일시금 대신 연금 수령 권장 |
| 이미 노령연금 수령 시작 | 이중 수령 불가 |
| 사회보장협정 적용 대상 | 일부 협정 조항에 따라 다를 수 있음 |

---

## 3. 수령 금액 계산 방법

반환일시금 수령액은 납부한 보험료 원금에 법정 이자율을 적용하여 계산합니다.

### 계산 공식

```
반환일시금 = 납부 보험료 총액 + (납부 보험료 × 이자율 × 기간)
```

### 이자율

| 기간 | 적용 이자율 |
|---|---|
| 1~3년 | 1년 만기 정기예금 이자율 |
| 3~5년 | 1년 만기 정기예금 이자율 |
| 5년 이상 | 1년 만기 정기예금 이자율 (연도별 고시) |

> 이자율은 매년 국민연금공단이 고시합니다. 정확한 수령 예상액은 국민연금공단 고객센터(국번없이 1355) 또는 내연금 앱에서 확인 가능합니다.

### 예시 계산

| 항목 | 예시 |
|---|---|
| 가입 기간 | 3년 (36개월) |
| 월 평균 납부 보험료 | 135,000원 (월급 300만원 × 4.5%) |
| 납부 원금 | 4,860,000원 |
| 이자 (약 3.0% 적용) | 약 291,600원 |
| **예상 수령액** | **약 5,151,600원** |

## 4. 신청 서류

| 서류 | 비고 |
|---|---|
| 반환일시금 지급청구서 | 국민연금공단 양식 사용 |
| 여권 사본 | 유효한 여권 |
| 외국인 등록증 사본 | 등록된 경우 |
| 출국 확인 서류 | 출국 후 신청 시: 출국 도장이 찍힌 여권 또는 출국증명서 |
| 신분증 | 본인 확인용 |
| 통장 사본 | 한국 계좌 또는 해외 계좌 (해외 송금 신청 시) |
| 위임장 | 대리인 신청 시 |

---

## 5. 신청 방법 및 절차

### 신청 방법 3가지

| 방법 | 내용 |
|---|---|
| 국민연금공단 방문 | 전국 국민연금공단 지사 직접 방문 |
| 우편 신청 | 필요 서류 우편 발송 |
| 온라인 신청 | 국민연금 전자민원서비스 (www.nps.or.kr) |

### 신청 절차

1. 필요 서류 준비
2. 국민연금공단 지사 방문 또는 온라인·우편 신청
3. 서류 심사 (통상 2~4주 소요)
4. 지급 결정 통보
5. 지정 계좌로 입금 (국내 계좌 또는 해외 계좌)

### 해외 계좌 송금 신청

- 해외에서도 신청 가능하며, 해외 은행 계좌로 직접 송금됩니다.
- 은행명, 계좌번호, SWIFT 코드 등 필요

## 6. 신청 시기 (출국 전 vs. 출국 후)

| 시기 | 가능 여부 | 비고 |
|---|---|---|
| 출국 전 | ✅ 가능 | 출국 예정일이 확정된 경우 |
| 출국 후 | ✅ 가능 | 해외에서 우편·온라인 신청 가능 |
| 한국 재입국 후 | ✅ 가능 | 단, 반환일시금 수령 후 재취업 시 재가입 가능 |

### 출국 전 신청 시 유의사항

출국 전 신청 시에도 지급은 출국 후에 이루어집니다. 출국 확인이 된 이후 처리되므로 출국 날짜에 맞춰 미리 신청해 두는 것이 편리합니다.

## 7. 사회보장협정 국가 주의사항

한국과 사회보장협정을 체결한 국가의 국민은 반환일시금 수령에 특별한 규정이 적용될 수 있습니다.

| 협정 유형 | 반환일시금 영향 |
|---|---|
| 연금 납부 면제 협정 | 처음부터 연금 미납 → 반환일시금 대상 없음 |
| 가입 기간 합산 협정 | 양국 가입 기간 합산으로 10년 충족 가능 → 연금 수령 선택 |
| 단순 보험 적용 제외 | 반환일시금 신청 가능 |

### 주요 협정 국가별 상황

| 국가 | 협정 유형 | 반환일시금 관련 |
|---|---|---|
| 미국 | 보험료 면제 | 처음부터 납부 면제 → 반환 없음 |
| 독일 | 가입 기간 합산 | 합산 후 연금 선택 가능 |
| 캐나다 | 가입 기간 합산 | 합산 후 연금 선택 가능 |
| 중국 | 반환 가능 협정 | 반환일시금 신청 가능 |
| 베트남 | 반환 가능 협정 | 반환일시금 신청 가능 |

> 협정 내용은 국가마다 다르므로 반드시 국민연금공단(1355)에 확인하세요.

## 8. 반환일시금 vs. 연금 수령

가입 기간이 10년 이상인 경우 반환일시금 대신 노령연금을 선택할 수 있습니다.

| 항목 | 반환일시금 | 노령연금 |
|---|---|---|
| 수령 시기 | 출국 후 즉시 | 만 60세 이후 매월 |
| 수령 금액 | 원금 + 이자 (일시금) | 매월 연금액 (장기적으로 훨씬 유리) |
| 조건 | 가입 기간 10년 미만 또는 선택 | 가입 기간 10년 이상 + 만 60세 |
| 거주지 | 외국 거주 시에도 수령 가능 | 외국 거주 시에도 수령 가능 |
| 추천 | 10년 미만이거나 즉시 자금 필요 시 | 장기적 노후 보장 목적 |

## 9. 세금 공제 여부

반환일시금 수령 시 세금 공제가 적용됩니다.

| 항목 | 내용 |
|---|---|
| 소득세 공제 여부 | 이자분에 대해 소득세 원천징수 |
| 원금 | 소득세 없음 |
| 이자 | 이자소득세 원천징수 (약 15.4%) |
| 비거주자 세율 | 이자에 대해 20% 원천징수 (조세조약 적용 시 감면 가능) |

> 납부 시 소득공제를 받은 보험료에 대해 환급 시 세금 처리가 달라질 수 있습니다. 정확한 세금 계산은 국세청 또는 세무사에게 문의하세요.

## 10. 자주 묻는 질문 (FAQ)

**Q. 이미 출국했는데 반환일시금을 신청할 수 있나요?**
A. 네. 해외에서도 국민연금공단 온라인 서비스(www.nps.or.kr) 또는 우편으로 신청할 수 있습니다. 해외 은행 계좌로 송금도 가능합니다.

**Q. 반환일시금 신청 후 얼마나 걸려서 받을 수 있나요?**
A. 서류 접수 후 통상 2~4주 내에 심사가 완료되어 지정 계좌로 입금됩니다.

**Q. 한국에 다시 돌아와 취업하면 이전 연금 가입 이력이 인정되나요?**
A. 반환일시금을 수령한 경우 해당 기간의 가입 이력은 소멸됩니다. 재취업 후 국민연금에 재가입하면 새로 가입 기간이 시작됩니다.

**Q. 연금 가입 기간이 10년이 넘어도 반환일시금을 받을 수 있나요?**
A. 10년 이상 가입한 경우 원칙적으로 노령연금 수급 자격이 있으므로 반환일시금 수령 대신 연금을 선택하게 됩니다. 특수한 경우 국민연금공단에 문의하세요.

**Q. 사망한 외국인 근로자의 유족도 반환일시금을 받을 수 있나요?**
A. 네. 외국인 가입자가 사망한 경우 유족이 반환일시금(유족 일시금)을 청구할 수 있습니다. 관련 서류를 갖추어 국민연금공단에 신청하시기 바랍니다.

## 11. 상담 안내

국민연금 반환일시금은 외국인 근로자가 한국을 떠날 때 챙겨야 할 중요한 권리입니다. 사회보장협정 적용 여부, 해외 송금 절차 등 복잡한 사항은 전문가의 도움을 받으시면 더욱 원활하게 처리하실 수 있습니다.

비전행정사사무소에서는 외국인 체류자격 및 사회보험 관련 전반적인 상담 서비스를 제공합니다.
