## 1. 韩国就业签证概述

在韩国就业须根据职种、雇佣形态和国籍选择相应签证。主要就业签证类型如下：

| 签证 | 名称 | 适用对象 |
|------|------|---------|
| E-7 | 特定活动 | 专业技术人才/高层次人才 |
| E-9 | 非专业就业 | 非熟练外国劳动者 |
| H-2 | 访问就业 | 海外韩裔外国人 |

此外还有E-1（教授）、E-2（外语教学）、E-3（研究）、E-4（技术指导）、E-5（专业职业）、E-6（文艺演出）等就业相关签证。

## 2. E-7签证（特定活动）详解

### E-7签证是什么

E-7签证是从事韩国法务部指定"特定活动"的专业就业签证，面向具备高技术和专业知识的人才，仅限于韩国政府认定所需的职种。

### 主要适用职种

E-7签证适用职种由法务部以**별표（附表）**形式规定（约186种以上），主要涵盖以下领域：

| 领域 | 职种示例 |
|------|---------|
| IT·科技 | 软件开发工程师、数据科学家、AI研究员 |
| 制造·工程 | 机械工程师、电气·电子技术工程师 |
| 医疗·健康 | 医生、牙科医生（部分护士） |
| 教育·研究 | 外语讲师（非英语）、研究员 |
| 商务·金融 | 国际业务人员、外国人投资者支援 |
| 文化·创意 | 设计师、影像制作、翻译·口译 |

### E-7签证申请要件

| 要件 | 内容 |
|------|------|
| 学历 | 相关领域学士学位以上，或同等经历 |
| 经验 | 相关工作经验1〜2年以上（因职种不同） |
| 雇主 | 与韩国境内合法企业签订劳动合同 |
| 薪资 | 达到规定最低薪资标准以上 |

### E-7-4（숙련기능인력，熟练技能人才）

E-7有一个特殊分类**E-7-4**（숙련기능인력积分制），持有E-9·H-2签证并有一定就业经验的人士，通过积分制可过渡到E-7-4，实现签证升级。

### E-7签证的主要特点

- **居留期限**：首次1年，续签后可延至2〜3年
- **家属随行**：配偶和子女可凭F-1签证赴韩
- **职种变更**：变更职种时须重新申请签证变更
- **走向F-2·F-5**：长期就业可申请F-2居住签证，进而申请F-5永居权

## 3. E-9签证（非专业就业）详解

### E-9签证是什么

E-9签证是基于韩国고용허가제（雇用许可制，EPS）发放的非熟练外国劳动者就业签证。**中国公民**是E-9的重要申请对象之一。

### 申请对象国

E-9的对象国为韩国政府签订双边协议的16个国家，包括中国（조선족除外，朝鲜族适用H-2）、菲律宾、越南、印度尼西亚等。

### 可从事行业

| 可就业 | 不可就业 |
|-------|---------|
| 制造业（中小企业） | 专业职（医疗·法律等） |
| 建筑业 | 管理职 |
| 农业·渔业 | 教育相关 |
| 部分服务业 | 金融·保险 |

### E-9签证的主要特点

| 项目 | 内容 |
|------|------|
| 居留期限 | 首次3年，可延1年10个月 |
| 工作单位变更 | 原则上最多3次 |
| 家属随行 | 不可（不可携带家属） |
| 最低工资 | 适用最低工资保障 |

## 4. H-2签证（访问就业）详解

### H-2签证是什么

H-2签证是面向在中国（조선族，朝鲜族）和原苏联地区（高丽人）居住的韩裔外国人（재외동포）的访问就业签证。中国朝鲜族是H-2的主要申请群体。

### 申请对象

- **조선족（朝鲜族）**：中国朝鲜族
- **고려인（高丽人）**：哈萨克斯坦等中亚及原苏联地区的韩裔
- ※对象国有限定，其他地区详见出入境·外国人厅公告

### 可从事行业

H-2可从事的行业有限定，主要为单纯·非熟练职种：

| 可就业 | 不可就业 |
|-------|---------|
| 制造业 | 专业职（医疗·法律等） |
| 建筑业 | 管理职 |
| 农业·渔业 | 教育相关 |
| 餐饮·住宿业 | 金融·保险 |

### H-2签证的主要特点

| 项目 | 内容 |
|------|------|
| 居留期限 | 首次1年，最长3年 |
| 就业申报 | 须向고용센터（雇用中心）申报就业 |
| 同业种转职 | 相对自由 |
| 转F-4的可能 | 条件满足后可变更为F-4（在外同胞）签证 |

## 6. 如何选择适合的签证

### 中国籍申请人的选择策略

根据个人背景和就业意向，建议如下：

**选择E-7的情形**
- 从事专业技术职（IT·工程·翻译·设计等）
- 有韩国企业的雇主担保（스폰서）
- 希望在韩长期稳定发展职业
- 以永居权为长期目标

**选择E-9的情形（中国籍，非朝鲜族）**
- 计划在制造业、农业等行业就业
- 通过雇用许可制参加EPSTOPIK考试并通过

**选择H-2的情形（中国朝鲜族）**
- 中国朝鲜族，可直接申请H-2
- 计划在制造·服务业等就业
- 考虑未来转F-4（在外同胞）签证

### E-7申请困难时的替代路径

- **D-10**（求职签证）：在韩国境内从事求职活动
- **D-8**（企业投资签证）：自行设立法人后在韩居留
- **F-2-7**（积分制居住签证）：满足积分条件后获得就业自由签证

## 7. 各签证向长期签证的过渡路径

### E-7 → F-2-7（居住签证）

持E-7签证就业一定期限后，可申请F-2-7积分制居住签证。取得F-2-7后，可在任何公司、任何职种自由就业，无需再变更签证。

### E-7 → F-5（永居权）

持E-7签证在韩居住5年以上（其中3年以上持E-7），并达到一定收入标准的，可申请F-5永居权。

### E-9·H-2 → E-7-4（熟练技能人才）

持E-9或H-2签证有就业经验者，可通过积分制（점수제）升级为E-7-4，进而开启申请F-2或F-5的通道。

### H-2 → F-4（在外同胞）

朝鲜族H-2持有者满足一定条件后，可变更为F-4（在外同胞）签证，享有更大的就业自由度，并可进一步申请F-5永居权。

## 8. 申请手续与所需文件

### E-7签证申请主要材料

| 材料 | 说明 |
|------|------|
| 사증발급인정서（签证发放认定书） | 韩国雇主向法务部申请 |
| 고용계약서（劳动合同书） | 与雇主签订的合同 |
| 학위증 및 경력증명서（学位·经历证明） | 境外学历需海牙认证 |
| 护照 | 有效护照原件 |
| 범죄경력조회 답변서（无犯罪记录证明） | 本国出具 |

### E-7签证申请流程（从中国申请）

1. **雇主向法务部申请사증발급인정（签证发放认定申请）**
2. **取得사증발급인정서（签证发放认定书）**：约2〜4周
3. **向驻华韩国大使馆/总领事馆提交申请材料**
4. **审核·签证发放**
5. **赴韩入境·外国人登录**

## 9. 常见问题解答（FAQ）

### Q1. 中国朝鲜族可以直接申请E-7签证吗？
**A**：可以。中国朝鲜族既可申请H-2，也可以凭学历和职业经历申请E-7。建议根据自身专业背景和就业意向与专业人士商议选择。

### Q2. E-7签证可以本人自行申请吗？
**A**：E-7签证以韩国雇主申请为主体，需由雇主向法务部提交사증발급인정申请（签证发放认定申请）。建议与雇主协商并委托专业行政士协助。

### Q3. 持E-7签证可以做自由职业吗？
**A**：E-7原则上以劳动合同为基础。希望从事自由职业·个体经营者可考虑D-9（贸易经营）或D-8（企业投资）等签证。

### Q4. 在韩持E-7签证期间想跳槽，怎么办？
**A**：变更职种时需申请签证变更；同职种内转职也需申报雇主变更。欢迎联系飞展行政士事务所咨询具体手续。

### Q5. E-7被拒怎么办？
**A**：收到不许可通知后，需确认被拒原因并采取改善措施。飞展行政士事务所也承接不许可后的再申请支持。

### Q6. H-2签证持有者可以申请永居权吗？
**A**：H-2不能直接申请F-5，但可通过H-2→F-4→F-5，或H-2→E-7-4→F-2→F-5等路径逐步实现。建议提前规划并咨询专业人士。

## 申请前的实用建议

### E-7签证申请的常见误区

**误区一：学历越高越容易获批**  
虽然学历是重要评分因素，但E-7更看重"学历与职种的匹配性"。工科学士配合IT职位，比管理学硕士申请工厂技术职更有优势。

**误区二：收到offer就能马上来韩国**  
E-7以雇主申请为前提，收到工作offer后，雇主需向法务部申请사증발급인정（签证发放认定），获批后申请人才能持사증발급인정서前往大使馆办理签证，前后约需4〜8周时间。提前规划至关重要。

**误区三：E-9可以跳槽到任何公司**  
E-9原则上仅允许在同一雇主处就业，转职受到严格限制（최대 3회），且须经雇用中心批准。
