# 外国人韩国所得税申报完整指南（2026年）：综合所得税·劳动所得税

在韩国有收入的外国人须依照韩国税法缴纳所得税。外国劳动者可选择适用单一税率（19%），并可享受租税条约减免等韩国国民无法享有的特别待遇。了解相关规定，有助于避免多缴税款并合法享受税务优惠。

## 1. 外国人的纳税义务

在韩有收入的外国人，依据居住者身份和收入类型承担不同的韩国所得税纳税义务。

| 类别 | 应税收入范围 |
|---|---|
| 居住者外国人 | 全球所有收入（全球所得征税） |
| 非居住者外国人 | 仅限韩国来源收入 |

---

## 2. 居住者与非居住者的区别

税法上居住者与非居住者的区别决定了纳税范围。

| 类别 | 判定标准 |
|---|---|
| 居住者 | 在韩有住所，或在韩居所满183天以上的个人 |
| 非居住者 | 在韩无住所且居所不足183天的个人 |

### 居住者认定标准（183天原则）

当年在韩居住183天以上即被认定为居住者，须就全球所得在韩纳税。

---

## 3. 劳动所得税预扣

在韩国企业就职的外国劳动者，每月薪资发放时由单位预扣所得税。

| 项目 | 内容 |
|---|---|
| 预扣方式 | 适用简易税额表（与韩国劳动者相同） |
| 预扣时间 | 每月发薪时 |
| 预扣税率 | 按所得区间累进税率6~45% |
| 地方所得税 | 所得税的10%附加征收 |

### 2026年所得税税率区间

| 应税所得额 | 税率 |
|---|---|
| 1,400万韩元以下 | 6% |
| 1,400万~5,000万韩元 | 15% |
| 5,000万~8,800万韩元 | 24% |
| 8,800万~1.5亿韩元 | 35% |
| 1.5亿~3亿韩元 | 38% |
| 3亿~5亿韩元 | 40% |
| 5亿韩元以上 | 42% |
| 10亿韩元以上 | 45% |

---

## 4. 外国人单一税率19%选择

外国劳动者可在首次入境韩国后**20年内**选择适用19%单一税率（不含地方所得税）。

| 项目 | 内容 |
|---|---|
| 税率 | 劳动所得的19%单一税率 |
| 适用期间 | 首次入境韩国之日起20年以内 |
| 选择时机 | 年终结算或综合所得税申报时选择 |
| 扣除项目 | 不适用所得扣除及税额抵免（仅适用税率） |

### 选择单一税率有利的情况

- 年薪较高，适用累进税率税负较重时
- 可扣除项目少，累进税方式不划算时

> 每年均可比较累进税率与单一税率，选择税负较低的方式申报。

## 5. 综合所得税申报（5月）

综合所得税申报期为每年5月1日至31日。

| 申报对象 | 情况 |
|---|---|
| 除劳动所得外有其他收入者 | 利息·股息·事业·租赁·其他所得等 |
| 在两处以上单位工作者 | 需合并申报 |
| 未进行年终结算者 | 需自行申报 |
| 自由职业者·个体经营者 | 事业所得需自行申报 |

### 申报方式

| 方式 | 内容 |
|---|---|
| 国税厅Hometax（www.hometax.go.kr） | 网上申报（外国人亦可使用） |
| 到辖区税务署窗口申报 | 现场申报 |
| 委托税务师 | 情况复杂时建议委托税务师代理申报 |

### 申报所需材料

- 劳动所得预扣税收据
- 金融收入明细（利息·股息）
- 租赁合同（有租赁收入时）
- 与事业相关的收支证明（有事业收入时）

## 6. 租税条约减免优惠

韩国与约90个国家签订了租税条约。适用租税条约时，特定收入可享受税率减免或免税优惠。

### 主要收入类型的条约优惠

| 收入类型 | 条约优惠示例 |
|---|---|
| 劳动所得 | 短期派遣劳动者减税（如居留不足183天等） |
| 事业所得 | 在韩无固定营业场所则不征税 |
| 股息 | 预扣税率减免（通常5~15%） |
| 利息 | 预扣税率减免（通常0~10%） |
| 使用费 | 预扣税率减免 |

### 主要国家租税条约预扣税率（非劳动所得）

| 国家 | 股息税率 | 利息税率 |
|---|---|---|
| 美国 | 15% | 12% |
| 中国 | 10% | 10% |
| 日本 | 15% | 10% |
| 德国 | 15% | 10% |

> 申请条约优惠，须向韩国税务署或所得支付方（雇主·金融机构等）提交本国居住证明及租税条约适用申请书。

## 7. 外国劳动者年终结算

每年1~2月进行的年终结算同样适用于外国劳动者。

| 项目 | 内容 |
|---|---|
| 申请时间 | 每年1~2月（通过公司办理） |
| 扣除项目 | 人员扣除、医疗费、教育费、保险费、捐款等 |
| 外国人注意事项 | 月租税额抵免等部分扣除有条件限制 |
| 单一税率选择 | 年终结算时可选择适用19%单一税率 |

### 外国劳动者主要扣除项目

| 扣除项目 | 适用条件 |
|---|---|
| 基本人员扣除（本人） | 150万韩元（始终适用） |
| 配偶扣除 | 配偶在韩居住时 |
| 医疗费税额抵免 | 韩国境内医疗支出 |
| 教育费税额抵免 | 子女韩国学校教育费 |
| 保险费扣除 | 在韩国加入保险时 |

## 8. 租赁收入·事业收入申报

通过不动产租赁或从事经营活动获取收入的外国人须申报综合所得税。

| 收入类型 | 申报义务 | 税率 |
|---|---|---|
| 住宅租赁收入（年不超过2,000万韩元） | 5月综合所得税申报 | 分类征税14%或合并申报 |
| 住宅租赁收入（年超过2,000万韩元） | 综合所得合并申报 | 累进税率6~45% |
| 事业所得 | 5月综合所得税申报 | 累进税率6~45% |
| 自由职业收入 | 5月综合所得税申报 | 累进税率6~45% |

## 9. 避免双重征税：境外已缴税额抵免

在韩为居住者且在本国也缴纳了税款的外国人，可依据避免双重征税协定申请境外已缴税额抵免。

| 项目 | 内容 |
|---|---|
| 境外已缴税额抵免 | 境外已缴税额可从韩国应纳税额中抵免 |
| 适用条件 | 居住者在申报全球所得时 |
| 抵免限额 | 可抵免韩国税额中属于境外来源收入的比例部分 |
| 申请方式 | 5月综合所得税申报时附上境外已缴税额抵免明细表 |

## 10. 常见问题解答

**Q. 外国人是否必须进行综合所得税申报？**
A. 仅有一处劳动所得且年终结算已完成者，无需另行申报。但如有自由职业收入、租赁收入、利息或股息等其他收入，则须在5月进行申报。

**Q. 选择19%单一税率一定更划算吗？**
A. 不一定。若收入较低或可扣除项目较多，累进税率可能更划算。建议每年两种方式均进行比较，选择税负较低的方式。

**Q. 在韩居留不足6个月的外国人也需要缴税吗？**
A. 居留不足183天者被认定为非居住者，仅对韩国来源收入征税。具体税率可能因租税条约而有所不同。

**Q. 如何申请租税条约减免优惠？**
A. 向韩国税务署或所得支付方（雇主、金融机构等）提交本国居住地证明（英文）及租税条约适用申请书即可。

**Q. 离开韩国前需要清缴税款吗？**
A. 如有未缴清税款，须在出境前到税务署缴清。欠缴税款可能导致出境受限。
