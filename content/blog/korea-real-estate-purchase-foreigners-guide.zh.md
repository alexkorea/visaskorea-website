# 外国人在韩国购买房产完整指南（2026年）：流程·税费·注意事项

外国人可以在韩国购买房产，但需遵守不同于韩国国民的申报义务，且部分地区存在限制。外国人在购买韩国房产前，必须了解取得程序、税务义务及外汇法规。

## 1. 外国人可以购买韩国房产吗？

根据《外国人土地法》及《房地产交易申报等相关法律》，外国人原则上可以在韩国取得土地及建筑物。

| 类型 | 是否可购买 |
|---|---|
| 公寓·住宅 | ✅ 可以 |
| 商用建筑 | ✅ 可以 |
| 土地（一般地区） | ✅ 申报后可取得 |
| 军事保护区土地 | ❌ 禁止或需获得许可 |
| 文化遗产保护区内土地 | ❌ 受限 |

---

## 2. 各类房产的限制规定

### 住宅类房产（公寓·独立住宅）

外国人可与韩国国民同等条件购买住宅类房产，但取得后须履行申报义务。

### 土地取得

依据《外国人土地法》，外国人取得土地后须在取得之日起60日内向所在地市·郡·区政府申报。部分地区（军事·文化遗产·生态系统保护区等）须事先取得许可。

| 地区类型 | 规定内容 |
|---|---|
| 一般地区 | 取得后60日内申报（无需事先许可） |
| 军事设施保护区 | 须事先取得许可 |
| 文化遗产保护区 | 须事先取得许可 |
| 生态系统保护区 | 须事先取得许可 |
| 自然环境保护区 | 须事先取得许可 |

## 3. 购房流程详解

| 步骤 | 内容 |
|---|---|
| 1. 看房及签订合同 | 通过持证房产中介找到房源，签订买卖合同 |
| 2. 交付定金 | 通常为成交价的10%（依合同而定） |
| 3. 交付尾款 | 支付尾款并办理所有权转移登记 |
| 4. 所有权转移登记 | 委托司法书士向登记所申请所有权转移登记 |
| 5. 房地产交易申报 | 自合同签订之日起30日内向所在地市·郡·区政府申报 |
| 6. 外国人土地取得申报 | 含土地的取得，须在取得后60日内申报 |
| 7. 缴纳取得税 | 在取得之日起60日内缴纳 |

## 4. 申报义务

### 房地产交易申报

| 项目 | 内容 |
|---|---|
| 申报期限 | 自合同签订之日起30日内 |
| 申报机关 | 房产所在地市·郡·区政府 |
| 申报方式 | 通过房地产交易管理系统（RTMS）网上或现场申报 |
| 申报人 | 卖方·买方共同申报（可委托中介代办） |

### 外国人土地取得申报

| 项目 | 内容 |
|---|---|
| 申报期限 | 自取得之日起60日内 |
| 申报机关 | 土地所在地市·郡·区政府 |
| 违规处罚 | 处以最高取得价款1.5%的罚款 |

## 5. 房产取得税费

外国人与韩国国民同样需缴纳房产取得相关税费。

| 税种 | 税率 | 备注 |
|---|---|---|
| 取得税 | 住宅1~3%，商业·土地4% | 税率因持有套数不同而有差异 |
| 地方教育税 | 取得税的20% | |
| 农渔村特别税 | 取得税的10% | 专用面积85㎡以上住宅适用 |
| 印花税 | 依合同金额确定 | 粘贴于买卖合同上 |
| 登记许可税 | 办理转移登记时缴纳 | |

### 住宅取得税税率（2026年）

| 持有套数 | 调整对象地区 | 非调整对象地区 |
|---|---|---|
| 第1套 | 1~3% | 1~3% |
| 第2套 | 8% | 1~3% |
| 第3套及以上 | 12% | 8% |

> 多套住宅重税规定同样适用于外国人。

## 6. 境外资金汇入及资金来源

从境外汇入韩国房产购买资金须遵守《外国汇兑交易法》相关规定。

| 项目 | 内容 |
|---|---|
| 携带1万美元以上现金入境 | 入境时须向海关申报 |
| 境外汇款 | 通过韩国银行外汇交易窗口处理 |
| 资金来源证明 | 建议准备银行贷款、薪资、投资收益等来源证明材料 |
| 房产资金申报 | 超过一定金额时须向韩国银行或外汇银行申报 |

## 7. 外国人能申请房贷吗？

持有稳定在留资格的外国人可向韩国银行申请住房抵押贷款（以LTV为基准），但收入证明要求比韩国国民更为严格。

| 项目 | 内容 |
|---|---|
| 可申请贷款的签证类型 | F-5（永住）、F-2（居住）、F-4（海外同胞）、E-7等稳定在留者 |
| LTV（抵押价值比率） | 调整对象地区40~50%，非调整地区60~70% |
| 收入证明 | 须证明韩国境内收入（劳动收入·事业收入） |
| 贷款限额 | 因银行及地区不同而有所差异 |

> 短期签证持有人（C-3、D-4等）获得贷款的可能性极低。

---

## 8. 租赁收入税务处理

将取得的房产出租时，需就租赁收入缴纳税款。

| 项目 | 内容 |
|---|---|
| 收入分类 | 租赁收入（住宅租赁收入、事业收入） |
| 税率 | 住宅租赁：年收入2,000万韩元以下适用分类课税（14%）或合并综合所得申报 |
| 申报方式 | 每年5月综合所得税申报 |
| 非居住者预扣税 | 对非居住外国人的租赁收入可预扣20% |

---

## 9. 出售时的税费（转让所得税）

出售房产时需缴纳转让所得税，外国人与韩国国民适用相同规定。

| 项目 | 内容 |
|---|---|
| 转让所得税率 | 依持有年限及套数6~75%不等 |
| 一户一宅免税 | 持有2年以上+居住2年以上（调整对象地区） |
| 非居住外国人 | 通常无法适用一宅免税（适用税收协定时可减免） |
| 申报期限 | 出售后2个月内向辖区税务署申报 |

> 非居住外国人通常难以满足一户一宅免税条件，强烈建议出售前咨询专业税务人士。

## 10. 常见问题解答

**Q. 持旅游签证（C-3）入境的外国人可以在韩国买房吗？**
A. 法律上可行，但短期签证持有人无法申请贷款，且申报手续较为繁琐。实际上，大多数购房外国人持有长期居留签证（F-2、F-5等）。

**Q. 在韩国购买房产后能获得签证或永久居留权吗？**
A. 仅购买自住房产并不能直接获得签证或永居资格。但若通过外国人投资（包含5亿韩元以上房地产投资）可满足D-8投资签证的申请条件。

**Q. 未办理申报手续会怎样？**
A. 违反房地产交易申报或外国人土地取得申报义务，将被处以最高取得价款1.5%的罚款。

**Q. 有哪些地区外国人不能购买房产？**
A. 外国人未经事先许可不得在军事保护区、文化遗产保护区、生态系统保护区内取得土地。对于公寓等建筑物，一般无地区限制。

**Q. 外国法人也可以购买韩国房产吗？**
A. 可以。外国法人可在韩国取得房产，但可能需满足《外国人投资促进法》规定的额外申报或许可要求。
