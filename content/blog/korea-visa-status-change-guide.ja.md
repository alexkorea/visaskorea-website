# 韓国在留資格変更完全ガイド（2026年版）：申請方法・条件・必要書類

韓国に滞在中の外国人が、現在のビザ（在留資格）を維持したまま異なる目的の活動を行う場合は、在留資格変更許可を取得する必要があります。出国せずに韓国国内で変更できる点が最大のメリットです。

## 1. 在留資格変更とは？

在留資格変更は、現在保有しているビザ（在留資格）の種類を別の種類に変更する手続きです。例えば、留学ビザ（D-2）で韓国に滞在中、卒業後に就職が決まり就労ビザ（E-7）に変更するケースや、結婚後に結婚移民ビザ（F-6）に変更するケースなどが該当します。

主な特徴：
- 韓国国内で出国なしに手続き可能
- 現在の在留資格の許可期間内に申請する必要がある
- 変更許可後、新しい在留資格で活動可能

---

## 2. 在留資格変更と在留期間延長の違い

| | 在留資格変更 | 在留期間延長 |
|---|---|---|
| 目的 | ビザの種類自体を変更 | 現在のビザを維持したまま期間を延長 |
| 例 | D-2留学→E-7就労 | E-7就労3年→さらに3年延長 |
| 複雑さ | 比較的複雑で審査が厳格 | 比較的シンプル |
| 書類 | 新しい資格要件を満たす書類 | 現在の資格維持を証明する書類 |

---

## 3. 主な変更ケース

| 変更前 | 変更後 | 主な理由 |
|---|---|---|
| D-2（留学） | E-7（特定活動） | 卒業後就職 |
| D-2（留学） | F-2（居住） | ポイント制要件の充足 |
| D-4（語学研修） | D-2（留学） | 正規課程への入学 |
| C-3（短期訪問） | D-2（留学） | 入学後の資格変更 |
| E-9（非専門就業） | E-7（特定活動） | 技能・経歴の認定 |
| F-3（同伴） | F-2（居住） | 独立在留要件の充足 |
| F-6（結婚移民） | F-2（居住） | 配偶者の死亡・離婚後 |
| その他 | F-5（永住） | 永住資格要件の充足 |

## 4. 申請時期と条件

| 項目 | 内容 |
|---|---|
| 申請可能な時期 | 現在の在留資格の許可期間内 |
| 不法滞在者の申請 | 原則として不可 |
| 変更不可の資格 | 査証免除入国者、一部の短期滞在者等 |
| 審査基準 | 申請資格の要件を満たしているかどうか |

> **重要**：在留期間満了後は変更申請ができません。必ず許可期間内に申請してください。

## 5. 申請場所と方法

### 窓口申請

| 申請場所 | 対象 |
|---|---|
| 居住地管轄の出入国・外国人庁（事務所） | 全国の外国人（原則） |
| ソウル出入国・外国人庁 | ソウル在住者 |
| 仁川空港出入国・外国人庁 | 仁川空港エリア |

### オンライン申請

| 方法 | 内容 |
|---|---|
| ハイコリア（HiKorea） | 一部の在留資格はオンラインで変更申請が可能（hikorea.go.kr） |

## 6. 共通の必要書類

| 書類 | 備考 |
|---|---|
| 在留資格変更許可申請書 | 出入国・外国人庁またはハイコリア様式 |
| パスポート原本 | 有効なパスポート |
| 外国人登録証 | 登録している場合 |
| 手数料の納付 | 該当在留資格の手数料 |
| 証明写真 | 3.5×4.5cmカラー1枚（必要な場合） |

## 7. 在留資格別の追加書類

| 在留資格 | 追加書類 |
|---|---|
| E-7（特定活動） | 雇用契約書、事業者登録証、学位・資格証のコピー |
| D-2（留学） | 入学許可書、在学証明書 |
| F-6（結婚移民） | 婚姻関係証明書、家族関係証明書、配偶者の招聘状 |
| F-2（居住） | 所得証明書、納税事実証明書、ポイント算定書類 |
| F-5（永住） | 在留期間証明書、所得・納税書類、韓国語能力証明 |
| F-4（在外同胞） | 在外同胞身分確認書類 |
| E-9→E-7 | 技術資格証明書、経歴証明書、雇用主の事業者登録証 |

## 8. 申請手続き

1. **資格確認** — 変更しようとする在留資格の要件を満たしているか確認
2. **書類準備** — 共通書類＋資格別の追加書類を揃える
3. **出入国・外国人庁を訪問** — ハイコリアでの予約後の訪問を推奨
4. **申請書の記入・提出** — 窓口で受付
5. **手数料の納付** — 該当する在留資格の手数料を支払う
6. **審査待機** — 資格により即日または数日〜数週間かかる
7. **変更許可の確認** — パスポートへのスタンプまたは外国人登録証の再発行

---

## 9. 審査期間と手数料

| 区分 | 内容 |
|---|---|
| 即日処理 | 単純なケースは当日処理も可能 |
| 審査型 | 複雑なケースは数日〜数週間かかる場合あり |
| 手数料 | 在留資格により異なる（通常6万〜10万ウォン程度） |

> 手数料は在留資格の種類と処理期間によって異なります。訪問前に出入国・外国人庁の公式サイトで最新の手数料をご確認ください。

## 10. よくある質問（FAQ）

**Q. 観光（C-3）ビザで入国後、韓国国内で留学ビザに変更できますか？**
A. 原則として、査証免除または短期訪問目的で入国した方の在留資格変更は制限されています。ただし、大学への入学許可等の特別な事情がある場合は例外が認められることもあるため、専門家への相談をお勧めします。

**Q. 在留資格変更の審査中も、現在のビザで滞在し続けられますか？**
A. はい。許可期間内に変更申請を提出した場合、審査結果が出るまでは合法的に在留できます。申請受付確認書を常に携帯してください。

**Q. E-7ビザに変更するには雇用契約書が必須ですか？**
A. はい。E-7ビザは特定の雇用主・職種に紐づいた資格のため、雇用契約書および雇用主の事業者登録証が必須書類となります。

**Q. 在留資格変更が不許可になった場合はどうなりますか？**
A. 異議申請を行うか、自主出国して海外で改めて該当ビザを申請する方法を検討できます。不許可後に在留期間が満了しても対応しなかった場合は不法滞在となるため、速やかに対処が必要です。

**Q. F-6（結婚移民）からF-2（居住）への変更にはどのくらい時間がかかりますか？**
A. F-6からF-2への変更は、婚姻期間・所得・韓国語能力などを総合審査するため、通常数週間〜数ヶ月かかります。書類を丁寧に準備し、専門家のサポートを受けることをお勧めします。

## 11. 相談案内

在留資格変更は延長より審査が厳格で、不許可になると不法滞在につながる可能性があるため、事前の十分な準備が非常に重要です。特にE-7・F-2・F-5など審査が厳しい資格については、専門家のサポートを受けることが安心です。

ビジョン行政書士事務所では、在留資格変更の代行申請・書類確認・不許可時の対応まで専門的にサポートしています。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
