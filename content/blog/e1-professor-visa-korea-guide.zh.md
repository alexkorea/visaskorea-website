# 韩国E-1教授签证完整指南（2026年）：资格、文件、在留期限与永久居留权

E-1（教授）签证是向在韩国教育机构从事专业教育或研究活动的外国人发放的签证。主要面向在四年制大学或同等学历机构担任正教授、副教授、讲师或研究员的外国人。

如果您已被韩国大学聘为教职人员，或计划在国立/公立研究机构从事教育研究活动，E-1是适合您的签证类型。

## 1. E-1签证是什么？

E-1是韩国《出入境管理法》规定的"教授"在留资格，向在韩国高等教育机构（大学、研究生院、专科学校等）从事专业教育或研究活动的外国人发放。

主要特征：
- 在高等教育机构或同等机构从事教学或研究活动
- 须具备博士学位或同等学历/工作经验
- 由相关机构（大学等）发起签证邀请程序
- 具有长期在留及转换永久居留权的路径

---

## 2. 申请资格

申请E-1签证须满足以下条件：

### 学历与工作经验要求

| 要求 | 标准 |
|---|---|
| 最低学历 | 相关领域博士学位 |
| 替代学历的工作经验 | 硕士学位+相关领域5年以上专业经验 |
| 进一步替代 | 学士学位+10年以上专业经验（部分情况下认可） |
| 职位类型 | 正教授、副教授、助理教授、专任讲师、特聘教授等 |

### 邀请机构要求

| 要求 | 标准 |
|---|---|
| 机构类型 | 依据《高等教育法》的大学、研究生院、专科学校等 |
| 劳动合同 | 与相关机构签订雇佣或聘任合同 |
| 活动内容 | 授课、研究、学生指导等教育相关活动 |

---

## 3. 可邀请机构类型

可发起E-1签证邀请的机构类型如下：

| 机构类型 | 示例 |
|---|---|
| 四年制大学 | 首尔大学、延世大学、高丽大学等 |
| 研究生院 | 各大学附属研究生院 |
| 专科学校 | 2~3年制专科学校 |
| 网络/远程大学 | 韩国放送通信大学、远程教育大学等 |
| 国立/公立教育机构 | 韩国教育开发院等教育部所属机构 |

> **注意**：语言学院、私立补习班、中小学等不属于E-1的可邀请机构。此类情况须考虑E-2（外籍英语教师）或E-7（特定活动）签证。

## 4. 所需材料

### 申请人提交材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 驻外使馆或法务部格式 |
| 护照原件 | 有效期6个月以上 |

| 工作经历证明 | 相关机构出具 |

### 邀请机构提交材料

| 材料 | 备注 |
|---|---|
| 邀请函 | 机构负责人或负责人员签名 |
| 雇佣（聘任）合同 | 注明薪资、职位及期限 |
| 营业执照或机构固有编号证 | |
| 机构认可文件 | 教育部认可或注册确认书 |

## 5. 申请流程

1. **与机构签订雇佣合同** — 完成大学或研究机构的聘任合同
2. **准备邀请材料** — 机构出具邀请函及相关材料
3. **在驻外使馆或出入境事务所申请** — 海外居住者在韩国使馆申请；已在韩国者申请在留资格变更
4. **材料审查** — 通常需5~15个工作日
5. **签证发放或在留资格变更许可**
6. **入境及外国人登记** — 入境后90天内

---

## 6. 在留期限与续签

| 区分 | 期限 |
|---|---|
| 最初在留期限 | 1~2年（根据聘任合同期限决定） |
| 续签 | 合同续签时可续签 |
| 续签次数限制 | 雇佣合同持续期间无特别限制 |

雇佣合同终止时，转移至其他机构须凭新的邀请材料申请在留资格变更或续签。

## 7. 配偶及家属同伴在留

E-1签证持有者的配偶及未成年子女可持F-3（随行）签证在韩国一同居留。

| 区分 | 内容 |
|---|---|
| 配偶在留资格 | F-3（随行） |
| 子女在留资格 | F-3（未成年）或D-4/D-2（留学） |
| F-3就业许可 | F-3基本不允许就业——须单独申请或变更在留资格 |

## 8. 从E-1转换为长期在留或永久居留权

E-1在留期间计入F-2-7积分制居住资格的积分计算，为获取永久居留权提供了明确路径。

| 情况 | 转换路径 |
|---|---|
| 达到F-2-7居住资格积分 | 申请F-2-7积分制居住资格 |
| 与韩国人结婚 | F-6结婚移民 |
| 满足F-5条件 | F-5永久居留权 |

F-2-7积分制居住资格综合韩语能力、年收入、专业资质、在留期限等指标进行评分，累计达到80分以上即可申请。教授及研究职位在学历和收入评分方面通常较为有利。

---

## 9. E-1、E-7、D-2对比

| | E-1教授 | E-7特定活动 | D-2留学 |
|--|--|--|--|
| 对象 | 高等教育机构教授/讲师 | 特定职种专业人员 | 在读大学生 |
| 学历要求 | 博士学位或同等经历 | 因职种而异 | 录取通知书 |
| 雇佣主体 | 大学/研究机构 | 韩国企业 | 无（学生身份） |
| 就业许可 | 仅限受邀机构 | 仅限雇用雇主 | 须申请兼职就业许可 |
| 长期在留路径 | F-2-7、F-5 | F-2-7、F-5 | 毕业后：D-10、E-7等 |

## 10. 常见问题解答

**Q. 没有博士学位可以申请E-1吗？**
A. 若具备硕士学位加相关领域5年以上工作经验，可能获得认可。但不同机构要求有所差异，审核官也有一定自由裁量权。拥有博士学位申请成功率更高。

**Q. 不懂韩语可以申请E-1签证吗？**
A. 可以——如果机构提供英语或其他语言授课，则不需要韩语能力。但若计划申请F-2-7积分制居住资格，韩语（TOPIK）成绩非常重要。

**Q. 持E-1可以在其他大学任教吗？**
A. 原则上不允许在受邀机构以外的地方工作。在其他大学任教可能需要单独申请就业许可或变更在留资格。

**Q. 兼职讲师合同可以申请E-1吗？**
A. 若非全职雇佣合同，签证可能较难获批。兼职或非正规合同可能需按E-7或类似类别审核，建议咨询专业人士。

**Q. 持E-1可以申请永久居留权（F-5）吗？**
A. 可以——在E-1状态下累计满5年，且F-2-7积分达到80分以上，即可申请F-2-7居住资格，进而申请F-5永久居留权。教授职位在收入和学历评分上较为有利。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
