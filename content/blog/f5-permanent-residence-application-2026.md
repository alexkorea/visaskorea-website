# F-5 영주권 신청 완벽 가이드 2026

한국 F-5 영주권은 체류 기간 제한 없이 한국에 거주할 수 있는 자격입니다. 실무에서는 경로마다 요건이 달라 혼란을 겪는 분들이 많습니다.

## 주요 F-5 취득 경로

| 경로 | 요건 |
|------|------|
| F-5-1 (장기 체류) | 적법 체류 5년 이상 |
| F-5-7 (재외동포) | F-4→2년 이상 + 자산 3억 |
| F-5-16 (점수제) | F-2-7→3년 이상 + 소득 GNI 2배 |
| F-5-18 (고액 투자) | 5억 원 이상 직접 투자 |

## 공통 결격 사유
- 최근 5년간 금고 이상 형 집행
- 세금 체납
- 강제 퇴거 이력 3년 미경과

## 신청 절차
1. 자격 요건 확인
2. 서류 준비 (4~6주)
3. 관할 출입국사무소 방문 신청
4. 심사 (4~12주)
5. F-5 영주증 발급
