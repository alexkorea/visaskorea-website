## 什么是D-8企业投资签证？

D-8企业投资签证是根据**《外国人投资促进法》**，面向在大韩民国进行投资并从事企业经营管理或专业技术活动的外国人发放的居留资格。韩国政府积极鼓励外国人直接投资，D-8签证是支持这一政策的核心制度之一。通过该签证，外国投资者可以合法地在韩国居留，并以投资企业的代表理事、高管或技术专家的身份开展业务活动。

D-8签证最显著的特点是，与普通就业签证不同，签证持有人是**企业的所有者或经营参与者**。因此，它与需要雇主担保的E-7等签证有着本质区别。由于投资者亲自设立法人并参与经营管理，D-8签证在稳定性和延期便利性方面具有显著优势。对于希望在韩国长期经营事业的外国人来说，这是最合适的签证类型。

D-8签证基于外国投资企业登记证发放，首次发放时通常给予1至2年的居留期限。只要企业正常运营，签证可以持续延期。此外，满足一定条件的D-8签证持有人可以将居留资格变更为**F-5永住权**，为在韩国的长期稳定居留提供了明确的路径。

## 哪些人需要D-8签证？

D-8企业投资签证面向希望在韩国创业或投资现有韩国企业并参与经营管理的外国人。具体而言，以下人群属于D-8签证的适用对象：进入韩国市场的海外企业法人代表、希望在韩国创办初创企业的外国技术人才，以及希望投入一定金额并积极参与企业经营的海外投资者。

近年来，以IT、生物科技、金融科技等**技术创业**为目的进入韩国的外国人数量大幅增加。韩国政府为积极支持此类技术创业，单独设立了D-8-4（技术创业）类型，在满足特定条件时可享受投资金额降低的优惠。该路径为拥有海外成功技术经验、希望在韩国寻求新商机的人才提供了最佳选择。

此外，目前以E-7（特定活动）、D-9（贸易经营）等签证在韩居留的外国人，如进行直接投资并设立法人，也可以将居留资格变更为D-8签证。许多在韩国积累了经商经验并决定独立创业的外国人正在利用这一途径，签证转换程序也已相当完善。

<div>💡 <strong>提示：</strong> D-8签证不仅需要投资，还要求实际在韩国居留并积极参与企业经营管理。仅投资而不参与经营活动的情况不符合D-8签证的申请条件。</div>

## D-8签证细分类型

D-8企业投资签证根据投资方式和活动内容分为多个细分类型。各类型的资格要件和投资条件各不相同，因此准确了解适合自身情况的类型非常重要。

| 类型 | 名称 | 对象 | 投资要求 |
|------|------|------|----------|
| **D-8-1** | 外商投资企业代表 | 外国投资企业的代表理事 | 投资1亿韩元以上 |
| **D-8-2** | 外商投资企业高管 | 外国投资企业的高管、干部 | 需完成企业注册 |
| **D-8-3** | 外商投资企业专业人才 | 外国投资企业的专业技术人员 | 需完成企业注册 |
| **D-8-4** | 技术创业 | 从事技术创业的外国人 | 可降低要求 |

**D-8-1（外商投资企业代表）**是最常见的类型，适用于根据《外国人投资促进法》投资1亿韩元以上并担任企业代表理事的情况。投资者需持有企业10%以上的有表决权股份，并实际参与经营管理。绝大多数外国投资者申请的就是这一类型。

**D-8-4（技术创业）**是为拥有创新技术、希望在韩国创业的外国人设计的类型。适用于获得中央行政机关长推荐、持有知识产权或被认定具有同等技术能力的人员。与D-8-1相比，投资金额要求可能降低，对技术型初创企业更为有利。还可以通过政府运营的创业签证项目（如OASIS）进入。

## 资格要件及投资要求

申请D-8企业投资签证，需要满足以下所有核心要件。下面将详细介绍投资金额、持股比例、营业场所等各项要求。

| 类别 | 要件 | 详细内容 |
|------|------|----------|
| **最低投资金额** | 1亿韩元以上 | 约8万美元，依据《外国人投资促进法》 |
| **持股比例** | 有表决权股份的10%以上 | 无表决权的优先股等不计入 |
| **营业场所** | 韩国国内注册营业地址 | 需能够开展实际经营活动 |
| **事业者登记** | 法人事业者登记 | 需完成税务局事业者登记 |
| **外商投资企业登记** | 外国投资企业登记 | 通过KOTRA或外汇银行申报 |
| **投资金汇款** | 海外→韩国国内汇款 | 需通过外汇银行正式汇款 |
| **经营参与** | 实质性经营活动 | 仅投资不参与经营不可 |
| **犯罪记录** | 无犯罪记录 | 不得属于入境禁止事由 |

1亿韩元的投资金必须以**注册资本**的形式缴纳到韩国法人账户，且必须从海外正式汇入。仅在韩国国内个人账户中持有的资金不被认可，必须通过外汇银行进行的外国人投资资金汇款路径得到确认。除现金出资外，也可以机械设备、知识产权等进行实物出资，但实物出资需经过授权评估机构的评估鉴定。

关于营业场所要求，需要特别注意的是，该空间必须**能够支持实际经营活动**。仅注册共享办公室地址可能不够充分，建议确保与业务性质和规模相匹配的办公空间。不过，对于IT、软件开发等本身不需要大型物理空间的行业，较小的办公室也可能被接受。

<div>⚠️ <strong>注意：</strong> 1亿韩元投资金必须在法人成立后作为注册资本缴纳。在法人成立前以个人名义持有的资金不被认可为投资金。所有资金必须通过外汇银行的正式外国人投资程序进行。</div>

## 所需文件详细说明

D-8签证申请需要准备大量文件。即使缺少一份文件也可能导致审查延迟或被拒，请务必根据以下清单进行充分准备。

| 序号 | 文件名称 | 备注 |
|------|----------|------|
| 1 | 综合申请表（居留资格授予/变更申请书） | 出入境管理事务所标准格式 |
| 2 | 护照原件及复印件 | 有效期6个月以上 |
| 3 | 标准规格照片1张 | 3.5cm × 4.5cm，6个月内拍摄 |
| 4 | 外国投资企业登记证 | KOTRA或外汇银行发放 |
| 5 | 法人登记簿誊本 | 3个月内发放 |
| 6 | 事业者登记证复印件 | 税务局发放 |
| 7 | 投资金汇款证明文件 | 外汇购入证明书、汇款确认书等 |
| 8 | 注册资本缴纳证明 | 银行发放的余额证明或缴纳证明 |
| 9 | 事业计划书 | 包含业务内容、营收预测、雇用计划 |
| 10 | 营业场所租赁合同 | 用于确认营业场所所在地 |
| 11 | 股东名册或出资确认书 | 用于确认持股比例 |
| 12 | 在职证明或高管选任议事录 | 用于确认代表理事/高管身份 |
| 13 | 本国无犯罪记录证明 | 需经海牙认证或领事认证 |
| 14 | 健康诊断书 | 含结核检查（部分国家） |

文件准备中最具挑战性的部分是**投资金汇款路径的证明**。需要以文件形式证明投资金从海外汇入韩国法人账户的全过程，包括海外汇款确认书、外汇购入证明书、法人账户入账记录等。如果资金来源不明确或汇款路径不一致，可能会被要求提交补充文件或导致审查延迟。

事业计划书虽然没有固定格式，但应详细说明**事业目的、主要业务内容、预计营收、雇用计划、投资资金使用计划**等。由于审查官将事业计划书作为判断该企业是否为合法实体的关键文件，需要投入充足的时间认真编写。如能附上市场分析资料、竞争对手分析、财务规划等，将有助于审查通过。

<div>💡 <strong>提示：</strong> 无犯罪记录证明必须从本国获取。属于《海牙认证公约》成员国的需进行海牙认证，非成员国需经相关大使馆领事认证。办理可能需要数周时间，请提前准备。</div>

## 申请流程六步骤

D-8企业投资签证的申请从投资计划制定到签证发放，主要分为六个步骤。以下将详细介绍每个步骤的流程及注意事项。

<img src="https://images.pexels.com/photos/4427620/pexels-photo-4427620.jpeg?auto=compress&cs=tinysrgb&w=800" alt="商务合同签署" />

### 第一步：制定投资计划

获取D-8签证的第一步是制定系统的投资计划。需要全面评估在韩国经营何种业务、投资规模多大、增长潜力如何等问题。在此阶段，应对商业理念的可行性、韩国市场需求和竞争环境进行深入分析。

此外，提前明确投资资金来源也非常重要。在签证审查过程中，可能需要证明投资资金来源的合法性，因此建议预先准备好能够证明资金来自合法收入或资产的材料。在此阶段咨询专业行政士，评估签证获批可能性并了解流程，将使后续步骤更加顺利。

### 第二步：设立法人及事业者登记

投资计划确定后，即可在韩国设立法人。最常见的形式是设立**株式会社（股份公司）**，包括起草公司章程、确定发起人、缴纳股本等流程。法人设立需在法院登记处办理设立登记，随后在管辖税务局完成事业者登记。

设立法人时需要特别注意的是**正确设定法人的经营范围**。签证审查过程中会确认法人的经营范围与实际业务活动是否一致，因此登记的经营范围必须与实际拟开展的业务内容相符。此外，法人的注册地址需与实际营业场所地址一致，因此在此阶段同步办理营业场所租赁合同更为高效。法人设立通常需要1至2周。

### 第三步：外国人投资申报

在法人设立的同时（或之前），需要进行**外国人投资申报**。可通过KOTRA（大韩贸易投资振兴公社）或外汇银行（国内商业银行的外汇窗口）办理。通过此申报程序，投资者的投资将被正式认定为《外国人投资促进法》下的外国直接投资。

申报时需填写投资者信息、投资目标企业信息、投资金额、投资方式（现金、实物等）、取得的股份数量及持股比例等。完成外国人投资申报后，将发放**外国投资企业登记证**，这是D-8签证申请的核心文件。通常的流程是先进行投资申报，再设立法人，然后汇入投资资金。

### 第四步：投资金汇款

完成外国人投资申报后，从海外向韩国法人账户汇入投资资金。必须通过**外汇银行**正式汇款，汇款时需明确标注为投资资金。汇款完成后，银行将发放外汇购入证明书等证明文件。

需要特别注意的是，**汇款人必须是投资者本人**。不接受通过第三方汇款，资金必须从投资者本人的海外账户直接汇入韩国法人账户。此外，由于投资资金需作为法人的注册资本缴纳，还需确认汇入资金在会计上已正确处理为注册资本。建议在此过程中咨询税务师或会计师。

### 第五步：签证申请

一切准备就绪后，向管辖**出入境管理事务所**提交D-8签证申请。从海外申请的，可向驻外韩国大使馆或领事馆申请签证；已在韩国居留的，可在出入境管理事务所申请居留资格变更或居留资格授予。

申请时需提交前文所列的全部文件。文件受理后，审查官将对提交的材料进行审查，必要时可能要求提交补充文件或补正材料。事业计划书的具体性、投资金的适当性、营业场所的真实性等是主要审查事项，因此在这些方面的充分准备至关重要。通过专业行政士审核文件，可以大大降低被拒的可能性。

### 第六步：签证发放及外国人登记

审查完成后即发放D-8签证。从海外获得签证的，入境韩国后需在90天内到出入境管理事务所办理**外国人登记**。外国人登记完成后将发放外国人登记证（居留卡），在韩国境内作为身份证明使用。

如果是在韩国居留期间通过居留资格变更获得D-8签证的，则无需另外办理外国人登记，只需变更现有外国人登记证上的居留资格即可。首次居留期限通常为1至2年，此后只要证明企业正常运营即可延期。

## 审查时间及费用

D-8签证的审查时间因申请途径和审查情况而异。以下是预计所需时间和费用的汇总。

| 项目 | 内容 |
|------|------|
| **驻外使领馆签证发放** | 约2-4周（因国家而异） |
| **韩国国内居留资格变更** | 约2-4周 |
| **居留期限延期** | 约1-2周 |
| **手续费（单次签证）** | 约60,000韩元 |
| **手续费（居留资格变更）** | 约130,000韩元 |
| **外国人登记手续费** | 约30,000韩元 |

审查时间取决于文件的完备程度和出入境管理事务所的工作量。如果文件准备完善，可能在2周内出结果；但如需补充文件，则可能超过一个月。因此建议留出充裕的时间，尽量在签证到期前至少1至2个月提出延期申请。

费用方面，除签证手续费外，还需考虑法人设立费用（登记许可税、律师费等）、营业场所租赁费用、会计税务费用等。不含投资金在内，初期总费用通常在500万至1,000万韩元左右。

<div>⚠️ <strong>注意：</strong> 手续费可能会变动，签证发放手续费也可能因国籍不同而有差异。请向出入境管理事务所或驻外使领馆确认最新费用标准。</div>

## 家属同行签证（F-3）

D-8签证持有人的**配偶和未成年子女**可以申请F-3（同行）签证，与家人一起在韩国居留。这是D-8签证的一大优势，使投资者能够在经营事业的同时享受稳定的家庭生活。

F-3签证申请所需文件包括家属关系证明文件（结婚证、出生证等）、D-8签证持有人的外国人登记证复印件、经济能力证明文件等。家属关系证明文件需经海牙认证或领事认证，根据需要可能还要求提供韩语翻译公证。F-3签证的居留期限不能超过D-8签证持有人的居留期限。

F-3签证持有人原则上不能就业，但如另行获得**居留资格外活动许可**，则可从事兼职工作等。此外，子女可以就读韩国的国际学校或普通学校，在子女教育方面也很有优势。

## 永住权（F-5）转换

满足一定条件的D-8签证持有人可以将居留资格变更为**F-5（永住）签证**。获得永住权后，可以在韩国无期限居住，就业活动也不受限制。

从D-8转换为F-5的主要要件如下：

| 要件 | 内容 |
|------|------|
| **投资金维持** | 维持5亿韩元以上投资 |
| **创造就业** | 常时雇用5名以上韩国国民 |
| **居留期间** | 在韩国居留5年以上 |
| **收入要件** | 达到GNI（国民总收入）标准以上 |
| **韩语能力** | 完成社会融合课程或TOPIK 2级以上 |
| **犯罪记录** | 无犯罪记录 |

F-5永住权是D-8签证持有人最理想的长期居留目标。投资金5亿韩元以上、雇用5名以上韩国国民的条件，对于成功经营企业的投资者来说是完全可以实现的。获得永住权后，无需再办理居留延期手续，可以自由从事经济活动。

不过，获得永住权后在**再入境许可**方面需要注意。如果离开韩国超过2年，永住权可能被取消，因此在长期出国前建议办理再入境许可。

<div>💡 <strong>提示：</strong> 根据投资规模的不同，F-5永住权转换的居留期间要件可能缩短。例如，大规模投资者可能仅需居留3年以上即可申请永住权。详细情况请咨询专业行政士。</div>

## D-8与D-9对比

D-8（企业投资）和D-9（贸易经营）都是外国人在韩国从事商务活动的签证，但法律依据和适用对象不同。为选择适合自身情况的签证，准确了解两者的区别至关重要。

| 对比项目 | D-8（企业投资） | D-9（贸易经营） |
|----------|----------------|----------------|
| **法律依据** | 《外国人投资促进法》 | 《出入境管理法》 |
| **最低投资金额** | 1亿韩元以上 | 3亿韩元以上（建议） |
| **外商投资企业登记** | 必须 | 不需要 |
| **持股比例要求** | 有表决权股份的10%以上 | 无具体规定 |
| **适用对象** | 外商投资企业代表/高管/专业人才 | 贸易商、个体经营者、分公司等 |
| **税收优惠** | 可享受外国投资税收减免 | 适用一般税率 |
| **F-5转换** | 投资5亿韩元+雇用5人 | 另有要求 |
| **家属同行** | 可申请F-3 | 可申请F-3 |

D-8签证最大的优势是可以享受**《外国人投资促进法》**下的各种支持和税收优惠。注册为外国投资企业后，可在法人税、所得税、取得税、财产税等方面获得减免（因行业和投资地区而异），还可利用KOTRA等政府机构提供的各类支持服务。

相比之下，D-9签证无需外国投资企业登记即可获得，手续相对简单，但投资金额要求更高且无税收优惠。D-9主要适合贸易、进出口代理、海外企业韩国分公司运营等用途。希望以个体经营者身份活动的也可能更适合D-9。

## 常见问题（FAQ）

**Q: D-8签证的最低投资金1亿韩元必须是现金吗？**

不一定。现金出资是最常见的方式，但也可以进行**实物出资**。可以用机械设备、知识产权（专利、商标等）、技术等进行实物出资，但需经授权评估机构评估确定价值。不过在实务中，现金出资最为简便，在审查中也更有利。

**Q: D-8签证可以邀请家属吗？**

可以。D-8签证持有人的**配偶和未成年子女**可以申请F-3（同行）签证。需提交证明家属关系的文件（结婚证、出生证等），且该文件需经海牙认证或领事认证。F-3签证的居留期限不能超过D-8签证持有人的居留期限。

**Q: 从D-8签证转换为永住权（F-5）需要多长时间？**

一般需要**在韩国居留5年以上**，同时满足维持5亿韩元以上投资、雇用5名以上韩国国民等条件。但投资规模较大或创造就业效果显著的，居留期间要求可能缩短。此外还需满足社会融合课程或韩语能力（TOPIK 2级以上）要求，建议提前准备。

**Q: 获得D-8签证后可以同时经营其他事业吗？**

D-8签证用于在注册的**外国投资企业**中的活动，如要在其他企业从事活动，需另行获得许可。但在同一法人内，公司章程所载经营范围内的活动是允许的。如需开展额外的经营活动，需申请居留资格外活动许可。

**Q: D-8签证审查被拒的主要原因是什么？**

主要拒签原因包括：①投资资金来源不明确，②事业计划书的可行性不足，③营业场所缺乏实体，④文件不全或提交虚假文件，⑤曾有出入境法规违反记录等。特别是被怀疑为空壳公司的情况，审查会非常严格，因此展示具体的实质性经营活动计划非常重要。

**Q: 已在韩国居留的情况下可以变更为D-8签证吗？**

可以。在韩国合法居留的外国人可以通过出入境管理事务所的**居留资格变更申请**转换为D-8签证。从E-7、D-9、F-2等其他居留资格变更为D-8是可行的，但各居留资格的具体要件可能不同，请事先确认。

**Q: D-8签证的居留期限是多久？**

首次发放时通常给予**1至2年**的居留期限。此后只要证明企业正常运营，每次可延期1至3年。延期时需提交法人的财务报表、营业收入实绩、雇用状况等。
