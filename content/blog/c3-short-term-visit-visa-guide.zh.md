# 韩国C-3短期访问签证完整指南（2026年）：种类、期限、申请材料及免签比较

C-3（短期访问）签证是向以观光、访问、商务、会议、亲属探访等短期目的来韩的外国人发放的签证。这是韩国入境签证中发放量最大的类型，在留期限最长为90天。

免签协议对象国国民无需C-3即可入境，但非免签对象国国民必须办理C-3签证。

## 1. C-3签证是什么？

C-3是韩国《出入境管理法》规定的"短期访问"在留资格，向以商业、观光、访问、会议、文化等90天以内短期目的来韩的外国人发放。

主要特征：
- 在留期限：最长90天（单次入境基准）
- 不可从事就业目的的活动
- 禁止营利性活动（部分商务目的除外）
- 取得多次入境签证后，在签证有效期内每次入境最长可在留90天

---

## 2. C-3细分种类

C-3根据访问目的细分如下：

| 种类 | 代码 | 主要用途 |
|---|---|---|
| 一般观光 | C-3-1 | 观光、休闲、医疗观光等 |
| 短期商务 | C-3-2 | 市场调查、合同洽谈、商业会谈 |
| 亲属访问 | C-3-3 | 探访家人或朋友 |
| 会议・活动参加 | C-3-4 | 国际会议、学术活动 |
| 文化・艺术活动 | C-3-5 | 观看演出、体育赛事 |
| 参加培训 | C-3-6 | 短期技术研修（非就业目的） |
| 新闻采访 | C-3-7 | 短期媒体采访 |
| 其他短期访问 | C-3-9 | 其他短期访问目的 |

须按实际目的申请对应细分代码，若从事登记代码以外的活动，可能被认定为超范围活动而面临处罚。

## 3. 申请资格及共同要件

无入境拒绝事由的外国人大多可申请C-3签证。

### 共同要件

| 要件 | 内容 |
|---|---|
| 有效护照 | 有效期6个月以上 |
| 访问目的明确 | 可说明观光、访问、商务等目的 |
| 经济能力 | 能证明在留期间的生活费（银行余额证明等） |
| 返程意愿 | 证明无在韩国非法滞留意图 |
| 无不良记录 | 无犯罪经历、无被强制驱逐记录 |

对特定国家国民可能要求额外材料。

---

## 4. 所需材料

### 共同材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 驻外使馆格式 |
| 护照原件 | 有效期6个月以上 |
| 照片1张 | 3.5×4.5cm |
| 签证费 | 因国家和签证类型而异 |

### 按访问目的所需额外材料

| 目的 | 额外材料 |
|---|---|
| 观光 | 机票预订确认书、住宿预订确认书、银行余额证明书 |
| 短期商务 | 韩国企业邀请函或访问目的说明书、在职证明书 |
| 亲属访问 | 邀请函（韩国在留亲属出具）、亲属关系证明材料 |
| 会议・活动 | 活动参加确认书、主办机构公函 |
| 医疗观光 | 医院预约确认书 |

各驻外使馆可能要求额外材料，申请前请在相关使馆官网确认。

## 5. 申请流程

C-3签证申请按以下顺序进行：

1. **准备材料** — 整备共同材料及访问目的别材料
2. **前往驻外使馆申请** — 亲自前往居住国内的韩国大使馆或领事馆（部分国家需网上预约后再前往）
3. **审查** — 通常5~10个工作日内处理完毕
4. **领取签证贴纸或电子签证**
5. **入境后90天内在留**

部分国家可在线申请电子签证（e-Visa）。

---

## 6. 在留期限与延期

| 区分 | 内容 |
|---|---|
| 基本在留期限 | 最长90天 |
| 在留期限延期 | 原则上不可延期 |
| 需要延期时 | 医疗等不可避免情况下，可向出入境管理局申请延期 |

C-3签证的延期非常受限。如需长期在留，应按目的申请长期在留资格（D-2、E-7、F-6等）。

## 7. C-3多次入境签证

C-3签证分为单次入境和多次入境两种。

| 区分 | 内容 |
|---|---|
| 单次入境 | 可入境1次，每次最长在留90天 |
| 多次入境 | 在签证有效期内不限次数入境，每次最长在留90天 |
| 多次入境签证有效期 | 通常为1年、3年或5年（根据入境记录而异） |

### 多次入境签证取得条件

入境记录良好且满足以下条件时可申请多次入境签证：

- 近3年内有2次以上的韩国入境记录
- 无超期滞留记录
- 能证明稳定收入或在职状态
- 短期商务或亲属访问的情况，须提供邀请企业或家庭关系证明

外交・公务、企业邀请等特定目的的情况下，多次入境签证通常可优先发放。

## 8. 免签入境与C-3对比

| 区分 | 免签入境（VWP） | C-3签证 |
|---|---|---|
| 对象 | 与韩国签有免签协议国家的国民 | 非免签国家国民 |
| 事前手续 | 需登记K-ETA（部分国家） | 需在驻外使馆申请签证 |
| 在留期限 | 最长90天 | 最长90天 |
| 延期 | 不可 | 原则上不可 |
| 入境目的 | 观光・访问・商务等 | 相同（需说明目的） |

免签对象国国民如有超期滞留记录或其他入境拒绝事由，也可能须另行办理签证。

韩国免签协议对象国名单请参考外交部签证豁免协议说明。

## 9. 持C-3可否在韩国境内变更签证？

原则上，持C-3在留期间在国内变更体留资格受到限制。但在以下例外情况下可以办理：

| 情况 | 变更可否 |
|---|---|
| 与韩国人结婚后申请F-6 | 可以（满足结婚要件时） |
| 确定在韩国就业后申请E-7 | 原则上不可——建议出境后申请E-7 |
| 收到韩国大学录取通知后申请D-2 | 原则上不可——建议出境后申请D-2 |
| 需要长期医疗治疗申请G-1 | 可以（需提供医疗目的说明） |

如计划在韩国工作或留学，最安全的做法是在入境前在本国取得相应目的签证。

## 10. 常见问题解答

**Q. 持C-3观光签证来韩国，可以打工吗？**
A. 不可以。C-3签证完全禁止就业（包括兼职）。未经授权就业将面临强制驱逐出境及入境禁止处分。如需就业，须在入境前办理相应就业签证（E-7、E-9等）。

**Q. 持C-3入境，快到90天了，可以延期吗？**
A. 原则上不可以。仅在突发疾病、自然灾害等不可避免的情况下，可向出入境管理局申请延长在留期限，但此为例外情形。若在留目的趋于长期化，请咨询专家了解转换长期签证的方法。

**Q. 亲属访问签证（C-3-3）的邀请人必须是韩国公民吗？**
A. 不是。在韩国合法居住的外国人也可作为邀请人。需要提供邀请人的在留资格、在留期限及关系证明材料。

**Q. 我曾在韩国超期滞留，还能申请C-3签证吗？**
A. 有超期滞留记录会大大增加签证被拒绝的可能性。根据超期滞留时间及驱逐记录，可能已被设定入境禁止期限，届时无法入境。请申请前咨询专家。

**Q. 持C-3入境后与韩国人结婚，可以不出境直接申请F-6吗？**
A. 可以。持C-3在韩国完成法律婚姻登记后，可在国内申请变更为F-6（结婚移民）签证，无需出境。但须注意F-6审查期间不要超过C-3在留期限。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
