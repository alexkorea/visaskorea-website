# 韓国外国人向けSIMカード・スマートフォン開通完全ガイド（2026年）：キャリア・プラン・手続き

韓国は世界最高水準の5G通信インフラを誇り、適切な書類があれば外国人でも簡単にスマートフォンやSIMカードを開通できます。このガイドでは、韓国の携帯通信サービスを利用したい外国人向けに実用的な情報をまとめています。

## 1. 外国人の開通条件 {#section-1}

外国人が韓国で携帯電話を開通するには、以下の条件が必要です。

| 条件 | 内容 |
|---|---|
| 身分証明 | パスポートまたは外国人登録証（ARC） |
| 在留資格 | 有効な韓国ビザの保有 |
| ポストペイド | 原則として外国人登録証が必要 |
| プリペイド | 一部キャリアではパスポートのみで可能 |
| 信用調査 | 不要または簡略化 |

> 外国人登録証を持たない短期訪問者も、パスポートでプリペイドSIMを空港・コンビニ・一部店舗で購入できます。

## 2. プリペイドvsポストペイド {#section-2}

| 項目 | プリペイド | ポストペイド |
|---|---|---|
| 必要書類 | パスポート（一部はARC必要） | 外国人登録証＋パスポート |
| 契約期間 | なし（チャージ式） | 12〜24か月 |
| 請求 | 残高がなくなると自動終了 | 毎月請求 |
| 通信速度 | プランによっては制限あり | フルLTE/5G |
| 端末 | SIMフリー端末が必要 | 割賦購入可能 |
| 向いている方 | 短期滞在者・旅行者 | 長期滞在者（6か月以上） |

## 3. 大手3キャリアの比較 {#section-3}

| キャリア | 特徴 |
|---|---|
| SKT（SKテレコム） | 韓国最大のキャリア、全国5Gカバレッジが最優秀 |
| KT | 第2位のキャリア、安定したデータ品質、外国人向けサービスを強化 |
| LGU+（LG U+） | 第3位のキャリア、外国人向けプランが充実、国際ローミングに強み |

> 3社の品質に大きな差はありません。料金と特典を比較して選ぶのがベストです。

## 4. 格安SIM（MVNO）の活用 {#section-4}

MVNOは大手3キャリアのネットワークを借りて、低価格でサービスを提供する事業者です。

| 特徴 | 内容 |
|---|---|
| 料金 | 同等のデータ量で大手キャリアより30〜50%安い |
| 通信品質 | SKT・KT・LGU+のいずれかのネットワーク使用（同等品質） |
| 外国人登録 | オンラインまたはコンビニで購入可能 |
| 主なMVNO | アルタモバイル・ハローモバイル・U+アルタ・セジョンテレコムなど |
| デメリット | 店舗数が少なく、サポートが限られる |

> 長期滞在の外国人にとって、MVNOは毎月の通信費を大幅に節約できます。

## 5. 空港でのSIM購入 {#section-5}

仁川国際空港と金浦空港では、入国直後にSIMカードを購入できます。

| 購入場所 | 位置 |
|---|---|
| KTローミングセンター | 仁川空港第1・第2ターミナル到着ロビー |
| SKT T-ローミング | 仁川空港到着ロビー |
| LGU+ローミングセンター | 仁川空港到着ロビー |
| コンビニ | 空港内のGS25・CUなど |
| オンライン事前注文 | 各キャリア公式ウェブサイト（入国前に注文し到着後受取） |

> 空港のSIMは主に7日・30日・90日などの短期データSIMが中心です。

## 6. 開通手続き（店舗訪問） {#section-6}

| ステップ | 内容 |
|---|---|
| 1 | キャリアの直営店または販売代理店を訪問 |
| 2 | パスポート＋外国人登録証を提示 |
| 3 | プランを選択（プリペイド/ポストペイド） |
| 4 | 申込書記入・署名 |
| 5 | SIMカードの受け取りまたは端末の開通 |
| 6 | 認証SMSを確認し開通完了 |

> 英語や日本語対応が可能な店舗を事前に確認しておくと便利です。外国人向けカスタマーサービス：SKT 080-011-6000 / KT 100 / LGU+ 101

## 7. 外国人の本人確認方法 {#section-7}

韓国ではさまざまなサービスで本人確認が必要です。

| 確認方法 | 外国人の利用可否 |
|---|---|
| 携帯SMS認証（OTP） | 可能（開通後） |
| 外国人登録番号認証 | 可能（ARC保有者） |
| 公同認証書（旧公認証書） | ARC保有者が取得可能 |
| PASSアプリ認証 | 可能（ARC＋韓国番号が必要） |
| カカオペイ認証 | ARC＋韓国銀行口座が必要 |

> 外国人登録証と韓国の携帯電話番号があれば、ほとんどの韓国オンラインサービスの本人確認が可能になります。

## 8. 主要プランの料金比較 {#section-8}

| 区分 | 月額 | データ量 |
|---|---|---|
| 基本プラン | 15,000〜25,000ウォン | 1〜3GB |
| 中間プラン | 35,000〜55,000ウォン | 10〜30GB |
| 無制限 | 65,000〜90,000ウォン | 完全無制限 |
| MVNO無制限 | 20,000〜40,000ウォン | 完全無制限 |
| プリペイド30日SIM | 20,000〜40,000ウォン | 2〜10GB |

> データ消費量が多い方は、MVNOの無制限プランを活用すれば大幅なコスト削減が可能です。

## 10. よくある質問（FAQ） {#section-10}

**Q. 外国人登録証なしでもSIMカードを買えますか？**
A. はい。プリペイドSIMはパスポートでコンビニ・空港・一部キャリア店舗で購入できます。ポストペイドの定期契約には原則として外国人登録証が必要です。

**Q. 韓国の電話番号なしでKakaoTalkは使えますか？**
A. 外国の電話番号でKakaoTalkに登録することは可能ですが、韓国番号があるとアプリ（および多くの韓国サービス）がよりスムーズに使えます。

**Q. 海外から持ってきたSIMフリーの端末は韓国のSIMで使えますか？**
A. 基本的に使えます。LTE対応周波数帯（Band 1・3・5・7・8・28）との互換性を事前に確認することをお勧めします。

**Q. 外国人もMVNOに加入できますか？**
A. はい。外国人登録証保有者はほとんどのMVNOサービスに加入できます。一部のMVNOは外国人向けのオンライン申込みにも対応しています。

**Q. 韓国の電話番号で銀行認証や海外送金はできますか？**
A. はい。韓国の銀行口座と連携すれば、SMS認証でインターネットバンキングなどが利用できます。ただし、外国人顧客向けのサービス範囲は銀行によって異なります。
