# 韩国在留资格变更完整指南（2026年）：申请方法、条件及所需材料

在韩国居留的外国人如希望从事与现有签证（在留资格）目的不同的活动，必须取得在留资格变更许可。最大的优点是无需出境，可在韩国境内直接办理。

## 1. 在留资格变更是什么？

在留资格变更是将现有签证（在留资格）类型变更为其他类型的程序。例如，持留学签证（D-2）在韩国居留，在毕业就业后变更为就业签证（E-7），或结婚后变更为结婚移民签证（F-6）等情况。

主要特点：
- 无需出境，可在韩国境内办理
- 须在现有在留资格许可期限内申请
- 获批后可凭新在留资格从事相关活动

---

## 2. 在留资格变更与签证延期的区别

| | 在留资格变更 | 签证（在留期限）延期 |
|---|---|---|
| 目的 | 变更签证类型本身 | 维持现有签证并延长在留期限 |
| 示例 | D-2留学→E-7就业 | E-7就业满3年→再延3年 |
| 复杂程度 | 相对复杂，审查更严格 | 相对简单 |
| 材料 | 证明符合新资格要求的材料 | 证明维持现有资格的材料 |

---

## 3. 主要变更案例

| 变更前 | 变更后 | 主要原因 |
|---|---|---|
| D-2（留学） | E-7（特定活动） | 毕业后就业 |
| D-2（留学） | F-2（居住） | 满足积分制条件 |
| D-4（语言研修） | D-2（留学） | 入读正规课程 |
| C-3（短期访问） | D-2（留学） | 入学后资格变更 |
| E-9（非专业就业） | E-7（特定活动） | 技能·经历获得认可 |
| F-3（随行） | F-2（居住） | 满足独立居住条件 |
| F-6（结婚移民） | F-2（居住） | 配偶去世·离婚后 |
| 其他 | F-5（永久居留） | 满足永久居留条件 |

## 4. 申请时机及条件

| 项目 | 内容 |
|---|---|
| 可申请时机 | 现有在留资格许可期限内 |
| 非法逗留者申请 | 原则上不可申请 |
| 不可变更资格 | 免签入境者、部分短期居留者等 |
| 审查标准 | 是否符合所申请资格的要求 |

> **重要**：在留期限届满后无法申请资格变更。请务必在许可期限内申请。

### 线下申请

| 申请地点 | 适用对象 |
|---|---|
| 居住地管辖出入境·外国人厅（事务所） | 全国外国人（原则上） |
| 首尔出入境·外国人厅 | 首尔居住者 |
| 仁川机场出入境·外国人厅 | 仁川机场区域 |

### 线上申请

| 方式 | 内容 |

| E-9→E-7 | 技术资格证书、经历证明书、雇主营业执照 |

## 8. 申请流程

1. **确认资格** — 确认是否符合所申请在留资格的要求
2. **准备材料** — 准备共同材料及各资格附加材料
3. **前往出入境·外国人厅** — 建议通过HiKorea预约后前往
4. **填写并提交申请书** — 窗口提交
5. **缴纳手续费** — 缴纳对应在留资格手续费
6. **等待审查** — 根据资格类型即时或数日至数周内办理
7. **确认变更许可** — 护照盖章或重新发放外国人登记证

---

## 9. 审查期限及费用

| 项目 | 内容 |
|---|---|
| 即时办理 | 简单案件可当天办理 |
| 审查型 | 复杂案件需数日至数周 |
| 手续费 | 因在留资格而异（通常6万~10万韩元） |

> 手续费因在留资格种类和处理期限而有所不同，前往出入境·外国人厅前请确认最新费用。

## 10. 常见问题解答

**Q. 以旅游（C-3）签证入境后，可以在韩国境内直接变更为留学签证吗？**
A. 原则上，以免签或短期访问目的入境者的在留资格变更受到限制。但大学入学等特殊情况可能例外——建议咨询专业人士。

**Q. 在留资格变更审查期间，可以以现有签证继续在韩居留吗？**
A. 可以。在许可期限内提交申请的，在审查结果出来之前被视为合法在留。请随时携带申请受理确认书。

**Q. 申请E-7就业签证变更，是否必须有雇用合同？**
A. 是的。E-7签证与特定雇主和职种挂钩，雇用合同及雇主营业执照为必要材料。

**Q. 在留资格变更申请被拒后怎么办？**
A. 可申请异议，或考虑自愿出境后在海外重新申请相应签证。被拒后如在留期限届满仍未采取行动，将成为非法逗留者——须立即采取措施。

**Q. 从F-6（结婚移民）变更为F-2（居住）需要多长时间？**
A. F-6到F-2的变更需综合审查婚姻期限、收入、韩语能力等多项条件，通常需要数周至数月。建议仔细准备材料并寻求专业人士协助。

## 11. 咨询指南

在留资格变更审查比签证延期更为严格，一旦被拒可能导致非法逗留，事前充分准备至关重要。尤其是E-7、F-2、F-5等审查严格的资格，建议寻求专业人士的帮助。
