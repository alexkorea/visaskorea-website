# 韩国E-2英语教师签证完全指南（2026年版）：申请要求·材料·长期居留路径

E-2（会话指导）签证允许符合条件国家的英语母语者在韩国语言学院、学校及大学担任英语教师。

E-2是一种对国籍、学历及雇主均有严格要求的专项签证，与范围更广的E-7签证存在明显区别。在接受工作邀约前，务必准确核实自身是否符合所有条件。

## 1. E-2是什么？——会话指导签证的适用范围 {#section-1}

E-2是韩国《出入境管理法》中的「会话指导」资格，允许符合条件的英语母语者在韩国从事英语教学活动。

### 符合条件的教学活动

- 在已注册私立语言培训机构（学院）担任英语教师
- 在公立或私立中小学担任英语原语教师助理（ETA）
- 在大学或研究生院讲授英语课程
- 在企业内部语言培训项目任教（须签订正式雇用合同）

E-2仅适用于英语教学。教授其他外语（中文、日语、法语等）须申请E-7等其他签证类别，而非E-2。

---

## 2. 国籍要求——7个符合条件的国家 {#section-2}

E-2签证**仅向以下7个英语母语国家的公民发放**：

| 国家 | 是否符合 |
|---|---|
| 美国 | ✅ |
| 英国 | ✅ |
| 加拿大 | ✅ |
| 爱尔兰 | ✅ |
| 澳大利亚 | ✅ |
| 新西兰 | ✅ |
| 南非 | ✅ |

以上7国以外的国籍，即使英语为母语，也不符合E-2条件。例如，菲律宾、印度、新加坡、牙买加等国公民须通过E-7或其他工作签证申请。

---

## 3. 学历要求——本科学位以上 {#section-3}

所有E-2申请人须持有**认可大学颁发的四年制本科学位或以上**。

| 要求 | 标准 |
|---|---|
| 最低学历 | 本科（四年制）学位 |
| 专业 | 不限（教育学、英语或相关专业可优先考量） |
| 证明材料 | 毕业证书+成绩单（附韩语或英语翻译件） |

两年制专科学历不满足E-2要求。无本科学位者可咨询是否有适用的E-7特定活动签证职种。

---

## 4. 无犯罪记录证明——E-2核心材料 {#section-4}

无犯罪记录证明是E-2申请中最重要的材料之一，也是最常导致申请延迟的环节。

### 无犯罪证明要求

| 项目 | 标准 |
|---|---|
| 出具机构 | 原籍国政府或国家警察机关 |
| 有效期 | 签发之日起6个月内 |
| 认证方式 | 须附海牙认证（Apostille）或本国公证 |
| 翻译 | 提交韩语或英语译本（可能要求公证翻译） |

**各国大致处理时长：**
- FBI（美国）：标准12周以上，通过认证代办约6至8周
- 加拿大皇家骑警（RCMP）：2至3周
- 澳大利亚联邦警察：4至6周
- 英国DBS（海外申请）：4至6周

无犯罪证明通常是E-2材料中准备时间最长的，务必提前3至4个月开始办理。

续签时还须额外提交韩国警察厅出具的国内犯罪记录查询结果。涉及毒品、性犯罪或暴力犯罪的前科可能导致E-2申请被拒。

## 5. 雇主要求——培训机构·学校·大学 {#section-5}

E-2须有**合格的雇主担保**。自由职业英语教学或无雇主状态不符合E-2申请条件。

### 认可雇主类型

| 雇主类型 | 条件 |
|---|---|
| 私立语言培训机构（学院） | 依《学院法》在当地教育主管部门注册 |
| 公立/私立中小学 | 政府运营或教育部门管辖 |
| 大学或研究生院 | 教育部认可的院校 |
| 企业内部培训 | 须签订直接全职雇用合同 |

未注册的私人补习、非正式英语场所，或未完成合规注册的小型英语学院均无法为E-2签证担保。

### 申请人材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 使用驻外使领馆或Hi Korea提供的表格 |
| 护照 | 有效期6个月以上 |
| 证件照 | 3.5×4.5cm，6个月内拍摄 |
| 本科学位毕业证书 | 须附海牙认证或公证 |
| 无犯罪记录证明 | 原籍国出具，附海牙认证，6个月内有效 |

| 材料 | 备注 |

| 雇用合同 | 须注明薪资、工时及合同期限 |
| 营业执照 | |
| 学院注册证书 | 学院类雇主须提供 |

## 7. 申请流程 {#section-7}

### 在海外申请（申请签证）

1. 与韩国雇主签订雇用合同
2. 雇主向法务部申请签证发放确认书
3. 雇主将确认书发送给申请人
4. 申请人向驻当地韩国大使馆或领事馆提交全部材料
5. 审核：通常需5至10个工作日
6. 签证发放后入境韩国

### 在韩国境内变更签证状态

若已持其他签证在韩居留：
1. 签订合同后由雇主取得签证发放确认书
2. 通过Hi Korea（hikorea.go.kr）或出入境外国人厅申请变更为E-2
3. 审核：通常需2至4周

## 8. 居留期限与续签 {#section-8}

| 项目 | 内容 |
|---|---|
| 初始居留期限 | 通常1年，与雇用合同期限挂钩 |
| 续签 | 在职期间可按年续签 |
| 更换雇主 | 需新雇主签证发放确认书+居留资格变更申请 |

**续签时**须提交更新后的雇用合同，并附上韩国警察厅出具的国内无犯罪证明，以及必要时更新的健康证明。建议至少在签证到期前一个月开始办理续签手续。

## 9. 从E-2到长期居留——F-2-7转换路径 {#section-9}

在韩以E-2身份工作数年后，转换为F-2-7（积分制长期居留签证）是实现长期居留的现实路径。

### 典型E-2教师的F-2-7积分预估

| 项目 | 情况说明 |
|---|---|
| 年龄（最高25分） | 25至29岁满分25分；30至34岁仍有20分 |
| 学历（最高35分） | 本科25分；硕士30分；博士35分 |
| 收入（最高60分） | 典型E-2薪资约GNI 1至1.5倍=20至30分；高薪岗位可达40分以上 |
| TOPIK韩语（最高20分） | 在韩工作期间专项备考可获得额外积分 |
| 国内工作经历加分 | 每年+1分（最多5年=5分） |

硕士学历+在韩工作5年+TOPIK 4级+有竞争力的薪资，通常可达到F-2-7 80分的合格线。

详细积分表及策略请参阅[F-2-7积分制长期居留签证指南](/zh/blog/f2-7-points-based-long-term-residency)。

## 10. 常见问题解答 {#section-10}

**Q. 我是加拿大永久居民（PR），但没有加拿大国籍，可以申请E-2吗？**
A. 不可以。E-2仅面向上述7国**公民**，不适用于永久居民。无加拿大国籍则不具备申请E-2的资格。

**Q. 我拥有双重国籍（美国+其他国家），用哪本护照申请？**
A. 出示美国护照即可。只要持有7个符合条件国家之一的国籍，即可申请E-2，另一国国籍不影响申请——除非其中一个国籍为韩国国籍（则无需外国工作签证）。

**Q. FBI背景调查需要多长时间？**
A. FBI直接服务标准处理目前需12周以上；通过FBI认可的代办机构通常可缩短至6至8周。建议包括海牙认证在内，至少预留3个月时间。

**Q. 持E-2期间可以在校外私下做家教吗？**
A. 不可以。E-2仅授权在您的注册雇主处从事教学。在担保机构以外进行有偿家教违反签证规定。

**Q. 能否从E-2转为E-7以绕过国籍限制？**
A. E-7对更多国籍开放，但需要在特定指定职种获得雇主的工作邀约。若雇主愿意为您的岗位申请E-7，且职种符合条件，则E-7在某些情况下可用于英语教学。建议咨询专业人士确认职种是否符合要求。

## 11. 咨询服务 {#section-11}

E-2申请最常见的问题是无犯罪证明准备延误，以及雇主提供的担保材料不完整。提前3至4个月开始办理无犯罪证明，并选择合规注册的雇主，是两个最关键的准备步骤。

飞展行政士事务所提供E-2签证申请、续签支持，以及F-2-7长期居留规划全程服务。
