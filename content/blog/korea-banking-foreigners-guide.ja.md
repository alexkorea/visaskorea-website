## 2. 外国人の口座開設条件と必要書類

### 基本条件

| 条件 | 内容 |
|---|---|
| 外国人登録証（ARC） | 基本的に必須（一部の銀行はパスポート＋ビザのみ可） |
| 在留資格 | 短期観光（B-1・B-2）以外を推奨 |
| 国内住所 | 外国人登録の住所 |

### 必要書類

| 書類 | 備考 |
|---|---|
| 外国人登録証（ARC） | ほとんどの銀行で必須 |
| パスポート | 必須 |
| 国内住所証明 | 賃貸借契約書またはARCの住所 |
| 在職証明書 | 一部の銀行が要求（就労者の場合） |
| 初回入金 | 銀行により異なる（₩0〜最低金額） |

## 4. インターネット・モバイルバンキングの設定

| 項目 | 内容 |
|---|---|
| デジタル証明書 | 銀行のアプリから発行可能 |
| セキュリティカード/OTP | 口座開設時に同時申請 |
| 海外電話番号 | 韓国番号がないとSMS認証が制限される場合あり |
| 外国人アプリ登録 | パスポート番号またはARCで本人認証 |

**モバイルバンキングのコツ：**
- 韓国のSIMカード（電話番号）があるとモバイルバンキングの設定が格段に楽になる
- 一部の銀行は海外番号でもSMS認証が可能 — 事前確認を推奨

## 5. 海外送金の方法

| 方法 | 手数料 | 特徴 |
|---|---|---|
| **銀行窓口送金** | 1件₩5,000〜₩10,000＋為替マージン | 従来の方法 |
| **インターネットバンキング送金** | 1件₩3,000〜₩5,000 | 窓口より安価 |
| **Kakao Pay送金** | 無料（1件₩5,000以内の限度） | 少額送金に便利 |
| **Toss国際送金** | 1件₩3,000〜、為替レート優遇 | 安くて簡単 |
| **ハナ1Qバンク** | 手数料優遇 | 海外口座との連携 |

**送金に必要な情報：**
- 受取人の銀行名とSWIFTコード・口座番号
- 受取人の氏名・住所
- 送金金額・通貨

## 6. ATMの利用方法

| 項目 | 内容 |
|---|---|
| 韓国銀行のATM | T-moneyチャージ、入出金、振込が可能 |
| 海外カードでの出金 | Visa/Mastercardなど海外カードに対応 |
| 手数料 | 海外カード1回につき約₩2,000〜₩3,000（自分のカードの手数料は別途） |
| コンビニATM | CU、GS25、7-Eleven — 24時間利用可 |

**英語ATMの使い方：**
- ほとんどのATMに英語オプションあり — 画面下部の「English」ボタンを押す

## 8. よくある質問（FAQ）

**Q. ARCなしで韓国の銀行口座を開設できますか？**
A. 一部の銀行ではパスポートとビザのみで開設できますが、利用できるサービスが制限される場合があります。フル機能を使うには、ARC取得後に開設することをお勧めします。

**Q. 韓国口座に海外からの送金を受け取れますか？**
A. はい。韓国銀行のSWIFTコードと口座番号を送金者に伝えれば、海外送金を受け取れます。

**Q. 外国人もKakaoBank・Tossを使えますか？**
A. はい。外国人登録証（ARC）を持つ外国人はアプリ内で非対面口座開設が可能です。

**Q. 韓国のATMで海外カードを使って現金を引き出せますか？**
A. はい。ほとんどのATMでVisa・Mastercardの海外カードに対応しています。1回につき約₩2,000〜₩3,000の手数料がかかり、さらに自分のカードの海外手数料が別途発生します。

**Q. モバイルバンキングに韓国の電話番号は必要ですか？**
A. ほとんどの銀行アプリはSMS認証に韓国番号が必要です。一部の銀行は海外番号でも対応しているので、来店前に確認することをお勧めします。
