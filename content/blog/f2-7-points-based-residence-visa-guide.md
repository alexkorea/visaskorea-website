# F-2-7 점수제 거주비자 완벽 가이드 (2026년): 합격 점수·항목별 배점

F-2-7 비자(점수제 거주비자)는 일정 요건을 갖춘 외국인이 점수제 평가를 통해 한국에 장기 거주할 수 있는 비자입니다. 합격 기준은 80점 이상이며, 점수에 따라 거주비자를 취득하고 최종적으로 F-5 영주권으로 이어질 수 있습니다.

## 1. F-2-7 비자란?

F-2-7은 법무부 점수제 평가를 통해 우수한 외국인 인재에게 부여하는 장기 거주비자입니다.

| 항목 | 내용 |
|---|---|
| 비자 종류 | F-2 (거주) 하위 유형 7번 |
| 합격 기준 | 80점 이상 (200점 만점) |
| 체류 기간 | 최초 1년, 갱신 3년 |
| 취업 허용 | 자유로운 취업 활동 가능 |
| 가족 초청 | F-3 비자로 동반 가족 초청 가능 |

---

## 2. 신청 자격

| 조건 | 내용 |
|---|---|
| 체류자격 | 유효한 한국 체류자격 보유 |
| 체류 기간 | 원칙적으로 한국에 합법적으로 체류 중 |
| 점수 요건 | 최종 합산 80점 이상 |
| 결격 사유 | 강제퇴거 명령 이력, 금고 이상 형사처벌 이력 없을 것 |

---

## 3. 점수 산정 기준 (공통 항목)

F-2-7 점수제는 총 200점 만점이며, 공통 항목에서 최대 130점을 받을 수 있습니다.

### 나이 (최대 25점)

| 나이 | 점수 |
|---|---|
| 25〜29세 | 25점 |
| 30〜34세 | 20점 |
| 35〜39세 | 15점 |
| 40〜44세 | 10점 |
| 45〜49세 | 5점 |
| 50세 이상 | 0점 |

### 학력 (최대 25점)

| 학력 | 점수 |
|---|---|
| 국내 박사 졸업 | 25점 |
| 국내 석사 졸업 | 20점 |
| 해외 박사 졸업 | 20점 |
| 국내 학사 졸업 | 15점 |
| 해외 석사 졸업 | 15점 |
| 해외 학사 졸업 | 10점 |
| 전문학사 (국내외) | 5점 |

### 한국어 능력 (최대 20점)

| 구분 | 점수 |
|---|---|
| TOPIK 5〜6급 또는 사회통합프로그램 5단계 이수 | 20점 |
| TOPIK 3〜4급 또는 사회통합프로그램 4단계 이수 | 15점 |
| TOPIK 1〜2급 또는 사회통합프로그램 2〜3단계 이수 | 10점 |

### 소득 또는 자산 (최대 60점)

| 소득 수준 (전년도 연간 소득) | 점수 |
|---|---|
| 국민 1인당 GNI의 3배 이상 | 60점 |
| 국민 1인당 GNI의 2.5〜3배 미만 | 50점 |
| 국민 1인당 GNI의 2〜2.5배 미만 | 40점 |
| 국민 1인당 GNI의 1.5〜2배 미만 | 30점 |
| 국민 1인당 GNI의 1〜1.5배 미만 | 20점 |
| 국민 1인당 GNI 미만 또는 재산 3억 원 이상 | 10점 |

> 2026년 기준 한국 국민 1인당 GNI는 약 4,200만 원입니다. 실제 기준은 신청 연도의 최신 수치를 확인하세요.

## 4. 가점 항목 (최대 40점)

| 가점 항목 | 점수 |
|---|---|
| 국내 학교 졸업 (학사 이상) | +5점 |
| 사회통합프로그램 이수 | +5점 |
| 국내 취업 경력 (1년마다) | +1점 (최대 +5점) |
| 국내 납세 실적 우수 | +5점 |
| 자원봉사 활동 (연간 50시간 이상) | +5점 |
| 한국 국민 또는 F-5 영주권자와의 결혼 | +5점 |
| 국내 부동산 소유 | +3점 |
| 공인된 자격증·전문 면허 보유 | +3점 |
| 체류 기간 (1년마다) | +1점 (최대 +5점) |

---

## 5. 감점 항목 (최대 -70점)

| 감점 사유 | 점수 |
|---|---|
| 체류자격 외 활동 위반 | -5점〜-20점 |
| 불법 취업 | -20점〜-40점 |
| 조세 체납 | -10점〜-30점 |
| 출국금지 이력 | -10점 |
| 범칙금·과태료 미납 | -3점〜-10점 |

> 감점 이력은 점수 합산 시 반드시 고려해야 합니다. 신청 전 법적 위반 이력을 전문가와 함께 점검하세요.

---

## 6. 합격 점수 계산 방법

**최종 점수 = 공통 항목 점수 + 가점 - 감점 ≥ 80점**

### 계산 예시 (30세, 한국 석사, TOPIK 4급, 연소득 6,000만 원)

| 항목 | 점수 |
|---|---|
| 나이 (30〜34세) | 20점 |
| 학력 (국내 석사) | 20점 |
| 한국어 (TOPIK 4급) | 15점 |
| 소득 (약 GNI 1.4배) | 20점 |
| 가점: 국내 취업 3년 | +3점 |
| **합계** | **78점** |

> 위 예시의 경우 합격 기준 80점에 2점 부족합니다. 한국어 점수를 높이거나(TOPIK 5급 취득) 추가 가점을 확보하면 합격 가능합니다.

---

## 7. 신청 방법 및 절차

### STEP 1: 점수 사전 산정

신청 전 공식 점수표에 따라 예상 점수를 계산합니다. 전문 행정사와 함께 점검하면 누락 없이 정확히 산정할 수 있습니다.

### STEP 2: 서류 준비

점수 항목별 증빙 서류를 완비합니다.

### STEP 3: 출입국·외국인청 방문 신청

거주지 관할 출입국·외국인청에 방문하여 신청서와 서류를 제출합니다.

### STEP 4: 심사 및 결과 통보

법무부에서 서류를 심사하며, 결과는 통상 2〜4주 내에 통보됩니다.

### STEP 5: 비자 발급

합격 시 F-2-7 체류자격이 부여됩니다.

## 8. 필요 서류

| 서류 | 비고 |
|---|---|
| 여권 원본 | 유효한 것 |
| 외국인등록증 | 기 등록자 |
| 사진 | 최근 6개월 이내 촬영, 흰 배경 |
| 점수 입증 서류 | 학위증·성적증명서·TOPIK 성적표·소득금액증명 등 |
| 가점 관련 서류 | 해당 항목에 따른 증빙 (자원봉사확인서, 납세증명서 등) |
| 신청서 | 출입국청 구비 양식 |

---

## 9. F-2-7에서 F-5 영주권으로

F-2-7 비자 취득 후 F-5(영주권) 신청의 길이 열립니다.

| 조건 | 내용 |
|---|---|
| F-2-7 체류 기간 | 최소 3년 이상 |
| 계속 체류 | 연속적으로 합법적 체류 유지 |
| 소득·납세 요건 | 안정적 소득 및 세금 납부 이력 |
| 한국어 요건 | TOPIK 3급 이상 또는 KIIP 이수 |

> F-5 영주권 취득 후에는 체류자격 갱신 없이 한국에 영구 거주할 수 있으며, 향후 귀화의 발판이 됩니다.

## 10. 자주 묻는 질문 (FAQ)

**Q. 점수를 80점에 맞추기 어려운데, 어떤 항목을 높이는 것이 가장 효과적인가요?**
A. 소득(최대 60점)과 한국어 능력(최대 20점) 항목이 가장 큰 비중을 차지합니다. 소득이 충분하다면 TOPIK 5급 취득 또는 KIIP 이수를 통해 15〜20점 추가 확보가 가능합니다.

**Q. F-2-7 비자로 가족을 한국에 데려올 수 있나요?**
A. 네. 배우자와 미성년 자녀는 F-3(동반) 비자로 동반 체류가 가능합니다.

**Q. 현재 E-7 비자인데 F-2-7으로 변경할 수 있나요?**
A. 네. E-7 비자 보유자는 점수 요건을 충족하면 F-2-7으로 체류자격 변경이 가능합니다. 소득·학력·한국어 점수가 합산 80점 이상이어야 합니다.

**Q. 신청 후 점수 미달이면 어떻게 되나요?**
A. 불허 결정을 통보받습니다. 기존 체류자격은 유지되므로, 점수를 높인 후 재신청이 가능합니다.

**Q. 감점이 있으면 합격이 불가능한가요?**
A. 감점이 있어도 최종 합산 점수가 80점 이상이면 합격 가능합니다. 다만 심각한 위반 이력(불법 취업, 강제퇴거 이력 등)은 아예 결격 사유가 될 수 있으므로 전문가 상담이 필요합니다.

## 11. 상담 안내

F-2-7 점수 산정은 항목이 복잡하고 증빙 서류가 다양합니다. 전문 행정사와 함께 정확한 점수를 계산하고 부족한 점수를 보완하는 전략을 세우면 합격 가능성을 크게 높일 수 있습니다.

비전행정사사무소에서는 F-2-7 점수 산정, 서류 준비, 신청 대리까지 전반적인 서비스를 제공합니다.
