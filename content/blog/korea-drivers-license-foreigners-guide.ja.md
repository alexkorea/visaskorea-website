# 在韓外国人運転免許完全ガイド（2026年）：取得・切替・国際免許

韓国に長期滞在する外国人は、新たに韓国運転免許を取得するか、保有する外国運転免許を韓国免許に切り替え（交換発給）することができます。このガイドでは、外国人が韓国で運転免許を取得・切り替えする全過程を順を追って解説します。

## 1. 韓国運転免許の種類

韓国運転免許は1種と2種に分かれています。

| 種類 | 区分 | 運転できる車両 |
|---|---|---|
| 1種 | 大型（1종 대형） | バス・大型トラック・特殊車両 |
| 1種 | 普通（1종 보통） | 15人以下の乗用車・12トン以下のトラック |
| 1種 | 特殊（1종 특수） | クレーン車・低床トレーラー・レッカー車 |
| 2種 | 普通（2종 보통） | 10人以下の乗用車・4トン以下のトラック |
| 2種 | 自動（2종 자동） | オートマチック限定 |
| 2種 | 小型（2종 소형） | 二輪車（125cc以上） |

> ほとんどの外国人は**2種普通（2종 보통）**または**1種普通（1종 보통）**を取得します。

## 2. 外国免許の韓国免許への切替（交換発給）

有効な外国運転免許証を持っている場合、試験の一部または全部が免除される条件で韓国免許に切り替えることができます。

### 協定国—全試験免除

韓国と運転免許の相互認証協定を締結した国の国民は、**筆記・技能・路上試験がすべて免除**されます。必要書類を持参して運転免許試験場を訪問するだけで手続きできます。

| 国 | 免除範囲 |
|---|---|
| アメリカ | 筆記・技能・路上試験すべて免除 |
| 日本 | 筆記・技能・路上試験すべて免除 |
| イギリス | 筆記・技能・路上試験すべて免除 |
| ドイツ | 筆記・技能・路上試験すべて免除 |
| カナダ | 筆記・技能・路上試験すべて免除 |
| フランス | 筆記・技能・路上試験すべて免除 |
| オーストラリア | 筆記・技能・路上試験すべて免除 |

> 協定国リストは変更されることがあります。申請前に道路交通公団（도로교통공단）で最新情報を確認してください。

### 非協定国（例：中国）

非協定国の国民は**筆記試験のみ**合格すれば、技能試験と路上試験は免除されます。

### 免許切替に必要な書類

1. 有効な外国運転免許証（原本）
2. 公式翻訳文（必要に応じて大使館または公証事務所による認証）
3. 外国人登録証
4. パスポート
5. 証明写真1枚
6. 身体検査結果（2年以内に発行されたもの）
7. 申請手数料

## 3. 新規取得：試験の流れ

外国免許を持っていない場合は、全課程の試験を受ける必要があります。

| ステップ | 内容 | 合格基準 |
|---|---|---|
| 1. 身体検査 | 視力・聴力・色覚検査 | 合格/不合格 |
| 2. 筆記試験 | 交通法規40問 | 60点（2種）/70点（1種） |
| 3. 技能試験 | 閉鎖コースでの運転技能 | 80点 |
| 4. 路上運転練習 | 教習所での10時間以上の練習 | 修了必須 |
| 5. 路上試験 | 公道での実地走行 | 70点 |

---

## 4. 筆記試験ガイド

### 試験概要

| 項目 | 内容 |
|---|---|
| 問題数 | 40問 |
| 試験時間 | 40分 |
| 合格点 | 60点（2種）/70点（1種） |
| 対応言語 | 韓国語・英語・中国語・日本語・ベトナム語 |
| 試験会場 | 全国の運転免許試験場 |

### 試験内容

- 交通標識・路面標示・信号機
- 安全運転の原則と交通法規
- 事故防止と応急処置
- 車両構造の基礎

> 道路交通公団ウェブサイト（safedriving.or.kr）で練習問題が提供されています。受験前に必ず活用してください。

---

## 5. 技能試験ガイド

技能試験は試験場の閉鎖コースで行われます。

| 項目 | 内容 |
|---|---|
| 合格点 | 80点 |
| 試験内容 | 駐車・曲進・障害物回避・発進/停止 |
| 減点事項 | 車線はみ出し・急ブレーキなど |
| 再受験 | 不合格の翌日から予約可能 |

---

## 6. 路上試験ガイド

路上試験は試験場周辺の公道で行われます。

| 項目 | 内容 |
|---|---|
| 前提条件 | 路上運転練習10時間の修了 |
| 合格点 | 70点 |
| 試験時間 | 約15〜20分 |
| 減点事項 | 速度違反・信号無視・危険な車線変更など |

---

| 項目 | 目安費用 |
|---|---|

| 技能試験 | 約25,000ウォン |

## 8. 国際運転免許証

有効な韓国運転免許証があれば、海外で運転するための国際運転免許証（국제운전면허증）を取得できます。

| 項目 | 内容 |
|---|---|
| 発行機関 | 各運転免許試験場・オンライン申請（safedriving.or.kr） |
| 有効期間 | 1年 |
| 有効国 | 約100か国（1968年ウィーン条約締約国） |
| 必要書類 | 韓国運転免許証・証明写真・申請書 |
| 手数料 | 約8,500ウォン |

> 国際運転免許証は韓国運転免許証と一緒に使用する必要があります。単独での使用はできません。

## 9. 免許の更新

| 項目 | 内容 |
|---|---|
| 有効期間 | 1種：10年 / 2種：10年 |
| 更新要件 | 視力検査（矯正視力0.8以上） |
| 更新手続き | 任意の運転免許試験場で手続き |

> 違反点数や未払い反則金がある場合は、免許停止を避けるため早めに更新してください。

## 10. よくある質問（FAQ）

**Q. 外国運転免許証で韓国で運転できますか？**
A. 入国日から1年以内は外国免許証で運転可能です。1年を超えた場合は韓国免許が必要です。ウィーン条約に基づいて発行された国際運転免許証も1年間有効です。

**Q. 筆記試験は日本語で受けられますか？**
A. はい。筆記試験は韓国語・英語・中国語・日本語・ベトナム語の5言語に対応しています。予約時に希望する言語を選択してください。

**Q. 全課程の手続きにどれくらいかかりますか？**
A. 身体検査から免許証交付まで、教習所を利用する場合は通常2〜4週間、独学で試験を個別予約する場合は1〜2週間程度かかります。

**Q. 筆記試験に落ちたらどうなりますか？**
A. 翌日から再受験が可能です。受験回数に制限はありませんが、毎回受験料が必要です。

**Q. 教習所には必ず通わなければなりませんか？**
A. 強制ではありませんが、路上試験前に10時間の路上運転練習が必要です。教習所を利用するのが最も手軽な方法です。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
