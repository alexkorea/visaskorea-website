## 1. 再入国許可免除制度とは

再入国許可免除制度とは、韓国に合法的に滞在している外国人が一時的に出国し、再び韓国に入国する際に、事前の再入国許可申請を省略できる制度です。

2016年改正前は、長期滞在外国人が出国する際には必ず「재입국허가」（再入国許可）を取得する必要がありました。この手続きには時間とコストがかかるため、外国人滞在者にとって大きな負担でした。

2016年改正後は、一定の条件を満たす外国人は自動的に再入国許可が免除され、許可証の取得なしに出国・再入国が可能となりました。

### 制度の目的
- 長期滞在外国人の利便性向上
- 出入国管理行政の効率化
- 外国人の生活環境改善

## 2. 再入国許可免除の対象者

再入国許可免除の対象となる外国人は以下の通りです。

### ✅ 免除対象ビザ（一般的な対象）

| ビザ種別 | 説明 |
|---------|------|
| F-1（家族同伴） | 長期滞在外国人の家族 |
| F-2（居住） | 点数制居住ビザ |
| F-3（同伴） | 就労ビザ保有者の家族 |
| F-4（在外同胞） | 海外在住韓国系外国人 |
| F-5（永住権） | 韓国永住権保有者 |
| F-6（結婚移民） | 韓国人配偶者を持つ外国人 |
| E-7（特定活動） | 専門職就労ビザ |
| D-8（企業投資） | 外国人投資家ビザ |
| D-7（企業内転勤） | 駐在員ビザ |

### ✅ 免除の基本条件

1. **有効な外国人登録証**を所持していること
2. 出国時に在留資格の有効期限が残っていること
3. 法令違反等による強制退去処分を受けていないこと
4. 出入国管理法上の禁止事項に該当しないこと

---

## 3. 免除されない場合（許可が必要なケース）

以下の場合は再入国許可が免除されず、出国前に再入国許可を取得する必要があります。

### ❌ 再入国許可が必要なケース

**在留期間関連**
- 在留資格の有効期限が出国時から1年以内に切れる場合
- 외국인등록증（外国人登録証）の有効期限が切れている場合

**行政的問題**
- 在留資格変更の申請中で結果が出ていない場合
- 出入国管理法違反で調査・審判中の場合
- 強制退去命令を受けたことがある場合

**特定のビザ種別**
- 短期ビザ（C-1、C-3など）での滞在者
- 외국인등록をしていない滞在者

## 4. 出国・入国時の注意事項

### 出国時のチェックリスト

出国する際には以下の点を確認してください。

1. **外国人登録証の有効期限確認**  
   出国前に外国人登録証の有効期限を確認してください。期限切れの場合は再入国許可免除が適用されません。

2. **在留資格の有効期限確認**  
   在留資格の有効期限内に帰国できることを確認してください。1年以上の期間が残っている場合は安心して出国できます。

3. **パスポートの有効期限確認**  
   パスポートが出国後も十分な有効期限を持っているか確認してください。

### 入国時の注意事項

韓国に再入国する際には以下の点に注意してください。

1. **在留資格の有効期限内の入国**  
   必ず在留資格の有効期限内に入国してください。期限を過ぎての入国は不法入国となります。

2. **外国人登録証の携帯**  
   入国審査時に外国人登録証の提示が求められます。必ず携帯してください。

3. **長期出国の場合の注意**  
   1年以上海外に滞在する場合は、帰国前に在外公館（韓国大使館・領事館）で手続きが必要なケースがあります。

## 6. 再入国許可免除期間の計算方法

再入国許可免除が適用される場合でも、以下の点に注意が必要です。

### 免除期間の基本ルール

- **原則**: 在留資格の有効期限まで
- **例外**: 在留資格の有効期限が出国から1年以内に切れる場合は要注意

### 計算例

**ケース1（問題なし）**  
在留資格有効期限：2027年12月31日  
出国日：2026年5月1日  
→ 有効期限まで1年7ヶ月以上あるため、通常の再入国許可免除が適用されます。

**ケース2（注意が必要）**  
在留資格有効期限：2026年8月31日  
出国日：2026年5月1日  
→ 有効期限まで3ヶ月しかないため、帰国後すぐに在留資格更新が必要です。

**ケース3（出国前に更新を）**  
在留資格有効期限：2026年6月30日  
出国日：2026年5月1日  
→ 出国前に在留資格の更新手続きを完了させることを強くお勧めします。

## 7. 外国人登録証の有効期限と再入国

外国人登録証（ARC: Alien Registration Card）の有効期限は再入国許可免除に直接影響します。

### 外国人登録証の更新タイミング

外国人登録証の有効期限が近づいている場合は、**出国前に必ず更新手続きを行ってください**。

- 更新申請場所：管轄出入国・外国人庁（または支所）
- 更新申請時期：有効期限の3ヶ月前から申請可能
- 必要書類：パスポート、外国人登録証、証明写真、申請書

### 外国人登録証が期限切れの場合

外国人登録証が期限切れの状態で出国した場合、再入国の際に問題が生じる可能性があります。必ず有効な外国人登録証を持った状態で出国してください。

## 8. よくある質問（FAQ）

### Q1. 再入国許可免除の場合、出国時に何か手続きは必要ですか？
**A**: 免除対象の場合、特別な手続きは不要です。通常通り空港の出入国審査を通過するだけでOKです。ただし、外国人登録証と在留資格の有効期限を事前に確認しておくことをお勧めします。

### Q2. 日本に2ヶ月間帰国する場合、再入国許可は必要ですか？
**A**: 免除対象ビザを保有し、在留資格の有効期限内に帰国できる場合は不要です。ただし、2ヶ月後に韓国の在留資格更新が控えている場合は、スケジュール管理に注意してください。

### Q3. 再入国許可免除中に在留資格の期限が切れた場合はどうなりますか？
**A**: 在留資格の有効期限が切れた状態では韓国に再入国できません。この場合、日本の韓国大使館・領事館で新たにビザを取得するか、帰国前に延長手続きを行う必要があります。

### Q4. 長期出張で6ヶ月以上日本に滞在する場合はどうすればよいですか？
**A**: 6ヶ月以上の不在の場合、韓国の在留資格（特に住民登録関連）に影響が出る可能性があります。事前に出入国・外国人庁、または専門の行政書士に相談することをお勧めします。

### Q5. 再入国許可免除と通常の再入国許可の違いは何ですか？
**A**: 再入国許可免除は手続き不要で自動的に適用されます。通常の再入国許可は出国前に申請・取得が必要です。免除の場合は許可証の発行もなく、コストもかかりません。

### Q6. F-5永住権保有者も再入国許可免除の対象ですか？
**A**: はい、F-5永住権保有者も再入国許可免除の対象です。ただし、永住権の有効期限管理には注意が必要です。長期不在の場合は永住権が取り消されるケースもあるため、専門家への相談をお勧めします。

### Q7. 外国人登録をしていない場合、免除は適用されますか？
**A**: 外国人登録をしていない場合は免除の対象外です。外国人登録は韓国に90日以上滞在する外国人に義務付けられています。

## 関連情報：韓国在留資格の種類

韓国には多様な在留資格（ビザ）があります。再入国許可免除制度を利用するためにも、自分が保有する在留資格の特性を正確に理解することが重要です。

### 長期滞在ビザの主な種類

| ビザ種類 | 主な対象者 |
|---------|---------|
| E-7（特定活動） | 専門職就労外国人 |
| D-8（企業投資） | 外国人投資家 |
| D-7（企業内転勤） | 海外本社からの駐在員 |
| F-2（居住） | 点数制居住ビザ取得者 |
| F-4（在外同胞） | 韓国系海外在住者 |
| F-5（永住） | 韓国永住権保有者 |
| F-6（結婚移民） | 韓国人との婚姻外国人 |

### 短期滞在ビザと長期滞在ビザの違い

再入国許可免除はあくまでも**長期滞在外国人**（외국인등록을 완료한 자）を対象としています。短期ビザ（C-3など観光·短期商用）での滞在者は免除の対象外となりますので、注意が必要です。

## 出入国・外国人庁（ハイコリア）の活用

韓国出入国に関する情報は、出入国・外国人庁（출입국·외국인청）の公式ポータル「ハイコリア（HI Korea）」から確認できます。

### ハイコリアでできること

- 在留資格の現状確認
- 在留期間の残日数確認
- 再入国許可・免除の該当可否チェック
- オンライン申請（一部の手続き）
- 相談予約の取得

### 연락처 및 방문 상담

直接窓口での相談は、管轄の出入국·외국인청に事前に予約してから行くことをお勧めします。混雑時は待ち時間が長くなることがあります。

韓国に長期滞在する外国人にとって、再入国許可免除制度は一時出国の際の大きな便利さをもたらします。ただし、外国人登録証と在留資格の有効期限の管理は自己責任で行う必要があります。

1. ✅ 外国人登録証の有効期限を確認
2. ✅ 在留資格の有効期限を確認

4. ✅ 免除対象ビザかどうかを確認
