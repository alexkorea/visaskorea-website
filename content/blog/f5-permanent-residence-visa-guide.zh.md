## 1. 什么是F-5永久居留？

F-5永久居留资格是授予获得韩国永久居留许可的外国人的居留资格，具有以下权益。

| 权益 | 内容 |
|---|---|
| 永久居留 | 无时间限制，可在韩国长期居住 |
| 就业·创业自由 | 几乎所有行业均可自由就业及经营 |
| 居留管理简化 | 无需续签签证，每3年更新一次外国人登记证 |
| 出入境自由 | 无需向海外使领馆报告，可自由出入境 |
| 携家属同住 | 配偶及未成年子女可以F-3资格随行 |

> 保持F-5资格并持续在韩居留，也是今后申请归化（取得国籍）的重要基础。

## 2. F-5申请资格类型

依据《出入境管理法施行令》，取得F-5资格有多种途径。

| 类型 | 主要申请对象 | 核心要求 |
|---|---|---|
| 普通永久居留 | 长期居留外国人 | 居留满10年+合法居留满5年 |
| F-2-7积分制 | F-2-7签证持有者 | 取得F-2-7后继续居留满3年 |
| 婚姻移民 | 韩国国民配偶 | 婚姻维持2年以上+合法居留2年以上 |
| 海外韩裔 | F-4签证持有者 | 合法居留满2年 |
| KIIP 4阶段以上 | 社会融合项目修了者 | KIIP 4阶段以上+持F-2以上签证 |
| 投资移民 | 投资签证持有者（D-8等） | 居留满5年+持续投资 |

## 3. 普通永久居留（5年居留基准）

依据《出入境管理法施行令》附表1-3的普通永久居留资格要求。

| 要求 | 具体内容 |
|---|---|
| 总居留期限 | 在韩居留满10年 |
| 合法连续居留 | 最近5年以上合法连续居留 |
| 生计能力 | 本人或家庭成员具备维持生计的财产或收入 |
| 品行端正 | 无不良犯罪记录 |
| 基本素养 | 了解韩国风俗习惯与制度 |

> 出境天数过多可能导致居留期限计算复杂。每年出境超过90天可能造成连续居留中断。

---

## 4. F-2-7积分制永久居留

F-2-7（积分制居住签证）持有者在取得签证后继续居留满3年，可申请变更为F-5。

| 要求 | 内容 |
|---|---|
| 现持签证 | F-2-7 |
| 追加居留期限 | 取得F-2-7后继续合法居留满3年 |
| 生计能力 | 须提供证明 |
| 品行 | 无违规记录 |

> 申请F-2-7需在200分满分中达到80分以上，需综合计算年龄、学历、韩国语、收入及加分项目。[查看F-2-7积分制指南](/zh/blog/f2-7-points-based-residence-visa-guide)

## 5. 婚姻移民永久居留

适用于目前与韩国国民保持有效婚姻关系的外国人。

| 要求 | 内容 |
|---|---|
| 婚姻状态 | 目前与韩国国民处于婚姻关系中 |
| 婚姻期限 | 婚姻维持满2年以上 |
| 居留期限 | 以F-6或其他资格在韩合法居留满2年以上 |
| 生计能力 | 提供本人或配偶名下的财产·收入证明 |

> 因非申请人过错（配偶死亡、失踪等）导致婚姻关系终止，但在韩抚养韩国出生子女者，仍可能符合申请条件。

## 6. 海外韩裔（F-4）永久居留

F-4签证持有者可以相对简化的条件取得永久居留资格。

| 要求 | 内容 |
|---|---|

| 居留期限 | 合法居留满2年以上 |
| 生计能力 | 须提供证明 |
| 品行 | 无违规记录 |

## 9. 申请流程

| 步骤 | 内容 | 所需时间 |
|---|---|---|
| 1. 确认资格 | 确定申请类型+计算年限/积分 | 即时 |

## 10. 常见问题解答

**Q. 取得F-5后还需要续签签证吗？**
A. 无需续签签证。但外国人登记证须每3年更新一次。F-5资格本身为永久有效。

**Q. 取得F-5后长期在海外居住，永久居留资格会被取消吗？**
A. 原则上，在国外居留满2年以上可能导致永久居留资格被取消。如计划长期出境，建议事先向出入境外国人厅申报回国意向。

**Q. 持F-5就业有限制吗？**
A. 几乎没有限制。可自由在各行业就业及经营企业，仅限E-9签证的特定简单劳务岗位除外。

**Q. 取得F-5后多久可以申请归化？**
A. 取得F-5后满足追加居留条件（通常为1年以上），并通过归化适应性考试后即可申请归化。持有F-5资格申请归化审查通常更为顺畅。

**Q. 收入较低会影响F-5申请吗？**
A. 生计能力是审查要求之一。在职且有健康保险及纳税记录，一般可满足此条件。如收入不稳定，建议申请前咨询专业人士。

**A**：大多数长期居住签证允许配偶和未成年子女以F-1（家庭陪同）签证一同来韩居住。具体要求请咨询专业人士。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
