# 韩国F-2-7积分制长期居留签证完全指南（2026年版）

F-2-7（积分制长期居留）是韩国对符合一定综合条件的外籍人士发放长期居留资格的**综合积分制签证**。

与E类就业签证不同，F-2-7不受雇主或职种限制，持有者可自由就业、创业和经营，灵活度极高。合格标准为**80分以上**，综合考量年龄、学历、韩语能力、收入及在韩居住期限等多项指标。

## 1. F-2-7是什么？——积分制长期居留的含义

F-2-7是韩国《出入境管理法》中居住（F-2）资格的子类别。法务部根据公告的积分表对申请人进行综合评估，**达到80分及以上**者可获得长期居留资格。

**F-2-7的核心优势：**
- 无就业行业及职种限制，可自由就业
- 可创办企业、自主经营
- 换工作无需重新申请签证
- 居留期限：初始1年，之后每次最长可续签3年
- 转换F-5永久居留权的核心路径

### 收入积分（最高60分）

收入积分以上一年度收入为基准，按**GNI（国民总收入）人均值的倍数**计算。

| GNI倍数 | 积分 |
|--------|------|
| 5倍及以上 | 60分 |
| 4倍及以上 | 55分 |

| 2倍及以上 | 40分 |
| 1.5倍及以上 | 30分 |
| 1倍及以上 | 20分 |
| 0.8倍及以上 | 10分 |
| 0.8倍以下 | 0分 |

**2026年参考GNI值**：约4,300万韩元（每年调整）。

## 3. 积分计算表——加分项目（最高40分）

在通用项目基础上，以下加分项目可累计计入：

| 加分项目 | 积分 |
|---------|------|
| 国内企业工作经历（每年1分，最多5年）| 最高5分 |
| 持有韩国国家资格证（因证书类型而异）| 5~15分 |
| 在韩国取得学位（超出通用学历项目的额外加分）| 本科+3分，硕士+5分，博士+10分 |
| 志愿服务记录 | 最高5分 |
| 社会融合项目（KIIP）完成额外加分 | 按项目阶段不同 |

## 4. 积分计算表——扣分项目（最高-70分）

违法记录或合规问题将导致扣分：

| 扣分项目 | 扣分 |
|---------|------|
| 违反出入境法规（依违规次数和类型）| -10至-70分 |
| 非法就业记录 | -20至-40分 |
| 强制遣返记录 | -70分 |
| 拖欠税款 | -5至-20分 |
| 欠缴健康保险费 | -5分 |

保持合法合规记录与获取高积分同等重要。存在严重违规记录者，即使正分达到80分，也可能被拒绝申请。

## 5. 提高积分的实战策略

### 最快速的积分提升方法

**韩语能力（TOPIK）**：从3级提升至4级可加4分，4级至5级再加4分。韩语是通过针对性备考相对快速提高积分的项目。

**收入**：收入项最高60分，权重最大。GNI2倍=40分，GNI3倍=50分。争取加薪、换至高薪岗位，或全面核实所有收入来源（含兼职）均可显著提高积分。

**韩国国家资格证**：通过公认中介师、专业工程师、IT认证等国家考试可获得5至15分加分。

### 积分不足80分时的应对策略

找出积分较低的项目，制定针对性提升计划。常见方法：备考TOPIK（约需6个月）、争取加薪、再积累一年在韩工作经历以获得加分。申请前务必确认是否存在扣分项目。

## 6. 申请资格与限制

### 可以申请的情形

- 目前持有效签证合法在韩居留的外籍人士
- 在现有签证有效期内提交申请
- F-2-7积分表达到80分以上

### 不可申请的情形

- 持E-9或H-2非专业就业签证者（须通过其他升级路径）
- 有非法滞留记录者（扣分较重，难以达到80分）
- 持观光（B-2）或短期访问（C-3）签证者（无法从短期签证变更为长期居留资格）

## 8. 申请流程

1. **计算积分** — 使用法务部F-2-7积分表核算自身分数
2. **准备材料** — 收集各项目证明文件
3. **通过Hi Korea（hikorea.go.kr）在线申请**或**前往所在地出入境外国人厅**
4. **审核期** — 通常需2至4周，期间可能收到补充材料通知
5. **批准** — F-2-7资格获批，换发新外国人登记证

## 9. 从F-2-7转换至F-5永久居留权

持F-2-7资格居住满3年后，可申请F-5-16（积分制永住）资格。

| 转换路径 | 主要条件 |
|---------|---------|
| F-5-16积分制永住 | F-2-7居留满3年 + 基本收入及品行要求 |
| F-5-1一般长期居民永住 | 合法在韩累计居留满5年（含F-2-7期间）+ 经济自立 |

F-2-7 → F-5是无韩国血统的长期在韩专业人士申请永久居留权的主要路径。

## 10. 常见问题解答

**Q. 持E-7签证可以直接转换为F-2-7吗？**
A. 可以。持E-7期间若积分达到80分以上，即可申请变更为F-2-7资格。变更后无需受雇主或职种限制，可自由就业。

**Q. 配偶无收入，可以单独申请F-2-7吗？**
A. 可以。若其他项目（年龄、学历、韩语、加分等）合计达到80分，仍可申请。收入项为零不影响其他项目的得分。部分情况下可考虑家庭共同收入，但需提前向出入境管理机构确认。

**Q. 不考TOPIK能达到80分吗？**
A. 可以。博士学位（35分）加上GNI3倍收入（50分）合计85分，无需韩语积分即可达标。但韩语最高20分的权重不可忽视，有条件的话建议准备。

**Q. 续签时是否需要重新达到80分？**
A. 是的。每次续签时均会重新审核积分条件。若收入下降或TOPIK成绩到期，请在续签前重新核算，确认是否仍符合要求。

**Q. F-2-7与F-4（在外同胞）有何区别？**
A. F-4须具有韩国血统（父母或祖父母曾持有韩国国籍），F-2-7则与血统无关，所有外籍人士均可通过积分申请。两者活动范围相近，但F-4转永居的路径更为简便（F-4→F-5-7，仅需在韩实际居住满2年）。
