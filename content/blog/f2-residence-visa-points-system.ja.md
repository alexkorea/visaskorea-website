## 1. F-2-7ビザとは

F-2-7ビザは、韓国に合法的に滞在する外国人が「点数制」という評価システムに基づいて取得できる長期居住ビザです。

### F-2-7の特徴

- **就労制限なし**：F-2-7取得後は、ほぼすべての職種で自由に働くことができます
- **家族帯同可能**：配偶者・子どもをF-1（家族同伴）ビザで呼び寄せられます
- **在留期間**：通常1〜3年、更新可能
- **F-5永住権への近道**：F-2-7で一定期間滞在後、F-5永住権の申請が可能

### どんな人に向いているか

- 韓国で長期的に生活・就労したい方
- 就職・転職の自由を求める方
- E-7などの就労ビザから安定した在留資格に移行したい方
- 将来的に永住権を目指している方

## 3. 点数制の評価項目と配点（詳細）

F-2-7の点数表は、基本項目（最大130点）と加点・減点項目で構成されています。

### 📊 基本項目①：年齢（最大25点）

| 年齢 | 点数 |
|------|------|
| 18〜24歳 | 5点 |
| 25〜29歳 | 15点 |
| 30〜34歳 | 25点 |
| 35〜39歳 | 20点 |
| 40〜44歳 | 15点 |
| 45〜49歳 | 10点 |
| 50歳以上 | 5点 |

**ポイント**: 30〜34歳が最高点（25点）です。若いほど有利とは限りません。

---

### 📊 基本項目②：学歴（最大25点）

| 学歴 | 点数 |
|------|------|
| 博士号（国内外） | 25点 |
| 修士号（国内外） | 20点 |
| 学士号 | 15点 |
| 短大・専門学校卒 | 10点 |
| 高校卒以下 | 5点 |

**注意**: 外国の学位を証明する場合、アポスティーユ認証が必要です。

---

### 📊 基本項目③：韓国語能力（最大20点）

| TOPIK級 | 点数 |
|--------|------|
| TOPIK 6級 | 20点 |
| TOPIK 5級 | 16点 |
| TOPIK 4級 | 12点 |
| TOPIK 3級 | 8点 |
| TOPIK 2級 | 4点 |
| TOPIK 1級 | 2点 |

**戦略**: TOPIK5〜6級取得は高得点への近道です。韓国語学習への投資は非常に有効です。

---

### 📊 基本項目④：所得・世帯収入（最大60点）

所得点数は、韓国の国民総所得（GNI）一人当たり平均との比較で算定されます。

| GNI対比 | 点数 |
|--------|------|
| GNI 5倍以上 | 60点 |
| GNI 4〜5倍 | 50点 |
| GNI 3〜4倍 | 40点 |
| GNI 2〜3倍 | 30点 |
| GNI 1.5〜2倍 | 20点 |
| GNI 1〜1.5倍 | 10点 |

※GNI基準額は毎年改定されます。2026年の基準については出入国・外国人庁または専門家に確認ください。

---

### 📊 加点項目（最大40点）

| 加点項目 | 点数 |
|---------|------|
| 韓国の大学・大学院卒業 | +10点 |
| 韓国政府奨学金経験者 | +10点 |
| 韓国国家資格保有（弁護士・医師等） | +15点 |
| 国内外の名門大学卒業 | +5〜15点 |
| 자원봉사（ボランティア活動） | +5点 |

---

### 📊 減点項目（最大−70点）

| 減点項目 | 減点 |
|---------|------|
| 出入国管理法違反 1回目 | −5点 |
| 出入国管理法違反 2回目 | −10点 |
| 税金未納・不誠実 | −5〜−20点 |
| 不法就労歴 | −20点 |
| 犯罪歴（刑事処分） | −10〜−70点 |

## 4. 点数計算の実例

### 実例1：32歳・修士号・TOPIK5級・GNI3倍超の会社員（申請可）

| 項目 | 点数 |
|------|------|
| 年齢（30〜34歳） | 25点 |
| 学歴（修士号） | 20点 |
| 韓国語（TOPIK5級） | 16点 |
| 所得（GNI3〜4倍） | 40点 |
| **合計** | **101点** ✅ |

### 実例2：27歳・学士号・TOPIK3級・GNI1.5倍の英語講師（申請不可）

| 項目 | 点数 |
|------|------|
| 年齢（25〜29歳） | 15点 |
| 学歴（学士号） | 15点 |
| 韓国語（TOPIK3級） | 8点 |
| 所得（GNI1.5〜2倍） | 20点 |
| **合計** | **58点** ❌ |

→ **改善策**: TOPIK6級取得で+12点、収入増加でさらに+20〜40点が可能

## 5. 必要書類一覧

### 必須書類

- 統合申請書（소정양식）
- パスポート（原本）
- 外国人登録証
- F-2-7点数確認表
- 証明写真（3.5cm×4.5cm）

### 学歴証明書類

- 卒業証明書（原本）または卒業証書コピー
- 成績証明書
- ※外国の学位の場合：アポスティーユ認証または韓国大使館の認証

### 韓国語能力証明

- TOPIK公式成績証明書

### 所得証明書類

- 소득금액증명원（所得金額証明書、税務署発行）
- 근로소득 원천징수영수증（源泉徴収票）
- 사업소득자는 사업소득 관련 서류（自営業者の場合）

### 추가서류（追加書類）

- 재직증명서（在職証明書）または 고용계약서（雇用契約書）
- 건강진단서（指定医療機関発行の健康診断書）

## 6. 申請手続きの流れ

### Step 1：自己採点（事前確認）
公式の점수제 자가진단（自己診断）フォームを使用して、おおよその点数を把握しましょう。

### Step 2：書類収集（1〜3週間）
書類によっては取得に時間がかかります。特に外国の学位のアポスティーユ取得は早めに始めることをお勧めします。

### Step 3：申請書提出
管轄의 출입국・외국인청（出入国・外国人庁）に書類を提出します。一部の申請はHi Koreaオンラインポータルからも可能です。

### Step 4：審査（2〜4週間）
審査中に追加書類の提出を求められることがあります。

### Step 5：許可通知・外国人登録証更新
許可が下りたら、外国人登録証の在留資格が更新されます。

## 7. F-2-7取得後の特典

### 就労の完全自由化
F-2-7保有者は、E系ビザの就労制限から解放されます。どの会社・職種でも自由に働けます。転職時のビザ変更手続きも不要です。

### 家族の帯同
配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。

### 사회통합프로그램（KIIP）参加
社会統合プログラムへの参加を通じて、韓国語能力向上と永住権・帰化への道が開けます。

### 금융・부동산 혜택（金融・不動産の優遇）
長期在留資格により、銀行ローンの審査やアパートの賃貸契約が容易になります。

## 8. F-2からF-5（永住権）への道

F-2-7は永住権（F-5）取得への有力なルートの一つです。

### F-5申請の主な条件（F-2保有者）

- F-2-7ビザで一定期間の在住実績
- 品行端正（犯罪歴なし）
- 独立した生計能力の証明
- 기본 한국어 능력（基本的な韓国語能力）
- 한국사회 이해（韓国社会への理解）

## 9. よくある質問（FAQ）

### Q1. 点数が80点ちょうどの場合、申請できますか？
**A**: 80点以上であれば申請資格はあります。ただし、書類の完全性や他の要素も審査されます。

### Q2. TOPIKなしでF-2-7を取得できますか？
**A**: TOPIKなしでは韓国語点数が0点となり、他の項目で高得点が必要になります。実際には非常に困難です。

### Q3. フリーランサーや自営業者も申請できますか？
**A**: できます。ただし、所得証明の書類が会社員とは異なります。事業所得の証明書類を適切に準備することが重要です。

### Q4. F-2-7の更新を忘れた場合はどうなりますか？
**A**: 在留資格の期限切れは不法滞在となります。必ず期限前に更新手続きを行ってください。

### Q5. 専門家への依頼は必要ですか？
**A**: 点数計算・書類準備は複雑です。特に外国の学位のアポスティーユ取得など、手間のかかる作業もあります。VISION行政書士事務所では日本語でのサポートを提供していますので、お気軽にご相談ください。

## F-2-7申請における注意事項

### 書類の有効期限管理

各証明書類には発行日からの有効期限があります。特に以下の書類は取得後すぐに申請しないと期限切れになる場合があります。

| 書類 | 有効期限 |
|------|---------|
| 주민등록등본（住民登録謄本） | 発行後3ヶ月以内 |
| 소득금액증명원（所得証明書） | 발행후 3개월 이내 |
| 재직증명서（在職証明書） | 発行後3ヶ月以内 |
| 외국인등록증（外国人登録証） | 在留資格有効期限まで |

### 신청 시기 선택（申請時期の選択）

F-2-7は在留資格の残余期間が十分ある状態で申請することが理想です。在留期間が残り少ない状態では、審査中に在留期限切れとなるリスクがあります。

**推奨申請タイミング**：在留期限の3〜6ヶ月前

## F-2-7の更新（재신청）

F-2-7は一度取得しても永続するわけではなく、定期的に更新が必要です。

### 更新時の注意点

- 更新時にも最新の점수표（点数表）に基づいて再審査されます
- 所得・収入状況が変化した場合は点数が変動します
- 犯罪歴・출입국법 위반（出入国法違反）がある場合は更新が困難になります

### 更新に必要な主な書類

更新時も初回申請と同様の書類が必要になる場合があります。特に所得証明書と健康診断書は更新のたびに新たに取得する必要があります。
