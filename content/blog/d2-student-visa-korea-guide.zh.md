# 韩国D-2留学签证完全指南（2026年版）：申请要求·打工规定·毕业后签证转换

D-2（留学）签证允许外籍人士在韩国大学、研究生院及同等学术机构就读正规学位课程。

D-2并非语言进修签证——**它针对以取得正式学位为目的的长期留学**，语言进修须申请D-4签证。许多外籍毕业生将D-2作为在韩长期发展的起点，毕业后顺利过渡到工作签证。

## 1. D-2是什么？——留学签证的适用范围

D-2是韩国《出入境管理法》中的「留学」资格，适用于在韩国认可学术机构就读学位课程的外籍人士。

### D-2子类别

| 代码 | 课程类型 |
|---|---|
| D-2-1 | 专科（2至3年制大学）在读 |
| D-2-2 | 本科（4年制大学）在读 |
| D-2-3 | 硕士课程在读 |
| D-2-4 | 博士课程在读 |
| D-2-5 | 研究生（非学位科研参与） |
| D-2-6 | 交换生（6个月至1年） |
| D-2-7 | 专业研究生院及其他正规课程 |

若仅在韩国进行语言进修而非攻读学位，正确签证为D-4（普通研修），而非D-2。

## 2. 入学要求——大学·研究生院·科研机构

申请D-2签证的前提是**获得韩国教育部认可院校的正式录取通知书**。

### 认可院校类型

- 教育部认可的四年制大学及研究生院
- 专科院校（2至3年制）
- 韩国科学技术院（KAIST）、浦项工科大学（POSTECH）等特殊院校
- 教育部登记在册的网络大学（部分符合条件的课程）

### 典型入学要求

各院校要求不尽相同，但一般须提供以下材料：

| 项目 | 通常要求 |
|---|---|
| 学历背景 | 至少高中毕业（研究生课程须具备本科学历） |
| 韩语水平 | 韩语授课课程须达TOPIK 3级以上（部分院校可无TOPIK入学） |
| 英语水平 | 全英文授课课程须提供TOEFL/IELTS成绩 |
| 学业记录 | 毕业证书+成绩单 |

## 3. 财力证明要求

财力证明是D-2签证审核的核心要素之一，须证明在韩学习期间具备自给自足的经济能力。

### 财力参考标准

| 项目 | 标准 |
|---|---|
| 最低余额 | 通常需达到1万美元以上或等值外币存款 |
| 证明期间 | 申请前3至6个月的平均存款余额 |
| 证明方式 | 银行存款余额证明（如需，须附公证或翻译件） |

如以担保人（如父母）财力进行证明，须同时提交担保人收入证明及亲属关系证明文件。

获得奖学金者可以奖学金确认函代替部分或全部财力证明材料。

## 5. 申请流程

### 在海外申请（申请签证）

1. 向韩国院校申请→收到录取通知书
2. 准备财力证明及学历材料
3. 向驻当地韩国大使馆或领事馆提交材料
4. 审核：通常需5至15个工作日
5. 签证发放后入境韩国
6. 入境后90日内在当地出入境外国人厅完成外国人登记

### 在韩国境内变更签证状态

若已持其他签证在韩居留：
1. 取得录取通知书并准备所需材料
2. 通过Hi Korea（hikorea.go.kr）或所在地出入境外国人厅申请变更为D-2
3. 审核：通常需2至4周

## 6. 在读期间打工——兼职就业许可

D-2持有者在特定条件下可以打工，但须事先取得**兼职就业许可**。

### 许可条件

| 条件 | 标准 |
|---|---|
| 学习年限 | 须在韩国完成至少1学期学习 |
| 许可工时 | 学期间每周不超过20小时（寒暑假期间不受限制） |
| 许可行业 | 专业类或一般服务类（禁止在娱乐场所、赌博场所等就业） |
| 申请方式 | 通过Hi Korea或出入境外国人厅申请 |

未取得许可擅自打工将被认定为非法就业，可能导致签证被撤销并被强制遣返。务必在开始任何有偿工作前取得许可。

---

## 7. 居留期限与续签

| 项目 | 内容 |
|---|---|
| 初始居留期限 | 1至2年，视课程时长而定 |
| 续签 | 在读期间可反复续签至毕业 |
| 续签条件 | 学业成绩达标、按时缴纳学费、满足出勤要求 |

成绩持续低下或出勤率严重不足可能导致续签被拒。大多数院校会向出入境管理机关报告在籍状态的变化。

## 8. 毕业后签证转换路径

在韩国完成学业后，可通过以下路径继续居留：

### 主要转换路径

| 签证 | 说明 |
|---|---|
| D-10求职签证 | 毕业后可在韩居留最长2年用于求职 |
| E-7特定活动签证 | 获得韩国雇主录用且职种符合条件时申请 |
| F-2-7积分制居留签证 | 韩国学位加分项使达到80分更容易 |
| D-8企业投资签证 | 在韩创办公司（投资1亿韩元以上） |

**F-2-7韩国学位加分项：**
- 在韩获得本科学位：+3分
- 在韩获得硕士学位：+5分
- 在韩获得博士学位：+10分

上述加分项仅适用于在韩国院校取得的学位。韩国研究生学位对F-2-7积分申请具有显著优势。

详细转换策略请参阅[E-7特定活动签证指南](/zh/blog/e7-specific-activities-visa-guide)和[F-2-7积分制长期居留签证指南](/zh/blog/f2-7-points-based-long-term-residency)。

## 9. D-2与D-4的区别——学位课程vs语言进修

| | D-2留学签证 | D-4普通研修签证 |
|--|--|--|
| 目的 | 攻读学位 | 语言进修、非学位培训 |
| 期限 | 学位课程时长（2至6年） | 通常1至2年 |
| 打工 | 取得许可后每周最多20小时 | 条件不同的打工许可 |
| F-2-7韩国学位加分 | 有 | 无 |
| 毕业/结业后转换路径 | D-10/E-7/F-2-7/D-8等多种 | 较为有限 |

许多留学生先以D-4完成语言进修，考取韩国大学后转换为D-2。D-4期间也可能计入F-2-7的国内居住时长。

## 10. 常见问题解答

**Q. 未收到录取通知书前可以先申请D-2签证吗？**
A. 不可以。录取通知书是D-2申请的必备材料。部分院校会发放有条件录取通知书，请直接联系院校国际处了解具体文件要求。

**Q. 以转学入学方式也可以申请D-2吗？**
A. 可以。提供转学录取通知书，并附上原校成绩单及毕业证书即可。

**Q. 持D-2期间可以参加实习吗？**
A. 在兼职就业许可允许的工时范围内，可以参加实习。即便是无薪实习，也建议事先向出入境管理机关确认是否需要取得许可。

**Q. D-2留学生需要参加韩国国民健康保险吗？**
A. 是的。自2019年起，D-2留学生须强制加入国民健康保险。可通过所在院校办理，也可直接前往国民健康保险公团申请。

**Q. 毕业后暂时找不到工作，还能留在韩国吗？**
A. 可以申请D-10（求职签证），毕业后最长可居留2年用于求职。D-2毕业生符合申请D-10的条件。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
