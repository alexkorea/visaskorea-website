# 韩国D-2留学签证完整指南（2026年）：申请·续签·兼职打工

D-2签证是发放给在韩国大学、研究生院或专科院校正式入学攻读学历课程的外国留学生的签证。本指南将从D-2签证申请到毕业后签证转换的全过程进行详细说明。

## 1. 什么是D-2留学签证？

D-2（留学）签证适用于在韩国教育部认可的高等教育机构正式入学攻读学历课程的外国留学生。

| 项目 | 内容 |
|---|---|
| 签证类型 | D-2（留学） |
| 允许活动 | 正式学历课程学习（专科·本科·硕士·博士） |
| 适用院校 | 教育部认可的四年制大学、专科院校、研究生院 |
| 有效期 | 2年以内（按学期或学年发放） |
| 兼职打工 | 提前获许可后每周20小时以内 |

## 3. 申请资格要求

| 要求 | 具体内容 |
|---|---|
| 入学许可 | 取得韩国认可高等教育机构的入学许可书 |
| 学历 | 高中毕业以上（研究生课程须具备学士学位） |
| 经济能力 | 有足够财力支付学费及生活费 |
| 在校表现 | 续签时须满足出勤率及学业成绩要求 |

## 5. 签证申请流程

| 步骤 | 内容 |
|---|---|
| 1 | 向韩国大学提交申请并收到录取通知 |
| 2 | 取得入学许可书 |
| 3 | 向驻外韩国大使馆/领事馆申请D-2签证 |
| 4 | 签证发放后入境韩国 |
| 5 | 入境后90天内办理外国人登记（出入境外国人厅） |
| 6 | 领取学生证及外国人登记证后开始学校生活 |

---

## 6. 入境后外国人登记

入境后须在90天内前往户籍所在地出入境外国人厅办理**外国人登记**。

| 所需材料 | 备注 |
|---|---|
| 护照 | |
| 证件照1张 | |
| 在学证明书或入学许可书 | 学校出具 |
| 住所证明（宿舍确认书或租赁合同） | |
| 登记费用 | 约30,000韩元 |

---

## 7. D-2签证续签

| 项目 | 内容 |
|---|---|
| 续签周期 | 按学期或学年（通常1—2年） |
| 申请时间 | 到期前2—3个月 |
| 续签条件 | 须满足出勤率要求；成绩不达标可能影响续签 |
| 所需材料 | 在学证明书、成绩单、出勤确认书、护照、外国人登记证 |

> 出勤率过低或受到学业警告，续签可能受到限制。请提前向学校国际处确认。

---

## 8. 兼职打工许可（时间制就业）

D-2签证持有者向出入境外国人厅申请**时间制就业许可**后，即可从事兼职工作。

| 项目 | 内容 |
|---|---|
| 允许时间 | 学期中每周20小时以内 |
| 寒暑假期间 | 不限时间 |
| 申请方式 | 前往出入境外国人厅或通过Hi Korea在线申请 |
| 所需材料 | 在学证明书、外国人登记证 |
| 允许职种 | 除单纯体力劳动外，多种职种均可 |

> 未经许可从事兼职工作，可能导致签证被取消并被遣返。

---

## 9. 毕业后签证转换

| 目标签证 | 条件 |
|---|---|
| D-10（求职） | 毕业后求职期间使用（最长1—2年） |
| E-1~E-7（就业） | 确认工作单位后转换为相应就业签证 |
| F-2-7（积分制） | 积分达标时可申请（韩国语、成绩、就业等均可加分） |
| F-6（婚姻） | 与韩国国民结婚时 |

> D-2在校期间的在韩居留时间，也可作为F-2-7积分制签证的居留年限加分项目。

## 10. 常见问题解答

**Q. 持D-2签证在学期间可以打工吗？**
A. 可以，但必须先取得时间制就业许可。学期中每周最多工作20小时，寒暑假期间不限时间。

**Q. 转专业或转校需要更换签证吗？**
A. 在同一院校内转专业无需更换签证。若转到其他院校，须向出入境外国人厅进行变更申报。

**Q. 休学期间D-2签证还有效吗？**
A. 休学期间一般可保持D-2资格，但续签时须证明有复学计划。长期休学建议向出入境外国人厅申报。

**Q. 毕业后可以直接转为就业签证吗？**
A. 毕业后可转换为D-10（求职）签证，用于求职活动，最长1—2年。确认工作单位后再转换为相应就业签证（E系列）。

**Q. 如何从D-4语言进修签证转换为D-2留学签证？**
A. 取得韩国大学入学许可后，向辖区出入境外国人厅申请居留资格变更即可。在D-4状态下完成语言进修后即可申请转换。
