# 韓国4大社会保険外国人完全ガイド（2026年）：加入義務・保険料・給付内容

韓国で合法的に就労する外国人労働者も、韓国国民と同様に4大社会保険（健康保険・国民年金・雇用保険・産業災害補償保険）が適用されます。4大保険は、労働者が疾病・負傷・失業・業務上の災害といったリスクから保護される社会的セーフティネットです。

## 1. 4大保険とは？

4大保険は、国家が義務加入を定めた4種類の社会保険制度です。

| 保険の種類 | 管轄機関 | 主な目的 |
|---|---|---|
| 健康保険 | 国民健康保険公団 | 医療費の支援 |
| 国民年金 | 国民年金公団 | 老後の所得保障 |
| 雇用保険 | 雇用労働部 | 失業給付および職業訓練の支援 |
| 産業災害補償保険 | 勤労福祉公団 | 業務上の負傷・疾病の補償 |

## 2. 外国人労働者の4大保険加入義務

| 保険 | 外国人への適用 | 備考 |
|---|---|---|
| 健康保険 | ✅ 加入義務 | 6か月以上滞在の場合 |
| 国民年金 | ✅ 原則として義務 | 相互主義原則適用（協定国は免除申請可） |
| 雇用保険 | ✅ 原則として義務 | 一部のビザ種別は対象外 |
| 産業災害補償保険 | ✅ 全面適用 | すべての就労外国人 |

## 3. 健康保険

### 職場加入者の保険料（2026年基準）

| 項目 | 比率 |
|---|---|
| 健康保険料 | 報酬月額×7.09% |
| 労働者負担 | 3.545% |
| 事業主負担 | 3.545% |
| 長期療養保険料 | 健康保険料×12.81% |

### 健康保険の給付内容

- 外来診察・入院・処方薬の費用の大部分を保険でカバー
- 健康診断の支援（職場加入者は2年ごとに無料）
- 出産支援金の給付

## 4. 国民年金

### 国民年金保険料（2026年基準）

| 項目 | 比率 |
|---|---|
| 保険料率 | 報酬月額×9% |
| 労働者負担 | 4.5% |
| 事業主負担 | 4.5% |

### 外国人の国民年金に関する主要事項

| 項目 | 内容 |
|---|---|
| 適用原則 | すべての就労外国人 |
| 免除対象 | 社会保障協定締結国の国民（下記参照） |
| 受給条件 | 加入期間10年以上+満60歳到達 |
| 返還一時金 | 帰国時に積立金の返還申請が可能 |

### 国民年金免除対象国（例）

米国・ドイツ・カナダ・フランス・日本など社会保障協定締結国の国民は、本国の年金加入を証明することで国民年金の加入免除申請ができます。

## 5. 雇用保険

### 雇用保険料（2026年基準）

| 項目 | 比率 |
|---|---|
| 失業給付保険料 | 報酬月額×1.8% |
| 労働者負担 | 0.9% |
| 事業主負担 | 0.9%+雇用安定・職業能力開発負担 |

### 外国人の雇用保険適用除外ビザ

| ビザ種別 | 適用状況 |
|---|---|
| E-9（非専門就業） | ❌ 任意加入（義務なし） |
| H-2（訪問就業） | ❌ 任意加入 |
| E-1〜E-7、F-2、F-4、F-5、F-6等 | ✅ 加入義務 |

> E-9・H-2ビザ保持者は加入義務の対象外ですが、事業主が申請すれば任意加入が可能です。

### 失業給付の受給条件

- 離職前18か月間のうち被保険単位期間が180日以上
- 非自発的離職（解雇、勧奨退職など）
- 積極的な再就職活動

## 6. 産業災害補償保険

産業災害補償保険は、業務中に発生した負傷・疾病・死亡に対する補償制度で、**就労する外国人全員に義務適用**されます。

| 項目 | 内容 |
|---|---|
| 保険料の負担 | 事業主が全額負担（労働者負担なし） |
| 適用範囲 | すべての就労外国人（ビザ種別不問） |
| 補償内容 | 療養費・休業給付・障害給付・遺族給付など |
| 申請方法 | 業務上の災害が発生したら直ちに事業主へ報告 |

## 8. 社会保障協定国による免除

韓国は複数の国と社会保障協定を締結しており、該当国の国民は国民年金などの加入免除申請が可能です。

| 主な協定締結国 | 免除可能な保険 |
|---|---|
| 米国・カナダ | 国民年金免除申請可 |
| ドイツ・フランス | 国民年金免除申請可 |
| 日本 | 国民年金免除申請可 |
| 英国・オーストラリア | 国民年金免除申請可 |

> 免除を受けるには本国の年金加入証明書の提出が必要です。最新の協定締結国リストは国民年金公団でご確認ください。

## 9. 国民年金返還一時金の申請

外国人が韓国を離れる際、国民年金の加入期間が10年未満の場合は**返還一時金**を受け取ることができます。

| 項目 | 内容 |
|---|---|
| 申請対象 | 韓国国籍を持たない者・帰国予定の外国人 |
| 申請時期 | 出国後または出国前 |
| 申請方法 | 国民年金公団の窓口・郵送・オンライン申請 |
| 支給額 | 納付元本＋利息 |

## 10. よくある質問（FAQ）

**Q. 4大保険に加入しないとどうなりますか？**
A. 事業主が4大保険を申告しなかった場合、過料と遡及保険料が課されます。労働者も給付を受けられなくなるため、就職直後に加入状況を確認することが重要です。

**Q. E-9ビザで就労した場合、失業給付を受けられますか？**
A. E-9ビザ保持者は雇用保険の義務加入対象外のため、原則として失業給付は受けられません。ただし任意加入している場合は、受給要件を満たせば受給できます。

**Q. 国民年金を納めていたのに韓国を離れることになりました。どうなりますか？**
A. 加入期間が10年未満の場合、返還一時金の申請で納付した金額を取り戻すことができます。10年以上の場合は満60歳以降に年金として受給できます。

**Q. 産業災害補償保険は外国人にも必ず適用されますか？**
A. はい。産業災害補償保険はビザの種別や登録の有無に関わらず、韓国で就労するすべての労働者に義務適用されます。保険料は事業主が100%負担します。

**Q. 日本国籍ですが、韓国で国民年金を払わなくてもよいですか？**
A. 日韓社会保障協定に基づき、日本の年金制度に加入していることを証明できれば、韓国の国民年金加入免除を申請できます。国民年金公団に免除申請書を提出してください。

## よくある質問（FAQ）

### Q1. 日本から直接韓国のビザを申請できますか？
**A**：はい、在日韓国大使館または在日本韓国総領事館（東京・大阪・名古屋・福岡・広島・仙台・新潟・札幌）で申請できます。事前予約と必要書類の確認をお勧めします。

### Q2. 専門家への依頼は必要ですか？
**A**：ビザ申請書類は複雑で、書類不備や記載ミスがあると申請が遅延したり不許可になる場合があります。VISION行政書士事務所では日本語でのサポートを提供しており、初回相談は無料です。

### Q3. 申請が不許可になった場合はどうすればよいですか？
**A**：不許可通知を受け取った後は、原因を確認し改善措置を講じる必要があります。当事務所では不許可後の再申請サポートも承っております。

### Q4. ビザ更新はいつ頃申請すべきですか？
**A**：在留期限の2〜3ヶ月前から書類準備を開始し、余裕を持って申請することをお勧めします。

### Q5. 家族も一緒に韓国に来ることができますか？
**A**：多くの長期在留ビザでは、配偶者と未成年の子どもをF-1（家族同伴）ビザで呼び寄せることができます。詳細は専門家にご相談ください。

## 韓国生活の実用情報

### 国民健康保険への加入

外国人登録完了後、長期在留ビザを持つ外国人は国民健康保険（건강보험）への加入が必要です。医療費の大部分をカバーできるため、早めに手続きをすることをお勧めします。

### 銀行口座の開設

有効な外国人登録証があれば、韓国の主要銀行（KB国民銀行、新韓銀行、ウリィ銀行、IBK企業銀行など）で口座を開設できます。給与受け取りや日常の金融業務に欠かせません。

### 交通カード（T-Money）

T-Moneyカードはソウル市内の地下鉄・バスに使用できるほか、コンビニでの買い物にも利用でき、韓国生活の必需品です。

### 韓国語学習リソース

長期在住には基本的な韓国語の習得をお勧めします。多文化家族支援センターや사회통합프로그램（KIIP、社会統合プログラム）では無料または低価格の韓国語講座を提供しています。
