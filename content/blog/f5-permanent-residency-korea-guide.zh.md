# 韩国F-5永久居留权完全指南（2026年版）：全部路径解析

韩国F-5（永久居留）资格允许外籍人士无限期居留韩国，自由就业、创业，无需取得韩国国籍，即可获得稳定的长期居留保障。

F-5并非单一资格，而是**由16个以上子类别构成的资格体系**，每个类别对应不同的申请路径。具体选择哪条路径，取决于您的居留经历、职业背景和民族背景。本指南重点介绍大多数长期在韩外籍人士使用的四条主要路径。

## 1. F-5永久居留权是什么？

F-5是韩国移民制度中授予无限期居留权的资格，无需归化即可在韩国永久生活。这是外籍人士在韩国可获得的最稳定长期身份。

**F-5的核心优势：**
- 不限居留期限——无需定期续签
- 完全就业自由——不受职种或雇主限制
- 可经营任何类型企业
- 只要不违反移民法规，资格长期有效
- 可长期出境并再入境（须在规定时限内）
- 是日后申请归化（韩国国籍）的基础

F-5不是续签概念——一旦取得，只要符合条件，无需重新申请即可继续居留。

## 2. F-5主要申请路径一览

| 路径代码 | 适用对象 | 核心要求 |
|---|---|---|
| F-5-1 | 长期合法居留外籍人士 | 合法居留5年+收入要求+无犯罪记录 |
| F-5-5 | D-8企业投资者 | D-8持续5年+雇员/营业收入要求 |
| F-5-7 | F-4在外同胞 | 持F-4+国内实际居住满2年 |
| F-5-16 | F-2-7积分制居留者 | F-2-7持满3年+收入及品行要求 |
| F-5-2 | 韩国国民配偶等 | 与韩国人结婚2年以上或抚养韩国子女 |
| F-5-6 | 高额投资者 | 投资50万美元以上+雇用5名韩国人 |

本指南重点介绍最常用的四条路径：F-5-1、F-5-5、F-5-7、F-5-16。

## 3. F-5-1——长期居留者永久居留权

F-5-1是适用于在韩国长期合法居留外籍人士的通用永久居留路径，不限签证类别。

### 申请要求

| 要求 | 标准 |
|---|---|
| 合法居留期限 | 在韩连续合法居留满5年 |
| 收入 | 上一年度收入达韩国人均GNI以上（2026年参考约4300万韩元） |
| 犯罪记录 | 无（或仅有轻微罚款记录） |
| 税款与健康保险 | 无拖欠 |

### 哪些签证持有者可申请？

持E-7、D-7、D-8、F-2等大多数工作或投资类签证满5年后均可考虑申请F-5-1。短期居留（B-2旅游、C-3短期访问）期间通常不计入5年居留时长。

---

## 4. F-5-5——投资者永久居留权（D-8路径）

F-5-5是专为长期在韩经营企业的D-8企业投资签证持有人设立的永久居留路径。

### 申请要求

| 要求 | 标准 |
|---|---|
| D-8居留期限 | 持续持有D-8资格满5年 |
| 雇员要求 | 雇用2名以上韩国全职员工 |
| 或营业收入要求 | 年营业收入1亿韩元以上 |
| 投资维持 | 保持1亿韩元以上投资额 |
| 收入、品行、纳税 | 满足共同要求 |

F-5-5不仅是等够5年——在这5年内须持续满足D-8的雇员及营业收入要求。

D-8签证详情请参阅[D-8企业投资签证指南](/zh/blog/d8-corporate-investment-visa-guide)。

## 5. F-5-7——在外同胞永久居留权（F-4路径）

F-5-7适用于已在韩国建立实际居住关系的F-4在外同胞签证持有人。

### 申请要求

| 要求 | 标准 |
|---|---|
| 资格 | 须持有或符合F-4在外同胞资格 |
| 国内居住期限 | 近2年每年在韩居住180天以上 |
| 收入 | 达人均GNI以上 |
| 品行与纳税 | 无犯罪记录，无税款拖欠 |

F-5-7是F-5各路径中最简便的之一：持F-4在韩居住满2年即可申请，无需积分表、无需雇主批准、无职种限制。

F-4签证详情请参阅[F-4在外同胞签证指南](/zh/blog/f4-overseas-korean-visa-guide)。

## 6. F-5-16——积分制永久居留权（F-2-7路径）

F-5-16是持有F-2-7（积分制长期居留）资格并维持一定年限的外籍人士申请永久居留权的路径。

### 申请要求

| 要求 | 标准 |
|---|---|
| F-2-7居留期限 | 持续持有F-2-7资格满3年 |
| 收入 | 达人均GNI以上 |
| 品行 | 无出入境违规记录 |
| 税款与健康保险 | 无拖欠 |

F-5-16是无韩国血统的在职外籍专业人士申请永久居留权最现实的路径。典型路径：E-7（特定活动）→ F-2-7（满3年）→ F-5-16。

F-2-7积分计算及策略详见[F-2-7积分制长期居留签证指南](/zh/blog/f2-7-points-based-long-term-residency)。

## 7. 共同要求：收入·品行·纳税

所有F-5申请路径均适用以下基本标准：

### 收入标准

| 基准 | 内容 |
|---|---|
| 最低收入 | 达上一年度韩国人均GNI以上 |
| 2026年参考值 | 约4300万韩元 |
| 证明材料 | 所得税纳税证明、劳动所得预扣凭证 |

### 品行标准

- 无有期徒刑以上刑事处罚记录
- 无出入境法规违规记录，或违规记录轻微已处理
- 有强制遣返记录者实际上无法申请F-5

### 税款与保险

- 无国税及地方税欠缴
- 无健康保险费未缴

## 8. 申请流程

1. **确认资格** — 核实是否满足所选路径的要求
2. **准备材料** — 收集路径专属材料及通用材料
3. **提交申请** — 通过Hi Korea（hikorea.go.kr）在线申请或前往所在地出入境外国人厅

## 9. 取得F-5后的变化

| 项目 | F-5取得前 | F-5取得后 |
|---|---|---|
| 就业/转职 | 受签证类别限制 | 不受限制，可自由就业 |
| 居留期限 | 须定期续签 | 无限期，无需续签 |
| 长期出境 | 须在签证有效期内回国 | 可出境，须在2年内回国 |
| 经营企业 | 须符合签证目的范围 | 不限行业 |
| 归化申请 | 须积累合法居留5年 | 可申请归化（须满足独立条件） |

**长期出境注意：** F-5资格通常在连续出境2年以上后失效。短暂出境没有问题，但如有长期旅居海外的计划，出发前请办理再入境许可。

## 10. 常见问题解答

**Q. 取得F-5是否需要放弃原有国籍？**
A. 不需要。F-5是居留资格，不是归化。保留原有国籍的同时，即可在韩国永久居留。

**Q. F-5-1的5年合法居留如何计算？**
A. 累计所有在韩合法居留时长，可跨越不同签证类别。短期旅游（B-2、C-3）及免签入境期间通常不计入。

**Q. 我取得F-5后，子女也能获得永久居留权吗？**
A. 在某些情况下，父母一方取得F-5时，未成年子女可申请随行F-5。具体须视子女自身的居留经历和情况而定，需另行确认。

**Q. 有少量税款未缴，会影响F-5申请吗？**
A. 申请前补缴欠款通常可消除影响。但反复拖欠或欠缴金额较大，则会对审核产生不利影响。

**Q. F-5-16（积分制永住）像F-2-7一样需要每次续签时重新计算积分吗？**
A. 不需要。F-5-16是永久资格，无需定期重新审核积分。只需在申请F-5-16时满足相关要求即可。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
