# 韩国D-4一般研修签证完全指南（2026年版）：语言培训·资格·兼职·转换D-2

D-4（一般研修）签证发放给赴韩**进行语言培训或职业技能培训**而非攻读学位的外国人。大学附设或私立韩国语培训学校的注册学员，以及在职业技能培训机构学习的外国人，是该签证的主要使用群体。

与D-2不同，D-4以非学位研修为目的，通常是计划日后升入韩国大学（D-2）或转换为就业签证（E-7）的起步阶段。

## 1. D-4签证是什么？

D-4是韩国《出入境管理法》中的"一般研修"居留资格，发放给在法务部认可机构注册接受培训的外国人，但不以攻读正式学位为目的。

核心特点：
- 以语言培训或职业技能培训为目的，而非取得学位
- 适用于语言培训学校、职业技能培训机构、技术研修机构等
- 满足一定条件后可申请兼职打工许可
- 研修结束后可转换为D-2（留学）或E-7（就业）等资格

---

## 2. 申请资格

### 基本条件

| 条件 | 内容 |
|---|---|
| 获得认可机构录取 | 须持有韩国法务部认可的D-4机构签发的录取通知书 |
| 资金能力 | 须证明在韩期间有能力支付学费及生活费 |
| 无结格事由 | 无犯罪记录，无出入境法规违规记录 |
| 研修目的真实 | 须有完成课程的真实意愿和能力 |

### D-4签证的典型使用者

- 在大学附设或私立韩国语培训学校注册的外国人
- 在韩国职业学校（烹饪学校、美容学校等）接受技能培训的外国人
- 受邀至韩国企业或公共机构参加技术研修的外国人

## 3. 可注册的教育机构类型

申请D-4签证须注册法务部认可的机构。

### 主要认可机构类型

| 机构类型 | 举例 |
|---|---|
| 大学附设韩国语教育院 | 首尔大学、延世大学、高丽大学语言教育院等 |
| 私立韩国语语言学院 | 法务部登记注册的私立语言学院 |
| 职业技能培训机构 | 韩国职业能力开发院指定培训机构 |
| 企业·公共机构研修 | 受邀研修项目（D-4-6） |

**注意：** 并非所有语言学院或教育机构都具备为D-4签证提供担保的资格。注册前务必确认该机构是否为法务部认可的D-4合规机构。

---

## 4. 资金证明要求

资金证明是D-4签证审查的重要评估项目。

### 一般标准

| 项目 | 内容 |
|---|---|
| 存款余额 | 通常相当于5,000~10,000美元以上（因国家和使领馆不同而有所差异） |
| 认可材料 | 银行存款余额证明（需体现维持3个月以上的资金） |
| 担保人可替代 | 父母或法定监护人的存款证明+担保确认文件 |

各使领馆标准可能有所不同，申请前请向所在地韩国使领馆确认具体要求。

## 5. 所需材料及申请流程

### 所需材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 韩国驻外使馆格式 |
| 护照 | 有效期6个月以上 |
| 证件照 | 3.5×4.5cm |
| 录取通知书 | 韩国培训机构签发 |
| 学费缴纳收据 | 或学费缴纳确认函 |
| 资金证明 | 存款余额证明（建议5,000美元以上） |
| 最终学历证明 | 毕业证书+翻译及公证 |
| 无犯罪记录证明 | 部分国籍需要提供 |

### 申请流程

1. 在韩国培训机构办理注册手续并取得录取通知书
2. 在居住国韩国大使馆或领事馆申请D-4签证
3. 签证发放后入境韩国
4. 入境后90日内完成外国人登记
5. 完成研修课程

## 6. 居留期限与续签

| 项目 | 内容 |
|---|---|
| 初始居留期限 | 通常6个月~1年（视课程时长而定） |
| 续签 | 继续注册可申请续签（通常最长可续签至2年） |
| 转学 | 转至其他D-4认可机构须向出入境管理处报告 |

许多D-4签证持有人以准备升入韩国大学（D-2）或在韩就业为目标。

## 7. 兼职打工（就业许可）

D-4签证原则上限制就业，但满足一定条件后可申请兼职打工许可。

### 兼职打工许可条件

| 条件 | 内容 |
|---|---|
| 持D-4居留满6个月 | 满6个月后可申请打工许可 |
| 允许时间 | 每周最多20小时 |
| 允许行业 | 简单服务业等（不允许从事专业职位） |
| 申请方式 | 向出入境外国人厅提交兼职打工许可申请 |

未经许可擅自就业属于违规行为，可能导致签证被取消及强制驱逐出境。

---

## 8. 从D-4转换至D-2·E-7·F-2

D-4可以成为在韩长期居留的起点。

### 主要转换路径

| 目标资格 | 条件 |
|---|---|
| D-2留学 | 持D-4期间获得韩国大学正规学位课程录取 → 申请转换D-2 |
| E-7特定活动 | 持D-4期间收到韩国企业录用通知 → 申请转换E-7（须在允许职类范围内） |
| F-2-7积分制居留 | D-4合法居留时间可能计入部分F-2-7加分项；通常需先转换D-2或E-7后积累足够积分 |

最常见的路径：D-4语言培训 → 提升韩语至TOPIK水平 → 升入韩国大学（D-2）→ 毕业 → D-10求职 → E-7就业。

详情请参阅[D-2留学签证指南](/zh/blog/d2-student-visa-korea-guide)。

## 9. D-4与D-2的比较

| | D-4一般研修 | D-2留学 |
|--|--|--|
| 目的 | 语言培训或职业技能培训 | 攻读正规学位 |
| 就读机构 | 语言培训学校·培训机构 | 大学·研究生院 |
| 能否取得学位 | 不可以 | 可以 |
| 兼职打工 | 满6个月后每周最多20小时 | 满足条件可许可 |
| 居留期限 | 通常1~2年 | 学位课程期间 |
| 后续转换 | 可转换D-2·E-7等 | 可转换D-10·E-7 |

## 10. 常见问题解答

**Q. 我完全不懂韩语，能持D-4签证去语言学校学习吗？**
A. 可以。D-4签证没有韩语能力要求。大多数持D-4签证的人都是从零基础开始学韩语，语言课程从初级班开始设置。

**Q. 持D-4期间可以去便利店打工吗？**
A. 入境满6个月后申请兼职打工许可，每周可工作不超过20小时。未经许可擅自就业属于签证违规行为。

**Q. D-4居留时间对F-2-7积分有帮助吗？**
A. D-4居留时间可能对F-2-7部分加分项有贡献，但仅靠D-4很难达到80分。通常的路径是先转换D-2或E-7，再积累足够积分后申请F-2-7。

**Q. 转到其他语言学校会影响签证吗？**
A. 转至另一家法务部认可的D-4机构是允许的，但须向出入境管理处报告机构变更。如果完全退学并中断在韩培训，则丧失D-4居留目的，将影响居留资格。

**Q. 持D-4期间被韩国大学录取，可以立即转换为D-2吗？**
A. 可以。持D-4期间收到韩国大学正规学位课程录取通知书后，可向出入境外国人厅申请转换D-2资格。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
