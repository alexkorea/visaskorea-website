# 韩国归化申请完整指南（2026年）：普通归化·简易归化·特别归化

取得韩国国籍后，无需签证即可永久居留，并与韩国国民享有同等的出行和就业权利。归化（귀화）是外国人取得韩国国籍的法律程序，根据个人情况分为**普通归化、简易归化和特别归化**三种类型。

## 1. 归化类型概览 {#section-1}

| 归化类型 | 主要申请对象 | 最低居留要求 |
|---|---|---|
| 普通归化 | 一般外国人 | 合法连续居留5年以上 |
| 简易归化 | 韩国国民配偶、海外韩裔等 | 居留2—3年（因条件而异） |
| 特别归化 | 韩国国民父母、有杰出贡献者等 | 无居留年限要求或大幅缩短 |

---

## 2. 普通归化条件 {#section-2}

依据《国籍法》第5条，须同时满足以下所有条件。

| 条件 | 具体内容 |
|---|---|
| 居留期限 | 在韩合法连续居留满5年 |
| 年龄 | 申请之日年满18周岁 |
| 行为能力 | 依本国法律为成年人，具备完全行为能力 |
| 生计能力 | 本人或共同生计家庭成员具备维持生活的财产或技术 |
| 品行端正 | 无不良犯罪记录（有严重犯罪前科者不予许可） |
| 韩国语能力 | 通过归化适应性考试 |
| 了解韩国社会 | 通过归化适应性考试 |

> **重要提示**：5年居留原则上须为连续居留。若因长期出境导致居留中断，年限计算可能受到限制。

---

## 3. 简易归化条件 {#section-3}

依据《国籍法》第6条，符合下列之一者，居留年限要求可适当放宽。

### 3-1. 与韩国国民婚姻

| 条件 | 居留要求 |
|---|---|
| 与韩国国民婚姻后在韩连续居留满**2年** | 在韩居留满2年 |
| 与韩国国民婚姻后在韩居留满**1年**，且在韩生育子女 | 在韩居留满1年 |
| 因非申请人过错导致婚姻无法继续（配偶死亡、失踪等），婚姻持续满**2年** | 经认定特殊情形后予以许可 |

### 3-2. 海外韩裔（在外同胞）

父母曾为韩国国民者（如移民二代等），在韩合法居留满**3年**即可申请。

### 3-3. 其他简易归化情形

- 在韩出生并连续居留满3年者
- 父母已归化的外国人子女，且本人居留满3年者

---

## 4. 特别归化条件 {#section-4}

依据《国籍法》第7条，下列人员无需满足居留年限要求即可申请归化。

| 申请对象 | 条件 |
|---|---|
| 父母现为韩国国民者 | 无居留年限要求 |
| 对大韩民国有特殊贡献者 | 经法务部长官认定 |
| 科学、经济、文化等领域优秀外国人才 | 由法务部长官推荐 |

---

## 5. 归化考试指南 {#section-5}

### 归化适应性考试（KINAT）

| 项目 | 内容 |
|---|---|
| 主管机构 | 移民融合研究所（出入境外国人政策本部主管） |
| 考试科目 | 韩国语能力（阅读、写作、听力、口语）+ 韩国社会理解 |
| 合格标准 | 两个科目均须达到最低合格分数 |
| 免考条件 | 持有TOPIK 4级以上（免除韩国语科目） |
| 全程免考 | 完成社会融合项目（KIIP）5阶段（免除全部科目） |

> **建议**：如正在准备归化，完成KIIP项目可免除全部归化考试，同时对申请F-5永久居留权也十分有利。

## 6. 所需材料 {#section-6}

| 材料 | 备注 |
|---|---|
| 归化许可申请书 | 出入境外国人厅提供的表格 |
| 护照复印件 | 全页复印 |
| 外国人登记证复印件 | |
| 基本证明书（适用于已在韩登记居住者） | |
| 本国出生证明 + 公证·认证/附加证书 | 附韩语翻译 |
| 本国家庭关系证明 + 公证·认证/附加证书 | 附韩语翻译 |
| 无犯罪记录证明（本国出具） | 6个月内签发 |
| 生计能力证明材料 | 在职证明、所得税纳税证明、银行存款余额证明等 |
| 归化适应性考试合格证明或免考资格证明 | |
| 证件照2张（3.5×4.5cm） | |

> 申请简易归化或特别归化时，还需提交额外材料（如婚姻关系证明书等）。

---

## 7. 申请流程 {#section-7}

| 步骤 | 内容 | 所需时间 |
|---|---|---|
| 1. 准备并通过归化考试 | KINAT考试或完成KIIP 5阶段 | 3—12个月 |
| 2. 准备材料 | 包括本国文件公证及认证/附加证书 | 1—3个月 |
| 3. 提交申请 | 前往户籍所在地出入境外国人厅窗口提交 | 当日 |
| 4. 面试审查 | 出入境外国人厅深度面试 | 提交后数月内 |
| 5. 国籍审查 | 法务部审查 | 12—24个月 |
| 6. 归化许可通知 | 收到法务部许可通知书 | — |
| 7. 宣誓 | 法务部或出入境外国人厅 | 收到通知后在指定期限内 |
| 8. 居民登记 | 住所地所在洞住民中心 | 宣誓后立即办理 |

> 全程审查时间因申请类型及材料完整程度而异，通常需要**1—2年**。

---

## 8. 归化后的手续 {#section-8}

取得归化许可后，依次完成以下手续：

1. **归化宣誓**：前往法务部或出入境外国人厅参加宣誓仪式
2. **居民登记**：前往住所地住民中心办理初次居民登记
3. **发放居民登记证**：申请居民登记证
4. **申请护照**：向外交部申请大韩民国护照
5. **放弃外国国籍**：大多数情况下须办理放弃外国国籍手续（持有双重国籍资格者除外）

---

## 9. 双重国籍规定 {#section-9}

韩国原则上不允许双重国籍，但以下情况可作例外：

| 适用对象 | 条件 |
|---|---|
| 65岁以上海外韩裔 | 恢复韩国国籍后可保留外国国籍 |
| 优秀外国人才 | 由法务部长官指定 |
| 外国母亲所生子女 | 须在年满22周岁前自行选择国籍 |
| 婚姻归化者 | 不允许双重国籍，须放弃外国国籍 |

> 如归化后不愿放弃外国国籍，请在申请前务必确认是否符合双重国籍资格。

## 10. 常见问题解答 {#section-10}

**Q. 归化申请受理期间外国人登记证到期怎么办？**
A. 提交申请后，审查期间体留资格保持有效。但仍需单独办理外国人登记证更新，以保持有效状态。

**Q. 持有TOPIK 4级可以免除归化考试吗？**
A. 是的，持有TOPIK 4级以上者可免除归化适应性考试的韩国语科目，但仍须单独参加韩国社会理解科目考试。KIIP 5阶段修了者可免除全部科目。

**Q. 归化申请期间可以出境吗？**
A. 可以，但长期出境可能影响居留年限的计算。建议在归化面试前尽量留在国内。

**Q. 归化后多久能办好韩国护照？**
A. 宣誓后，依次办理居民登记（约1个月）→ 居民登记证领取 → 护照申请（约1—2周），合计约宣誓后1—2个月即可拿到韩国护照。

**Q. 申请归化前必须先取得F-5永久居留权吗？**
A. 不必要。可以不持有F-5签证直接申请归化。但实务中许多人选择先取得F-5再申请归化，可能在居留年限方面更占优势。

## 11. 咨询指南 {#section-11}

归化申请的条件和材料因类型而异，审查周期也较长，专业人士的协助至关重要。尤其是本国文件公证与认证/附加证书办理、归化面试准备等环节，聘请专业行政士可大幅降低被拒风险。
