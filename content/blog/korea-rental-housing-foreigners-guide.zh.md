# 韩国外国人租房完整指南（2026年）：全租·月租·法律保障

韩国独特的房屋租赁制度——尤其是"全租（전세）"这种一次性交纳大额保证金、到期全额退还的方式——对许多外国人来说颇为陌生。在签署租房合同之前，充分了解租赁结构、保证金保护方式及相关法律权利至关重要。

## 1. 了解韩国租房类型 {#section-1}

韩国的住宅租赁方式主要分为三种。

| 租赁类型 | 概述 |
|---|---|
| 全租（전세） | 租期内向房东一次性支付大额保证金，合同结束后全额退还，无需缴纳月租 |
| 月租（월세） | 小额保证金＋每月固定租金 |
| 保证金月租（보증부월세） | 中等保证金＋减少的月租，全租与月租的中间形式 |

---

## 2. 全租与月租对比 {#section-2}

| 项目 | 全租 | 月租 |
|---|---|---|
| 保证金规模 | 非常大（数千万至数亿韩元） | 较小或中等 |
| 月付租金 | 无 | 需要 |
| 初期负担 | 高 | 相对较低 |
| 保证金风险 | 存在（需防范全租诈骗） | 相对较低 |
| 适合对象 | 有储蓄的长期居住者 | 初期资金不足或短期居住者 |

> 大多数初来韩国的外国人通常选择月租或保证金月租方式。

## 3. 租房合同流程 {#section-3}

| 步骤 | 内容 |
|---|---|
| 1 | 通过持牌中介查找房源（直接交易也可，但建议通过中介） |
| 2 | 查阅建筑登记簿（등기부등본），确认是否有抵押、查封情况 |
| 3 | 签署租赁合同（임대차계약서）并盖章 |
| 4 | 支付定金（通常为保证金的10%） |
| 5 | 支付余款并入住 |
| 6 | 办理搬入登记（전입신고）＋取得确定日期（확정일자） |

---

## 4. 搬入登记与确定日期（保证金保障） {#section-4}

这两项手续是保护保证金的法律依据，务必完成。

| 手续 | 内容 |
|---|---|
| 搬入登记（전입신고） | 入住后14天内在住民中心（或政府24在线）办理地址变更登记 |
| 确定日期（확정일자） | 在住民中心或法院对租赁合同进行日期认证盖章 |

> 完成以上两项手续后，即可获得**对抗力（대항력）**和**优先受偿权（우선변제권）**——即使房东更换或房产被拍卖，您的保证金也可优先退还。

**持有外国人登记证的外国人可与韩国居民同样办理上述手续。**

---

## 5. 住宅租赁保护法主要内容 {#section-5}

**住宅租赁保护法（주택임대차보호법）**对租户权益提供了有力保障。

| 条款 | 内容 |
|---|---|
| 最短租期 | 2年——即使房东坚持较短期限，租户也有权要求2年 |
| 合同续签请求权 | 可要求续签一次2年合同（共保障4年居住权） |
| 租金涨幅限制 | 续签时租金涨幅不得超过5%（适用于调整对象地区） |
| 默示续签（묵시적 갱신） | 合同到期前双方未发出通知，自动按原条件续签 |
| 保证金退还 | 合同结束后，房东须立即退还保证金 |

---

## 6. 外国人租房注意事项 {#section-6}

| 注意事项 | 内容 |
|---|---|
| 须持外国人登记证 | 无有效外国人登记证（ARC）通常难以签署租房合同 |
| 公司名义签约 | 公司驻华员工可以公司名义签约 |
| 短期签证持有者 | 持B-2、C-3等短期签证者无法办理搬入登记→保证金保障受限 |
| 语言障碍 | 合同以韩语书写→务必翻译后确认或请专业人士陪同 |
| 核查登记簿 | 务必在登记簿（등기부등본）中确认是否有抵押、假扣押、假处分 |

## 7. 全租诈骗预防 {#section-7}

近年来全租诈骗案件激增，务必核查以下事项。

| 预防项目 | 核查方式 |
|---|---|
| 全租率确认 | 保证金超过房产市值80%则存在风险（全租诈骗风险） |
| 查阅登记簿 | 签约前及支付余款前务必再次核查 |
| 核实房东身份 | 核查身份证及印章，代理人签约须提供授权委托书 |
| 加入全租保证保险 | 建议申请HUG（住宅城市保证公社）或SGI首尔保证保险 |
| 确认优先债权 | 抵押贷款＋优先租赁保证金总额不应超过房产价值的70% |

## 8. 房产APP与中介的使用 {#section-8}

| 方式 | 特点 |
|---|---|
| Naver房产（네이버 부동산） | 韩国最大房源数据库，主要为韩语界面 |
| Zigbang（직방）/ Dabang（다방） | 专注单间/准住宅型办公室，提供详细图片和视频 |
| 持牌房产中介（공인중개사） | 可协助起草合同、核查登记簿、办理确定日期；收取中介费 |
| 外国人专属中介 | 部分中介提供英语、中文、日语服务 |

> 中介费依租金金额而定，通常为（保证金＋月租×100）的0.3—0.4%。

## 9. 搬出与保证金退还 {#section-9}

| 项目 | 内容 |
|---|---|
| 搬出通知 | 合同到期前1—6个月通知房东不续租 |
| 保证金退还时间 | 合同到期腾空房屋后，原则上房东须立即退还 |
| 房东拒不退还时 | 发送内容证明（내용증명）→申请租赁权登记命令（임차권등기명령）→支付命令·少额案件审判 |
| 搬出地址变更登记 | 迁入新住所后办理搬出登记（전출신고，住民中心或在线） |

## 10. 常见问题解答 {#section-10}

**Q. 外国人可以在韩国签署全租合同吗？**
A. 可以。只要持有有效外国人登记证（ARC），外国人即可与韩国居民同等签署全租合同、办理搬入登记并取得确定日期。

**Q. 持旅游签证或短期签证可以办理搬入登记吗？**
A. 不可以。持短期居留签证（B-2、C-3等）的外国人无法办理搬入登记，因此难以享受住宅租赁保护法的保障。需要长期居留签证及外国人登记证才能获得全面保障。

**Q. 房东不退还保证金怎么办？**
A. 首先发送内容证明要求退还，如无效可申请租赁权登记命令、支付命令或提起少额诉讼。情况复杂时建议咨询专业人士。

**Q. 外国人可以申请全租保证保险吗？**
A. 可以。持有效外国人登记证的外国人可申请HUG全租保证保险，要求保证金在保险限额以内，且须完成搬入登记和取得确定日期。

**Q. 看不懂韩语合同怎么办？**
A. 务必在签约前充分了解合同内容——可通过双语中介或专业翻译协助。切勿签署无法理解的合同。
