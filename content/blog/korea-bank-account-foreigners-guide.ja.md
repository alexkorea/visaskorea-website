# 韓国外国人銀行口座開設完全ガイド（2026年版）：必要書類・銀行比較

韓国に住む外国人にとって、給与受取・公共料金支払い・ショッピングなどに韓国の銀行口座は必需品です。適切な書類を準備すれば外国人でも口座開設ができ、外国人登録証（ARC）発行前でも一部の銀行ではパスポートのみで開設できます。

## 1. 外国人は銀行口座を開設できる？ {#section-1}

合法的な在留資格を持つ外国人は、ほとんどの場合、韓国の銀行口座を開設できます。

| 状況 | 口座開設の可否 |
|---|---|
| ARC（外国人登録証）保有者 | ✅ ほぼ全ての銀行で可能 |
| ARCなし・パスポートのみ | ✅ 一部の銀行で可能（制限あり） |
| 観光ビザ（C-3）等の短期滞在者 | ✅ 一部の銀行で可能（制限多い） |
| 不法滞在者 | ❌ 不可 |

---

## 2. 主な銀行の紹介 {#section-2}

韓国の主要な市中銀行で外国人の口座開設が可能です。

| 銀行 | 外国人への対応 | 特徴 |
|---|---|---|
| KB国民銀行 | ★★★★☆ | 英語サービスあり、一部支店に外国人専用窓口 |
| 新韓銀行 | ★★★★☆ | 多言語アプリ対応、英語・中国語・日本語サービス |
| ハナ銀行 | ★★★★★ | 外国人特化サービス、多言語窓口あり |
| ウリ銀行 | ★★★☆☆ | 英語サービスあり |
| NH農協銀行 | ★★★☆☆ | 地方支店が多い |
| KEBハナ銀行 | ★★★★★ | 外国人専用窓口が多数 |
| カカオバンク | ★★★☆☆ | スマートフォン専用、ARC必須 |
| トスバンク | ★★★☆☆ | スマートフォン専用、ARC・外国人登録番号必須 |

---

## 3. ARCなしでの口座開設 {#section-3}

ARCなしでも一部の銀行では制限付きで口座開設が可能です。

| 銀行 | 条件 |
|---|---|
| ハナ銀行 | パスポート＋ビザ＋国内の連絡先 |
| 新韓銀行 | パスポート＋ビザ＋在職証明書または在学証明書 |
| KB国民銀行 | 支店によって異なる。事前に問い合わせを推奨 |

> ARCなしで開設した口座は、振込限度額などに制限が設けられることが多いです。ARC発行後に口座情報を更新することをお勧めします。

---

## 4. ARC保有者の口座開設 {#section-4}

ARC保有者はほぼ全ての主要銀行で、韓国国内の方と同等の口座を開設できます。

| 項目 | 内容 |
|---|---|
| 利用可能な銀行 | ほぼ全ての主要銀行 |
| 口座の種類 | 普通預金・貯蓄預金・定期預金など |
| 外国人向け特別商品 | 一部の銀行で外貨両替・海外送金優遇商品あり |

---

## 5. 必要書類（共通） {#section-5}

| 書類 | 備考 |
|---|---|
| パスポート原本 | 有効なもの |
| 外国人登録証（ARC） | 登録済みの場合は必須 |
| 国内住所 | 公共料金の領収書や賃貸契約書等で証明 |
| 連絡先 | 韓国の携帯電話番号を推奨 |
| 在職証明書または在学証明書 | 一部の銀行が要求 |

## 7. インターネット/モバイルバンキングの設定 {#section-7}

外国人もオンライン・モバイルバンキングを利用できますが、金融証明書の発行が必要な場合があります。

| 項目 | 内容 |
|---|---|
| 金融証明書の発行 | 銀行の窓口で発行可能 |
| モバイルアプリ | 各銀行専用のアプリあり |
| 英語氏名入力 | パスポートの氏名と一致させる必要あり |
| OTPカード | 振込限度額を増額する場合に必要 |

## 8. デビットカード・クレジットカードの発行 {#section-8}

| カードの種類 | 条件 | 備考 |
|---|---|---|
| デビットカード | ARC＋普通預金口座 | 口座開設と同時に申請可能 |
| クレジットカード | ARC＋収入証明＋信用履歴 | 韓国滞在期間が短いと発行が難しい場合あり |
| プリペイドカード | 特別な条件なし | チャージ式で限度額あり |

## 9. 海外送金の方法 {#section-9}

韓国から海外に送金する方法はいくつかあります。

| 方法 | 特徴 |
|---|---|
| 銀行窓口での海外送金 | 最も一般的、手数料は比較的高め |
| インターネットバンキング海外送金 | 窓口より迅速で便利 |
| KEBハナ銀行の外為サービス | 外貨・海外送金に特化したサービス |
| フィンテックサービス（Wiseなど） | 手数料が安く、為替レートが有利 |

## 10. よくある質問（FAQ） {#section-10}

**Q. 来韓してすぐ、ARCなしで口座開設できますか？**
A. はい。ハナ銀行・新韓銀行などの一部の銀行では、パスポートとビザだけで口座開設できます。ただし振込限度額などに制限がある場合があります。ARC発行後は口座情報の更新をお勧めします。

**Q. 日本語で相談できる銀行はありますか？**
A. ハナ銀行・新韓銀行は一部の支店（外国人が多いエリア）で日本語対応が可能です。訪問前に支店に確認してください。

**Q. 学生ビザ（D-2）でも口座開設できますか？**
A. はい。ARC、パスポート、在学証明書を提出することで口座開設が可能です。

**Q. 外国人もカカオバンクやトスバンクを使えますか？**
A. ARC（外国人登録証）と外国人登録番号があれば利用できます。ただし、アプリのインターフェースは韓国語のみです。

**Q. クレジットカードが発行されにくい場合はどうすればよいですか？**
A. まずデビットカードで韓国での取引実績を積み、安定した収入が確認できるようになってから（通常6〜12ヶ月程度）クレジットカードの申請に挑戦すると承認率が上がります。
