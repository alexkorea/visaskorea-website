# F2-7 점수 올리는 현실적인 방법 2026

F2-7(점수제 거주비자)는 120점 만점에 기준 점수(보통 80점 이상)를 충족해야 신청 가능합니다. 핵심은 내가 어느 항목에서 점수를 얻을 수 있고, 어느 항목을 보완할 수 있는지 파악하는 것입니다.

---

## 목차
1. 배점표 구조 요약
2. 나이 항목 — 고정 점수
3. 소득 항목 — 가장 빠르게 올릴 수 있는 영역
4. 한국어능력 항목 — TOPIK·사회통합프로그램
5. 학력 항목 — 이공계 우대
6. 자격증 항목
7. 봉사활동·납세 가점
8. 감점 항목 주의
9. 실전 조합 사례
10. 자주 묻는 질문

---

## 1. 배점표 구조 요약

F2-7 배점표는 크게 기본 항목과 가점 항목으로 구성됩니다.

| 항목 | 최대 점수 |
|------|---------|
| 나이 | 20점 |
| 학력 | 30점 |
| 소득 | 20점 |
| 한국어 | 20점 |
| 자격증 | 10점 |
| 봉사·납세 가점 | 최대 10점 |
| **합계** | **120점 (기준 80점)** |

---

## 2. 나이 항목 — 고정 점수

나이는 바꿀 수 없는 항목입니다. 나이 점수 구조는 25~29세 구간에서 최고점이 나오고, 고령일수록 점수가 낮아집니다.

- **25~29세**: 20점
- **30~34세**: 18점
- **35~39세**: 16점
- **40~44세**: 12점
- **45~49세**: 8점
- **50세 이상**: 4점

실무에서는 나이 점수가 낮은 40대 이상 신청자는 소득·한국어·봉사 항목에서 보완이 필요합니다.

---

## 3. 소득 항목 — 가장 빠르게 올릴 수 있는 영역

소득은 전년도 소득(국세청 소득확인증명서 기준)으로 평가됩니다.

| 전년도 소득 | 점수 |
|-----------|------|
| GNI 300% 이상 | 20점 |
| GNI 200~300% | 16점 |
| GNI 150~200% | 12점 |
| GNI 100~150% | 8점 |
| GNI 80~100% | 4점 |
| GNI 80% 미만 | 0점 |

2025년 기준 1인당 GNI는 약 4,200만 원. GNI 100%(약 4,200만 원/년) 이상이면 8점, 200%(약 8,400만 원/년)이면 16점입니다.

**실무 포인트**: 사업자등록 후 종합소득세 신고를 성실히 하면 소득 증빙이 명확해집니다. 직장인은 근로소득원천징수영수증을 제출하면 됩니다.

---

## 4. 한국어능력 항목 — TOPIK과 사회통합프로그램

한국어 항목은 TOPIK(한국어능력시험) 또는 사회통합프로그램(KIIP) 이수로 점수를 얻습니다.

| 구분 | 내용 | 점수 |
|------|------|------|
| TOPIK 6급 | 최상위 | 20점 |
| TOPIK 5급 | | 16점 |
| TOPIK 4급 | | 12점 |
| TOPIK 3급 | | 8점 |
| TOPIK 2급 | | 4점 |
| 사회통합프로그램 5단계 수료 | TOPIK 5급 상당 | 16점 |
| 사회통합프로그램 4단계 수료 | TOPIK 4급 상당 | 12점 |

**실무 포인트**: TOPIK 시험은 연 3회 시행. 사회통합프로그램은 시간이 더 걸리지만 비용이 무료이고 시험 없이 단계 이수로 점수 인정.

---

## 5. 학력 항목 — 이공계 우대

| 학력 | 일반 계열 | 이공계 계열 |
|------|---------|---------|
| 박사 | 30점 | 30점 |
| 석사 | 25점 | 28점 |
| 학사 | 18점 | 22점 |
| 전문학사 | 10점 | 13점 |
| 고졸 이하 | 5점 | 5점 |

이공계 학위는 동일 학력 대비 최대 4점 추가됩니다. 한국 내 대학 졸업자는 졸업증명서, 해외 졸업자는 학력 인증이 필요합니다.

---

## 6. 자격증 항목

국가기술자격 또는 전문자격(변호사·의사·공인회계사 등)을 보유하면 최대 10점입니다.

| 자격 | 점수 |
|------|------|
| 국가자격증 기사 이상 또는 전문자격 | 10점 |
| 산업기사 | 7점 |
| 기능사 | 5점 |

한국 취업 중에 관련 국가기술자격을 취득하면 점수 확보에 유리합니다.

---

## 7. 봉사활동·납세 가점

| 항목 | 점수 |
|------|------|
| 사회봉사활동 (연간 200시간 이상) | 10점 |
| 사회봉사활동 (연간 100시간 이상) | 7점 |
| 사회봉사활동 (연간 50시간 이상) | 5점 |
| 성실 납세 (3년 이상) | 3점 |

봉사활동은 1365자원봉사포털 등에 등록된 기관에서 활동해야 인정됩니다.

---

## 8. 감점 항목 주의

- **불법체류 이력**: 과거 불법체류 1개월 이하 –5점, 1~3개월 –10점, 3개월 초과 –20점
- **범죄 전과**: 집행유예 이상 –10점 이상
- **체류자격 외 활동**: –5점

신청 전 자신의 이력을 점검해야 합니다.

---

## 9. 실전 조합 사례

**사례: 42세 남성, 소득 GNI 180%, 학사(이공계), TOPIK 4급, 봉사 60시간**

| 항목 | 점수 |
|------|------|
| 나이 (40~44세) | 12점 |
| 소득 (GNI 150~200%) | 12점 |
| 학력 (학사·이공계) | 22점 |
| 한국어 (TOPIK 4급) | 12점 |
| 봉사 (60시간) | 5점 |
| **합계** | **63점** |

63점으로 기준 미달. 대안: 소득 GNI 200% 이상으로 올리면 +4점 = 67점, 봉사를 100시간으로 늘리면 +2점 = 69점. TOPIK 5급 취득 시 +4점 = 73점. 여전히 부족하다면 소득을 GNI 300% 이상으로 올려 최대치를 확보해야 합니다.

---

## 10. 자주 묻는 질문

**Q. 점수 계산을 사전에 확인할 수 있나요?**
A. 출입국·외국인청 방문 상담 또는 하이코리아(hikorea.go.kr)에서 자가 점검이 가능합니다.

**Q. 점수 미달 시 재신청 기간 제한이 있나요?**
A. 점수 미달로 불허 처리된 경우 일정 기간 후 재신청 가능하며, 통상 점수 개선 후 재신청합니다.

**Q. TOPIK 성적 유효기간이 있나요?**
A. TOPIK 성적은 유효기간이 없습니다. 단, 최근 성적이 유리하면 최근 것을 제출하는 것이 좋습니다.

**Q. 한국에서 취득한 학위만 인정되나요?**
A. 해외 학위도 인정됩니다. 단, 해외 학위는 학력인증기관의 확인서가 필요합니다.
