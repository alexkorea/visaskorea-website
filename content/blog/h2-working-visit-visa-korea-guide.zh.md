# 韩国H-2访问就业签证完全指南（2026年版）：资格·就业范围·配额·转换永居

H-2（访问就业）签证允许在特定国家（主要为中国和独联体国家）居住的韩裔同胞（朝鲜族及高丽人）赴韩从事就业活动。

与F-4不同，H-2**就业范围限于制造业、建筑业、农业等非专业劳务岗位**，且受**年度配额**限制。但H-2的优势在于，入境前无需预先确定雇主，入境后可自行寻找工作。

## 1. H-2是什么？——访问就业资格解析

H-2是韩国《出入境管理法》中的「访问就业」资格，允许海外韩裔同胞赴韩并在指定的非专业岗位工作。

核心特征：
- 仅适用于特定国家的韩裔同胞
- 就业范围限于非专业劳务岗位（制造业、建筑业、农业、餐饮辅助等）
- 入境前无需雇主担保，入境后可自行找工作
- 受年度配额限制；配额用完后当年不再发放

---

## 2. 申请资格——国籍与血统要求

H-2并非向所有海外韩裔开放，仅适用于居住在**特定指定国家**的韩裔同胞。

### 主要适用国家

| 国家/地区 | 是否适用 |
|---|---|
| 中国（朝鲜族） | ✅（H-2最大受益群体） |
| 乌兹别克斯坦、哈萨克斯坦、俄罗斯、吉尔吉斯斯坦（高丽人） | ✅ |
| 其他法务部指定国家 | ✅ |
| 美国、加拿大、澳大利亚、英国等 | ❌——适用F-4签证 |

居住在美国、加拿大、澳大利亚等西方国家的海外韩裔适用F-4（在外同胞）签证，而非H-2。

### 血统要求

| 类型 | 条件 |
|---|---|
| 父母或祖父母曾持有韩国国籍 | 本人取得外国国籍后仍可认定同胞身份 |
| 本人曾持有韩国国籍后取得外国国籍 | 认定为同胞 |

---

## 3. 允许就业范围

H-2的就业范围**限于非专业、普通劳务岗位**。

### 主要允许行业

| 行业 | 具体内容 |
|---|---|
| 制造业 | 工厂流水线生产岗位 |
| 建筑业 | 建筑工地辅助工作（不含专业技术岗） |
| 农业·渔业 | 农场及渔业季节性劳务 |
| 餐饮辅助 | 餐厅服务员、厨房助手 |
| 住宿·清洁 | 酒店/民宿清洁及辅助服务 |
| 家政服务 | 家政助理、育儿助理（部分允许） |

### 禁止从事的岗位

- 专业职位（医疗、法律、会计、IT专业等）
- 娱乐·赌博·成人相关行业
- 白领办公室岗位（原则上不允许）

如需从事专业岗位，须申请F-4或E-7签证。

---

## 4. 年度配额制度

H-2签证受**年度配额**限制，由法务部每年公告配额数量。配额用尽后，当年不再发放H-2签证。

| 项目 | 内容 |
|---|---|
| 配额公告周期 | 每年由法务部公告 |
| 申请方式 | 配额开放后，于韩国驻外使领馆先到先得 |
| 配额用尽时 | 需等待下一年度配额开放后再申请 |

请关注所在国韩国驻外使领馆或法务部出入境管理网站，及时获取配额开放信息。

## 5. 所需材料及申请流程

### 所需材料

| 材料 | 备注 |
|---|---|
| 签证申请表 | 韩国驻外使馆格式 |
| 护照 | 有效期6个月以上 |
| 证件照 | 3.5×4.5cm |
| 同胞身份证明材料 | 户口本（中国）、家族关系证明、血统关系证明文件等 |
| 外国身份证或居住证明 | |
| 使领馆要求的附加材料 | 因国家不同而异 |

### 申请流程

1. 在居住国韩国大使馆或领事馆申请H-2签证
2. 接受同胞身份审查及配额核查
3. 签证发放后入境韩国
4. 入境后90日内完成外国人登记
5. 在允许就业范围内自行寻找雇主，受雇后加入就业保险

## 6. 社会融合项目（KIIP）——H-2特别优惠

H-2签证持有人完成韩国社会融合项目（KIIP）可享受多项优惠。

### KIIP为H-2持有人带来的优惠

| 优惠 | 内容 |
|---|---|
| F-4转换优惠 | KIIP修了有助于满足转换F-4的相关条件 |
| F-2-7加分 | KIIP完成阶段对应不同F-2-7积分加分项 |
| 归化优惠 | 申请归化时可获得部分阶段豁免及面试准备优惠 |

KIIP全国各地出入境外国人厅及指定教育机构均可免费报名参加。

---

## 7. 居留期限与续签

| 项目 | 内容 |
|---|---|
| 初始居留期限 | 通常1年（最长可达3年） |
| 出境后再入境 | 需重新确认配额是否充足 |
| 长期续签 | 在允许就业范围内持续工作可申请续签 |

长期持有H-2并完成KIIP，为转换F-4或申请F-5创造了现实条件。

---

## 8. 从H-2转换至F-4和F-5

H-2是临时性就业居留资格。希望在韩长期稳定居留者，可通过以下路径转换：

### 主要转换路径

| 目标资格 | 主要要求 |
|---|---|
| F-4在外同胞 | 确认同胞血统+无结格事由（符合F-4条件即可转换） |
| F-5-1长期居留永居 | 合法居留5年以上（含H-2期间）+收入要求+无犯罪记录 |
| F-5-7在外同胞永居 | 先转换F-4→国内实际居住满2年→申请F-5-7 |
| F-2-7积分制居留 | 利用KIIP完成加分项，达到80分以上 |

H-2居留期限计入F-5-1所需的5年合法居留时长。

F-4签证详情请参阅[F-4在外同胞签证指南](/zh/blog/f4-overseas-korean-visa-guide)，F-5永居路径请参阅[F-5永久居留权指南](/zh/blog/f5-permanent-residency-korea-guide)。

## 9. H-2与F-4的区别

| | H-2访问就业 | F-4在外同胞 |
|--|--|--|
| 适用国籍 | 仅限指定国家（中国·独联体） | 所有国家 |
| 就业自由度 | 限非专业劳务岗位 | 大多数行业均可（普通体力劳动除外） |
| 配额 | 受年度配额限制 | 无配额 |
| 专业职位就业 | 不允许 | 允许 |
| 永居转换路径 | H-2→F-5-1，或经F-4→F-5-7 | F-4→F-5-7（国内居住2年） |

若具备F-4申请资格，通常比H-2更为有利：无配额限制、就业范围更广、转永居路径更直接。

## 10. 常见问题解答

**Q. 我是中国朝鲜族，不会韩语也能申请H-2吗？**
A. H-2没有韩语能力要求。但完成KIIP、提升韩语水平，对转换F-4和长期居留都大有帮助。

**Q. 持H-2入境后可以随意找工作吗？**
A. 在允许就业范围内可自由找工作，无需预先确定雇主。但须遵守允许行业范围，在禁止行业就业属违规行为。

**Q. 配额已用完，我该怎么办？**
A. 须等待下一年度配额开放。如符合F-4申请条件（无配额限制），申请F-4可能是更稳妥的选择，建议咨询专业人士。

**Q. 俄罗斯和中亚国家的高丽人也可以申请H-2吗？**
A. 可以。居住在俄罗斯、哈萨克斯坦、乌兹别克斯坦等独联体国家的韩裔同胞（高丽人）符合H-2申请条件，但需提供韩国血统证明文件。

**Q. 持H-2期间可以携带家属来韩国吗？**
A. H-2主要是个人就业许可。配偶和未成年子女可申请F-3随行签证，但具体条件与一般长期居留签证的家属随行有所不同，建议咨询移民专业人士了解最新规定。

## 11. 咨询服务

H-2申请涉及同胞血统证明、配额确认和允许就业范围判断等多个复杂环节。F-4转换策略及长期居留规划也需根据个人情况具体分析。

飞展行政士事务所提供H-2签证申请、F-4转换评估及F-5永久居留权规划全程服务。
