# 韩国国籍取得（归化）完整指南（2026年）：种类、条件及申请方法

在韩国长期生活的外国人可以考虑申请大韩民国国籍（归化）。归化不仅仅是延长居留，而是成为大韩民国国民、享有全部法律权利的重要决定。本指南详细介绍归化种类、申请条件、所需材料及审查流程。

## 1. 什么是归化？

归化是外国人取得大韩民国国籍的程序。归化完成后，将成为大韩民国国民，享有选举权、担任公职等全部法律权利。

根据韩国国籍法，归化分为三种类型：
- **一般归化**：已在韩国合法居留一定期间的外国人
- **简易归化**：与韩国国民结婚或为韩国国民子女等具有特殊关系的外国人
- **特别归化**：对国家有特殊贡献的外国人

---

## 2. 归化种类及条件

| 种类 | 主要条件 | 居留期间要求 |
|---|---|---|
| 一般归化 | 连续居留5年以上 | 5年以上 |
| 简易归化（结婚） | 与韩国国民婚姻维持2年以上+在韩居留1年以上 | 婚姻2年+居留1年 |
| 简易归化（韩国国民子女） | 韩国国民直系子女 | 1年以上 |
| 简易归化（收养） | 被韩国国民收养 | 1年以上 |
| 特别归化 | 对国家·社会有特殊贡献 | 居留要求可豁免 |

---

## 3. 一般归化要求详解

一般归化须同时满足以下全部条件：

| 要求 | 内容 |
|---|---|
| 居留期间 | 连续合法居留5年以上 |
| 年龄 | 满18周岁以上 |
| 品行 | 品行端正 |
| 生计能力 | 具备抚养本人及家属的经济能力 |
| 韩语能力 | 达到足以授予大韩民国国籍的韩语水平 |
| 国家观 | 认同大韩民国宪法体制 |

> "品行端正"条件通常意味着无犯罪记录或仅有轻微违规记录。

---

## 4. 简易归化适用对象

简易归化的居留期间要求低于一般归化。

### 婚姻归化（F-6配偶）

| 条件 | 内容 |
|---|---|
| 基本条件 | 与韩国国民婚后满2年+在韩国内居留1年以上 |
| 短期居留例外 | 婚后满3年+连续在韩居留1年以上 |
| 特殊情况 | 配偶死亡·失踪或离婚后独自抚养韩国子女者 |

### 其他简易归化

| 类型 | 条件 |
|---|---|
| 韩国国民子女 | 直系血缘，在韩居留1年以上 |
| 韩国国民孙子女 | 祖父母或父母为韩国国民 |
| 在韩出生外国人 | 父母一方持有韩国国籍 |
| 被韩国国民收养者 | 在韩居留1年以上 |

---

## 5. 特别归化适用对象

特别归化可为对国家·社会有卓越贡献的外国人豁免或减少居留期间要求。

| 对象 | 内容 |
|---|---|
| 科学·经济·文化贡献者 | 对韩国发展有显著贡献的外国人 |
| 体育贡献者 | 计划以大韩民国代表身份参加或已参加国际大赛的外国人 |
| 国家安全贡献者 | 在国防领域有特殊贡献的外国人 |

---

## 6. 归化申请流程

1. **确认资格** — 确认归化类型及居留期间、申请条件是否满足
2. **准备材料** — 准备对应归化类型的全部材料
3. **向法务部出入境·外国人政策本部申请** — 前往管辖出入境·外国人厅或在线申请
4. **基本素养考试** — 参加韩语考试（社会融合项目结业或单独考试）
5. **审查** — 品行·经济能力·韩语能力等综合审查
6. **归化面试** — 韩语能力及国家观面试审查
7. **获批归化** — 法务部批准后领取归化证书
8. **国籍选择·放弃** — 不允许双重国籍的情况下，申报放弃原有国籍

## 8. 归化审查项目

| 审查项目 | 内容 |
|---|---|
| 居留期间 | 是否满足连续合法居留期间要求 |
| 品行 | 犯罪记录、违法情况 |
| 经济能力 | 证明具备自立生活能力 |
| 韩语能力 | 韩语口语能力（面试或TOPIK成绩） |
| 国家观 | 对韩国宪法及民主主义的理解 |
| 社会融合项目 | 是否结业（结业可免除归化考试） |

---

## 9. 归化后双重国籍处理

大韩民国原则上不允许双重国籍。

| 区分 | 处理方法 |
|---|---|
| 归化后原则 | 归化后1年内放弃外国国籍 |
| 例外允许 | 部分特别归化者·婚姻归化者允许双重国籍 |
| 外国人登记注销 | 归化完成后归还外国人登记证 |
| 居民登记新注册 | 归化完成后首次办理居民登记 |

> 2011年国籍法修订后，部分外国人（婚姻归化者、特别归化者等）在不放弃外国国籍的情况下也可保留韩国国籍，即允许双重国籍。

## 10. 常见问题解答

**Q. 取得韩国国籍后必须放弃本国国籍吗？**
A. 一般归化者须在归化后1年内放弃外国国籍。但婚姻归化者及部分特别归化者允许双重国籍。国籍法修订后，在一定条件下可认定双重国籍，建议咨询专业人士。

**Q. 归化审查需要多长时间？**
A. 申请后通常需要1~2年以上。材料不足或审查排队情况可能使时间更长。

**Q. 韩语水平不高也可以申请归化吗？**
A. 归化审查包含韩语能力评估（面试或韩语考试）。完成社会融合项目（KIIP）5级可免除归化考试，提前参加KIIP更为有利。

**Q. 申请归化前改变居住地会影响审查吗？**
A. 合法居留期间通过出入境记录确认，地址变更影响不大，但频繁出境导致连续居留中断可能对审查产生不利影响。

**Q. 归化申请被拒后可以重新申请吗？**
A. 可以。了解被拒原因并补足相关条件后可重新申请，也可对不许可决定提出异议申请。
