## 1. 外国人开通条件 {#section-1}

外国人在韩国办理手机开通通常需要以下条件：

| 条件 | 内容 |
|---|---|
| 身份证明 | 护照或外国人登记证（ARC） |
| 居留资格 | 持有效韩国签证 |
| 后付费开通 | 原则上须持有外国人登记证 |
| 预付费开通 | 部分运营商仅凭护照即可办理 |
| 信用审核 | 无须或手续简化 |

> 无外国人登记证的短期访客可凭护照在机场、便利店或部分运营商门店购买预付费SIM卡。

---

## 2. 预付费与后付费对比 {#section-2}

| 项目 | 预付费 | 后付费 |
|---|---|---|
| 所需证件 | 护照（部分须ARC） | 外国人登记证＋护照 |
| 合同期限 | 无（充值制） | 12—24个月 |
| 计费方式 | 余额用完自动停止 | 每月扣费 |
| 网速 | 部分套餐可能受限 | 全速LTE/5G |
| 购机 | 需自备解锁手机 | 可合约购机 |
| 适合对象 | 短期居留者、游客 | 长期居留者（6个月以上） |

## 3. 三大运营商比较 {#section-3}

| 运营商 | 特点 |
|---|---|
| SKT（SK电信） | 韩国最大运营商，全国5G覆盖最优 |
| KT（韩国电信） | 第二大运营商，数据质量稳定，外国人服务不断强化 |
| LGU+（LG U+） | 第三大运营商，外国人专属套餐多，国际漫游服务有优势 |

> 三家运营商质量差距不大，建议对比价格和优惠后再做选择。

---

## 4. 虚拟运营商（MVNO）使用指南 {#section-4}

虚拟运营商是租用三大运营商网络资源、以更低价格提供服务的运营商。

| 特点 | 内容 |
|---|---|
| 价格 | 同等流量比三大运营商便宜30—50% |
| 网络质量 | 使用SKT、KT或LGU+网络（质量相同） |
| 外国人注册 | 可在线或便利店购买 |
| 主要品牌 | 알뜰모바일、헬로모바일、U+알뜰、세종텔레콤等 |
| 缺点 | 门店较少，售后服务有限 |

> 对于长期居住的外国人而言，虚拟运营商是节省通信费用的绝佳选择。

## 5. 机场SIM卡购买 {#section-5}

在仁川国际机场和金浦机场，可在入境后立即购买SIM卡。

| 购买地点 | 位置 |
|---|---|
| KT漫游中心 | 仁川机场1号、2号航站楼到达大厅 |
| SKT T-漫游 | 仁川机场到达大厅 |
| LGU+漫游中心 | 仁川机场到达大厅 |
| 便利店 | 机场内GS25、CU等便利店 |
| 在线预订 | 各运营商官方网站（入境前下单，到港取卡） |

> 机场SIM卡主要为短期数据SIM，通常提供7天、30天、90天等套餐。

## 6. 开通流程（到店办理） {#section-6}

| 步骤 | 内容 |
|---|---|
| 1 | 前往运营商直营店或授权代理店 |
| 2 | 出示护照＋外国人登记证 |
| 3 | 选择套餐（预付费/后付费） |
| 4 | 填写申请材料并签名 |
| 5 | 领取SIM卡或完成手机开通 |
| 6 | 确认收到验证短信后开通完成 |

> 建议提前确认提供英语或中文服务的门店。外国人客服热线：SKT 080-011-6000 / KT 100 / LGU+ 101

## 7. 外国人身份认证方法 {#section-7}

在韩国使用各类服务时通常需要进行身份认证。

| 认证方式 | 外国人是否可用 |
|---|---|
| 手机短信验证（OTP） | 可以（开通后） |
| 外国人登记号码认证 | 可以（ARC持有者） |
| 公同认证书（原公认证书） | ARC持有者可申请 |
| PASS APP认证 | 可以（须ARC＋韩国号码） |
| 카카오페이认证 | 须ARC＋韩国银行账户 |

> 持有外国人登记证和韩国本地手机号码后，可使用大多数韩国在线服务的身份认证功能。

| 项目 | 内容 |
|---|---|
| 支持eSIM的运营商 | SKT、KT、LGU+均支持 |

## 10. 常见问题解答 {#section-10}

**Q. 没有外国人登记证也能在韩国买SIM卡吗？**
A. 可以。凭护照即可在便利店、机场和部分运营商门店购买预付费SIM卡。后付费合约套餐原则上需要外国人登记证。

**Q. 没有韩国号码也能使用KakaoTalk吗？**
A. 可以用外国号码注册KakaoTalk，但拥有韩国号码后使用该应用（及许多韩国服务）会更加流畅。

**Q. 能用我从海外带来的解锁手机配韩国SIM吗？**
A. 一般可以，前提是手机已解锁。建议提前确认频段兼容性（LTE频段1、3、5、7、8、28）。

**Q. 外国人可以申请虚拟运营商套餐吗？**
A. 可以，持有外国人登记证的人员可以申请大多数虚拟运营商服务。部分运营商支持在线外语注册。

**Q. 韩国手机号码可以用于银行验证和境外汇款吗？**
A. 可以。与韩国银行账户绑定后，可通过短信验证使用网银等服务。但不同银行对外国人客户的服务范围可能有所不同。
