# 韩国E-7特定活动签证完全指南（2026年版）

E-7（特定活动）签证是韩国企业及机构聘用外籍专业人员时最常用的就业签证类别，涵盖IT、金融、设计、教育、医疗及特殊技能等广泛职种。

核心限制：**申请职位必须在法务部公告的允许职种目录内**。不在目录中的岗位，E-7签证无从申请。了解哪些职种符合资格，以及各职种对应的学历、经历和薪资要求，是决定申请成败的关键。

## 1. E-7签证是什么？——"特定活动"的含义

E-7是韩国《出入境管理法》规定的"特定活动"签证类别。"特定活动"是指法务部长官以公告形式认定的**允许职种目录（职业编码）**中所列的工作。

E-7的核心原则：
- **职种限定**：只能从事申请时指定的职种
- **雇主指定**：签证绑定特定雇主，换工作须重新申请
- **资格审查**：各职种设有学历、经历及/或薪资门槛

E-7涵盖专业技术人才（IT、金融、工程、设计、教育、医疗、法律等）及E-7-4（熟练技能人员）子类别下的特殊技能职种。

---

## 2. 允许职种——主要类别

法务部负责维护并定期更新E-7允许职种目录，主要类别如下：

### 专业技术类

| 类别 | 代表职种 |
|------|---------|
| 科研与工程 | 自然科学研究员、工程师 |
| IT技术 | 软件开发工程师、数据分析师、网络安全专家 |
| 金融 | 投资分析师、财务管理师、会计师 |
| 设计 | 工业设计、UX/UI设计、时装设计 |
| 市场营销 | 全球营销专家 |
| 翻译口译 | 指定语言专业翻译/口译 |
| 医疗 | 执业医师、护士（需满足单独执照要求） |
| 教育 | 大学教授、研究教授、特定专业讲师 |
| 管理咨询 | 企业战略与管理顾问 |
| 法律 | 外国法律顾问（以本国律师执照为准） |

### E-7-4 熟练技能人员

2019年起，E-7-4子类别允许具备一定工作经历的非专业外籍劳工（E-9或H-2持有者），在满足特定条件后转换为E-7身份。

---

## 3. 学历与工作经历要求

各职种要求有所不同，一般原则如下：

### 普通专业职种

| 要求 | 最低标准 |
|------|---------|
| 学历 | 相关领域本科以上（硕士/博士优先） |
| 工作经历 | 相关领域1年以上（可依学历高低调整） |
| 经历代替学历 | 部分职种可以5年以上相关工作经历替代本科学历 |

### IT职种特殊规定

IT岗位更注重**实际技能的证明**，而非单纯学历。提交作品集、开源项目贡献记录及专业证书（如AWS认证、CISA等）可有效弥补学历不足。

### 薪资与学历的关联

以工作经历代替本科学历申请时，可能适用比持有学历者更高的薪资标准。建议提前向负责的出入境管理人员进行咨询。

---

## 4. 薪资要求

E-7签证设有**法定最低薪资**标准。

### 基本标准

| 标准 | 内容 |
|------|------|
| 法定最低薪资 | 不得低于韩国雇用劳动部公告的全国平均工资的80% |
| 2026年参考值 | 约2,700万韩元以上（每年调整） |
| 首都圈标准 | 实务中3,000万韩元以上通过率更高 |

### 各职种特殊说明

- **高级专业人才（硕士/博士以上）**：薪资要求在实务中执行相对灵活
- **熟练技能职（E-7-4）**：各职种有单独公告的最低薪资标准
- **初创企业/中小企业**：薪资低于标准时，若能提供企业发展潜力及招聘必要性的充分证明，仍有可能获批

---

## 5. 雇主（企业）资格要求

申办E-7签证的雇主也须满足相应条件：

| 要求 | 内容 |
|------|------|
| 营业执照 | 已在韩国正式登记的法人或个体工商户 |
| 经营持续性 | 至少有1年以上的经营记录 |
| 依法纳税 | 无国税欠缴记录 |
| 四大保险 | 员工已正常参加四大保险并缴纳保费 |
| 外籍员工比例 | 符合所在行业及企业规模的外籍员工雇用比例限制 |

成立不足1年的初创企业须额外提供企业运营实力及外籍员工招聘必要性的证明材料。

## 7. 申请流程

### 境外申请（签证办理）

1. 向所在国韩国大使馆/领事馆提交材料
2. 审核（通常需5至15个工作日）
3. 签证签发后入境韩国
4. 入境后90日内办理外国人登记

### 在韩境内变更居留资格

1. 通过Hi Korea（www.hikorea.go.kr）在线申请或前往所在地出入境外国人厅
2. 审核（通常需2至4周）
3. 变更获批后换发新外国人登记证

---

## 8. 有效期与续签

| 项目 | 内容 |
|------|------|
| 初始有效期 | 通常为1年（大型知名企业及高薪岗位可达2至3年） |
| 续签申请 | 到期前至少30天，通过Hi Korea或出入境外国人厅申请 |
| 续签审核项目 | 持续在职证明、工资转账记录、四大保险缴纳证明、纳税证明 |
| 续签次数限制 | 无限制（持续就业期间可无限续签） |

## 9. 从E-7转换至F-2·F-5的路径

在韩长期工作的E-7持有者可逐步转换为更稳定的居留资格：

| 转换路径 | 主要条件 |
|---------|---------|
| F-2-7积分制长期居留 | 持E-7身份积分达80分以上 |
| F-5-1长期居民永住 | 合法在韩居留满5年以上 + 经济自立 + 无犯罪记录 |
| F-5-16积分制永住 | F-2-7居留满3年后申请F-5-16 |

**E-7持有者在F-2-7积分制中的优势**：收入项目（最高60分）对高薪者更为有利。薪资具竞争力且在韩居留数年的E-7专业人士，通常可高效积累足够分数。

## 10. 常见问题解答

**Q. 持E-7签证可以在其他公司做兼职吗？**
A. 不可以。E-7签证绑定单一雇主和职种，在其他公司从事任何工作（包括无偿咨询）均违反签证条件，存在被注销的风险。

**Q. 换工作后需要重新申请E-7吗？**
A. 是的。须申请变更指定雇主，可作为资格变更或续签时同步办理雇主变更。工作变动后须及时向出入境外国人厅申报。

**Q. 没有本科学历，能申请E-7吗？**
A. 部分职种可以。对于特定职种，5年以上相关工作经历可以替代本科学历。但具体情况因职种编码而异，建议申请前进行专业咨询。

**Q. 可以带家属（配偶、子女）一同来韩吗？**
A. 可以，配偶和未成年子女可以F-3随行签证入境。需注意，F-3持有者原则上不得在韩工作，如需就业须另行申请工作许可。

**Q. E-7申请被拒，不知道原因怎么办？**
A. 韩国出入境管理法对拒绝理由的告知无明确规定，实务中难以直接获取。可通过与管理官员面谈、提起行政审判，或委托行政士/律师进行审查，以了解可能的拒绝原因。

## 11. 咨询服务

E-7签证能否成功，很大程度上取决于职种编码是否匹配、薪资是否达标、雇主材料是否完整。任何一环出现问题都可能导致申请被拒。
