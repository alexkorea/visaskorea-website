## 1. 海外汇款基本条件

| 项目 | 内容 |
|---|---|
| 必要材料 | 外国人登记证（ARC）或护照 + 韩国银行账户 |
| 收款人信息 | 姓名、地址、开户行名称、账号、SWIFT/BIC代码 |
| 汇款币种 | 韩元（KRW）→ 换汇后汇出目标外币 |
| ARC优势 | 持有ARC者汇款限额更高，手续更简便 |
| 税务申报 | 个人生活费年额5万美元以下无需申报 |

> 以工资或生活费名义向国内汇款，在韩国无需单独进行税务申报。但大额资产转移请事先咨询专业税务或行政士人员。

## 2. 银行汇款

| 银行 | 服务名称 | 特点 |
|---|---|---|
| 韩亚银行 | 全球韩元/韩亚ONE | 中国·东南亚特化，支持APP汇款 |
| 新韩银行 | SOL海外汇款 | APP 24小时汇款，提供汇率优惠活动 |
| 国民银行 | KB海外汇款 | 通过KB星级银行APP操作，覆盖135个国家 |
| 友利银行 | WiBee海外汇款 | APP及ATM均可办理 |
| 企业银行 | IBK海外汇款 | 设有外籍员工专属服务 |

| 项目 | 内容 |
|---|---|
| 手续费 | 每笔3,000—20,000韩元 + 中间行手续费 |
| 汇率 | 基准汇率1—2%点差 |
| 处理时间 | 1—3个工作日 |
| 汇款限额 | 持ARC者：年5万美元以下无需特别申报 |
| 最低金额 | 视各银行规定（通常无最低限制） |

> 在韩外籍员工多使用企业银行（IBK）或韩亚银行全球韩元服务。通过手机APP汇款通常可享受手续费折扣。

## 3. 金融科技汇款服务（Wise等）

| 服务 | 特点 | 手续费 |
|---|---|---|
| Wise（原TransferWise） | 使用中间汇率，费用透明 | 约0.4—1%金额 + 少量固定费用 |
| 西联汇款 | 全球200+国家现金取款，处理快速 | 约5—15美元 + 汇率差价 |
| MoneyGram | 可现金取款，韩国有代理点 | 约5—10美元 |
| SentBe（센트비） | 韩国金融科技，东南亚特化 | 每笔1,000—3,000韩元 |
| Payoneer | 仅限自由职业者及网络业务 | 视服务而定 |

> Wise因汇率透明、手续费低，是在韩外国人使用最广泛的金融科技汇款服务。可直接从韩国银行账户以韩元汇出。

## 5. 主要汇款服务手续费对比

*示例：100万韩元（约700美元）汇至美国*

| 服务 | 汇款手续费 | 汇率差价 | 预计总成本 |
|---|---|---|---|
| Wise | 约3,000—5,000韩元 | 无（中间汇率） | 低 |
| 韩亚银行APP | 约3,000—5,000韩元 | 约1% | 中 |
| 国民银行柜台 | 约10,000—15,000韩元 | 约1.5% | 高 |
| 西联汇款 | 约5,000—15,000韩元 | 约2—3% | 高 |
| GS25 MoneyGram | 约7,000—20,000韩元 | 约2—3% | 高 |

> 小额汇款时，每笔固定手续费影响较大；大额汇款时，汇率差价才是主要成本。

## 6. 汇款限额及申报义务

| 类别 | 内容 |
|---|---|
| 年5万美元以下 | 个人生活费/工资汇款无需特别申报 |
| 年5万美元以上 | 须向韩国银行或持牌外汇金融机构申报 |
| 非居民（短期居留） | 证明资金来源后可汇款 |
| 房产·股票收益 | 须提交资本利得税缴纳证明 |
| 单笔超1万美元 | 金融机构自动向金融情报机构（FIU）报告 |

> 大多数在韩外籍员工个人汇款年额在5万美元以内，无需特别申报。涉及资产转移或投资收益汇款，请事先咨询税务或行政士专业人员。

## 7. 汇率节省技巧

| 技巧 | 内容 |
|---|---|
| 设置汇率提醒 | 通过银行APP或Wise设置目标汇率提醒，在有利时机汇款 |
| 使用手机APP | 比柜台手续费节省50—70% |
| 关注汇率优惠活动 | 韩亚、新韩、国民银行APP定期举办汇率优惠活动 |
| 合并汇款 | 多次小额汇款不如一次大额，节省固定手续费 |
| 对比Wise与银行 | 中小额汇款Wise通常更优；大额汇款可对比银行优惠活动 |

## 9. 常见问题解答

**Q. 没有韩国银行账户可以汇款吗？**
A. 可以。西联汇款和便利店MoneyGram允许以现金方式汇款，无需银行账户。但手续费较高，且汇款限额可能更低。

**Q. 汇款到海外需要缴税吗？**
A. 个人生活费或工资性质的汇款在韩国不需要缴纳税款。但收款国可能有相关规定，请确认对方国家的税务政策。

**Q. 汇款需要多长时间到账？**
A. Wise和西联汇款通常数小时内完成，银行SWIFT汇款一般需1—3个工作日。收款银行处理可能再需1—2天。

**Q. 哪种方式手续费最低？**
A. Wise通常以中间汇率和透明收费，在中小额汇款方面最具性价比。大额汇款时，银行汇率优惠活动也值得关注。

**Q. 向中国汇款有什么特殊注意事项？**
A. 中国个人外汇年收入限额为5万美元，收款人需持有实名认证的银行账户。人民币兑换须符合中国外汇管理规定。

## 在韩生活实用信息

### 国民健康保险加入

完成外国人登录后，持长期居住签证的外国人须加入国民健康保险（건강보험）。可覆盖大部分医疗费用，强烈建议尽早办理。

### 银行开户

持有效外国人登录证，可在韩国各大银行（KB国民、新韩、友利、IBK企业银行等）开立账户，方便日常金融业务及薪资接收。

### 交通卡（T-Money）

外国人可使用T-Money交通卡乘坐首尔市内地铁、公交，也可在便利店购物使用，是在韩生活必备的支付工具。

### 韩语学习资源

在韩长期生活建议学习基础韩语。다문화가족지원센터（多文化家庭支援中心）和사회통합프로그램（KIIP，社会融合计划）提供免费或低价韩语课程。
