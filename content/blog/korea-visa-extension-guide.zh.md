# 韩国签证（在留期限）延期申请方法完整指南（2026年）

在韩国，如果在允许在留期限届满前未能取得在留期限延长许可，将成为非法逗留者。在留期限延期是在维持现有在留资格的同时，合法延长在韩居留时间的核心程序。本指南按签证类别详细介绍延期方法、所需材料、申请时机及注意事项。

## 1. 在留期限延期是什么？

在留期限延期是指在维持现有在留资格（签证类型）不变的情况下，延长在韩国的许可在留期限的程序。

- 必须在许可在留期限届满前申请
- 获批后可以相同在留资格继续在韩居留
- 如需变更签证类型，须办理"在留资格变更"而非延期

---

## 2. 申请时机

| 情况 | 建议申请时机 |
|---|---|
| 一般在留资格 | 期限届满前4周~1个月 |
| 需要准备复杂材料时 | 建议提前2个月准备 |
| 最晚期限 | 在留期限届满前一天 |

> **重要**：在留期限届满后无法提交延期申请，请务必在期限内申请。

---

## 3. 申请地点及方式

### 线下申请

| 申请地点 | 适用对象 |
|---|---|
| 居住地管辖出入境·外国人厅（事务所） | 全国外国人（原则上） |
| 首尔出入境·外国人厅 | 首尔居住者 |
| 仁川机场出入境·外国人厅 | 仁川机场区域 |

### 线上申请

| 方式 | 内容 |
|---|---|
| HiKorea | 部分在留资格可在线申请延期（hikorea.go.kr） |
| 电子民愿系统 | 可提前提交材料及预约 |

## 4. 各签证类型延期要求

| 在留资格 | 主要延期要求 |
|---|---|
| D-2（留学） | 在籍证明·成绩证明，确认持续在校 |
| D-4（语言研修） | 注册确认书，出勤率达标 |
| E-7（特定活动） | 维持雇用合同、营业执照、纳税记录 |
| E-9（非专业就业） | 雇用许可书续签，雇主确认 |
| F-2（居住） | 收入·纳税记录，满足F-2维持条件 |
| F-6（结婚移民） | 婚姻关系持续，配偶保证确认 |
| F-4（海外韩国人） | 确认海外韩国人资格持续有效 |
| F-5（永久居留） | 部分F-5持有人需定期确认 |
| C-3（短期访问） | 原则上不可延期（特殊情况可例外） |

## 5. 共同所需材料

| 材料 | 备注 |
|---|---|
| 在留期限延长许可申请书 | 出入境·外国人厅或HiKorea格式 |
| 护照原件 | 确认有效期 |
| 外国人登记证 | 已登记者提供 |
| 各在留资格附加材料 | 见下文 |
| 手续费缴纳 | 对应在留资格手续费 |

### 各在留资格主要附加材料

| 在留资格 | 附加材料 |
|---|---|
| 留学·语言研修（D-2/D-4） | 在籍证明、学费缴纳收据 |
| 就业（E系列） | 雇用合同、在职证明、营业执照 |
| 结婚移民（F-6） | 婚姻关系证明书、家庭关系证明书 |
| 随行（F-3） | 主在留资格者的在留资格维持确认材料 |
| 居住（F-2） | 收入证明、纳税事实证明 |

## 6. 延期申请流程

1. **准备材料** — 提前准备对应在留资格的所有材料
2. **前往出入境·外国人厅（建议预约）** — 通过HiKorea提前预约
3. **填写并提交申请书** — 窗口提交或线上提交
4. **缴纳手续费** — 缴纳对应在留资格手续费
5. **等待审查** — 即时办理或数日内办理
6. **确认延期许可** — 护照盖章或外国人登记证更新

---

## 7. 审查期限及费用

| 项目 | 内容 |
|---|---|
| 即时办理 | 简单延期案件可当天办理 |
| 材料审查 | 复杂案件需数日至数周 |
| 手续费 | 因在留资格而异（通常6万~10万韩元左右） |

> 手续费因在留资格和延期期限而有所不同，前往出入境·外国人厅前请确认最新费用。

---

## 8. 延期被拒及超期逗留注意事项

| 情况 | 内容 |
|---|---|
| 延期被拒时 | 考虑自愿出境或申请异议 |
| 非法逗留时 | 强制出境·入境禁止处分 |
| 未申请超期居留 | 超期第1天起即为罚款对象 |

> 在留期限届满后继续在韩居留属于"非法逗留"，可能面临强制出境和最长10年入境禁止处分。

---

## 9. 在留资格变更与在留期限延期的区别

| | 在留期限延期 | 在留资格变更 |
|--|--|--|
| 目的 | 维持现有签证并延长在留 | 变更签证类型本身 |
| 示例 | E-7满3年→再延3年 | D-2留学→E-7就业 |
| 程序复杂度 | 相对简单 | 更复杂，审查更严格 |
| 材料 | 证明维持现有资格的材料 | 新资格要求的材料 |

## 10. 常见问题解答

**Q. 可以在在留期限届满当天申请延期吗？**
A. 不建议。建议至少在届满前2周~1个月提交申请。届满当天办理可能存在困难，当天申请后如在审查期间届满，可能引发问题。

**Q. 可以通过HiKorea（hikorea.go.kr）在线申请延期吗？**
A. 部分在留资格可在hikorea.go.kr在线申请延期，但并非所有在留资格均可在线办理，请提前确认。

**Q. 申请审查期间在留期限届满怎么办？**
A. 在届满前提交申请的，在审查结果出来之前被视为合法在留。但须随时携带申请受理确认书作为证明。

**Q. 护照快到期了，还能申请延期吗？**
A. 如护照有效期较短，延期许可期限可能被限制在护照有效期内。建议先更换护照后再申请延期。

**Q. 延期手续费是多少？**
A. 因在留资格和延期期限而异，一般在6万~10万韩元左右。请在法务部出入境·外国人政策本部官方网站确认最新费用。
